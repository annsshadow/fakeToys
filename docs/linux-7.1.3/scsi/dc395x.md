
## dc395x SCSI 驱动


### 状态


该驱动已使用 CD-R 与 CD-R/W 驱动器进行测试，使用这些设备应当是安全的。针对硬盘的测试
尚未深入进行，如果你想尝试将该驱动用于硬盘，应谨慎行事。

该驱动由 `最初的 2.4 驱动
<https://web.archive.org/web/20140129181343/http://www.garloff.de/kurt/linux/dc395/>`_
演化而来。问题、疑问与补丁应提交到 `Linux SCSI 邮件列表 <linux-scsi@vger.kernel.org>`_。

### 参数


驱动使用 SCSI BIOS 设置中 EEPROM 里的配置。如果没有 EEPROM，则驱动使用默认值。
两者都可以通过命令行参数（模块或内核参数）覆盖。

可用参数如下：

safe
   默认值：0，可取的值：0 或 1

   若 safe 设为 1，则适配器将使用保守的（“safe”）默认设置。这相当于：

		dc395x=7,4,9,15,2,10 的简写

adapter_id
   默认值：7，可取的值：0 到 15

   设置主机适配器（host adapter）的 SCSI ID。

max_speed
   默认值：1，可取的值：0 到 7

   ==  ========
   0   20   Mhz
   1   12.2 Mhz
   2   10   Mhz
   3   8    Mhz
   4   6.7  Mhz
   5   5.8  Hhz
   6   5    Mhz
   7   4    Mhz
   ==  ========

dev_mode
   设备配置的位图

   DevMode 位定义：

      === ======== ========  =========================================
      Bit Val(hex) Val(dec)  含义
      === ======== ========  =========================================
       0    0x01       1     奇偶校验（Parity check）
       1    0x02       2     同步协商（Synchronous Negotiation）
       2    0x04       4     断开连接（Disconnection）
       3    0x08       8     启动时发送 Start 命令。（未使用）
       4    0x10      16     标记命令队列（Tagged Command Queueing）
       5    0x20      32     宽协商（Wide Negotiation）
      === ======== ========  =========================================

adapter_mode
   适配器配置的位图

   AdaptMode 位定义

    ===== ======== ========  ====================================================
      Bit Val(hex) Val(dec)  含义
    ===== ======== ========  ====================================================
       0    0x01       1     支持超过两个驱动器。（未使用）
       1    0x02       2     对大于 1GB 的 HD 使用 DOS 兼容映射。
       2    0x04       4     启动时复位 SCSI 总线。
       3    0x08       8     主动否定（Active Negation）：改善 SCSI 总线抗噪性。
       4    0x10      16     在 BIOS seek 命令时立即返回。（未使用）
    (*)5    0x20      32     检查 LUN >= 1。
    ===== ======== ========  ====================================================

tags
   默认值：3，可取的值：0-5

   若指定了 x，则标签数为 1<<x

reset_delay
   默认值：1，可取的值：0-180

   SCSI 复位后不接受命令的秒数


对于内建驱动，参数应加 `dc395x.` 前缀（例如 “dc395x.safe=1”）。
