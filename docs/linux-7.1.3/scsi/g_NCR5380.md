
## g_NCR5380 驱动


Copyright |copy| 1993 Drew Eckhard

NCR53c400 扩展 Copyright |copy| 1994,1995,1996 Kevin Lentin

本文档记录了 Kevin Lentin 实现的 NCR53c400 扩展，以及对 NCR5380 核心的若干
增强。

本驱动支持 NCR5380 与 NCR53c400 以及兼容卡，支持端口映射或内存映射模式。

如果板卡支持，建议使用中断，因为这样允许目标设备断开连接，从而提高 SCSI
总线利用率。

如果 irq 参数为 254 或完全省略，驱动将自动探测正确的 IRQ 线。如果 irq 参数
为 0 或 255，则不使用 IRQ。

NCR53c400 不支持 DMA，但它具备伪 DMA（Pseudo-DMA），驱动已对其提供支持。

本驱动会在 /proc/scsi/g_NCR5380/x 中提供它检测到的部分信息，其中 x 为
系统启动时检测到的 SCSI 卡编号。后续会有更多信息补充。

本驱动可作为模块使用。当以模块方式加载时，可以在 insmod/modprobe 命令行
上传递参数：

  ============= ===============================================================
  irq=xx[,...]	中断
  base=xx[,...]	端口或基地址（分别对应端口映射或内存映射）
  card=xx[,...]	卡类型：

		==  ======================================
		0   NCR5380，
		1   NCR53C400，
		2   NCR53C400A，
		3   Domex Technology Corp 3181E (DTC3181E)
		4   Hewlett Packard C2502
		==  ======================================
  ============= ===============================================================

这些旧式参数只能支持一张卡：

  ============= =================================================
  ncr_irq=xx   中断
  ncr_addr=xx  端口或基地址（分别对应端口映射或内存映射）
  ncr_5380=1   设置为 NCR5380 板卡
  ncr_53c400=1 设置为 NCR53C400 板卡
  ncr_53c400a=1 设置为 NCR53C400A 板卡
  dtc_3181e=1   设置为 Domex Technology Corp 3181E 板卡
  hp_c2502=1   设置为 Hewlett Packard C2502 板卡
  ============= =================================================

```

	modprobe g_NCR5380 irq=5 base=0x350 card=1

```
```

	modprobe g_NCR5380 ncr_irq=5 ncr_addr=0x350 ncr_53c400=1

```
```

	modprobe g_NCR5380 base=0x350 card=0

```
```

	modprobe g_NCR5380 ncr_addr=0x350 ncr_5380=1

```
```

	modprobe g_NCR5380 irq=255 base=0xc8000 card=1

```
```

	modprobe g_NCR5380 ncr_irq=255 ncr_addr=0xc8000 ncr_53c400=1

```
例如，两张卡，DTC3181（非 PnP 模式）位于 0x240，无 IRQ
```

	modprobe g_NCR5380 irq=0,7 base=0x240,0x300 card=3,4

```
