## ADIS16475 驱动

本文介绍 Linux IIO 子系统下 ADIS16475 系列 SPI 接口 IMU（惯性测量单元）驱动，涵盖所支持ADIS1646x/1647x/1650x 等型号、设备属性与 sysfs 接口。面向使用加速度陀螺仪进行运动感知的驱动开发者与硬件集成人员



本驱动支Analog Device 基于 SPI 总线IMU（惯性测量单元）

## 1. 支持的设


- `ADIS16465 <https://www.analog.com/ADIS16465>`_
- `ADIS16467 <https://www.analog.com/ADIS16467>`_
- `ADIS16470 <https://www.analog.com/ADIS16470>`_
- `ADIS16475 <https://www.analog.com/ADIS16475>`_
- `ADIS16477 <https://www.analog.com/ADIS16477>`_
- `ADIS16500 <https://www.analog.com/ADIS16500>`_
- `ADIS16505 <https://www.analog.com/ADIS16505>`_
- `ADIS16507 <https://www.analog.com/ADIS16507>`_

每个受支持的设备都是一个精密、微型的微机电系统（MEMS）惯性测量单元（IMU），包含三轴陀螺仪和三轴加速度计。IMU 设备中的每个惯性传感器都结合了信号调理，以优化动态性能。工厂校准对每个传感器的灵敏度、偏置、对齐、线性加速度（陀螺仪偏置）以及打击点（percussion point，加速度计位置）进行表征。结果，每个传感器都有动态补偿公式，能在广泛的条件范围内提供准确的传感器测量

## 2. 设备属


加速度计、陀螺仪测量总是被提供。此外，驱动还提供获取设备计算出的增量角度（delta angle）和增量速度（delta velocity）测量的能力

增量角度测量表示每次采样更新之间角位移的计算，而增量速度测量表示每次采样更新之间线速度变化的计算

最后，提供温度数据，显IMU 设备内部温度的粗略测量。这些数据对监测热环境中的相对变化最有用

每个惯性传感器（加速度计和陀螺仪）的信号链都包含应用独特的校正公式，这些公式源自对每ADIS 设备0°C +85°C 温度范围内对偏置、灵敏度、对齐、对线性加速度的响应（陀螺仪）以及打击点（加速度计位置）的广泛表征。这些校正公式不可访问，但用户确实有机会通过 calibbias 属性分别为每个传感器调整偏置

每个 IIO 设备，在 `/sys/bus/iio/devices/iio:deviceX` 下都有一个设备文件夹，其X 是该设备IIO 索引。这些文件夹下驻留着一组设备文件，取决于所讨论硬件设备的特性和功能。这些文件在 IIO ABI 文档中被一致地泛化并作了说明

### 通道的处理后值（processed values


可以从通道_raw 属性读取值。返回的值是设备报告的原始值。要获取该通道的处理后值，应用以下公式


        processed value = (_raw + _offset) * _scale

其中 _offset _scale 是设备属性。如果不存在 _offset 属性，就直接假定其值为 0

adis16475 驱动5 种类型的通道提供数据，下表显示了处理后值的测量单位，它们由 IIO 框架定义

+-------------------------------------+---------------------------+
| 通道类型                            | 测量单位                  |
+-------------------------------------+---------------------------+
| X、Y、Z 轴的加速度                  | 米每二次方秒             |
+-------------------------------------+---------------------------+
| X、Y、Z 轴的角速度                  | 弧度每秒                  |
+-------------------------------------+---------------------------+
| X、Y、Z 轴的增量速度                | 米每                   |
+-------------------------------------+---------------------------+
| X、Y、Z 轴的增量角度                | 弧度                      |
+-------------------------------------+---------------------------+
| 温度                                | 毫摄氏度                  |
+-------------------------------------+---------------------------+

### 使用示例


显示设备名称


	root:/sys/bus/iio/devices/iio:device0> cat name
        adis16505-2

显示加速度计通道值：


        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_raw
        -275924
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_y_raw
        -30142222
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_z_raw
        261265769
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_scale
        0.000000037

- X 杞村姞閫熷害 = in_accel_x_raw * in_accel_scale = 鈭?.010209188 m/s^2
- Y 杞村姞閫熷害 = in_accel_y_raw * in_accel_scale = 鈭?.115262214 m/s^2
- Z 轴加速度 = in_accel_z_raw * in_accel_scale = 9.666833453 m/s^2

显示陀螺仪通道值：


        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_x_raw
        -3324626
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_y_raw
        1336980
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_z_raw
        -602983
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_scale
        0.000000006

- X 轴角速度 = in_anglvel_x_raw * in_anglvel_scale = .019947756 rad/s
- Y 轴角速度 = in_anglvel_y_raw * in_anglvel_scale = 0.00802188 rad/s
- Z 轴角速度 = in_anglvel_z_raw * in_anglvel_scale = .003617898 rad/s

设置加速度计通道的校准偏移：


        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_calibbias
        0

        root:/sys/bus/iio/devices/iio:device0> echo 5000 > in_accel_x_calibbias
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_calibbias
        5000

设置陀螺仪通道的校准偏移：


        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_y_calibbias
        0

        root:/sys/bus/iio/devices/iio:device0> echo -5000 > in_anglvel_y_calibbias
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_y_calibbias
        -5000

设置采样频率


	root:/sys/bus/iio/devices/iio:device0> cat sampling_frequency
        2000.000000

        root:/sys/bus/iio/devices/iio:device0> echo 1000 > sampling_frequency
        1000.000000

设置加速度计和陀螺仪的带宽：


        root:/sys/bus/iio/devices/iio:device0> cat filter_low_pass_3db_frequency
        720

        root:/sys/bus/iio/devices/iio:device0> echo 360 > filter_low_pass_3db_frequency
        root:/sys/bus/iio/devices/iio:device0> cat filter_low_pass_3db_frequency
        360

显示序列号：


        root:/sys/kernel/debug/iio/iio:device0> cat serial_number
        0x04f9

显示产品 id


        root:/sys/kernel/debug/iio/iio:device0> cat product_id
        16505

显示闪存写入次数


        root:/sys/kernel/debug/iio/iio:device0> cat flash_count
        150

显示固件版本


        root:/sys/kernel/debug/iio/iio:device0> cat firmware_revision
        1.6

显示固件日期


        root:/sys/kernel/debug/iio/iio:device0> cat firmware_date
        06-27-2019

## 3. 设备缓冲区（Device buffers


本驱动支IIO 缓冲区

所有设备都支持使用缓冲区获取原始加速度、陀螺仪和温度测量

以下设备系列还支持使用缓冲区获取增量速度、增量角度和温度测量

- ADIS16477
- ADIS16500
- ADIS16505
- ADIS16507

不过，当使用缓冲区获取加速度或陀螺仪数据时，增量读数不可用，反之亦然

### 使用示例


current_trigger 中设置设备触发器（如果尚未设置）


        root:/sys/bus/iio/devices/iio:device0> cat trigger/current_trigger

        root:/sys/bus/iio/devices/iio:device0> echo adis16505-2-dev0 > trigger/current_trigger
        root:/sys/bus/iio/devices/iio:device0> cat trigger/current_trigger
        adis16505-2-dev0

为缓冲区读取选择通道


        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_deltavelocity_x_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_deltavelocity_y_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_deltavelocity_z_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_temp0_en

设置要存储在缓冲区中的样本数量：


        root:/sys/bus/iio/devices/iio:device0> echo 10 > buffer/length

启用缓冲区读取：


        root:/sys/bus/iio/devices/iio:device0> echo 1 > buffer/enable
