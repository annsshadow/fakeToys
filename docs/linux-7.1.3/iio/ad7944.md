
## AD7944 驱动


Analog Devices Inc. AD7944 及类似器件的 ADC 驱动。模块名`ad7944`

## 支持的设

该驱动支持以下芯片：

- `AD7944 <https://www.analog.com/AD7944>`_
- `AD7985 <https://www.analog.com/AD7985>`_
- `AD7986 <https://www.analog.com/AD7986>`_


## 支持的特

### SPI 接线模式


该驱动目前支持众多可SPI 接线配置中的三种
##### CS 模式 线，无忙指示




                                         +-------------+
                    +--------------------| CS          |
                    v                    |             |
    VIO   +--------------------+         |     HOST    |
     |    |        CNV         |         |             |
     +--->| SDI   AD7944   SDO |-------->| SDI         |
          |        SCK         |         |             |
          +--------------------+         |             |
                    ^                    |             |
                    +--------------------| SCLK        |
                                         +-------------+

要在设备树中选择此模式，请将 `adi,spi-mode` 属性设置为 `"single"` 并省`cnv-gpios`
属性
这是使用 `SPI offload support`_ 时唯一支持的接线配置
##### CS 模式 线，无忙指示




                                         +-------------+
     +-----------------------------------| CS          |
     |                                   |             |
     |              +--------------------| GPIO        |
     |              v                    |             |
     |    +--------------------+         |     HOST    |
     |    |        CNV         |         |             |
     +--->| SDI   AD7944   SDO |-------->| SDI         |
          |        SCK         |         |             |
          +--------------------+         |             |
                    ^                    |             |
                    +--------------------| SCLK        |
                                         +-------------+

要在设备树中选择此模式，请省`adi,spi-mode` 属性并提供 `cnv-gpios` 属性
##### 链模式，无忙指示




                                                                 +-------------+
                  +-------------------------+--------------------| CS          |
                  v                         v                    |             |
        +--------------------+    +--------------------+         |     HOST    |
        |        CNV         |    |        CNV         |         |             |
   +--->| SDI   AD7944   SDO |--->| SDI   AD7944   SDO |-------->| SDI         |
   |    |        SCK         |    |        SCK         |         |             |
  GND   +--------------------+    +--------------------+         |             |
                  ^                         ^                    |             |
                  +-------------------------+--------------------| SCLK        |
                                                                 +-------------+

要在设备树中选择此模式，请将 `adi,spi-mode` 属性设置为 `"chain"`，添`spi-cs-high`
标志，添`#daisy-chained-devices` 属性，并省`cnv-gpios` 属性
### 参考电

支持全部 3 种可能的参考电压源
- 内部参- 外部 1.2V 参考与内部缓冲- 外部参
该源由设备树决定。如果存`ref-supply`，则使用外部参考。如果存`refin-supply`则使用内部缓冲器。如果两者都不存在，则使用内部参考
### 未实现的特

- `BUSY` 指示


## 设备属

这个系列中有两种类型ADC：伪差分和全差分。通道名称根据 ADC 的类型而不同
### 伪差ADC


AD7944 AD7985 是伪差分 ADC，具有以下属性：

+---------------------------------------+--------------------------------------------------------------+
| Attribute                             | Description                                                  |
+=======================================+==============================================================+
| `in_voltage0_raw`                   | Raw ADC voltage value (**IN+** referenced to ground sense).    |
+---------------------------------------+--------------------------------------------------------------+
| `in_voltage0_scale`                 | Scale factor to convert raw value to mV.                     |
+---------------------------------------+--------------------------------------------------------------+

模式下，额外的芯片将作为额外的电压输入通道出现，例`in_voltage1_raw`
### 全差ADC


AD7986 是全差分 ADC，具有以下属性：

+---------------------------------------+--------------------------------------------------------------+
| Attribute                             | Description                                                  |
+=======================================+==============================================================+
| `in_voltage0-voltage1_raw`          | Raw ADC voltage value (**IN+** - **IN-**).                       |
+---------------------------------------+--------------------------------------------------------------+
| `in_voltage0-voltage1_scale`        | Scale factor to convert raw value to mV.                     |
+---------------------------------------+--------------------------------------------------------------+

模式下，额外的芯片将作为额外的电压输入通道出现，例`in_voltage2-voltage3_raw`
## SPI offload 支持


为了达到最大采样率，该驱动可以`AXI SPI Engine`_ 配合使用以提SPI offload 支持

当使SPI offload 时，某些属性会不同
- `trigger` 目录被移除- 添加`in_voltage0_sampling_frequency` 属性用于设置采样率- 添加`in_voltage0_sampling_frequency_available` 属性用于查询最大采样率- `timestamp` 通道被移除- 缓冲数据格式可能与未使用 offload 时不同，例如 `in_voltage0_type` 属性
如果设备树中存在 `turbo-gpios` 属性，驱动将在缓冲读取期间打开 TURBO，否则关闭它
## 设备缓冲


该驱动支IIO 触发缓冲
更多信息请参[iio_devbuf](iio_devbuf)
