
## AD7625 驱动


Analog Devices Inc. AD7625、AD7626、AD7960 AD7961 设备ADC 驱动。模块名`ad7625`

## 支持的设


该驱动支持以下芯片：

- `AD7625 <https://www.analog.com/AD7625>`_
- `AD7626 <https://www.analog.com/AD7626>`_
- `AD7960 <https://www.analog.com/AD7960>`_
- `AD7961 <https://www.analog.com/AD7961>`_

该驱动需要使Pulsar LVDS HDL 项目

- `Pulsar LVDS HDL <http://analogdevicesinc.github.io/hdl/projects/pulsar_lvds/index.html>`_

要触发转换并启用随后的数据传输，设备需要带相位偏移的耦合 PWM 信号

## 支持的特


### 转换控制模式


该驱动目前支持两种可LVDS 转换控制方法之一

##### Echoed-Clock 接口模式



                                                +----------------+
                     +xxxxxxxxxxxxxxxxxxxxxxxxxx| CNV            |
                     X                          |                |
                     v                          |    HOST        |
          +----------------------------+        |                |
          |      CNV+/CNV-   DCO+/DCO- |xxxxxxx>| CLK_IN         |
          |                            |        |                |
          |                            |        |                |
          |       AD7625         D+/D- |xxxxxxx>| DATA_IN        |
          |                            |        |                |
          |                            |        |                |
          |                  CLK+/CLK- |<xxxxxxx| CLK & CLK_GATE |
          +----------------------------+        |                |
                                                +----------------+

### 参考电


支持三种可能的参考电压源

- 内部参考（AD7625 AD7626 可用
- 外部参考与内部缓冲
- 外部参

源由设备树决定。如果存`ref-supply`，则使用外部参考。如果存`refin-supply`，则使用内部缓冲。如果两者都不存在，则使用内部参考

### 未实现的特


- 自时钟模


## 设备属


AD762x 是一款全差分 ADC，具有以下属性：

+---------------------------------------+--------------------------------------------------------------+
| 属                                 | 描述                                                         |
+=======================================+==============================================================+
| `scale`                             | 将缓冲读取的原始值转换为 mV 的比例因子                    |
+---------------------------------------+--------------------------------------------------------------+
