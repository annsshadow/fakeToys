
## AD4062 驱动


Analog Devices Inc. AD4060/AD4062 器件的 ADC 驱动。模块名为 `ad4062`。

## 支持的设备


本驱动支持以下芯片：

- `AD4060 <https://www.analog.com/AD4060>`_
- `AD4062 <https://www.analog.com/AD4062>`_

## 接线模式


该 ADC 通过 I3C 总线接口，并包含两个可编程 GPIO。

ADC 转换启动发生在读命令末尾的 I3C stop（P）位的 SDA 上升沿。

这两个可编程 GPIO 是可选的，如果存在则会通过 devicetree 的 `interrupt-names` 属性
分配一个角色：

- GP0：被分配为 Threshold Either（阈值双边）信号的角色。
- GP1：被分配为 Data Ready（数据就绪）信号的角色。

如果 devicetree 中存在 `gpio-controller` 属性，那么未出现在 `interrupt-names` 中
的 GPO 会作为 GPO 暴露出来。

## 设备属性


该 ADC 仅包含一个通道，具有以下属性：

   :header-rows: 1

   - - Attribute
     - Description
   - - `in_voltage_calibscale`
     - 设置硬件施加到采样值上的增益缩放因子，以补偿系统增益误差。
   - - `in_voltage_oversampling_ratio`
     - 将设备的突发平均模式设置为使用内部采样率进行过采样。值 1 禁用突发平均模式。
   - - `in_voltage_oversampling_ratio_available`
     - 可用过采样值的列表。
   - - `in_voltage_raw`
     - 返回原始 ADC 电压值。
   - - `in_voltage_scale`
     - 返回通道相对参考电压的缩放比例 `ref-supply`，如果前者不存在则为
       `vdd-supply`。

还包含以下设备属性：

   :header-rows: 1

   - - Attribute
     - Description
   - - `sampling_frequency`
     - 设置单次扫描的持续时间，用于突发平均模式。持续时间由
       `(n_avg - 1) / fosc + tconv` 描述，其中 `n_avg` 是过采样比例，`fosc` 是
       内部采样率，`tconv` 是 ADC 转换时间。
   - - `sampling_frequency_available`
     - 列出可用的采样频率，基于当前的过采样比例计算。如果比例为 1，则频率为
       `1/tconv`。

## 中断


中断通过 `interrupt-names` 和 `interrupts` 属性进行映射。

`interrupt-names` 中的 `gp0` 项设置 Threshold（阈值）信号的角色，`gp1` 项设置 Data
Ready（数据就绪）信号的角色。

如果各自不存在，驱动会回退到启用与 I3C IBI 相同的角色。

## 低功耗模式


设备在空闲时进入低功耗模式以节省功耗。启用事件会使设备退出低功耗模式，因为 ADC 会
自主采样以断言事件条件。

## IIO 触发器支持


驱动注册了一个 IIO 触发器 `ad4062-devX`，供同一设备使用，以将采样值捕获到软件缓冲
区。在启用并读取缓冲区之前，必须通过设置 `current_trigger` 将触发器附加到设备。

采集是顺序进行的，受协议时序、软件延迟和内部时序的约束，采样率不可配置。突发平均
模式确实会影响有效采样率，因为它增加了输出单个采样所需的内部时序。

## 阈值事件


ADC 支持一种监控模式以触发阈值事件。驱动支持一个同时用于上升和下降读数的单一
中断。

该功能通过设置 `thresh_either_en` 来启用/禁用。在监控模式下，设备持续运行在自主
模式。任何寄存器访问都会使设备回到配置模式，因此任何访问都会禁用监控模式。

提供了以下事件属性：

   :header-rows: 1

   - - Attribute
     - Description
   - - `sampling_frequency`
     - 监控模式下使用的频率，在模式激活时设置设备内部采样率。
   - - `sampling_frequency_available`
     - 可用采样率的列表。
   - - `thresh_either_en`
     - 启用监控模式。
   - - `thresh_falling_hysteresis`
     - 设置最小阈值的滞回值。
   - - `thresh_falling_value`
     - 设置最小阈值。
   - - `thresh_rising_hysteresis`
     - 设置最大阈值的滞回值。
   - - `thresh_rising_value`
     - 设置最大阈值。

## GPO 控制器支持


该设备支持将 GP0 和 GP1 用作 GPO。如果 devicetree 包含节点 `gpio-controller`，则
该设备被标记为 GPIO 控制器，并且未列在 `interrupt-names` 中的 GP 会作为 GPO 暴露
出来。GPIO 索引与引脚名称相匹配，因此如果 GP0 未暴露但 GP1 暴露，则索引 0 被屏蔽，
只能设置索引 1。
