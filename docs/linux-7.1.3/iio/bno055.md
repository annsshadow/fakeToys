
## BNO055 驱动


## 1. 概述


该驱动支持 Bosch BNO055 IMU（同时支持串口和 I2C 总线）。

加速度计、磁力计和陀螺仪的测量值始终可用。当 "fusion_enable" sysfs 属性设为 1 时，还会提供方向（包括欧拉角和四元数）、线速度和重力矢量，但部分传感器设置（例如低通滤波和量程）会被锁定（由 IMU 固件控制）。

该驱动也支持 IIO 缓冲区。

## 2. 校准


只有当 IMU 运行在融合模式时，才会持续执行自动校准过程。不过可以通过将 sysfs 属性 in_magn_calibration_fast_enable 写入 0 来禁用磁力计自动校准。

该驱动可访问自动校准标志（即你可以判断 IMU 是否已成功自动校准）以及校准数据块。

用户可以将该数据块保存到固件文件中（即在 /lib/firmware 下），驱动在探测时会查找该文件。如果找到，则用此校准数据初始化 IMU。这样用户就不必每次都执行校准流程（校准需要以各种方式移动 IMU）。

驱动会使用两个不同的文件名查找校准数据文件：首先查找名称后缀为 IMU 唯一 ID（在 sysfs 中作为 serial_number 暴露）的文件；这在存在多个 IMU 实例时很有用。如果找不到该文件，则查找"通用"校准文件（当只有一个 IMU 时可以使用，无需为随设备变化的复杂名称而烦恼）。

有效的校准文件名例如：
 bno055-caldata-0e7c26a33541515120204a35342b04ff.dat
 bno055-caldata.dat

在非融合模式下，IIO 的 'offset' 属性提供对校准数据偏移量（如果有）的访问，以便用户可将其应用到 accel、angvel 和 magn 等 IIO 属性上。在融合模式下则不需要它们（IMU 固件在内部应用了这些修正），读取时返回零。
