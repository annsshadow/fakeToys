### Wiring connections


AD4000 系列器件可通过几种不同的模式连接到 SPI 主机控制器

##### CS mode, 3-wire turbo mode


数据手册中的"三线"模式最接近标准 SPI 连接，对于这些器件而言，就是将控制器的 CS 信号线连接到器件CNV 引脚，其SPI 信号线按常规方式连接。该配置在数据手册中被（容易令人误解地）称为"CS 模式，三Turbo 模式"连接
注意：AD4000 系列数据手册三线"模式的定义与标准 spi-3wire 模式并不相同
这是唯一允许访问配置寄存器的连接模式，但要求 SPI 控制器支`SPI_MOSI_IDLE_HIGH` 特性

在设备树中省`adi,sdi-pin` 属性以选择此模式

```

                                         +-------------+
     + ----------------------------------| SDO         |
     |                                   |             |
     |               +-------------------| CS          |
     |               v                   |             |
     |    +--------------------+         |     HOST    |
     |    |        CNV         |         |             |
     +--->| SDI   AD4000   SDO |-------->| SDI         |
          |        SCK         |         |             |
          +--------------------+         |             |
                    ^                    |             |
                    +--------------------| SCLK        |
                                         +-------------+

```
##### CS mode, 3-wire, without busy indicator


另一种被支持三线"模式的接线配置将 SDI 引脚硬连线到数字输入/输出接口电源（VIO）。在此设置下，控制器无需支持 `SPI_MOSI_IDLE_HIGH`，但无法访问寄存器。此连接模式节省一根信号线，且可与任何 SPI 控制器配合工作

将设备树属`adi,sdi-pin` 设置`"high"` 以选择此模式

```

                                         +-------------+
                    +--------------------| CS          |
                    v                    |             |
    VIO   +--------------------+         |     HOST    |
     |    |        CNV         |         |             |
     +--->| SDI   AD4000   SDO |-------->| SDI         |
          |        SCK         |         |             |
          +--------------------+         |             |
                    ^                    |             |
                    +--------------------| SCLK        |
                                         +-------------+

```
此外，也可以GPIO 连接到器件的 CNV 引脚。这类似于前一种接线配置，但省去了 CS 信号线的使用

```

                                         +-------------+
                    +--------------------| GPIO        |
                    v                    |             |
    VIO   +--------------------+         |     HOST    |
     |    |        CNV         |         |             |
     +--->| SDI   AD4000   SDO |-------->| SDI         |
          |        SCK         |         |             |
          +--------------------+         |             |
                    ^                    |             |
                    +--------------------| SCLK        |
                                         +-------------+

```
##### CS mode, 4-wire without busy indicator


在数据手册的"四线"模式下，控制器的 CS 信号线连接到 ADC SDI 引脚，并将一GPIO 连接ADC CNV 引脚。此连接模式更适合多个 ADC 可共享同一 CNV 触发信号的场景

`adi,sdi-pin` 设置`"cs"` 以选择此模式


```

                                         +-------------+
     + ----------------------------------| CS          |
     |                                   |             |
     |               +-------------------| GPIO        |
     |               v                   |             |
     |    +--------------------+         |     HOST    |
     |    |        CNV         |         |             |
     +--->| SDI   AD4000   SDO |-------->| SDI         |
          |        SCK         |         |             |
          +--------------------+         |             |
                    ^                    |             |
                    +--------------------| SCLK        |
                                         +-------------+

```
## IIO Device characteristics


AD4000 系列驱动支持差分与伪差分 ADC

AD4000 系列器件提供的量程压缩（span compression）特性，可通过更改电压通道`_scale_available` 属性来启用或禁用。请注意，量程压缩配置需要写AD4000 配置寄存器，而这只有ADC 以三Turbo 模式接线、且 SPI 控制器支`SPI_MOSI_IDLE_HIGH` 时才可行。若不满足这些条件，则不会提`_scale_available` 属性

除此之外，差分与伪差分电压通道所提供sysfs 接口略有不同

### Pseudo-differential ADCs


伪差AD4000 系列器件的典型电压通道属性：

+-------------------------------------------+------------------------------------------+
| Voltage Channel Attributes                | Description                              |
+===========================================+==========================================+
| `in_voltage0_raw`                       | Raw ADC output code.                     |
+-------------------------------------------+------------------------------------------+
| `in_voltage0_offset`                    | Offset to convert raw value to mV.       |
+-------------------------------------------+------------------------------------------+
| `in_voltage0_scale`                     | Scale factor to convert raw value to mV. |
+-------------------------------------------+------------------------------------------+
| `in_voltage0_scale_available`           | Toggles input span compression           |
+-------------------------------------------+------------------------------------------+

### Differential ADCs


差分 AD4000 系列器件的典型电压通道属性：

+-------------------------------------------+------------------------------------------+
| Voltage Channel Attributes                | Description                              |
+===========================================+==========================================+
| `in_voltage0-voltage1_raw`              | Raw ADC output code.                     |
+-------------------------------------------+------------------------------------------+
| `in_voltage0-voltage1_scale`            | Scale factor to convert raw value to mV. |
+-------------------------------------------+------------------------------------------+
| `in_voltage0-voltage1_scale_available`  | Toggles input span compression           |
+-------------------------------------------+------------------------------------------+

### SPI offload support


为达到最大采样率，本驱动可配SPI 卸载引擎（例如通常集成`AXI SPI Engine`_ 中的引擎）使用，以提SPI 卸载支持


为匹SPI 卸载的传输速度，ADC 必须以三Turbo 模式或三线无忙指示模式连接，并将 SPI 控制器的 CS 信号线连接到 CNV 引脚

当配置为支持 SPI 卸载时，IIO 设备将提供不同的接口

- 提供 `in_voltage0_sampling_frequency` `in_voltage0-voltage1_sampling_frequency` 文件，用于设置采样率
- 不提IIO 触发设备（无 `trigger` 目录）
- 不提`timestamp` 通道

此外，由于当器件三线"模式接线、且使用 SPI 卸载时每次采样仅进行一次传输，ADC 输出会存在一个采样周期的延迟，因此缓冲区中的第一个数据样本无效，因为它包含的是更早一次转换的结果
