
## ADIS16550 驱动

本文件为 Linux IIO（工I/O）子系统ADIS16550 惯性测量单元（IMU）的设备驱动说明，介绍其支持的硬件、通过 sysfs 暴露的加速度计与陀螺仪等设备属性，供驱动使用者与内核开发者查阅

本驱动支Analog Devices 基于 SPI 总线IMU（惯性测量单元）
## 1. 支持的设
- `ADIS16550 <https://www.analog.com/ADIS16550>`_

ADIS16550 是一套完整的惯性系统，包含三轴陀螺仪和三轴加速度计。出厂校准对每个传感器的灵敏度、偏置和对准进行了标定。因此，每个传感器都拥有各自独立的动态补偿公式，从而提供精确的传感器测量值
## 2. 设备属
加速度计与陀螺仪的测量值始终提供。此外，该驱动还支持获取由设备计算得到的增量角度（delta angle）与增量速度（delta velocity）测量值
增量角度测量表示每次采样更新之间的角位移计算值，而增量速度测量表示每次采样更新之间的线速度变化计算值
最后，还提供温度数据，反映 IMU 器件内部温度的粗略测量值。该数据主要用于监测热环境的相对变化
每个 IIO 设备都在 `/sys/bus/iio/devices/iio:deviceX`（其X 为设备的 IIO 索引）下拥有一个设备文件夹。根据具体硬件设备的特性与功能，这些文件夹中存放着一组设备文件。这些文件在 IIO ABI 文档中有统一的说明

### 通道的处理后数
通道的数值可`_raw` 属性读取。返回值是设备上报的原始值。要获得该通道的处理后数值，请套用以下公式：

        processed value = (_raw + _offset) * _scale

其中 `_offset` `_scale` 均为设备属性。若不存`_offset` 属性，则直接假定其值为 0
adis16550 驱动提供 5 类通道的数据，下表展示了处理后数值的测量单位（由 IIO 框架定义）：

+--------------------------------------+---------------------------+
| Channel type                         | Measurement unit          |
+--------------------------------------+---------------------------+
| Acceleration on X, Y, and Z axis     | 米每二次方秒（m/s^2    |
+--------------------------------------+---------------------------+
| Angular velocity on X, Y and Z axis  | 弧度每秒（rad/s        |
+--------------------------------------+---------------------------+
| Delta velocity on X. Y, and Z axis   | 米每秒（m/s            |
+--------------------------------------+---------------------------+
| Delta angle on X, Y, and Z axis      | 弧度（rad              |
+--------------------------------------+---------------------------+
| Temperature                          | 毫摄氏度（m°C          |
+--------------------------------------+---------------------------+

### 使用示例

显示设备名称
        root:/sys/bus/iio/devices/iio:device0> cat name
        adis16550

显示加速度计通道数值：

        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_raw
        6903851
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_y_raw
        5650550
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_z_raw
        104873530
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_scale
        0.000000095

- X 轴加速度 = in_accel_x_raw * in_accel_scale = 0.655865845 m/s^2
- Y 轴加速度 = in_accel_y_raw * in_accel_scale = 0.53680225 m/s^2
- Z 轴加速度 = in_accel_z_raw * in_accel_scale = 9.96298535 m/s^2

显示陀螺仪通道数值：

        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_x_raw
        193309
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_y_raw
        -763676
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_z_raw
        -358108
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_scale
        0.000000003

- X 轴角速度 = in_anglvel_x_raw * in_anglvel_scale = 0.000579927 rad/s
- Y 轴角速度 = in_anglvel_y_raw * in_anglvel_scale = .002291028 rad/s
- Z 轴角速度 = in_anglvel_z_raw * in_anglvel_scale = .001074324 rad/s

设置加速度计通道的校准偏置：

        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_calibbias
        0

        root:/sys/bus/iio/devices/iio:device0> echo 5000 > in_accel_x_calibbias
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_calibbias
        5000

设置陀螺仪通道的校准偏置：

        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_y_calibbias
        0

        root:/sys/bus/iio/devices/iio:device0> echo -5000 > in_anglvel_y_calibbias
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_y_calibbias
        -5000

设置采样频率
        root:/sys/bus/iio/devices/iio:device0> cat sampling_frequency
        4000.000000

        root:/sys/bus/iio/devices/iio:device0> echo 1000 > sampling_frequency
        1000.000000

设置加速度计通道的带宽：

        root:/sys/bus/iio/devices/iio:device0> cat in_accel_filter_low_pass_3db_frequency
        0

        root:/sys/bus/iio/devices/iio:device0> echo 100 > in_accel_filter_low_pass_3db_frequency
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_filter_low_pass_3db_frequency
        100

显示序列号：

        root:/sys/kernel/debug/iio/iio:device0> cat serial_number
        0x000000b6

显示产品 ID
        root:/sys/kernel/debug/iio/iio:device0> cat product_id
        16550

显示闪存写入次数
        root:/sys/kernel/debug/iio/iio:device0> cat flash_count
        13

显示固件版本
        root:/sys/kernel/debug/iio/iio:device0> cat firmware_revision
        1.5

显示固件日期
        root:/sys/kernel/debug/iio/iio:device0> cat firmware_date
        28-04-2021

## 3. 设备缓冲
本驱动支IIO 缓冲区
该设备支持通过缓冲区获取原始加速度、陀螺仪、增量速度、增量角度以及温度测量值
不过，当通过缓冲区获取加速度或陀螺仪数据时，增量读数将不可用，反之亦然。这是因为该设备一次只能读取“加速度与陀螺仪数据”或“增量速度与增量角度数据”中的一组，而在这两种突发数据选择模式之间切换较为耗时
### 使用示例

current_trigger 中设置设备触发源（若尚未设置）：

        root:/sys/bus/iio/devices/iio:device0> cat trigger/current_trigger

        root:/sys/bus/iio/devices/iio:device0> echo adis16550-dev0 > trigger/current_trigger
        root:/sys/bus/iio/devices/iio:device0> cat trigger/current_trigger
        adis16550-dev0

为缓冲区读取选择通道
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_deltavelocity_x_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_deltavelocity_y_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_deltavelocity_z_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_temp0_en

设置缓冲区中存储的采样数量：

        root:/sys/bus/iio/devices/iio:device0> echo 10 > buffer/length

启用缓冲区读取：

        root:/sys/bus/iio/devices/iio:device0> echo 1 > buffer/enable
