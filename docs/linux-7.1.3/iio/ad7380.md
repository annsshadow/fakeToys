## 支持的特

### SPI 接线模式


ad738x ADC 可以在多SDO 线上/2/4）输出数据。驱动当前仅支持 1 SDO 线
### 参考电

#### ad7380-4


ad7380-4 仅支持外部参考电压（2.5V 3.3V）。必须在设备树中声明`refin-supply`
#### ad7389-4


ad7389-4 仅支持内部参考电压。在这种情况下，`refin-supply` `refio-supply` 属性都会被省略
#### ADAQ 器件


ADAQ 器件没有外部参考，但使用来自其某个电源（`refin-supply`）的 3.3V 内部参考
#### ad738x 系列中的其他所有器

ad738x 中的其他所有器件支2 种可能的参考电压来源：

- 内部参考（2.5V- 外部参考（2.5V 3.3V
来源由设备树决定。如`refio-supply` 存在，则用作外部参考，否则使用内部参考
### 过采样与分辨率提

该系列支2 种过采样类型：普通平均和滚动平均。驱动仅支持普通平均，因为滚动平均可以通过处理已捕获的数据缓冲区来实现。可用的倍率为：1（禁用过采样2/4/8/16/32
当启用片上过采样功能时，ADC 的性能可超过默认分辨率。为了适配可实现的性能提升，可以启用额外的两位分辨率。由于分辨率提升功能只能在启用过采样时启用，而如果没有分辨率提升，过采样的作用也不大，因此驱动仅在启用过采样时（当且仅当）自动启用分辨率提升
由于分辨率提升功能会16 位芯片现在具18 位数据，这意味着 storagebits 必须16 位改32 位，我们使用新的 ext_scan_type 特性以允许在运行时更改 scan_type。遗憾的libiio 并不支持它。因此在启用或禁用过采样时，用户必须使用以下命令重启 iiod

	root:~# systemctl restart iiod

### 报警（Alert

ad738x 系列的双通道变体在配置为 1 SDO 线模式时，可以将 SDOB 线用作报警引脚。四通道变体在配置为 1 2 SDO 线模式时，可以将 SDOD 用作报警引脚，不过驱动当前仅支持 1 SDO 线模式（参见 `SPI wiring modes`_）
在一次转换结束时，如果转换结果超过报警上限或低于报警下限，则低电平有效的报警引脚会被置位。它CS 的下降沿被清除。报警引脚对所有通道是共用的
用户可以使用常规iio 事件属性启用报警：


	events/thresh_either_en

上限和下限阈值对所有通道是共用的，也可以使用常规iio 事件属性设置：


	events/in_thresh_falling_value
	events/in_thresh_rising_value

如果 debugfs 可用，用户可以读ALERT 寄存器以确定出错的通道和方向
在大多数用例中，用户会将报警引脚硬连线以触发关机
### 通道选择与序列器（仅限单端芯片）


该系列的单端芯片（ad7386/7/8(-4)）在每个 ADC 前端都有一2:1 多路复用器。它们还包含额外的配置寄存器，允许手动选择或自动切换（序列器模式）多路复用器输入
IIO 的角度来看，所有输入都会被导出，即 ad7386/7/8 导出 4 个通道，ad7386-4/7-4/8-4 导出 8 个通道
多路复用器的输入 `AinX0` 对应IIO 通道的前半部分（0-1 0-3），输入 `AinX1` 对应于后半部分（2-3 4-7）。AD7386/7/8 通道器件）示例：


	   IIO   | AD7386/7/8
	         |         +----------------------------
	         |         |     _____        ______
	         |         |    |     |      |      |
	voltage0 | AinA0 --|--->|     |      |      |
	         |         |    | mux |----->| ADCA |---
	voltage2 | AinA1 --|--->|     |      |      |
	         |         |    |_____|      |_____ |
	         |         |     _____        ______
	         |         |    |     |      |      |
	voltage1 | AinB0 --|--->|     |      |      |
	         |         |    | mux |----->| ADCB |---
	voltage3 | AinB1 --|--->|     |      |      |
	         |         |    |_____|      |______|
	         |         |
	         |         +----------------------------

当启用序列器模式时，有效采样率会减半
#### 增益（仅ADAQ 器件

ADAQ 器件在每ADC 前端有一个可通过引脚选择的增益。可以使`adi,gain-milli` 属性从设备树中选择合适的增益。引脚接线请参阅数据手册中的典型连接图部分

## SPI 卸载（offload）支

为了实现最大采样率，该驱动可以`AXI SPI Engine`_ 配合使用以提SPI 卸载支持

当使SPI 卸载时，某些属性会有所不同
- `trigger` 目录被移除- 新增 `in_voltage0_sampling_frequency` 属性用于设置采样率- 新增 `in_voltage0_sampling_frequency_available` 属性用于查询最大采样率- `timestamp` 通道被移除- 缓冲区数据格式可能与未使用卸载时不同，例`in_voltage0_type` 属性
