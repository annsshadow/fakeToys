
## ADE9000 驱动


本驱动支Analog Device ADE9000 电能测量 IC（位SPI 总线上）

## 1. 支持的设


- `ADE9000 <https://www.analog.com/media/en/technical-documentation/data-sheets/ADE9000.pdf>`_

ADE9000 是一款高精度、完全集成的多相电能与电能质量监测器件。卓越的模拟性能与数字信
处理（DSP）内核使其能够在宽动态范围内实现精确的电能监测。集成的高精度基准确保了在温
范围内的低漂移，包含可编程增益放大器（PGA）和模数转换器（ADC）在内的整个通道最大组
漂移小于 ±25 ppm/°C

## 2. 设备属


针对电压、电流、有功功率、无功功率、视在功率以及三相的功率因数，提供了功率与电能测量

每个 IIO 设备都在 `/sys/bus/iio/devices/iio:deviceX` 下拥有一个设备文件夹，其X 是该
设备IIO 索引。这些文件夹下根据所讨论硬件设备的特性和功能包含一组设备文件。这些文
经过了统一的泛化处理，并在 IIO ABI 文档中有详细说明

## 3. 校准与缩


ADE9000 提供了多级增益与偏移校正

**校准增益（每通道*
  在数字域为每个通道类型应用的精细校准增益
  通过 `calibscale` 属性（AIGAIN、AVGAIN、APGAIN 寄存器）控制

**校准偏移（每通道*
  由器件内部应用的硬件校准偏移

  - 功率测量：通过功率通道`calibbias` 属性（xWATTOS、xVAROS 寄存器）控制
  - RMS 测量：通过 RMS 通道`calibbias` 属性（IRMSOS、VRMSOS 寄存器）控制

  这些是芯片内部的校准，并非由用户空间施加的偏移

## 4. 事件属


ADE9000 提供了映射到 IIO 事件的各种中断。事件功能仅在相应的中断在设备树中连接时才可用

+---------------------------------------------+---------------------------+
| IIO Event Attribute                         | ADE9000 鏁版嵁鎵嬪唽瀵瑰簲椤?          |
+---------------------------------------------+---------------------------+
| in_voltage[0-2]_thresh_either_en            | 过零检测中断（ZXVx）            |
+---------------------------------------------+---------------------------+
| in_altvoltage[0-2]_rms_thresh_rising_en     | RMS 浪涌检测中断（SWELLx）      |
+---------------------------------------------+---------------------------+
| in_altvoltage[0-2]_rms_thresh_rising_value  | RMS 浪涌阈值（SWELL_LVL 寄存器） |
+---------------------------------------------+---------------------------+
| in_altvoltage[0-2]_rms_thresh_falling_en    | RMS 暂降/跌落检测中断（DIPx）     |
+---------------------------------------------+---------------------------+
| in_altvoltage[0-2]_rms_thresh_falling_value | RMS 暂降/跌落阈值（DIP_LVL 寄存器）|
+---------------------------------------------+---------------------------+
| in_current[0-2]_thresh_either_en            | 电流过零检测中断（ZXIx）          |
+---------------------------------------------+---------------------------+

事件方向

- `rising`：超过上限阈值（膨胀/涌浪检测）
- `falling`：低于下限阈值（凹陷/跌落检测）
- `either`：任意阈值越界（过零检测）
- `none`：超时或无方向事

**注意**：事件属性仅在相应的中断（irq0、irq1、dready）在设备树中指定时才可用。驱动可以在
没有中断的情况下工作，但功能会减弱

## 5. 设备缓冲


本驱动支持用于波形捕获的 IIO 缓冲区。缓冲区功能要求连接 dready 中断

该器件支持捕获用于电能质量分析的电流与电压波形。波形缓冲区可配置为从不同的通道组合捕获
数据

缓冲捕获支持的通道组合

- A 相：电压与电流（IA + VA
- B 相：电压与电流（IB + VB
- C 相：电压与电流（IC + VC
- 所有相：所有电压与电流通道
- 独立通道：IA、VA、IB、VB、IC、VC

### 使用示例


A 相启用波形捕获：


        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_current0_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_voltage0_en

设置缓冲区长度并启用


        root:/sys/bus/iio/devices/iio:device0> echo 100 > buffer/length
        root:/sys/bus/iio/devices/iio:device0> echo 1 > buffer/enable

## 6. 时钟输出


ADE9000 在使用外部晶时钟源时，可通过 CLKOUT 引脚提供时钟输出。通过指定设备树中
`#clock-cells = <0>` 来启用此功能。输出时钟将"clkout" 注册，并可被其他设备引用

## 7. 使用示例


显示设备名称


	root:/sys/bus/iio/devices/iio:device0> cat name
        ade9000

读取电压测量值：


        root:/sys/bus/iio/devices/iio:device0> cat in_voltage0_raw
        12345
        root:/sys/bus/iio/devices/iio:device0> cat in_voltage0_scale
        0.000030517

- A 鐩哥數鍘?= in_voltage0_raw * in_voltage0_scale = 0.3769 V

读取功率测量值：


        root:/sys/bus/iio/devices/iio:device0> cat in_power0_active_raw
        5678
        root:/sys/bus/iio/devices/iio:device0> cat in_power0_scale
        0.000244140

- A 鐩告湁鍔熷姛鐜?= in_power0_active_raw * in_power0_scale = 1.386 W

配置校准增益


        # Set current channel 0 calibration gain
        root:/sys/bus/iio/devices/iio:device0> echo 0x800000 > in_current0_calibscale
        # Set voltage channel 0 calibration gain
        root:/sys/bus/iio/devices/iio:device0> echo 0x7FFFFF > in_voltage0_calibscale

配置 RMS 电压事件阈值（需要中断）


        # Set RMS sag detection threshold
        root:/sys/bus/iio/devices/iio:device0> echo 180000 > events/in_altvoltage0_rms_thresh_falling_value
        # Enable RMS sag detection
        root:/sys/bus/iio/devices/iio:device0> echo 1 > events/in_altvoltage0_rms_thresh_falling_en

        # Set RMS swell detection threshold
        root:/sys/bus/iio/devices/iio:device0> echo 260000 > events/in_altvoltage0_rms_thresh_rising_value
        # Enable RMS swell detection
        root:/sys/bus/iio/devices/iio:device0> echo 1 > events/in_altvoltage0_rms_thresh_rising_en
