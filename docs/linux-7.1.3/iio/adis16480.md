
## ADIS16480 驱动

本文件为 Linux IIO 子系统下 ADIS16480 系列惯性测量单元（IMU）的驱动说明，介绍其支持的多种型号、通过 sysfs 暴露的陀螺仪/加速度磁力计等设备属性，供驱动使用者查阅


该驱动支Analog Device 基于 SPI 总线IMU（惯性测量单元）
## 1. 支持的设

- `ADIS16375 <https://www.analog.com/ADIS16375>`_
- `ADIS16480 <https://www.analog.com/ADIS16480>`_
- `ADIS16485 <https://www.analog.com/ADIS16485>`_
- `ADIS16486 <https://www.analog.com/ADIS16486>`_
- `ADIS16487 <https://www.analog.com/ADIS16487>`_
- `ADIS16488 <https://www.analog.com/ADIS16488>`_
- `ADIS16489 <https://www.analog.com/ADIS16489>`_
- `ADIS16490 <https://www.analog.com/ADIS16490>`_
- `ADIS16495 <https://www.analog.com/ADIS16495>`_
- `ADIS16497 <https://www.analog.com/ADIS16497>`_
- `ADIS16545 <https://www.analog.com/ADIS16545>`_
- `ADIS16547 <https://www.analog.com/ADIS16547>`_

每个受支持的设备都是一个完整的惯性系统，包含三轴陀螺仪和三轴加速度计。设备中的每个惯性传感器都结合了信号调理电路，以优化动态性能。出厂校准针对每个传感器的灵敏度、偏置和对齐特性进行了表征。因此，每个传感器都有自己的动态补偿公式，从而提供准确的传感器测量值
## 2. 设备属

加速度计和陀螺仪的测量值始终提供。此外，该驱动还支持获取设备计算出的增量角度（delta angle）和增量速度（delta velocity）测量值
增量角度测量表示每次采样更新之间的角位移计算，而增量速度测量表示每次采样更新之间的线速度变化计算
最后，还提供温度数据，它粗略地反映 IMU 设备内部的温度。这些数据最适用于监控热环境中的相对变化
ADIS16480 ADIS16488 还提供对气压数据和三轴磁力计测量值的访问
每个 IIO 设备都有一个设备文件夹，位`/sys/bus/iio/devices/iio:deviceX`，其X 是设备的 IIO 索引。这些文件夹中包含一组设备文件，具体取决于相关硬件设备的特性和功能。这些文件在 IIO ABI 文档中有统一的泛化说明和记录

### 通道处理后的

通道值可以从_raw 属性读取。返回的值是设备报告的原始值。要获得通道的处理后值，请应用以下公式：


        processed value = (_raw + _offset) * _scale

其中 _offset _scale 是设备属性。如果不存在 _offset 属性，则假定其值为 0
adis16480 驱动提供 7 种类型通道的数据，下表展示了处理后值的测量单位，这些单位由 IIO 框架定义
+--------------------------------------+---------------------------+
| 通道类型                             | 测量单位                  |
+--------------------------------------+---------------------------+
| X、Y、Z 轴加速度                     | 米每二次方秒              |
+--------------------------------------+---------------------------+
| X、Y、Z 轴角速度                     | 弧度每秒                  |
+--------------------------------------+---------------------------+
| X、Y、Z 轴增量速度                   | 米每                   |
+--------------------------------------+---------------------------+
| X、Y、Z 轴增量角                  | 弧度                      |
+--------------------------------------+---------------------------+
| 温度                                 | 毫摄氏度                  |
+--------------------------------------+---------------------------+
| X、Y、Z 轴磁                      | 高斯（Gauss           |
+--------------------------------------+---------------------------+
| 气压                                 | 千帕（kilo Pascal     |
+--------------------------------------+---------------------------+

### 使用示例


显示设备名称

	root:/sys/bus/iio/devices/iio:device0> cat name
        adis16545-1

显示加速度计通道值：


        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_raw
        1376728
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_y_raw
        4487621
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_z_raw
        262773792
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_scale
        0.000000037

- X 轴加速度 = in_accel_x_raw * in_accel_scale = 0.050938936 m/s^2
- Y 轴加速度 = in_accel_y_raw * in_accel_scale = 0.166041977 m/s^2
- Z 轴加速度 = in_accel_z_raw * in_accel_scale = 9.722630304 m/s^2

显示陀螺仪通道值：


        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_x_raw
        -1041702
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_y_raw
        -273013
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_z_raw
        2745116
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_scale
        0.000000001

- X 轴角速度 = in_anglvel_x_raw * in_anglvel_scale = .001041702 rad/s
- Y 轴角速度 = in_anglvel_y_raw * in_anglvel_scale = .000273013 rad/s
- Z 轴角速度 = in_anglvel_z_raw * in_anglvel_scale = 0.002745116 rad/s

设置加速度计通道的校准偏移：


        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_calibbias
        0

        root:/sys/bus/iio/devices/iio:device0> echo 5000 > in_accel_x_calibbias
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_calibbias
        5000

设置陀螺仪通道的校准偏移：


        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_y_calibbias
        0

        root:/sys/bus/iio/devices/iio:device0> echo -5000 > in_anglvel_y_calibbias
        root:/sys/bus/iio/devices/iio:device0> cat in_anglvel_y_calibbias
        -5000

设置采样频率

	root:/sys/bus/iio/devices/iio:device0> cat sampling_frequency
        4250.000000

        root:/sys/bus/iio/devices/iio:device0> echo 1000 > sampling_frequency
        1062.500000

设置加速度计通道的带宽：


        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_filter_low_pass_3db_frequency
        0

        root:/sys/bus/iio/devices/iio:device0> echo 300 > in_accel_x_filter_low_pass_3db_frequency
        root:/sys/bus/iio/devices/iio:device0> cat in_accel_x_filter_low_pass_3db_frequency
        300

显示序列号：


        root:/sys/kernel/debug/iio/iio:device0> cat serial_number
        0x000c

显示产品 ID

        root:/sys/kernel/debug/iio/iio:device0> cat product_id
        16545

显示闪存写入次数

        root:/sys/kernel/debug/iio/iio:device0> cat flash_count
        88

        root:/sys/kernel/debug/iio/iio:device0> cat firmware_date

## 3. 设备缓冲

该驱动支IIO 缓冲区
所有设备都支持通过缓冲区获取原始加速度、陀螺仪和温度测量值
以下设备系列还支持通过缓冲区获取增量速度、增量角度和温度测量值：

- ADIS16545
- ADIS16547

然而，当通过缓冲区获取加速度或陀螺仪数据时，增量读数将不可用，反之亦然。这是因为设备一次只允许读取加速度和陀螺仪数据，或者增量速度和增量角度数据，而在这两种突发数据选择模式之间切换非常耗时
### 使用示例


若尚未设置，current_trigger 中设置设备触发器

        root:/sys/bus/iio/devices/iio:device0> cat trigger/current_trigger

        root:/sys/bus/iio/devices/iio:device0> echo adis16545-1-dev0 > trigger/current_trigger
        root:/sys/bus/iio/devices/iio:device0> cat trigger/current_trigger
        adis16545-1-dev0

选择缓冲区读取的通道

        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_deltavelocity_x_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_deltavelocity_y_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_deltavelocity_z_en
        root:/sys/bus/iio/devices/iio:device0> echo 1 > scan_elements/in_temp0_en

设置缓冲区中存储的样本数量：


        root:/sys/bus/iio/devices/iio:device0> echo 10 > buffer/length

启用缓冲区读取：


        root:/sys/bus/iio/devices/iio:device0> echo 1 > buffer/enable
