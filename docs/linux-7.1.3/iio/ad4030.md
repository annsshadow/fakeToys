
## AD4030 驱动


Analog Devices 公司 AD4030 及类似器件的 ADC 驱动。模块名称为 `ad4030`。


## 支持的设备


本驱动支持以下芯片：

- `AD4030-24 <https://www.analog.com/AD4030-24>`_
- `AD4032-24 <https://www.analog.com/AD4032-24>`_
- `AD4630-16 <https://www.analog.com/AD4630-16>`_
- `AD4630-24 <https://www.analog.com/AD4630-24>`_
- `AD4632-16 <https://www.analog.com/AD4632-16>`_
- `AD4632-24 <https://www.analog.com/AD4632-24>`_

## IIO 通道


数据手册中描述的每个"硬件"通道被拆分为 2 个 IIO 通道：

- 一个用于差分数据的通道
- 一个用于公共字节的通道

根据"硬件"通道数量的不同，可能的 IIO 通道如下：

+------------------------------------+------------------------------------+
| 1 通道 ADC                      | 2 通道 ADC                     |
+====================================+====================================+
| - voltage0-voltage1 (differential) | - voltage0-voltage1 (differential) |
| - voltage2 (common-mode)           | - voltage2-voltage3 (differential) |
|                                    | - voltage4 (common-mode)           |
|                                    | - voltage5 (common-mode)           |
+------------------------------------+------------------------------------+

### 标签


为了便于使用，IIO 通道提供了一个标签。对于差分通道，标签为 `differentialN`，
其中 `N` 为"硬件"通道 id。对于共模通道，标签为 `common-modeN`，其中 `N`
为"硬件"通道 id。

可能的标签如下：

+-----------------+-----------------+
| 1 通道 ADC   | 2 通道 ADC  |
+=================+=================+
| - differential0 | - differential0 |
| - common-mode0  | - differential1 |
|                 | - common-mode0  |
|                 | - common-mode1  |
+-----------------+-----------------+

## 支持的特性


### SPI 接线模式


驱动当前支持以下 SPI 接线配置：

##### 单通道模式


在此模式下，每个通道都有自己的 SDO 线来发送转换结果。目前此模式只能用于
AD4030，它只有一个通道，因此只使用一条 SDO 线。


    +-------------+         +-------------+
    |     ADC     |         |     HOST    |
    |             |         |             |
    |         CNV |<--------| CNV         |
    |          CS |<--------| CS          |
    |         SDI |<--------| SDO         |
    |        SDO0 |-------->| SDI         |
    |        SCLK |<--------| SCLK        |
    +-------------+         +-------------+

##### 交织模式


在此模式下，两个通道的转换结果在一条 SDO 线上按位交织。因此接线与 `单通道模式`_ 相同。

##### SPI 卸载接线



    +-------------+         +-------------+
    |         CNV |<-----+--| GPIO        |
    |             |      +--| PWM0        |
    |             |         |             |
    |             |      +--| PWM1        |
    |             |      |  +-------------+
    |             |      +->| TRIGGER     |
    |          CS |<--------| CS          |
    |             |         |             |
    |     ADC     |         |     SPI     |
    |             |         |             |
    |         SDI |<--------| SDO         |
    |         SDO |-------->| SDI         |
    |        SCLK |<--------| SCLK        |
    +-------------+         +-------------+

在此模式下，`cnv-gpios` 和 `pwms` 属性都是必需的。`pwms` 属性指定连接到
ADC CNV 引脚的 PWM。SPI 卸载会有一个 `trigger-sources` 属性以指示 SPI
卸载（PWM）触发源。对于 AD4030 及类似的 ADC，样本 N 有两个可能的数据传输区。
其中之一（区域 1）在样本 N 的数据转换完成后开始，而另一个（区域 2）在样本
N + 1 的 CNV 上升沿之后 9.8 纳秒开始。

上图所示的配置旨在区域 2 中执行数据传输。为了在高采样率下同时满足 ADC 时序
要求，在 PWM0 和 PWM1 的上升沿之间加入一个偏移，将 SPI 传输延迟到 CNV 上升沿
之后 9.8 纳秒。这需要一个能够提供这种偏移的专用 PWM 控制器。`AD4630-FMC HDL 项目`_
例如，可以配置为在区域 2 数据读取窗口期间采样 AD4030 数据。


### SPI 时钟模式


仅支持 SPI 时钟模式。

### 输出模式


暴露的 IIO 通道多于数据手册中描述的通道。这是由于 `差分数据 + 共模`_ 编码
在单个转换结果中包含两类信息。因此一个"器件"通道提供 2 个 IIO 通道，一个用于
差分数据，一个用于公共字节。

##### 差分数据


此模式在以下情况被选择：

- 在缓冲读取中仅启用了差分通道
- Oversampling 属性设置为 1

##### 差分数据 + 共模


此模式在以下情况被选择：

- 在缓冲读取中启用了差分和共模通道
- Oversampling 属性设置为 1

对于 24 位芯片，此模式也提供 16 位差分数据，但尚不可选择。

##### 平均差分数据


此模式在以下情况被选择：

- 在缓冲读取中仅选择启用了差分通道
- Oversampling 属性大于 1

### 数字增益与偏移


每个差分数据通道都有一个应用于其上的 16 位无符号可配置硬件增益。默认值为 1。
注意应用增益可能导致数值饱和。

每个差分数据通道都有一个有符号可配置硬件偏移。对于以 `-24` 结尾的 ADC，增益
编码在 24 位上。类似地，以 `-16` 结尾的 ADC 增益编码在 16 位上。注意应用偏移
可能导致数值饱和。

ADC 返回的最终差分数据先应用增益，再应用偏移计算得出。

增益由 `calibscale` IIO 属性控制，而偏移由 `calibbias` 属性控制。

### 参考电压


芯片通过 `REF` 输入支持外部参考电压，或通过 `REFIN` 输入支持内部带缓冲的
参考电压。驱动查看设备树以确定正在使用哪一个。如果存在 `ref-supply`，则使用
外部参考电压并禁用内部缓冲。如果存在 `refin-supply`，则使用内部带缓冲的参考
电压。

### 复位


硬件和软件复位都受支持。驱动首先查看设备树，看 `reset-gpio` 是否已填充。
如果不存在，驱动将回退到通过写入设备寄存器进行软件复位。
