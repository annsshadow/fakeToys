RAID 4/5/6 缓存



Raid 4/5/6 除了正常RAID 磁盘外，还可以包含一个额外的磁盘用作数据缓存。缓存磁盘并不会改变 RAID 磁盘的作用。缓存磁盘缓存写RAID 磁盘的数据。该缓存可以处于写透（write-through，自 4.4 起支持）或写回（write-back，自 4.10 起支持）模式。mdadm（自 3.4 起支持）新增'--write-journal' 选项，用于创建带缓存的阵列。详情请参阅 mdadm 手册。默认情况下（RAID 阵列启动时），缓存处
```

	echo "write-back" > /sys/block/md0/md/journal_mode

```
```

	echo "write-through" > /sys/block/md0/md/journal_mode

```

在两种模式下，对阵列的所有写入都会先落到缓存磁盘上。这意味着缓存磁盘必须速度快且可持续


写透模



该模式主要修写洞"（write hole）问题。对RAID 4/5/6 阵列，一次不干净的关机可能导致某些条带中的数据处于不一致状态，例如数据与校验位不匹配。原因在于一次条带写入涉及多RAID 磁盘，而在不干净关机之前，写入可能尚未触及所RAID 磁盘。我们将存在不一致数据的阵列称为降级（degraded）。MD 会尝试重新同步阵列以使其恢复正常状态。但在重新同步完成之前，任何系统崩溃都会带来 RAID 阵列中真实数据损坏的风险。这个问题被称为"写洞"


写透缓存会先将所有数据缓存在缓存磁盘上。在数据安全地写入缓存磁盘后，数据才会被刷写RAID 磁盘上。这两步写入将保证即使阵列处于降级状态，MD 也能在不干净关机后恢复正确数据。因此该缓存可以填补"写洞"


在写透模式下，MD 会在数据安全地写RAID 磁盘后才向上层（通常是文件系统）报告 IO 完成，因此缓存磁盘故障不会导致数据丢失。当然，缓存磁盘故障意味着阵列再次暴露写洞"风险之中


在写透模式下，缓存磁盘不需要很大。几百兆字节就足够了


写回模式



写回模式同样修复"写洞"问题，因为所有写入数据都被缓存在缓存磁盘上。但"写回"缓存的主要目标是加速写入。如果一次写入跨越了一个条带的所RAID 磁盘，我们称之为整条带（full-stripe）写入。对于非整条带写入，MD 必须先读取旧数据才能计算出新的校验位。这些同步读取会损害写入吞吐。一些顺序写入但并未在同一时间派发的写入也会受此开销影响。写回缓存会聚合数据，并仅当数据成为整条带写入后才将其刷写到 RAID 磁盘。这将完全避免该开销，因此对某些工作负载非常有帮助。一个典型的例子就是先顺序写入再调用 fsync 的工作负载


在写回模式下，MD 会在数据落到缓存磁盘后立即向上层（通常是文件系统）报告 IO 完成。数据会在满足特定条件之后才被刷写到 RAID 磁盘。因此缓存磁盘故障会导致数据丢失


在写回模式下，MD 还会在内存中缓存数据。内存缓存包含与缓存磁盘上相同的存储数据，因此掉电不会导致数据丢失。内存缓存大小会对阵列性能产生影响。建
```

	echo "2048" > /sys/block/md0/md/stripe_cache_size

```

在此模式下，过小的缓存磁盘会使写入聚合效率降低（取决于工作负载）。建议在写回模式下使用至少数吉字节大小的缓存磁盘


实现



写透和写回缓存使用相同的磁盘格式。缓存磁盘被组织为一个简单的写入日志。该日志元数（meta data）和"数据"（data）对组成。元数据描述数据，还包含用于恢复识别的校验和与序ID。数据可以是 IO 数据和校验数据。数据也带有校验和。校验和存储在数据之前的元数据中。该校验和是一项优化，因为 MD 可以随意写入元数据和数据而无需担心顺序。MD 超级块中有一个字段指向日志头部的有效元数据


日志的实现相当直接。困难的部分在于 MD 向缓存磁盘和 RAID 磁盘写入数据的顺序。具体来说，在写透模式下，MD IO 数据计算校验位，IO 数据和校验位都写入日志，在数据和校验位已在日志中就绪后将数据和校验位写入 RAID 磁盘，最IO 完成。读取则像往常一样从 RAID 磁盘读取


在写回模式下，MD IO 数据写入日志并报IO 完成。此时数据也被完整缓存在内存中，这意味着读取必须查询内存缓存。如果满足某些条件，MD 会将数据刷写RAID 磁盘。MD 会为该数据计算校验位并将校验位写入日志。完成之后，MD 会将数据和校验位都写RAID 磁盘，然MD 可以释放内存缓存。刷写条件可能是：条带变为整条带写入、空闲缓存磁盘空间偏低，或空闲的内核内存缓存空间偏低


在不干净关机之后，MD 会进行恢复。MD 从日志中读取所有元数据和数据。序ID 和校验和将帮助我们检测损坏的元数据和数据。如MD 找到一个带有数据和有效校验位（raid4/5 1 个校验位，raid6 2 个）的条带，MD 会将数据和校验位写入 RAID 磁盘。如果校验位不完整，则将其丢弃。如果部分数据损坏，也将其丢弃。MD 随后以正常方式加载有效数据并将其写入 RAID 磁盘
