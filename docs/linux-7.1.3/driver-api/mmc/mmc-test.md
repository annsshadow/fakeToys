
## MMC 测试框架


## 概述


`mmc_test` 框架旨在测试主机控制器驱动以及 MMC 子系统所处理的所有设备的
性能与可靠性。这不仅包括 MMC 设备，也包括 SD 卡以及该子系统支持的其他设备。

该框架提供多种测试，用于评估主机控制器与设备交互的不同方面，例如读写性能、
数据完整性与错误处理。这些测试有助于确保主机控制器驱动与设备在各种条件下
都能正确工作。

`mmc_test` 框架在以下方面特别有用：

- 验证 MMC 与 SD 主机控制器驱动的功能与性能。
- 确保 MMC 与 SD 设备的兼容性与可靠性。
- 识别并诊断 MMC 子系统中的问题。

测试结果记录在内核日志中，提供关于测试结果与遇到的任何问题的详细信息。

注意：你的卡上的任何内容都会被这些测试覆盖。

## 初始化


要使用 `mmc_test` 框架，请遵循以下步骤：

1. **启用 MMC 测试框架**：

   确保 `CONFIG_MMC_TEST` 内核配置选项已启用。这可以通过配置内核来完成：

   .. code-block:: none

      make menuconfig

   导航至：

   Device Drivers  --->
     <*> MMC/SD/SDIO card support  --->
       [*]   MMC host test driver

   或者，你也可以直接在内核配置文件中启用它：

   .. code-block:: none

      echo "CONFIG_MMC_TEST=y" >> .config

   如有必要，重新编译并安装内核。

2. **加载 MMC 测试模块**：

   如果 `mmc_test` 框架被编译为模块，你需要使用 `modprobe` 加载它：

   .. code-block:: none

      modprobe mmc_test

## 为测试绑定 MMC 卡


要启用 MMC 测试，你需要将 MMC 卡从 `mmcblk` 驱动解绑，并将其绑定到 `mmc_test`
驱动。这样 `mmc_test` 框架就能接管该 MMC 卡以进行测试。

1. 识别 MMC 卡：

   .. code-block:: sh

      ls /sys/bus/mmc/devices/

   这会列出 MMC 设备，例如 `mmc0:0001`。

2. 将 MMC 卡从 `mmcblk` 驱动解绑：

   .. code-block:: sh

      echo 'mmc0:0001' > /sys/bus/mmc/drivers/mmcblk/unbind

3. 将 MMC 卡绑定到 `mmc_test` 驱动：

   .. code-block:: sh

      echo 'mmc0:0001' > /sys/bus/mmc/drivers/mmc_test/bind

绑定之后，你应当会在内核日志中看到一行表明该卡已被认领用于测试的提示：


   mmc_test mmc0:0001: Card claimed for testing.


## 用法 —— debugfs 条目


一旦启用了 `mmc_test` 框架，你就可以与位于 `/sys/kernel/debug/mmc0/mmc0:0001`
的以下 debugfs 条目交互：

1. **test**：

   该文件用于运行特定的测试。向该文件写入测试编号即可执行测试。

   .. code-block:: sh

      echo <test_number> > /sys/kernel/debug/mmc0/mmc0:0001/test

   测试结果反映在内核日志信息中。你可以使用 `dmesg` 命令查看内核日志，或检查
   `/var/log/` 下的日志文件。

   .. code-block:: sh

      dmesg | grep mmc0

   示例：

   要运行测试编号 4（带数据校验的基本读）：

   .. code-block:: sh

      echo 4 > /sys/kernel/debug/mmc0/mmc0:0001/test

   检查内核日志中的结果：

   .. code-block:: sh

      dmesg | grep mmc0

2. **testlist**：

   该文件列出所有可用的测试。你可以读取该文件以查看测试列表及其对应的编号。

   .. code-block:: sh

## 测试结果


测试结果记录在内核日志中。每个测试都会记录其开始、结束与结果。可能的结果有：

- **OK**：测试成功完成。
- **FAILED**：测试失败。
- **UNSUPPORTED (by host)**：主机不支持该测试。
- **UNSUPPORTED (by card)**：卡不支持该测试。
- **ERROR**：测试过程中发生错误。

## 内核日志输出示例


运行测试时，你会在内核日志中看到类似如下的日志条目：


   [ 1234.567890] mmc0: Starting tests of card mmc0:0001...
   [ 1234.567891] mmc0: Test case 4. 基本读操作 （带数据校验）...
   [ 1234.567892] mmc0: Result: OK
   [ 1234.567893] mmc0: Tests completed.

在此示例中，执行了测试用例 4（带数据校验的基本读），结果为 OK。
