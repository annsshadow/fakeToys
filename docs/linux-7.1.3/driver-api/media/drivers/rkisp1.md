
## Rockchip 图像信号处理器驱动（rkisp1

### 各版本及其差

rkisp1 模块在不SoC 实现间经历了一些变化。供应商将其指定为：

- V10：至少用rk3288 rk3399
- V11：在原始供应商代码中声明，但未使- V12：至少用rk3326 px30
- V13：至少用rk1808
- V20：用rk3568 及以
目前内核支持基于 V10 V12 变体rkisp1 实现。V11 似乎并未实际被使用，
V13 需要更多补充但尚未被研究，尤其是它似乎仅限于未广泛上市rk1808
另一方面，V20 很可能用于未来的 SoC，并且在供应商内核中经历了非常大的变化，
因此需要相当多的研究
### V10 V12 的变

- V12 支持新的 CSI 主机实现，但仍可使用来自 V10 的相同实- 镜头阴影校正模块的宽度从 12 位改13 - AWB AEC 模块被替换以支持更细粒度的数据采
### V12 V13 的变

V13 的列表不完整，需要进一步调查
- V13 不再支持旧的 CSI 主机实现
