
##### V4L2 通用 ISP 参数与统计信息支

## 设计理由


ISP 配置参数和统计信息由驱动处理并收集，并通过通常反映 ISP 外设寄存器布局的数据类型与用户空间交换
每个 ISP 驱动为其参数定义自己的元数据输出格式，并为统计信息定义元数据捕获格式。缓冲区布局由一组反映寄存器布局C 结构体实现。C 结构体的数量和类型由格式定义固定，并成为 Linux 内核 uAPI/uABI 接口的一部分
由于扩展用户 API/ABI 接口时向后兼容性的硬性要求，ISP 驱动被主线接受之后，修改其捕获或输出元数据格式即使不是不可能，也非常困难
事实上，通常ISP 驱动的第一个被接受的修订版本之后，缓冲区布局就需要被修改——无论是为了支持新的硬件模块、修bug，还是支持硬件的不同修订版本
上述每种情况都需要定义一种新的元数据格式，使得驱动难以维护和扩展，并需要用户空间根据所使用内核的修订版本使用正确的格式
## V4L2 ISP 配置参数


基于这些原因，Video4Linux2 ISP 配置参数和统计信息定义了通用类型。驱动仍应为其元数据输出和捕获节点定义自己的格式，但缓冲区布局可以使用 include/uapi/linux/media/v4l2-isp.h 中定义的可扩展、带版本的类型来定义
驱动应提供其支持ISP 模块的定义以及缓冲区的预期最大大小
对于驱动开发者，一组用于协助校验从用户空间接收到的缓冲区的辅助函数drivers/media/v4l2-core/v4l2-isp.c 中可用
