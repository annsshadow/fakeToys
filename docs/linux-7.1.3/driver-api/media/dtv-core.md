
### 数字电视（DVB）设

数字电视设备由若干不同的驱动实现
- 桥接驱动，负责与连接其他设备的总线（PCI、USB、SPI）通信，绑定到其他驱动
  并实现数字解复用逻辑（软件或硬件）；

- 前端驱动，通常实现为两个独立的驱动
  - 调谐器驱动，实现控制硬件中负责调谐到数字电视转发器或物理频道    那部分的逻辑。调谐器的输出通常是基带或中频（IF）信号；

  - 解调器驱动（即“demod”），实现控制数字电视解码硬件的逻辑。解调器的输    是数字流，通常多个音频、视频和数据通道使用 MPEG 传输[#f1]_ 复用
在大多数硬件上，前端驱动通过 I2C 总线与桥接驱动通信
