
## 驱动特定的回调函

`pldmfw` 模块依赖设备驱动，通过以下操作来实现设备特定的行为
### `.match_record`


`.match_record` 操作用于判断给定PLDM 记录是否与正在更新的设备相匹配。这需要将记录中的记录描述符与设备提供的信息进行比较。许多记录描述符PLDM 标准定义，但也允许设备实现自己的描述符
如果给定记录与设备匹配，`.match_record` 操作应返true
### `.send_package_data`


`.send_package_data` 操作用于将记录中的设备特定包数据发送给设备固件。如果匹配的记录提供了包数据，`pldmfw` 将调`.send_package_data` 函数，并传入指向包数据的指针以及包数据长度。设备驱动应将此数据发送给固件
### `.send_component_table`


`.send_component_table` 操作用于将组件信息转发给设备。对于每个适用的组件（即匹配记录所指示的每个组件）都会调用一次。设备驱动应将组件信息发送给设备固件，并等待响应。所提供的传输标志指示这是第一个、最后一个还是中间的组件，并且应作为组件表信息的一部分转发给固件。如果固件指示该组件无法更新，驱动应返回错误；如果组件可以更新，则返回零
### `.flash_component`


`.flash_component` 操作用于通知设备驱动刷写给定的组件。驱动必须执行任何必要的步骤，将组件数据发送给设备
### `.finalize_update`


`.finalize_update` 操作用于 `pldmfw` 库，以便让设备驱动执行完成更新所需的任何剩余设备特定逻辑
