
## PLDM 固件文件格式概述


PLDM 固件包是一个二进制文件，其中包含一个描述固件包内容的头部。它包括一个初始包头部、一条或多条固件记录，以及一个或多个描述要烧录的实际闪存内容的组件。

```

        overall file layout
      +----------------------+
      |                      |
      |  Package Header      |
      |                      |
      +----------------------+
      |                      |
      |  Device Records      |
      |                      |
      +----------------------+
      |                      |
      |  Component Info      |
      |                      |
      +----------------------+
      |                      |
      |  Package Header CRC  |
      |                      |
      +----------------------+
      |                      |
      |  Component Image 1   |
      |                      |
      +----------------------+
      |                      |
      |  Component Image 2   |
      |                      |
      +----------------------+
      |                      |
      |         ...          |
      |                      |
      +----------------------+
      |                      |
      |  Component Image N   |
      |                      |
      +----------------------+

```
## 包头部


包头部以 PLDM 文件格式的 UUID 开头，并包含有关该文件所用格式版本的信息。它还包括总的头部大小、发布日期、组件位图的大小，以及整体的包版本。

```

             header layout
      +-------------------------+
      | PLDM UUID               |
      +-------------------------+
      | Format Revision         |
      +-------------------------+
      | Header Size             |
      +-------------------------+
      | Release Date            |
      +-------------------------+
      | Component Bitmap Length |
      +-------------------------+
      | Package Version Info    |
      +-------------------------+

```
## 设备记录


设备固件记录区以一个计数开始，指示文件中记录的总数，随后是每条记录。单条设备记录描述了匹配该记录的设备。所有有效的 PLDM 固件文件必须至少包含一条记录，但如果支持多个设备，也可以可选地包含多于一条记录。

每条记录将通过描述设备的 TLV（如 PCI 设备和厂商信息）来标识其所支持的设备。它还会指示该设备使用哪一组组件。给定的记录可能只使用所提供的组件的一个子集。一条记录也可以可选地包含设备特定的包数据，这些数据将在更新过程中被设备固件使用。

```

         area layout
      +---------------+
      |               |
      |  Record Count |
      |               |
      +---------------+
      |               |
      |  Record 1     |
      |               |
      +---------------+
      |               |
      |  Record 2     |
      |               |
      +---------------+
      |               |
      |      ...      |
      |               |
      +---------------+
      |               |
      |  Record N     |
      |               |
      +---------------+

           record layout
      +-----------------------+
      | Record Length         |
      +-----------------------+
      | Descriptor Count      |
      +-----------------------+
      | Option Flags          |
      +-----------------------+
      | Version Settings      |
      +-----------------------+
      | Package Data Length   |
      +-----------------------+
      | Applicable Components |
      +-----------------------+
      | Version String        |
      +-----------------------+
      | Descriptor TLVs       |
      +-----------------------+
      | Package Data          |
      +-----------------------+

```
## 组件信息


组件信息区以一个组件数量计数开始。该计数之后是每个组件的描述。组件信息指向文件中存储组件数据的位置，并包含用于标识组件版本的版本数据。

```

         area layout
      +-----------------+
      |                 |
      | Component Count |
      |                 |
      +-----------------+
      |                 |
      | Component 1     |
      |                 |
      +-----------------+
      |                 |
      | Component 2     |
      |                 |
      +-----------------+
      |                 |
      |     ...         |
      |                 |
      +-----------------+
      |                 |
      | Component N     |
      |                 |
      +-----------------+

           component layout
      +------------------------+
      | Classification         |
      +------------------------+
      | Component Identifier   |
      +------------------------+
      | Comparison Stamp       |
      +------------------------+
      | Component Options      |
      +------------------------+
      | Activation Method      |
      +------------------------+
      | Location Offset        |
      +------------------------+
      | Component Size         |
      +------------------------+
      | Component Version Info |
      +------------------------+
      | Package Data           |
      +------------------------+


```
## 包头部 CRC


组件信息之后是一个短小的 4 字节 CRC，它是对所有头部信息内容计算得到的。

## 组件映像


组件映像位于 PLDM 固件文件中的包头部信息之后。每个映像只是一个二进制块，其起始位置和大小由组件信息区中相应的组件结构定义。
