
## PLDM 固件闪存更新库


`pldmfw` 实现了使用 PLDM for Firmware Update 标准更新设备上闪存的功能
<https://www.dmtf.org/documents/pmci/pldm-firmware-update-specification-100>。

- [file-format](file-format)
- [driver-ops](driver-ops)

## ``pldmfw`` 库概述


`pldmfw` 库供设备驱动使用，用于基于遵循 PLDM 固件文件格式的固件文件实现
设备闪存更新。

它通过一个 ops 表来实现，该表允许设备驱动提供底层的设备相关功能。

`pldmfw` 实现了将 PLDM 固件文件的打包二进制格式解析为数据结构的逻辑，然后
使用所提供的函数操作来判断该固件文件是否与设备匹配。如果匹配，它会通过设备
驱动提供的设备相关实现，将记录（record）与组件（component）数据发送给固件。
一旦设备固件表示可以执行更新，固件数据便会被发送给设备以进行编程。

## 解析 PLDM 文件


PLDM 文件格式使用打包的二进制数据，其中多数多字节字段以小端（Little Endian）
格式存储。若干数据是变长的，包括版本字符串以及记录与组件的数量。因此，要
索引记录、记录描述符或组件并不简单直接。

为了避免对打包二进制数据的访问扩散，`pldmfw` 库会将这些数据解析并提取到更
简单的数据结构中，以便访问。

为了安全地处理固件文件，会注意避免对多字节字段的非对齐访问，并正确地从小端
格式转换为 CPU 主机格式。此外，记录、描述符与组件都存储在链表中。

## 执行一次闪存更新


要执行一次闪存更新，`pldmfw` 模块会执行以下步骤：

1. 解析固件文件，获取记录与组件信息。
2. 遍历各条记录，判断设备是否与文件中的任意记录匹配。将使用第一条匹配的记录。
3. 如果匹配的记录提供了包数据，则将该包数据发送给设备。
4. 对于该记录所指示的每个组件，将组件数据发送给设备。对于每个组件，固件可能
   返回该更新是否合适的指示。如果有任何组件不合适，则取消更新。
5. 对于每个组件，将二进制数据发送给设备固件以进行更新。
6. 在所有组件都编程完成后，执行任何最终的设备相关操作以完成更新。
