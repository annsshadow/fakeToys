## 用于 IDT Tsi721 PCI Express 到 SRIO 桥接的 RapidIO 子系统 mport 驱动。


## 1. 概述


该驱动实现了所有当前定义的 RapidIO mport 回调函数。它支持维护读和写操作、
入站和出站 RapidIO 门铃（doorbell）、入站维护端口写（port-write）以及
RapidIO 消息传递。

为了生成 SRIO 维护事务，该驱动使用 Tsi721 的一个 DMA 通道。该机制提供了对
更大跳数（hop count）范围和目标 ID 的访问，而无需更改出站窗口转换。

RapidIO 消息传递支持为每个邮箱使用专用的消息传递通道。对于入站消息，该驱动
使用目标 ID 匹配将消息转发到相应的消息队列。消息传递回调的实现与 RIONET 驱动
（基于 RapidIO 消息传递服务的以太网）完全兼容。

1. 模块参数：

- 'dbg_level'
      - 该参数允许控制该设备驱动生成的调试信息量。该参数由一组位掩码构成，
        这些位掩码对应于特定的功能块。
        有关掩码定义请参见 'drivers/rapidio/devices/tsi721.h'
        该参数可以动态更改。
        使用 CONFIG_RAPIDIO_DEBUG=y 以在顶层启用调试输出。

- 'dma_desc_per_channel'
      - 该参数定义为每个注册的 Tsi721 DMA 通道分配的硬件缓冲区描述符数量。
        其默认值为 128。

- 'dma_txqueue_sz'
      - DMA 事务队列大小。定义每个 DMA 通道可以接受的待处理事务请求数量。
        默认值为 16。

- 'dma_sel'
      - DMA 通道选择掩码。位掩码，定义哪些硬件 DMA 通道（0 ... 6）将向
        DmaEngine 核心注册。如果位设置为 1，则相应的 DMA 通道将被注册。
        未被该掩码选择的 DMA 通道将不会被该设备驱动使用。默认值为 0x7f
        （使用所有通道）。

- 'pcie_mrrs'
      - 覆盖 PCIe 最大读请求大小（MRRS）的值。该参数提供了覆盖 PCIe 配置
        过程中设置的 MRRS 值的能力。Tsi721 支持最大 4096B 的读请求大小。
        该参数的值必须按照 PCIe 规范设置：
        0 = 128B，1 = 256B，2 = 512B，3 = 1024B，4 = 2048B，5 = 4096B。
        默认值为 '-1'（= 保留平台设置）。

- 'mbox_sel'
      - RIO 消息传递 MBOX 选择掩码。这是一个位掩码，定义由该设备驱动管理的
        消息传递 MBOX。掩码位 0 - 3 对应于 MBOX0 - MBOX3。如果相应的位设置为
        '1'，则 MBOX 处于驱动控制之下。默认值为 0x0f（= 全部）。

## 3. DMA 引擎支持


Tsi721 mport 驱动支持本地系统内存与远程 RapidIO 设备之间的 DMA 数据传输。
该功能根据通用 Linux 内核 DMA 引擎框架定义的 SLAVE 模式 API 实现。

根据系统需求，可以通过设置 CONFIG_RAPIDIO_DMA_ENGINE 选项来包含/排除 RapidIO
DMA 操作。Tsi721 miniport 驱动使用八个可用 BDMA 通道中的七个来支持 DMA 数据传输。
一个 BDMA 通道被保留用于生成维护读/写请求。

如果 Tsi721 mport 驱动在构建时包含了 RAPIDIO_DMA_ENGINE 支持，该驱动将接受
DMA 特定的模块参数：

  "dma_desc_per_channel"
    - 定义 Tsi721 每个 BDMA 通道使用的硬件缓冲区描述符数量
                           （默认 - 128）。
