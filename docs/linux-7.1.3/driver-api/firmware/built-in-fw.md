## 内置固件


固件可以被内置到内核中，这意味着将固件直接构建进 vmlinux，以避免需要从
文件系统查找固件。相反，可以直接在内核内部查找固件。你可以使用以下内核配置
选项启用内置固件
  - CONFIG_EXTRA_FIRMWARE
  - CONFIG_EXTRA_FIRMWARE_DIR

有几个理由可能让你考虑CONFIG_EXTRA_FIRMWARE 将固件构建进内核
- 速度
- 访问启动设备需要固件，而用户不想把固件塞进启动 initramfs
即使你有这些需求，也有一些理由可能让你无法使用内置固件：

- 法律层面 - 固件GPL 不兼- 某些固件可能是可选的
- 固件可能可以升级，因此新固件将意味着完整的内核重新构建- 某些固件文件可能体积非常大。remote-proc 子系统就是一个处理此类固件的例子
- 固件可能需要动态从某些设备特定的位置抓取，例如某些 WiFi 芯片组的校准数据  这种校准数据对每个售出的设备可能是唯一的
