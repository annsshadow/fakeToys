
## CXL 设备热插拔


设备热插拔指的是设备的**物理**热插拔（从机器中添加或移除一个物理设备）。

BIOS/EFI 软件应在**启动时刻**配置充足的资源，以便热插拔的设备能被软件配置
（例如近端域、HPA 区域以及主机桥配置）。

BIOS/EFI **不应（也不建议）**在热插拔时对热插拔设备进行配置（即 HDM 解码器
应保持未编程状态）。

本文档涵盖其中部分资源的示例，但不应被视为详尽无遗。

## 热移除（Hot-Remove）


热移除一个设备通常要求小心地移除管理这些设备的软件结构（内存区域、相关驱动）。

在未仔细拆除驱动栈的情况下硬移除一个 CXL.mem 设备，很可能导致系统发生机器检查
（machine-check），或者（如果内存访问仅限于用户空间）至少引发 SIGBUS。

## 内存设备热添加（Memory Device Hot-Add）


启动时存在的设备可能与 [CEDT<acpi/cedt>](CEDT<acpi/cedt>) 中报告的 CXL 固定内存窗口（Fixed Memory Window）
相关联。该 CFMWS 可能与设备大小匹配，但 CEDT CFMWS 的构建是平台定义的。

热添加一个内存设备需要这个预定义、**静态**的 CFMWS 拥有足够的 HPA 空间来描述该设备。

有几种常见场景需要考虑。

### 启动时已存在的单端点内存设备


启动时存在的设备很可能已在 [CEDT<acpi/cedt>](CEDT<acpi/cedt>) 中报告了其容量。如果移除一个设备并热插拔一个新设备，
新设备的容量将被限制为原始 CFMWS 的容量。

如果添加大于原始设备的容量，且区域大小大于 CFMWS 大小，内存区域的创建将失败。

CFMWS 是**静态**的，无法调整。可能会热插拔不同大小设备的平台，必须分配足够的
CFMWS 空间，**在启动时刻**覆盖所有未来预期的设备。

### 启动时已存在的多端点内存设备


非交换器（switch）形式的多端点设备超出了 CXL 规范描述的范围，但技术上是可能的。
我们在此描述它们仅出于说明目的——这并不暗示 Linux 支持。

一个支持热插拔的 CXL 内存设备，例如将多个扩展器呈现为单一大容量设备的设备，应当报告
**最大
```

                  HB0
                  RP0
                   |
     [Multi-Endpoint Memory Device]
              _____|_____
             |          |
        [Endpoint0]   [Empty]


```
将大小限制为启动时预设的容量，会把热添加支持限制为替换启动时即存在的容量。

### 启动时没有 CXL 设备


当启动时不存在 CXL 内存设备时，某些平台会省略 [CEDT<acpi/cedt>](CEDT<acpi/cedt>) 中的 CFMWS。发生这种情况时，
热添加是不可能的。

这描述了任何给定设备在启动时不存在的基本情形。如果未来可能的设备在启动时的 CEDT
中没有被描述，那么该设备的热添加将受限或不可能。

要让平台支持完整内存设备的热添加，它必须分配一个拥有足够内存容量、覆盖所有未来可能
添加容量的 CEDT CFMWS 区域（以及任何相关的 CEDT CHBS 条目）。

为了直接在主机桥/根端口（root port）上，或在主机桥下游的交换器上支持内存热插拔，平台
必须在启动时构建一个 CEDT CFMWS，拥有足够的资源以支持最大可能（或预期）的热插拔
```

         HB0                 HB1
      RP0    RP1             RP2
       |      |               |
     Empty  Empty            USP
                      ________|________
                      |    |    |     |
                     DSP  DSP  DSP   DSP
                      |    |    |    |
                         All  Empty

```
例如，BIOS/EFI 可以提供一个选项，配置一个带有预配置内存容量的 CEDT CFMWS（按主机桥，
或按主机桥交织集），即使启动时没有设备连接到根端口或下游端口（如上图所示）。


## 交织集（Interleave Sets）


### 主机桥交织


跨主机桥交织的内存区域在 [CEDT<acpi/cedt>](CEDT<acpi/cedt>) 中**静态**定义。要应用跨主机桥的交织，必须**在启动时刻**
提供一个描述该交织的 CFMWS 条目。热插拔的设备无法在热插拔时添加主机桥交织能力。

参见 [Flexible CEDT Configuration<example-configurations/flexible>](Flexible CEDT Configuration<example-configurations/flexible>)
示例，了解平台如何为热插拔内存设备提供此类灵活性。BIOS/EFI 软件应考虑提供带有
热插拔支持的灵活 CEDT 配置选项。

### HDM 交织


由解码器施加的交织可以灵活地处理热插拔设备，因为解码器可以在热插拔后重新编程。

要向已有的、施加了 HDM 的交织区域添加或移除设备，必须先拆除并重新创建该区域。
