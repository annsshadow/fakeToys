## Linux 的 PTP 硬件时钟基础设施

本补丁集为 Linux 引入了对 IEEE 1588 PTP 时钟的支持。结合 SO_TIMESTAMPING 套接字选项，它提供了一种用于开发 PTP 用户空间程序、将 Linux 与外部时钟同步以及使用 PTP 硬件时钟辅助功能的标准化方法。

一个新的类驱动导出了一个供具体时钟驱动使用的内核接口，以及一个用户空间接口。该基础设施支持一整套完整的 PTP 硬件时钟功能。

  - 基本时钟操作
    - 设置时间
    - 获取时间
    - 以原子方式按给定偏移量平移时钟
    - 调整时钟频率

  - 辅助时钟功能
    - 对外部事件打时间戳
    - 可由用户空间配置的周期性输出信号
    - 从用户空间访问低通滤波器（LPF）
    - 通过 PPS 子系统同步 Linux 系统时间

## PTP 硬件时钟内核 API

   一个 PTP 时钟驱动向类驱动注册自己。类驱动处理所有与用户空间的交互。时钟驱动的作者只需实现编程时钟硬件的细节。时钟驱动通过一个简单的消息传递接口，将异步事件（告警和外部时间戳）通知给类驱动。

   类驱动支持多个 PTP 时钟驱动。在正常的用例中，只需要一个 PTP 时钟。不过，出于测试和开发的目的，在单个系统中拥有多个时钟会很有用，以便进行性能比较。

## PTP 硬件时钟用户空间 API

   类驱动还会为每个已注册的时钟创建一个字符设备。用户空间可以将该字符设备的打开文件描述符用作 POSIX 时钟 id，并可以调用 clock_gettime、clock_settime 和 clock_adjtime。这些调用实现了基本的时钟操作。

   用户空间程序可以使用标准化的 ioctl 控制时钟。一个程序可以查询、启用、配置以及禁用辅助时钟功能。用户空间可以通过阻塞式 read() 和 poll() 接收时间戳事件。

## 编写时钟驱动

   时钟驱动包含 include/linux/ptp_clock_kernel.h，并通过向注册方法提供一个 'struct ptp_clock_info' 来注册自己。时钟驱动必须实现接口中的所有函数。如果某个时钟不提供特定的辅助功能，那么驱动应当从这些函数简单地返回 -EOPNOTSUPP。

   驱动必须确保接口中的所有方法都是可重入的。由于大多数硬件实现把时间值当作一个 64 位整数，以两个 32 位寄存器访问，因此驱动应当使用 spin_lock_irqsave/spin_unlock_irqrestore 来防止并发访问。这种加锁无法在类驱动中完成，因为时钟驱动的中断服务例程也可能需要这个锁。

### PTP 硬件时钟对 '.adjphase' 的要求

   'struct ptp_clock_info' 接口有一个 '.adjphase' 函数。为了实现这个函数，PHC 需要满足一组要求。

     - PHC 在内部实现一个伺服算法，用于修正 '.adjphase' 调用中传入的偏移量。
     - 当调用其他 PTP 调整函数时，PHC 伺服算法被禁用。

   **注意：** '.adjphase' 并不是一个简单地基于所提供偏移量“跳转” PHC 时钟时间的时间调整功能。它应当使用内部算法来修正所提供的偏移量。

## 受支持的硬件

   - Freescale eTSEC gianfar

     - 2 个外部触发时间戳，可编程极性（可选中断）
     - 2 个告警寄存器（可选中断）
     - 3 个周期性信号（可选中断）

   - National DP83640

     - 6 个可配置为输入或输出的 GPIO
     - 6 个具有专用功能（LED/JTAG/clock）的 GPIO 也可用作通用输入或输出
     - GPIO 输入可以对外部触发打时间戳
     - GPIO 输出可以产生周期性信号
     - 1 个中断引脚

   - Intel IXP465

     - 辅助从/主模式快照（可选中断）
     - 目标时间（可选中断）

   - Renesas (IDT) ClockMatrix™

     - 最多 4 个独立的 PHC 通道
     - 集成低通滤波器（LPF），通过 .adjPhase 访问（符合 ITU-T G.8273.2）
     - 可编程输出周期性信号
     - 可编程输入可以对外部触发打时间戳
     - 通过固件（idtcm.bin）进行驱动和/或硬件配置
          - LPF 设置（带宽、相位限制、自动保持、物理层辅助（按 ITU-T G.8273.2））
          - 可编程输出 PTP 时钟，任意频率最高达 1GHz（提供给其他 PHY/MAC 时间戳器、给 ASSP/SoC/FPGA 的 refclk）
          - 锁定到 GNSS 输入，在 GNSS 与用户空间 PHC 控制之间自动切换（可选）

   - NVIDIA Mellanox

     - GPIO
          - ConnectX-6 Dx 及更高版本的某些变体支持一个可以对外部触发打时间戳的 GPIO，以及一个用于产生周期性信号的 GPIO。
          - ConnectX-5 及更早产品的某些变体支持一个 GPIO，配置为对外部触发打时间戳或产生周期性信号。
     - PHC 实例
          - 所有 ConnectX 设备都有一个自由运行的计数器
          - ConnectX-6 Dx 及更高设备有一个 UTC 格式的计数器
