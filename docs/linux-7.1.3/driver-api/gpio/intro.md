## GPIO Interfaces


本目录中的文档给出了关于如何在驱动中访问 GPIO，以及如何为本身提供 GPIO 的设备编写驱动的详细说明。


## What is a GPIO?


"通用输入/输出"（GPIO）是一种灵活的、由软件控制数字信号。它们由多种芯片提供，对于从事嵌入式和定制硬件开发的 Linux 开发者来说非常熟悉。每个 GPIO 代表连接到特定引脚（或球栅阵列（BGA）封装上的"球"）的一个位。板级原理图显示了哪些外部硬件连接到哪些 GPIO。驱动可以写成通用的形式，由板级设置代码将此类引脚配置数据传递给驱动。

片上系统（SOC）处理器严重依赖 GPIO。在某些情况下，每个非专用引脚都可以配置为 GPIO；而且大多数芯片至少有几十个 GPIO。可编程逻辑器件（如 FPGA）可以轻松提供 GPIO；像电源管理器、音频编解码器这样的多功能芯片通常也有几个这样的引脚，以缓解 SOC 上的引脚稀缺；此外还有通过 I2C 或 SPI 串行总线连接的"GPIO 扩展器"芯片。大多数 PC 南桥有几十个支持 GPIO 的引脚（只有 BIOS 固件知道它们是如何使用的）。

GPIO 的确切能力在各系统之间有所不同。常见选项：

  - 输出值可写（高=1，低=0）。某些芯片还对如何驱动该值有所选项，例如只有某个值被驱动，而另一个值支持"线与"（wire-OR）及类似方案（特别是"开漏"（open drain）信号）。

  - 输入值同样可读（1，0）。某些芯片支持读回配置为"输出"的引脚，这在"线与"情况下（以支持双向信号）非常有用。GPIO 控制器可能具有输入去毛刺/去抖逻辑，有时可通过软件控制。

  - 输入通常可用作 IRQ 信号，通常是边沿触发，有时是电平触发。此类 IRQ 可能被配置为系统唤醒事件，以将系统从低功耗状态唤醒。

  - 通常一个 GPIO 可以根据不同产品板的需要配置为输入或输出；也存在单向的 GPIO。

  - 大多数 GPIO 可以在持有自旋锁时访问，但通过串行总线访问的通常不能。某些系统同时支持两类。

在给定板子上，每个 GPIO 都用于一个特定目的，例如监视 MMC/SD 卡的插入/移除、检测卡的写保护状态、驱动 LED、配置收发器、位拆裂（bit-banging）串行总线、触发硬件看门狗、感知开关等。


## Common GPIO Properties


这些属性贯穿 GPIO 接口的所有其他文档，理解它们很有用，尤其是在你需要定义 GPIO 映射时。

### Active-High and Active-Low


很自然地会假设当 GPIO 的输出信号为 1（"高"）时它是"有效"（active）的，为 0（"低"）时则是无效（inactive）的。然而在实践中，GPIO 的信号在到达其目的地之前可能被反相，或者设备可能就"有效"的含义采用不同的约定。这类决策对设备驱动应当是透明的，因此可以定义一个 GPIO 为 active-high（"1"表示"有效"，默认）或 active-low（"0"表示"有效"），这样驱动只需要关心逻辑信号，而不必关心线路电平上发生了什么。

### Open Drain and Open Source


有时共享信号需要使用"开漏"（open drain，只有低电平被实际驱动）或"开源"（open source，只有高电平被驱动）信号。这个术语适用于 CMOS 晶体管；"开集电极"（open collector）用于 TTL。上拉或下拉电阻产生高或低电平信号。这有时称为"线与"（wire-AND）；或者更实际地，从负逻辑（低=真）的角度来看，这是"线或"（wire-OR）。

开漏信号的一个常见例子是共享的 active-low IRQ 线。此外，双向数据总线信号有时也使用开漏信号。

有些 GPIO 控制器直接支持开漏和开源输出；很多则不支持。当你需要开漏信号但硬件不直接支持它时，有一个常见的惯用法可以用来用任何可用作输入或输出的 GPIO 引脚来模拟它：

 **LOW**: `gpiod_direction_output(gpio, 0)` ... 这会驱动信号并覆盖上拉。

 **HIGH**: `gpiod_direction_input(gpio)` ... 这会关闭输出，从而由上拉（或其他设备）控制该信号。

同样的逻辑可用于模拟开源信号，即驱动高电平并将 GPIO 配置为输入以实现低电平。这种开漏/开源模拟可以由 GPIO 框架透明地处理。

如果你"驱动"信号为高，但 gpiod_get_value(gpio) 报告低值（在适当的上升时间过后），你就知道有其他组件正在将共享信号驱动为低。这不一定是错误。一个常见的例子是 I2C 时钟的拉伸方式：需要更慢时钟的从设备延迟 SCK 的上升沿，I2C 主设备相应调整其信号速率。
