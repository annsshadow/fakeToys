## 用于自制廉价基于 BT8xx PCI GPIO 卡（bt8xxgpio）的驱动


关于更深入的文档，请参见 https://bues.ch/cms/unmaintained/btgpio.html

一块通用的数24 端口 PCI GPIO 卡可以由普通的 Brooktree bt848、bt849、bt878 bt879 模拟电视调谐器卡改造而成。Brooktree 芯片用于旧的模拟 Hauppauge WinTV PCI 卡。你可以在网上轻易以低价找到二手的它们
bt8xx 芯片确实24 个数GPIO 端口这些端口可通过 SMD 芯片封装上的 24 个引脚访问

## 如何物理访问 GPIO 引脚


有几种方式可以访问这些引脚。有人可能会拆下整个芯片并将其放到定制的 PCI 板上，或者只拆下每个独立GPIO 引脚并焊接到细小的导线上。由于芯片封装确实很小，无论如何都需要一些高级焊接技巧
