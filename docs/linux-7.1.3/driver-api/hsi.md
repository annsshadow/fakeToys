## 高速同步串行接口（HSI


### 简


高速同步接口（HSI）是一种全双工、低延迟协议，针对应用处理器与基带芯片组之间的裸片级互连进行了优化。它MIPI 联盟2003 年制定规范，此后由多个厂商实现

HSI 接口支持通过多个通道（通常8 个）进行全双工通信，并能够达到高达 200 Mbit/s 的速度

该串行协议使用两个信DATA FLAG 作为组合的数据与时钟信号，以及额外的 READY 信号用于流控。额外的 WAKE 信号可用于将芯片从待机模式唤醒。信号通常AC 作为从应用裸片发往蜂窝裸片的信号前缀，以 CA 作为反方向的信号前缀

```

    +------------+                                 +---------------+
    |  Cellular  |                                 |  Application  |
    |    Die     |                                 |      Die      |
    |            | - - - - - - CAWAKE - - - - - - >|               |
    |           T|------------ CADATA ------------>|R              |
    |           X|------------ CAFLAG ------------>|X              |
    |            |<----------- ACREADY ------------|               |
    |            |                                 |               |
    |            |                                 |               |
    |            |< - - - - -  ACWAKE - - - - - - -|               |
    |           R|<----------- ACDATA -------------|T              |
    |           X|<----------- ACFLAG -------------|X              |
    |            |------------ CAREADY ----------->|               |
    |            |                                 |               |
    |            |                                 |               |
    +------------+                                 +---------------+

```

### Linux 中的 HSI 子系


Linux 内核中，hsi 子系统应当用HSI 设备。hsi 子系统包HSI 控制器的驱动（包括多端口控制器的支持），并提供使HSI 端口的通用 API

它还包含 HSI 客户端驱动，这些驱动利用通用 API 来实HSI 接口上使用的协议。这些客户端驱动可以使用任意数量的通道

### hsi-char 设备


每个端口会自动注册一个称hsi_char 的通用客户端驱动，它为用户空间提供一个代HSI 端口的字符设备。它可以用于从用户空间通过 HSI 进行通信。用户空间可以使用以ioctl 命令配置 hsi_char 设备

HSC_RESET
 刷新 HSI 端口

HSC_SET_PM
 启用或禁用客户端

HSC_SEND_BREAK
 发break

HSC_SET_RX
 设置 RX 配置

HSC_GET_RX
 获取 RX 配置

HSC_SET_TX
 设置 TX 配置

HSC_GET_TX
 获取 TX 配置
