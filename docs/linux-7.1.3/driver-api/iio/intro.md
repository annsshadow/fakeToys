
## 简介


工业 I/O 子系统（IIO）的主要目的是为在某种意义下执行模数转换（ADC）或数模
转换（DAC）或两者的设备提供支持。其目标是填补 somewhat 类似的 hwmon 与
[input <../input>](Input <../input>) 子系统之间的空白。Hwmon 面向用于监控系统本身（如风扇转速控制
或温度测量）的低采样率传感器。[Input <../input>](Input <../input>) 顾名思义，专注于人机交互输入设备
（键盘、鼠标、触摸屏）。在某些情况下，这些与 IIO 之间存在相当大的重叠。

属于此类别的设备包括：

- 模数转换器（ADCs）
- 加速度计
- 电容到数字转换器（CDCs）
- 数模转换器（DACs）
- 陀螺仪
- 惯性测量单元（IMUs）
- 颜色与光传感器
- 磁力计
- 压力传感器
- 接近传感器
- 温度传感器

通常这些传感器通过 [SPI <../spi>](SPI <../spi>) 或 [I2C <../i2c>](I2C <../i2c>) 连接。传感器设备的一个常见用例是
具有组合功能（例如光加接近传感器）。
