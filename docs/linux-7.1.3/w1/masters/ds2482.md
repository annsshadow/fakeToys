## 内核驱动 ds2482


支持芯片：

  - Maxim DS2482-100, Maxim DS2482-800

    Prefix: 'ds2482'

    Addresses scanned: 无

    Datasheets:

        - http://datasheets.maxim-ic.com/en/ds/DS2482-100.pdf
        - http://datasheets.maxim-ic.com/en/ds/DS2482-800.pdf

Author: Ben Gardner <bgardner@wabtec.com>


### 说明


Maxim/Dallas Semiconductor 的 DS2482 是一款 I2C 设备，提供一条（DS2482-100）或八条（DS2482-800）1-wire 总线。


### 一般说明


有效地址为 0x18、0x19、0x1a 和 0x1b。

不过，该设备无法通过读取 i2c 总线来探测，因此不进行探测。你应该显式实例化该设备。

```

  $ modprobe ds2482
  $ echo ds2482 0x18 > /sys/bus/i2c/devices/i2c-0/new_device

```
