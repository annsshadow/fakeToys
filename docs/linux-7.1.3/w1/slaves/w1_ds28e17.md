## 内核驱动 w1_ds28e17


支持芯片
  - Maxim DS28E17 1-Wire I2C 主桥

supported family codes:

        =================  ====
	W1_FAMILY_DS28E17  0x19
        =================  ====

Author: Jan Kandziora <jjj@gmx.de>


### 描述

DS28E17 是一个充I2C 总线主设备的 Onewire 从设备
该驱动为检测到的每DS28E17 设备创建一个新I2C 总线。随着 DS28E17 设备的插入和移除，I2C
总线也随之出现和消失。连接到 DS28E17 I2C 从设备可以由内核或用户空间工具访问，就像它们
连接到“原生”的 I2C 总线主设备一样

```

  SUBSYSTEM=="i2c-dev", KERNEL=="i2c-[0-9]*", ATTRS{name}=="w1-19-*", \
          SYMLINK+="i2c-$attr{name}"

```
可用于基DS28E17 芯片的唯一 id 创建稳定/dev/i2c- 条目

驱动参数为：

speed	这设置了 DS28E17 一连接就被配置为的默认 I2C 速度。DS28E17 的上电默认值为 400kBaud	但芯片可能在 Onewire 总线上来来去去而不断电，一“w1_ds28e17驱动注意Onewire
	总线上一个新连接的或重新连接DS28E17 设备，它就会重新应用此设置
	有效值为 1000000 [kBaud]。任何其他值表示在检测到时保留当DS28E17 设置不变	默认值为 100
stretch	这设置了用于新连接的 DS28E17 设备的默stretch 值。它是一个乘子，用于计算 I2C 传输
	的忙等待时间。这是为了应对那些大量使I2C 时钟拉伸（clock stretching）特性的 I2C
	从设备，因而所需的超时无法被预先正确计算。由w1_ds28e17 驱动在预先计算的等待时间
	后会在循环中检DS28E17 的忙标志，几乎不需要调整此设置
	除非你收ETIMEDOUT 错误以及内核日志中的 “w1_slave_driver
	19-00000002dbd8: busy timeout”，否则将其保留1
	有效值为 1 9。默认值为 1

该驱动为每个设备创建 sysfs 文件 /sys/bus/w1/devices/19-<id>/speed /sys/bus/w1/devices/19-<id>/stretch，预载了来自驱动参数的默认设置。它们可以随时更改此外还会创建一个目/sys/bus/w1/devices/19-<id>/i2c-<nnn> 作为 I2C 总线主设备的 sysfs
结构
