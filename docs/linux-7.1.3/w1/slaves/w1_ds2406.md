## w1_ds2406 内核驱动


支持的设备：

  - Maxim DS2406（及其他 family 0x12）可寻址开
作者：Scott Alfter <scott@alfter.us>

### 描述


w1_ds2406 驱动允许对连接的设备进行开关控制。这些芯片还提供 128 字节OTP EPROM，但读写不受支持。在 TSOC-6 封装下，DS2406 提供两个开关输出，并可从专用输入引脚取电。在 TO-92 封装下，它提供一个输出，并仅使用寄生电源
该驱动提供两sysfs 文件。state 可读，给出每个开关的当前状态，PIO A 位于 bit 0，PIO B 位于 bit 1。驱动将此状态与 0x30 进行或运算，以便 shell 脚本得到 ASCII 0/1/2/3 来使用。output 可写，bit 0 bit 1 分别控制 PIO A PIO B。bit 2-7 被忽略，因此可以安全地写ASCII 数据
写时均校CRC。校验失败会返回 I/O 错误。写入失败时，开关状态不会改变
