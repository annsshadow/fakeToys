## 内核驱动 w1_ds2413


支持的芯片：

  - Maxim DS2413 1-Wire 双通道可寻址开关

支持的 family code：

        ================        ====
        W1_FAMILY_DS2413        0x3A
        ================        ====

作者：Mariusz Bialonczyk <manio@skyboo.net>

### 描述


DS2413 芯片具有两个开漏输出（PIO A 和 PIO B）。
通过 sysfs 文件 "output" 和 "state" 提供支持。

### 读取状态

"state" 文件提供一个单字节值，其格式与芯片的 PIO_ACCESS_READ 命令相同（详见数据手册）：

======== =============================================================
Bit 0:   PIOA 引脚状态
Bit 1:   PIOA 输出锁存状态
Bit 2:   PIOB 引脚状态
Bit 3:   PIOB 输出锁存状态
Bit 4-7: Bit 3 到 Bit 0 的取反（由内核模块校验）
======== =============================================================

此文件只读。

### 写入输出

你可以使用 "output" 文件设置 PIO 引脚。
它是可写的，你可以向此 sysfs 文件写入一个单字节值。
同样，字节格式与 PIO_ACCESS_WRITE 命令相同：

======== ======================================
Bit 0:   PIOA
Bit 1:   PIOB
Bit 2-7: 任意（驱动会将其设为 "1"）
======== ======================================


该芯片具有某种针对传输错误的基本保护。
读取状态时，会有四位取反位。
驱动会校验该取反，若其错误则返回 I/O 错误。

写入输出时，主设备必须以取反形式重复 PIO 输出数据字节，并等待确认。
如果写入连续三次失败，写入同样返回 I/O 错误。
