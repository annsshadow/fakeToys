## 空闲页上报（Free Page Reporting）


空闲页上报是一种 API，设备可以通过它注册以接收系统当前未使用的页列表。这在虚拟化场景下很有用，客户机随后能够利用这些数据通知虚拟机监控器它不再使用内存中的某些页。

对于驱动（通常是一个 balloon 驱动）要使用此功能，它将分配并初始化一个 page_reporting_dev_info 结构体。它将在该结构体中填充的字段是用于处理 scatterlist 的"report"函数指针。它还必须保证在每次调用该函数时能够处理至少 PAGE_REPORTING_CAPACITY 数量的 scatterlist 条目。假设当前没有其他页上报设备已经注册，对 page_reporting_register 的调用将向报告框架注册页上报接口。

一旦注册，页上报 API 将开始向驱动上报成批的页。该 API 会在接口注册 2 秒后开始上报页，并且会在任意足够高阶（order）的页被释放 2 秒后继续上报。

被上报的页将存储在传递给上报函数的 scatterlist 中，最后一个条目在 entry nent - 1 处设置了 end 位。当上报函数正在处理页时，分配器无法访问这些页。一旦上报函数执行完毕，这些页将被返回到它们来源的自由区域。

在移除一个正在使用空闲页上报的驱动之前，需要调用 page_reporting_unregister，以移除当前正被空闲页上报使用的 page_reporting_dev_info 结构体。这样做将阻止通过该接口发出进一步的报告。如果注册了另一个驱动或同一个驱动，它可以从上一个驱动停止上报空闲页的位置继续。
