
## 关于内核中寄存器组使用的说明


### 简


SH-3 SH-4 CPU 系列传统上包含单个部分寄存器组（SR.RB 选择，仅 r0 ... r7 被分组），而其他系列可能具有功能更完整的分组，或者干脆没有此类能力

### SR.RB 分组


对于此类分组，如SR.RB 被设置为我们感兴趣的组，则分组的寄存器直接映射到 r0 ... r7，否则仍可使ldc/stc 来引用分组寄存器（作r0_bank ... r7_bank），当处于另一组的上下文中时。开发人员在使用这些分组寄存器编写代码时必须牢记 SR.RB 的值，原因显而易见。用户空间也无法访问 bank1 的值，因此内核可以相当有效地将它们用作临时寄存器

目前内核使用了其中几个寄存器

 - r0_bank、r1_bank（作k0 k1 被引用，用于异常处理时作为临时寄存器）

 - r2_bank（用于跟EXPEVT/INTEVT 代码

  - do_IRQ() 及其相关函数用于基于中断异常向量跳转表偏移进irq 映射

 - r6_bank（全局中断掩码
