## PA-RISC 调试


好的，这里有一些调试 linux/parisc 底层部分的提示。


## 1. 绝对地址


当前大量汇编代码在实模式下运行，这意味着使用绝对地址而不是像内核其余部分那样
使用虚拟地址。要将绝对地址转换为虚拟地址，你可以在 System.map 中查找，并加上
__PAGE_OFFSET（当前为 0x10000000）。


## 2. HPMC


当实模式代码尝试访问不存在的内存时，你会得到一个 HPMC 而不是内核 oops。要调试
HPMC，尝试找到 System Responder/Requestor 地址。System Requestor 地址应与
（其中一个）处理器 HPA（I/O 范围内的高地址）匹配；System Responder 地址是实
模式代码尝试访问的地址。

System Responder 地址的典型值是大于 __PAGE_OFFSET (0x10000000) 的地址，这意味
着虚拟地址在实模式代码尝试访问它之前没有被转换为物理地址。


## 3. Q 位揭秘


某些非常关键的代码必须清除 PSW 中的 Q 位。清除 Q 位后发生的情况是，CPU 不会
更新中断处理程序用于查明机器被中断位置的寄存器——因此，如果在清除 Q 位的指令
与重新设置它的 RFI 之间发生中断，你将不知道它确切发生在哪里。如果幸运，IAOQ
会指向清除 Q 位的指令；如果不幸，它会指向任何地方。通常 Q 位问题会表现为无法
解释的系统挂起或跑出物理内存末端。
