
## Linux/x86-64 下对 CPU 热插拔的固件支持


Linux/x86-64 现在支持 CPU 热插拔。由于各种原因 Linux 希望
在启动时间之前知道可以插入的最大 CPU 数量
进入系统。 ACPI 3.0目前还没有官方途径提供
这些信息从固件到操作系统。

在 ACPI 中，每个 CPU 都需要 MADT 表中的 LAPIC 对象（5.2.11.5）
ACPI 3.0 规范）。  ACPI已经有了禁用LAPIC的概念
通过将 LAPIC 对象中的启用位设置为零来实现对象。

对于 CPU 热插拔，Linux/x86-64 现在期望任何未来可能的热插拔
CPU 已在 MADT 中可用。如果 CPU 尚不可用
它应该将其 LAPIC 启用位设置为 0。Linux 将使用该数字
禁用的 LAPIC 来计算未来 CPU 的最大数量。

在最坏的情况下，用户可以使用命令行覆盖此选择
选项（additional_cpus=...），但建议提供正确的
数字（或它的合理近似值，错误趋于更多而不是更少）
在 MADT 中以避免手动配置。
