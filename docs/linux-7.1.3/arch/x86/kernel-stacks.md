## x86-64 上的内核

大部分文本来Keith Owens，由 AK 修改

x86_64 的页大小（PAGE_SIZE）为 4K
与所有其它体系结构一样，x86_64 为每个活动线程都提供了一个内核栈。这些线程栈大小THREAD_SIZE*PAGE_SIZE）。只要线程还活着或是僵尸（zombie）状态，这些中就包含有用数据。当线程处于用户空间时，除了底部thread_info 结构外，内核栈是
空的
除了每个线程的栈之外，还与每CPU 关联有专门的栈。这些栈仅在内核控制CPU 使用；当 CPU 返回用户空间时，这些专门栈中不包含有用数据。主要的 CPU 栈有
- 中断栈。IRQ_STACK_SIZE

  用于外部硬件中断。如果这是第一个外部硬件中断（即不是嵌套的硬件中断），那么内核
  会从当前任务切换到中断栈。就i386 上分离的线程栈和中断栈一样，这为内核中断处理
  提供了更多空间，而无需增大每个线程栈的大小
  中断栈在处理软中断（softirq）时也会使用
切换到内核中断栈是由软件基于每个 CPU 的中断嵌套计数器完成的。这是必需的，因为
x86-64 的“IST”硬件栈无法在不产生竞争的情况下嵌套
x86_64 还有一i386 上不具备的特性，即能够为指定事件（如双重错误（double faultNMI）自动切换到新栈，这使得x86_64 上处理这些异常事件更加容易。该特性称中断栈表（IST，Interrupt Stack Table）。每CPU 最多可7 IST 条目。IST 代码
是任务状态段（TSS）的索引。TSS 中的 IST 条目指向专用栈；每个栈可以是不同的大小
IST 由中断门描述符（interrupt-gate descriptor）的 IST 字段中的非零值选择。当中断
发生且硬件加载此类描述符时，硬件会根IST 值自动设置新的栈指针，然后调用中断处程序。如果中断来自用户模式，那么中断处理程序的序章（prologue）会切换回每线程栈如果软件希望允许嵌套IST 中断，那么处理程序必须在进入和退出中断处理程序时调整
IST 值。（偶尔会这样做，例如用于调试异常。）

具有不同 IST 代码（即不同栈）的事件可以嵌套。例如，调试中断可以安全地被 **NMI**
打断。arch/x86_64/kernel/entry.S 中的 paranoidentry 在进入和退出所IST 事件调整栈指针，理论上允许相同代码的 IST 事件被嵌套。然而在大多数情况下，分配给某个
IST 的栈大小假设同一代码不会被嵌套。如果这一假设被打破，栈就会损坏
当前分配IST 栈有
- ESTACK_DF。EXCEPTION_STKSZ（PAGE_SIZE）
  用于中断 8 —双重错误异常DF）
  在处理一个异常又引发另一个异常时调用。发生在内核非常混乱时（例如内核栈指针损坏）  使用单独的栈使内核在许多情况下能够足够好地恢复，仍然输出一oops
- ESTACK_NMI。EXCEPTION_STKSZ（PAGE_SIZE）
  用于不可屏蔽中断（NMI）
  NMI 可以在任何时刻送达，包括内核正在切换栈的过程中。对 NMI 事件使用 IST 避免  对内核栈先前状态做出假设
- ESTACK_DB。EXCEPTION_STKSZ（PAGE_SIZE）
  用于硬件调试中断（中1）和软件调试中断（INT3）
  调试内核时，调试中断（硬件和软件）可以在任何时刻发生。对这些中断使用 IST 避免  对内核栈先前状态做出假设
  为了正确处理嵌套#DB，存在两DB 栈实例。在进入 #DB 时，#DB IST 栈指  被切换到第二个实例，因此嵌套#DB 从一个干净的栈开始。嵌套的 #DB IST 栈指  切换到一个保护孔（guard hole），以捕获三重嵌套
- ESTACK_MCE。EXCEPTION_STKSZ（PAGE_SIZE）
  用于中断 18 —机器检查异常（#MC）
  MCE 可以在任何时刻送达，包括内核正在切换栈的过程中。对 MCE 事件使用 IST 避免  对内核栈先前状态做出假设
更多细节请参Intel IA32 AMD AMD64 体系结构手册

如果它符合帧指针链（frame pointer chain），我们就不带问号地打印它，因为知道它是真实
回溯的一部分
如果地址不符合我们预期的帧指针链，我们仍然打印它，但打印一个’。它可能有两层含义：

 - 要么该地址不是调用链的一部分：它只是内核栈上来自早期函数调用的陈旧值。这是常   情况
 - 要么它是调用链的一部分，但函数内部没有正确建立帧指针，所以我们无法识别它
这样，无论帧指针是否正确建立，我们总是会打印出真实的调用链（外加几个多余条目）但在大多数情况下，我们也能正确得到调用链。打印的条目严格按栈顺序排列，因此你可以
从中推断更多信息
