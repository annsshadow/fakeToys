## STM32F746 概述


### 简


STM32F746 是面向各种应用的 Cortex-M7 MCU。它具有以下特性：

- 运行频率最高达 216MHz Cortex-M7 核心
- 1MB 内部 flash20KB 内部 RAM4KB 备份 SRAM
- 用于连接 SDRAM、NOR NAND 存储器的 FMC 控制
- 双模QSPI
- SD/MMC/SDIO 支持
- 以太网控制器
- USB OTFG FS & HS 鎺у埗鍣。
- I2C、SPI、CAN 总线支持
- 多个 16 位与 32 位通用定时
- 串行音频接口
- LCD 鎺у埗鍣。
- HDMI-CEC
- SPDIFRX
