## STM32H743 概述


### 简介


STM32H743 是面向各种应用的 Cortex-M7 MCU。它具有以下特性：

- 运行频率最高达 400MHz 的 Cortex-M7 核心
- 2MB 内部 flash，1MB 内部 RAM
- 用于连接 SDRAM、NOR 和 NAND 存储器的 FMC 控制器
- 双模式 QSPI
- SD/MMC/SDIO 支持
- 以太网控制器
- USB OTFG FS & HS 控制器
- I2C、SPI、CAN 总线支持
- 多个 16 位与 32 位通用定时器
- 串行音频接口
- LCD 控制器
- HDMI-CEC
- SPDIFRX
- DFSDM
