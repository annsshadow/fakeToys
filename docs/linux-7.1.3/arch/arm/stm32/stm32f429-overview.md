## STM32F429 概述


### 简介


STM32F429 是一款面向多种应用的 Cortex-M4 MCU。其特性包括：

- ARM Cortex-M4，最高 180MHz，带 FPU
- 2MB 内部 Flash 存储器
- 通过 FMC 控制器支持外部存储器（PSRAM、SDRAM、NOR、NAND）
- I2C、SPI、SAI、CAN、USB OTG、Ethernet 控制器
- LCD 控制器与摄像头接口
- 加密处理器
