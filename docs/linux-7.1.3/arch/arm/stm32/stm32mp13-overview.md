## STM32MP13 概述


### 简介


STM32MP131/STM32MP133/STM32MP135 是面向各种应用的 Cortex-A MPU。它们具有以下特性：

- 一个 Cortex-A7 应用核
- 标准存储器接口支持
- 标准连接性，广泛继承自 STM32 MCU 系列
- 全面的安全支持

更多细节：

- Cortex-A7 核心运行频率最高达 900MHz
- 用于连接 SDRAM、NOR 和 NAND 存储器的 FMC 控制器
- QSPI
- SD/MMC/SDIO 支持
- 2 个以太网控制器
- CAN
- ADC/DAC
- USB EHCI/OHCI 控制器
- USB OTG
- I2C、SPI、CAN 总线支持
- 多个通用定时器
- 串行音频接口
- LCD 控制器
- DCMIPP
- SPDIFRX
- DFSDM
