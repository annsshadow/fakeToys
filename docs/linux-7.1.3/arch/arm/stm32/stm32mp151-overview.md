## STM32MP151 概述


### 简介


STM32MP151 是面向各种应用的 Cortex-A MPU。它具有以下特性：

- 单个 Cortex-A7 应用核
- 标准存储器接口支持
- 标准连接性，广泛继承自 STM32 MCU 系列
- 全面的安全支持

更多细节：

- 运行频率最高达 800MHz 的 Cortex-A7 核心
- 用于连接 SDRAM、NOR 和 NAND 存储器的 FMC 控制器
- QSPI
- SD/MMC/SDIO 支持
- 以太网控制器
- ADC/DAC
- USB EHCI/OHCI 控制器
- USB OTG
- I2C、SPI 总线支持
- 多个通用定时器
- 串行音频接口
- LCD-TFT 控制器
- DCMIPP
- SPDIFRX
- DFSDM
