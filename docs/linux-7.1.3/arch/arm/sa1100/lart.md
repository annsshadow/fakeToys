## Linux 高级无线电终端（LART）


LART 是一块小型（7.5 x 10cm）SA-1100 板，专为嵌入式应用而设计。它拥有 32MB DRAM、4MB Flash ROM、双 RS232 以及所有其他 StrongARM 附件。几乎所有 SA 信号都可通过多个连接器直接访问。电源支持 3.5V 到 16V 的电压，并留有余量以支持一系列子板（daughterboard）。一个四口以太网 / IDE / PS2 / 声音子板正在开发中，还有大量其他子板处于不同的规划阶段。

该板的硬件设计已以开放许可证发布；更多信息请参见 LART 页面：http://www.lartmaker.nl/。
