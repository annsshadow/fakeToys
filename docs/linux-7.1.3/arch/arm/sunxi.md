## ARM Allwinner SoC

本文档列出 Linux 内核主线支持的 ARM Allwinner（SunXi）系列 SoC，并按 Cortex-A7/A8/A20/A31 等具体型号提供数据手册与用户手册链接，供嵌入式平台移植与硬件选型参考。



本文档列出当前由 Linux 内核主线支持的所有 ARM Allwinner SoC。本文档还会提供这些
SoC 的文档和/或数据手册链接。
