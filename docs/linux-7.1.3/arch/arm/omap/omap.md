## OMAP 历史


本文件包含有关在 omaps 上运行主线内核的文档。

KERNEL		NEW DEPENDENCIES
======		======================================================

		使 MMC1 能够正常工作。

		使基于 DRA7 和 K2G 的板卡上所有 MMC 实例都能工作。
