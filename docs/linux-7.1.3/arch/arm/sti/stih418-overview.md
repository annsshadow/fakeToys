## STiH418 概述


### 简


    STiH418 是面UHDp60 机顶盒以及卫星、有线、地面和 IP-STB 市场的服务器/连接客户端应用的新一SoC

    特
    - ARM Cortex-A9 1.5 GHz quad core CPU (28nm)
    - SATA2, USB 3.0, PCIe, Gbit Ethernet
    - HEVC L5.1 Main 10
    - VP9
