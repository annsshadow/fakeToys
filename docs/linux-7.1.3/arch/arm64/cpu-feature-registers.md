## ARM64 CPU 特性寄存器

本文件说明 ARM64 架构下将 CPU 特性寄存器（ID 寄存器）通过 HWCAP_CPUID 导出到用户空间的 ABI，描述其动机、安全约束与可见寄存器列表，供应用程序在运行时探测 CPU 能力时参考。



Author: Suzuki K Poulose <suzuki.poulose@arm.com>


本文件描述了将 AArch64 CPU ID/特性寄存器导出到用户空间的 ABI。该 ABI 的可用性通过 HWCAPs 中的 HWCAP_CPUID 对外通告。

### 1. 动机


ARM 架构定义了一组特性寄存器，用于描述 CPU/系统的能力。对这些系统寄存器的访问在 EL0 受限，应用程序没有可靠的方法提取这些信息以在运行时做出更好的决策。虽然应用程序可以通过 HWCAPs 获取有限的信息，但其使用存在一些问题。

 a) 对 HWCAPs 的任何更改都需要更新用户空间（例如 libc）才能检测到新变化，而这些更新可能需要很长时间才能进入各发行版。导出这些寄存器使应用程序无需更新工具链即可获取信息。

 b) 对 HWCAPs 的访问有时受限（例如在 libc 之前，或在启动时 ld 初始化期间）。

 c) HWCAPs 无法有效表示非布尔型信息。架构为在 ID 寄存器中表示特性定义了规范格式；该格式定义明确，能够表示所有有效的架构变体。


### 2. 要求


 a) 安全性：

    应用程序应当能够使用该基础设施提供的信息在整个系统上安全运行。这在具有异构 CPU 的系统上意义更为重大。该基础设施导出一个在系统所有可用 CPU 上都安全的值。

    例如，如果至少有一个 CPU 未实现 CRC32 指令，而其他 CPU 实现了，我们就应报告 CRC32 未实现。否则，当应用程序被调度到不支持 CRC32 的 CPU 上时可能会崩溃。

 b) 安全性：

    应用程序只能接收与用户空间正常操作相关的信息。因此，部分字段被屏蔽（即设为不可见），其值被设置为表示该特性“不支持”。可见特性列表见第 4 节。此外，内核可能根据自身所支持的功能来操纵这些字段。例如，如果内核不支持 FP，则这些值可能指示 FP 不可用（即便 CPU 提供了该能力）。

 c) 实现定义特性

    该基础设施不导出任何按 ARMv8-A 架构定义为 IMPLEMENTATION DEFINED 的寄存器。

 d) CPU 识别：

    导出 MIDR_EL1 以帮助识别处理器。在异构系统上，这可能存在竞态（就像 getcpu() 一样）。在进程使用寄存器值时，它可能已被迁移到另一个 CPU，除非设置了 CPU 亲和性。因此，无法保证该值反映其当前正在执行的 CPU。受此限制，REVIDR 和 AIDR 不被导出，因为这些寄存器只有与 MIDR 配合使用才有意义。或者，MIDR_EL1、REVIDR_EL1 和 AIDR_EL1 通过以下路径导出
```

	/sys/devices/system/cpu/cpu$ID/regs/identification/
	                                              \- midr_el1
	                                              \- revidr_el1
	                                              \- aidr_el1

```
### 3. 实现


该基础设施建立在 'MRS' 指令的模拟之上。从应用程序访问受限的系统寄存器会产生异常，并最终向进程发送 SIGILL。如果来源属于受支持的系统寄存器空间，该基础设施会挂入异常处理程序并模拟该操作。

```

	Op0=3, Op1=0, CRn=0, CRm=0,2,3,4,5,6,7

```
（有关寄存器列表，请参阅 ARMv8 ARM DDI 0487A.h 中的表 C5-6 “非调试系统寄存器访问的系统指令编码”。）

下列规则应用于该基础设施返回的值：

 a) 'IMPLEMENTATION DEFINED' 字段的值设为 0。
 b) 保留字段的值填入架构定义的保留值。
 c) 'visible'（可见）字段的值为该特定特性的系统范围内安全值（MIDR_EL1 除外，见第 4 节）。
 d) 所有其他字段（即不可见字段）被设为指示该特性缺失（按架构定义）。

```
  #include <asm/hwcap.h>
  #include <stdio.h>
  #include <sys/auxv.h>

  #define get_cpu_ftr(id) ({					\
		unsigned long __val;				\
		asm("mrs %0, "#id : "=r" (__val));		\
		printf("%-20s: 0x%016lx\n", #id, __val);	\
	})

  int main(void)
  {

	if (!(getauxval(AT_HWCAP) & HWCAP_CPUID)) {
		fputs("CPUID registers unavailable\n", stderr);
		return 1;
	}

	get_cpu_ftr(ID_AA64ISAR0_EL1);
	get_cpu_ftr(ID_AA64ISAR1_EL1);
	get_cpu_ftr(ID_AA64MMFR0_EL1);
	get_cpu_ftr(ID_AA64MMFR1_EL1);
	get_cpu_ftr(ID_AA64PFR0_EL1);
	get_cpu_ftr(ID_AA64PFR1_EL1);
	get_cpu_ftr(ID_AA64DFR0_EL1);
	get_cpu_ftr(ID_AA64DFR1_EL1);

	get_cpu_ftr(MIDR_EL1);
	get_cpu_ftr(MPIDR_EL1);
	get_cpu_ftr(REVIDR_EL1);

  #if 0
	/* Unexposed register access causes SIGILL */
	get_cpu_ftr(ID_MMFR0_EL1);
  #endif

	return 0;
  }

```
