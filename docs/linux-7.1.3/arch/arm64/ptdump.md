## 内核页表转储


ptdump 是一个 debugfs 接口，提供内核页表的详细转储。它以人类可读的格式，全面展示了内核虚拟内存布局，以及各个区域相关联的属性。转储内核页表有助于验证权限和内存类型。检查页表项及其权限有助于识别潜在的安全漏洞，例如具有过于宽松访问权限的映射或不恰当的 memory 保护。

内存热插拔允许在不重启系统的情况下动态扩展或收缩可用内存。为了保持内存管理数据结构的一致性和完整性，arm64 以写模式使用 `mem_hotplug_lock` 信号量。此外，在读模式下，`mem_hotplug_lock` 支持 `get_online_mems()` 和 `put_online_mems()` 的高效实现。它们保护被 ptdump 代码访问的内存不被下线。

为了转储内核页表，请启用以下
```

 CONFIG_PTDUMP_DEBUGFS=y

 mount -t debugfs nodev /sys/kernel/debug
 cat /sys/kernel/debug/kernel_page_tables

```
通过分析 `cat /sys/kernel/debug/kernel_page_tables` 的输出，可以获取关于该表项的虚拟地址范围、该表项所覆盖的内存区域大小、页表的层级结构，以及每个页相关联属性的信息。页属性提供了关于访问权限、执行能力、映射类型（如叶子级 PTE 或块级 PGD、PMD 和 PUD）以及页在内核内存中访问状态的信息。评估这些属性有助于理解内核页的内存布局、访问模式和安全特征。
