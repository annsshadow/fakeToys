
## VCPU 分派统计


对于共享处理器（Shared Processor）LPAR，POWER 管理程序（Hypervisor）维护着 LPAR 处理器（vcpu）到物理处理器芯片（代表“home”节点）的相对静态映射，并尽量总是在其关联的物理处理器芯片上分派 vcpu。然而，在某些场景下，vcpu 可能会在另一个处理器芯片上分派（偏离其 home 节点）。

可以使用 /proc/powerpc/vcpudispatch_stats 获取与 vcpu 分派行为相关的统计信息。向该文件写入 '1' 可启用统计收集，而写入 '0' 则禁用统计。默认情况下，每个 vcpu 的 DTLB 日志每秒处理 50 次，以免遗漏任何条目。该处理频率可通过 /proc/powerpc/vcpudispatch_stats_freq 更改。

这些统计信息本身可通过读取 procfs 文件 /proc/powerpc/vcpudispatch_stats 获得。输出中的每一行对应一个 vcpu，由第一个字段表示，其后跟随 8 个数字。

第一个数字对应：

1. 自统计收集开始以来 vcpu 的总分派次数

接下来的 4 个数字表示 vcpu 分派的分散情况：

2. 本次 vcpu 与上次在同一处理器上分派的次数
3. 本次 vcpu 与上次在不同处理器核上、但在同一芯片内分派的次数
4. 本次 vcpu 在不同芯片上分派的次数
5. 本次 vcpu 在不同插槽/抽屉（下一个 numa 边界）上分派的次数

最后的 3 个数字表示与 vcpu 的 home 节点相关的统计：

6. 本次 vcpu 在其 home 节点（芯片）内分派的次数
7. 本次 vcpu 在不同节点上分派的次数
8. 本次 vcpu 在更远的节点（numa 距离）上分派的次数

```

    $ sudo cat /proc/powerpc/vcpudispatch_stats
    cpu0 6839 4126 2683 30 0 6821 18 0
    cpu1 2515 1274 1229 12 0 2509 6 0
    cpu2 2317 1198 1109 10 0 2312 5 0
    cpu3 2259 1165 1088 6 0 2256 3 0
    cpu4 2205 1143 1056 6 0 2202 3 0
    cpu5 2165 1121 1038 6 0 2162 3 0
    cpu6 2183 1127 1050 6 0 2180 3 0
    cpu7 2193 1133 1052 8 0 2187 6 0
    cpu8 2165 1115 1032 18 0 2156 9 0
    cpu9 2301 1252 1033 16 0 2293 8 0
    cpu10 2197 1138 1041 18 0 2187 10 0
    cpu11 2273 1185 1062 26 0 2260 13 0
    cpu12 2186 1125 1043 18 0 2177 9 0
    cpu13 2161 1115 1030 16 0 2153 8 0
    cpu14 2206 1153 1033 20 0 2196 10 0
    cpu15 2163 1115 1032 16 0 2155 8 0

```
在上述输出中，对于 vcpu0，自启用统计以来共发生了 6839 次分派。其中 4126 次与上次在同一物理 cpu 上分派。2683 次在不同核上、但在同一芯片内分派，而 30 次与上次分派相比发生在不同芯片上。

此外，在总共 6839 次分派中，我们看到有 6821 次发生在该 vcpu 的 home 节点上，而 18 次发生在 home 节点之外、相邻的芯片上。
