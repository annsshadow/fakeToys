## CPU 系列


本文档试图总结 arch/powerpc 中存在并受支持的一些不同 CPU 系列。


### Book3S（又称 sPAPR）


- 哈希 MMU（603 和 e300 除外）
- Radix MMU（POWER9 及以后）
- 软件加载的 TLB（603 和 e300）
- 除哈希 MMU 外可选的软件加载 TLB（755、7450、e600）
