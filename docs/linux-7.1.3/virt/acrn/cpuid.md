
## ACRN CPUID 位


在 ACRN 虚拟机管理程序上运行的来宾 VM 可以使用以下命令检查其某些功能
CPUID。

ACRN cpuid 功能有：

功能：0x40000000

```

   eax = 0x40000010
   ebx = 0x4e524341
   ecx = 0x4e524341
   edx = 0x4e524341

```
请注意，ebx、ecx 和 edx 中的该值对应于字符串
“ACRNACRNACRN”。 eax中的值对应最大cpuid函数
存在于此叶子中，如果在叶子中添加更多功能，将会更新
未来。

功能：定义 ACRN_CPUID_FEATURES (0x40000001)

```

          ebx, ecx, edx
          eax = an OR'ed group of (1 << flag)

```
其中`flag`定义如下：

================================= =========== ================================
标志值含义
================================= =========== ================================
ACRN_FEATURE_PRIVILEGED_VM 0 来宾虚拟机是特权虚拟机
================================= =========== ================================

功能：0x40000010

```

          ebx, ecx, edx
          eax = (Virtual) TSC frequency in kHz.

```
