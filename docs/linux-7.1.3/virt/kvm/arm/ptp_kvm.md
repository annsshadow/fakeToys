
## arm/arm64 上的 PTP_KVM 支持

本页描述ARM/ARM64 架构上通过 KVM hypercall 实现PTP_KVM 高精度时间同步机制，说明其用于在宿主机与客户机间传递墙上时钟与计数器值的接口及参数、返回值定义



PTP_KVM 用于主机与客户机之间的高精度时间同步。它依赖于通过 KVM 特定hypercall，将墙上时钟（wall clock）和计数器值从主机传输到客户机

### ``ARM_SMCCC_VENDOR_HYP_KVM_PTP_FUNC_ID``


检索特定计数器的当前时间信息。没有字节序（endianness）限制

+---------------------+-------------------------------------------------------+
| 是否存在          | 可选（Optional                                      |
+---------------------+-------------------------------------------------------+
| 调用约定| HVC32                                                 |
+---------------------+----------+--------------------------------------------+
| 功能 ID       | (uint32) | 0x86000001                                 |
+---------------------+----------+----+---------------------------------------+
| 参数         | (uint32) | R1 | `KVM_PTP_VIRT_COUNTER (0)`          |
|                     |          |    +---------------------------------------+
|                     |          |    | `KVM_PTP_PHYS_COUNTER (1)`          |
+---------------------+----------+----+---------------------------------------+
| 返回值：      | (int32)  | R0 | 出错时为 `NOT_SUPPORTED (-1)`，否则为 |
|                     |          |    | 墙上时钟时间的高 32                 |
|                     +----------+----+---------------------------------------+
|                     | (uint32) | R1 | 墙上时钟时间的低 32                 |
|                     +----------+----+---------------------------------------+
|                     | (uint32) | R2 | 计数器的32                       |
|                     +----------+----+---------------------------------------+
|                     | (uint32) | R3 | 计数器的32                       |
+---------------------+----------+----+---------------------------------------+
