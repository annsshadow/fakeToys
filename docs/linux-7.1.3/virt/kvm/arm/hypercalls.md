
## KVM/arm64 向客户机暴露的特hypercall

本文记录 KVM/arm64 向客户机操作系统暴露的特hypercall，依Arm SMC 调用约定（DEN0028/C）以 HVC 指令发出，列出各 hypercall 的调用约定、功ID 与参数，arm64 虚拟化与 KVM 开发者参考

本文档记录了 KVM/arm64 可能向客户机操作系统暴露KVM/arm64 特定hypercall。这hypercall 依据 Arm SMC 调用约定（DEN0028/C.1 版，使用 HVC 指令发出

https://developer.arm.com/docs/den0028/c

所KVM/arm64 特定hypercall 都分配在 “Vendor Specific Hypervisor Service Call”（供应商特定的管理程序服务调用）范围内，其 UID `28b46fb6-2ec5-11e9-a9ca-4b564d003a74`。客户机应当使用该服务范围内标准“Call UID函数来查询此 UID，以确定 KVM/arm64 特定hypercall 是否可用

### ``ARM_SMCCC_VENDOR_HYP_KVM_FEATURES_FUNC_ID``

为其KVM/arm64 hypercall 提供一种发现机制

+---------------------+-------------------------------------------------------------+
| Presence:           | KVM/arm64 UID 强制要求                                      |
+---------------------+-------------------------------------------------------------+
| Calling convention: | HVC32                                                       |
+---------------------+----------+--------------------------------------------------+
| Function ID:        | (uint32) | 0x86000000                                       |
+---------------------+----------+--------------------------------------------------+
| Arguments:          | 鏃?                                                       |
+---------------------+----------+----+---------------------------------------------+
| Return Values:      | (uint32) | R0 | 可用函数0-31 的位                     |
|                     +----------+----+---------------------------------------------+
|                     | (uint32) | R1 | 可用函数32-63 的位                    |
|                     +----------+----+---------------------------------------------+
|                     | (uint32) | R2 | 可用函数64-95 的位                    |
|                     +----------+----+---------------------------------------------+
|                     | (uint32) | R3 | 可用函数96-127 的位                   |
+---------------------+----------+----+---------------------------------------------+

### ``ARM_SMCCC_VENDOR_HYP_KVM_PTP_FUNC_ID``

参见 ptp_kvm.rst

### ``ARM_SMCCC_KVM_FUNC_HYP_MEMINFO``

查询 pKVM 受保护虚拟机的内存保护参数

+---------------------+-------------------------------------------------------------+
| Presence:           | 可选；仅限 pKVM 受保护客户机                             |
+---------------------+-------------------------------------------------------------+
| Calling convention: | HVC64                                                       |
+---------------------+----------+--------------------------------------------------+
| Function ID:        | (uint32) | 0xC6000002                                       |
+---------------------+----------+----+---------------------------------------------+
| Arguments:          | (uint64) | R1 | 保留 / 必须为零                              |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R2 | 保留 / 必须为零                              |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R3 | 保留 / 必须为零                              |
+---------------------+----------+----+---------------------------------------------+
| Return Values:      | (int64)  | R0 | 出错时为 `INVALID_PARAMETER (-3)`，否  |
|                     |          |    | 为内存保护粒度（字节数）                       |
+---------------------+----------+----+---------------------------------------------+

### ``ARM_SMCCC_KVM_FUNC_MEM_SHARE``

KVM 主机共享一个内存区域，授予其读、写和执行权限。该区域的大小等于由 `ARM_SMCCC_KVM_FUNC_HYP_MEMINFO` 通告的内存保护粒度

+---------------------+-------------------------------------------------------------+
| Presence:           | 可选；仅限 pKVM 受保护客户机                             |
+---------------------+-------------------------------------------------------------+
| Calling convention: | HVC64                                                       |
+---------------------+----------+--------------------------------------------------+
| Function ID:        | (uint32) | 0xC6000003                                       |
+---------------------+----------+----+---------------------------------------------+
| Arguments:          | (uint64) | R1 | 要共享的内存区域的基地址 IPA                |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R2 | 保留 / 必须为零                              |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R3 | 保留 / 必须为零                              |
+---------------------+----------+----+---------------------------------------------+
| Return Values:      | (int64)  | R0 | `SUCCESS (0)`                             |
|                     |          |    +---------------------------------------------+
|                     |          |    | `INVALID_PARAMETER (-3)`                  |
+---------------------+----------+----+---------------------------------------------+

### ``ARM_SMCCC_KVM_FUNC_MEM_UNSHARE``

撤销 KVM 主机对先前由 `ARM_SMCCC_KVM_FUNC_MEM_SHARE` 共享的内存区域的访问权限。该区域的大小等于由 `ARM_SMCCC_KVM_FUNC_HYP_MEMINFO` 通告的内存保护粒度

+---------------------+-------------------------------------------------------------+
| Presence:           | 可选；仅限 pKVM 受保护客户机                             |
+---------------------+-------------------------------------------------------------+
| Calling convention: | HVC64                                                       |
+---------------------+----------+--------------------------------------------------+
| Function ID:        | (uint32) | 0xC6000004                                       |
+---------------------+----------+----+---------------------------------------------+
| Arguments:          | (uint64) | R1 | 要取消共享的内存区域的基地址 IPA            |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R2 | 保留 / 必须为零                              |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R3 | 保留 / 必须为零                              |
+---------------------+----------+----+---------------------------------------------+
| Return Values:      | (int64)  | R0 | `SUCCESS (0)`                             |
|                     |          |    +---------------------------------------------+
|                     |          |    | `INVALID_PARAMETER (-3)`                  |
+---------------------+----------+----+---------------------------------------------+

### ``ARM_SMCCC_KVM_FUNC_MMIO_GUARD``

请求将由管理程序将一个给定内存区域作MMIO 处理，允许对该区域的访问KVM 主机模拟。该区域的大小等于由 `ARM_SMCCC_KVM_FUNC_HYP_MEMINFO` 通告的内存保护粒度

+---------------------+-------------------------------------------------------------+
| Presence:           | 可选；仅限 pKVM 受保护客户机                             |
+---------------------+-------------------------------------------------------------+
| Calling convention: | HVC64                                                       |
+---------------------+----------+--------------------------------------------------+
| Function ID:        | (uint32) | 0xC6000007                                       |
+---------------------+----------+----+---------------------------------------------+
| Arguments:          | (uint64) | R1 | MMIO 内存区域的基地址 IPA                   |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R2 | 保留 / 必须为零                              |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R3 | 保留 / 必须为零                              |
+---------------------+----------+----+---------------------------------------------+
| Return Values:      | (int64)  | R0 | `SUCCESS (0)`                             |
|                     |          |    +---------------------------------------------+
|                     |          |    | `INVALID_PARAMETER (-3)`                  |
+---------------------+----------+----+---------------------------------------------+

### ``ARM_SMCCC_VENDOR_HYP_KVM_DISCOVER_IMPL_VER_FUNC_ID``

+---------------------+-------------------------------------------------------------+
| Presence:           | 可选；仅限 KVM/ARM64 客户                                |
+---------------------+-------------------------------------------------------------+
| Calling convention: | HVC64                                                       |
+---------------------+----------+--------------------------------------------------+
| Function ID:        | (uint32) | 0xC6000040                                       |
+---------------------+----------+--------------------------------------------------+
| Arguments:          | 鏃?                                                       |
+---------------------+----------+----+---------------------------------------------+
| Return Values:      | (int64)  | R0 | `SUCCESS (0)`                             |
|                     |          |    +---------------------------------------------+
|                     |          |    | `NOT_SUPPORTED (-1)`                      |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R1 | Bits [63:32] 保留/必须为零                   |
|                     |          |    +---------------------------------------------+
|                     |          |    | Bits [31:16] 主版本号                       |
|                     |          |    +---------------------------------------------+
|                     |          |    | Bits [15:0] 次版本号                        |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R2 | 目标实现的数                             |
|                     +----------+----+---------------------------------------------+
|                     | (uint64) | R3 | 保留 / 必须为零                              |
+---------------------+----------+----+---------------------------------------------+

|                     | (uint64) | R1 | 所选实现的 MIDR_EL1                         |
