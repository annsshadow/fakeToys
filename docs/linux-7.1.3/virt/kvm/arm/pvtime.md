
## arm64 的半虚拟化时间支持


Arm 规范 DEN0057/A 定义了面向 AArch64 客户机的半虚拟化时间支持标准：

https://developer.arm.com/docs/den0057/a

KVM/arm64 通过提供一些 hypervisor 服务调用，实现了该规范中“被窃取时间”（stolen time）
部分，以支持半虚拟化客户机获取其执行时间被窃取多少的视图。

定义了两个新的兼容 SMCCC 的超级调用（hypercall）：

- PV_TIME_FEATURES: 0xC5000020
- PV_TIME_ST:       0xC5000021

这些仅在 SMC64/HVC64 调用约定下可用，因为半虚拟化时间对 32 位 Arm 客户机不可用。
在调用 PV_TIME_FEATURES 之前，应使用 SMCCC 1.1 的 ARCH_FEATURES 机制探测其是否存在。

PV_TIME_FEATURES

    ============= ========    =================================================
    Function ID:  (uint32)    0xC5000020
    PV_call_id:   (uint32)    要查询是否支持的函数。
                              目前仅支持 PV_TIME_ST。
    Return value: (int64)     NOT_SUPPORTED (-1) 或 SUCCESS (0)，取决于相关
                              PV-time 特性是否被 hypervisor 支持。
    ============= ========    =================================================

PV_TIME_ST

    ============= ========    ==============================================
    Function ID:  (uint32)    0xC5000021
    Return value: (int64)     此 VCPU 的被窃取时间数据结构的 IPA。失败时：
                              NOT_SUPPORTED (-1)
    ============= ========    ==============================================

PV_TIME_ST 返回的 IPA 应由客户机映射为具有内、外写回缓存属性、位于内部可共享（inner
shareable）域的普通内存。hypervisor 保证从返回的 IPA 开始的共 16 字节会被有意义地填充
（见下方结构）。

PV_TIME_ST 返回调用 VCPU 的结构。

### 被窃取时间（Stolen Time）


PV_TIME_ST 超级调用所指向的结构如下：

+-------------+-------------+-------------+----------------------------+
| Field       | Byte Length | Byte Offset | Description                |
+=============+=============+=============+============================+
| Revision    |      4      |      0      | 版本 1.0 必须为 0          |
+-------------+-------------+-------------+----------------------------+
| Attributes  |      4      |      4      | 必须为 0                  |
+-------------+-------------+-------------+----------------------------+
| Stolen time |      8      |      8      | 以无符号纳秒表示的被窃取时间|
|             |             |             | 指示该 VCPU 线程在物理 CPU |
|             |             |             | 上被非自愿停止运行的时长。 |
+-------------+-------------+-------------+----------------------------+

结构中的所有值均以小端（little-endian）方式存储。

该结构将由 hypervisor 在调度 VCPU 之前更新。它将位于提供给客户机的普通内存中的一个保留
区域内。客户机不应尝试写入该内存。客户机的每个 VCPU 都有一个这样的结构。

建议预留一个或多个 64k 页用于这些结构，而不作他用，这样可使客户机使用 64k 页映射该区域，
并避免与其他内存产生属性冲突。

用户空间接口请见
Documentation/virt/kvm/devices/vcpu.rst <kvm_arm_vcpu_pvtime_ctrl>。
