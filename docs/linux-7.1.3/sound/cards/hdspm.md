=======================================
软件接口 ALSA-DSP MADI 驱动 
=======================================

（从德文翻译而来，所以英文不太好 ;-)）

2004 - winfried ritsch


驱动已添加了完整的功能。由于其中一些控件和启动选项是 ALSA 标准，下面只描述和讨论
特殊的控件。


## 硬件功能


### 音频传输


- 通道数 -- 取决于传输模式

		所选通道数范围为 1..Nmax。使用较少通道数的原因仅仅是为了资源分配，
		因为未使用的 DMA 通道会被禁用，分配的内存也更少。这样 PCI 系统的
		吞吐量也可以相应调整。（仅对低性能板卡重要）。

- 单速（Single Speed） -- 1..64 通道 

		 （注意：选择 56 通道模式用于传输或作为接收方时，MADI 上只传输/接收
		 56 个通道，但所有 64 个通道都对混音器可用，因此这是驱动的通道计数）

- 双速（Double Speed） -- 1..32 通道

		 注意：选择 56 通道模式用于传输/接收模式时，MADI 上只传输/接收
		 28 个通道，但所有 32 个通道都对混音器可用，因此这是驱动的通道计数

- 四速（Quad Speed） -- 1..16 通道 

		 选择 56 通道模式用于传输/接收模式时，MADI 上只传输/接收
		 14 个通道，但所有 16 个通道都对混音器可用，因此这是驱动的通道计数

- 格式 -- 带符号 32 位小端（SNDRV_PCM_FMTBIT_S32_LE）

- 采样率 --

       单速 -- 32000, 44100, 48000

       双速 -- 64000, 88200, 96000（未测试）

       四速 -- 128000, 176400, 192000（未测试）

- 访问模式 -- MMAP（内存映射），非交错（PCM_NON-INTERLEAVED）

- 缓冲区大小 -- 64,128,256,512,1024,2048,8192 采样

- 分片（fragments） -- 2

- 硬件指针 -- 2 种模式


		 该卡支持读出 DMA 读/写所在的当前缓冲区指针。由于 PCI 的批量（bulk）
		 模式，它只有 64 字节的精度。因此它对于 ALSA 中层函数并不是真正可用
		 （这里缓冲区 ID 能给出更好的结果），但如果应用程序使用了 MMAP。因此
		 它可以在加载时通过参数 precise-pointer 配置。


		 （提示：在实验中我发现指针最大会偏大 64，从不偏小。所以如果你减去 64，
		 总是能得到一个安全的写指针，ALSA 内部在此模式下就使用了这一点。理论上
		 现在你可以得到低至 16 个采样的延迟，这是中断可能性的四分之一。）

   - 精确指针 -- 关
				使用中断来计算指针

   - 精确指针 -- 开
				使用硬件指针。

### 控制器


由于 DSP-MADI-Mixer 有 8152 个推子（Fader），使用标准混音器控件没有意义，因为这会
破坏大多数（尤其是图形化的）ALSA 混音器 GUI。因此混音器控件必须由一个使用 hwdep 接口的
二维控制器来提供。

所有 128+256 个峰值（Peak）和 RMS 表也可以经由 hwdep 接口访问。由于即使你只需要一个，
也总是复制和转换峰值与 RMS 电平可能带来性能问题，我决定导出硬件结构，这样如果有需要，
某些驱动高手可以通过 ioctl 实现混音器或峰值表的存储器映射，或者只做复制而不做转换。一个
测试应用程序展示了该控制器的用法。

- 延迟控件 --- 未实现！！！

	   注意：在 Windows 驱动中延迟可以通过控制面板访问，但缓冲区大小由 ALSA 通过
	   hwparams 调用控制，不应在运行状态下更改，所以我在这里没有实现它。

- 系统时钟 -- 暂停！！！！

  - 名称 -- "System Clock Mode"

  - 访问 -- 读 写

  - 值 -- "Master" "Slave"

		  ！！！！这是一个硬件功能，但与 Clock-source 控制器冲突，后者是一种
		  ALSA 标准。将卡设置为特定模式（某个频率下的主模式或从模式）是有意义的，
		  因为即使不使用音频应用程序，一个工作室也应该有可工作的同步设置。所以
		  请改用 Clock-source-controller！！！！

- 时钟源（Clock Source）  

  - 名称 -- "Sample Clock Source"

  - 访问 -- 读 写

  - 值 -- "AutoSync", "Internal 32.0 kHz", "Internal 44.1 kHz",
    "Internal 48.0 kHz", "Internal 64.0 kHz", "Internal 88.2 kHz",
    "Internal 96.0 kHz"

		 在特定的主频率（从而也是速度模式）与从模式（Autosync）之间选择。另请
		 参见 "Preferred Sync Ref"

       ！！！！这不是一个纯粹的硬件功能，而是之前由一些 ALSA 驱动通过 ALSA 实现的，
       所以我也就使用了它。！！！

- 首选同步参考（Preferred Sync Ref）

  - 名称 -- "Preferred Sync Reference"

  - 访问 -- 读 写

  - 值 -- "Word" "MADI"

		 在自动同步模式下可以选择首选的同步源。如果它不可用，则在可能的情况下
		 使用另一个。

		 注意：由于 MADI 的比特率远高于字时钟（word-clock），卡在 MADI 模式下应该
		 能同步得更好。但由于 RME 的 PLL 非常好，字时钟也几乎没有什么问题。我从未
		 发现过区别。

- TX 64 通道

  - 名称 -- "TX 64 channels mode"

  - 访问 -- 读 写

  - 值 -- 0 1

		 使用 64 通道模式（1）还是 56 通道模式进行 MADI 传输（0）。

		 注意：该控件仅用于输出。输入模式由发送 MADI 的硬件自动检测。

- 清除 TMS

  - 名称 -- "Clear Track Marker"

  - 访问 -- 读 写

  - 值 -- 0 1

		 不要在 AES 上将较低的 5 个音频位用作额外的位。

- 安全模式或自动输入（Safe Mode oder Auto Input）

  - 名称 -- "Safe Mode"

  - 访问 -- 读 写

  - 值 -- 0 1（默认开）

		 如果开启（1），那么当光纤或同轴连接之一发生故障时，会切换到正常工作的
		 那一个，且没有采样丢失。只有当你把第二个用作备份连接时它才有用。

- 输入（Input）

  - 名称 -- "Input Select"

  - 访问 -- 读 写

  - 值 -- optical coaxial

		 选择输入，光纤或同轴。如果安全模式处于活动状态，这是首选输入。

### 混音器


- 混音器（Mixer）

  - 名称 -- "Mixer"

  - 访问 -- 读 写

  - 值 - <通道号 0-127> <值 0-65535>

		 这里第一个值取通道索引，用于获取/设置相应的混音器通道，其中 0-63 是
		 输入到输出的推子，64-127 是回放到输出的推子。值 0 表示通道静音，32768
		 表示放大 1 倍。

- 通道 1-64（Chn 1-64）

       用于 ALSA 混音器工具的快速混音器。混音器矩阵的对角线从回放实现到输出。

- 线路输出（Line Out）

  - 名称  -- "Line Out"

  - 访问 -- 读 写

  - 值 -- 0 1

		 打开和关闭模拟输出，这与混音或路由无关。模拟输出反映的是通道 63、64。

### 信息（仅读访问）


- 采样率（Sample Rate）

  - 名称 -- "System Sample Rate"

  - 访问 -- 只读

		 获取采样率。

- 测量的外部速率（External Rate measured）

  - 名称 -- "External Rate"

  - 访问 -- 只读

		 本应是 "Autosync Rate"，但使用的名称遵循 ALSA 方案。报告自动同步时使用的
		 外部采样频率。

- MADI 同步状态（MADI Sync Status）

  - 名称 -- "MADI Sync Lock Status"

  - 访问 -- 读

  - 值 -- 0,1,2

       MADI 输入为 0=未锁定, 1=已锁定, 或 2=已同步。

- 字时钟同步状态（Word Clock Sync Status）

  - 名称 -- "Word Clock Lock Status"

  - 访问 -- 读

  - 值 -- 0,1,2

       字时钟输入为 0=未锁定, 1=已锁定, 或 2=已同步。

- 自动同步（AutoSync）

  - 名称 -- "AutoSync Reference"

  - 访问 -- 读

  - 值 -- "WordClock", "MADI", "None"

		 同步参考要么是 "WordClock"、"MADI" 或 none。

- RX 64ch --- 尚未实现

       MADI 接收器处于 64 通道模式或 56 通道模式。

- AB_inp   --- 未测试 

		 用于自动输入的输入。

- 实际缓冲区位置（actual Buffer Position） --- 未实现

	   ！！！这是一个 ALSA 内部函数，所以不使用控件！！！


## 调用参数


- index int 数组（min = 1, max = 8） 

     RME HDSPM 接口的索引值。ALSA 内的卡索引

     注意：ALSA 标准

- id string 数组（min = 1, max = 8） 

     RME HDSPM 接口的 ID 字符串。

     注意：ALSA 标准

- enable int 数组（min = 1, max = 8）

     启用/禁用特定的 HDSPM 声卡。

     注意：ALSA 标准

- precise_ptr int 数组（min = 1, max = 8）

     启用或禁用精确指针。

     注意：仅在应用程序支持时使用（这是一种特殊情况）。

- line_outs_monitor int 数组（min = 1, max = 8）

     默认将回放流发送到模拟输出。

	  注意：每个回放通道被混音到相同编号的输出通道（路由）。这违背了 ALSA 约定，
	  即加载驱动后所有通道必须被静音，但之前在其他卡上用过，所以出于历史原因我
	  再次使用了它）

- enable_monitor int 数组（min = 1, max = 8）

     默认在通道 63/64 上启用模拟输出。

      注意：这里模拟输出被启用（但未路由）。
