## ALSA BT87x 驱动


## 简

你可能已经注意到，bt878 采集卡实际上*两个** PCI 功能
```

  $ lspci
  [ ... ]
  00:0a.0 Multimedia video controller: Brooktree Corporation Bt878 (rev 02)
  00:0a.1 Multimedia controller: Brooktree Corporation Bt878 (rev 02)
  [ ... ]

```
第一个负责视频，它向后兼bt848。第二个负责音频。snd-bt87x 是第二个功能的驱动它是一个声音驱动，可用于录制声音（并且***录制，不回放）。由于大多数电视卡附一条可以插入你声卡 line-in 的短线，如果你只是想看电视，可能并不需要这个驱动…
有些卡根本没有把任何东西连接到芯片的音频输入引脚上，而另一些卡则使用音频功能来
传输 MPEG 视频数据，因此你的卡的音频录制很可能无法工作

## 驱动状

驱动现在已稳定。不过，它并不了解许多电视卡，并且会拒绝为它不认识的卡加载
如果驱动报怨（“发现未知的电视卡，音频驱动将不会加载”），你可以指定 `load_all=1`
选项来强制驱动尝试使用你卡的音频采集功能。如果录制数据的频率不对，可以尝试指`digital_rate` 选项，使用默认32000 以外的值（通常44100 64000）
如果你有一张未知的卡，请将卡的 ID 与名称发送到 <alsa-devel@alsa-project.org>无论音频采集是否工作，以便此驱动的未来版本能够识别你的卡

## 音频模式


该芯片支持两种不同的模式（数模拟）。snd-bt87x 注册两个 PCM 设备，每种模式一个它们不能同时使用

## 数字音频模式


第一个设备（hw:X,0）提16 位立体声。采样率取决于通过 I2S 接口Bt87x 提供数字
声音的外部源

## 模拟音频模式（A/D

第二个设备（hw:X,1）提8 16 位单声道。支持的采样率在 119466 448000 Hz 之间
（是的，这些数字就是这么高）。如果你设置CONFIG_SND_BT87X_OVERCLOCK 选项，最采样率为 1792000 Hz，但在我的卡上，超过 896000 Hz 后音频数据就变得不可用了
该芯片有三个模拟输入。因此你会得到一个用于控制这些输入的音调（mixer）设备
