## HD-Audio 编解码器特定的混音器控制


本文档解释编解码器特定的混音器控制
### Realtek 编解码器


Channel Mode（通道模式  这是一个枚举控制，用于更改环绕声通道的设置，仅在环绕声通道可用时出现。它给出要使用的通道数，
  "2ch"4ch"6ch" "8ch"。根据配置，这也控制I/O 插孔的插孔重任务分配（jack-retasking）
Auto-Mute Mode（自动静音模式）
  这是一个枚举控制，用于更改耳机和线路输出插孔的自动静音行为。如果机器上有内置扬声器以及耳机  线路输出插孔，则会出现此控制。当只有耳机或线路输出插孔时，它给出 "Disabled" "Enabled" 状态  启用时，插入插孔会自动将扬声器静音
  当耳机和线路输出插孔都存在时，它给"Disabled"Speaker Only"（仅扬声器）"Line-Out+Speaker"
  （线路输扬声器）。选择仅扬声器时，插入耳机或线路输出插孔会静音扬声器，但不会静音线路输出。选择
  线路输出+扬声器时，插入耳机插孔会同时静音扬声器和线路输出

### IDT/Sigmatel 编解码器


Analog Loopback（模拟回环）
  此控制启禁用模拟回环电路。仅当在编解码器提示中将 "loopback" 设为 true 时才出现（参HD-Audio.txt）  注意，在某些编解码器上，模拟回环与正PCM 播放是互斥的，即开启此功能时你将听不到任何 PCM 流
Swap Center/LFE（交换中LFE  交换中置LFE 通道的顺序。通常，左声道对应中置，右声道对应 LFE。开启此功能时，左声道对LFE  右声道对应中置
Headphone as Line Out（耳机作为线路输出  当此控制开启时，将耳机插孔视为线路输出插孔。即，耳机不会自动静音其他线路输出，并且不会为引脚设置
  HP 放大器
Mic Jack Mode、Line Jack Mode   这些枚举控制输入插孔引脚的方向和偏置。根据插孔类型，可以设为 "Mic In" "Line In" 以确定输入偏置，
  或者当引脚是用于环绕声通道的多 I/O 插孔时，可以设为 "Line Out"

### VIA 编解码器


Smart 5.1
  一个枚举控制，用于将多 I/O 插孔重新分配为环绕声输出。开启时，相应的输入插孔（通常是一line-in   一mic-in）被切换为环绕声CLFE 输出插孔
Independent HP（独立耳机  当启用此枚举控制时，耳机输出从独立的流（第三PCM，如 hw:0,2）路由，而非主数据流。在耳机 DAC   侧面CLFE 通道 DAC 共享的情况下，DAC 会自动切换到耳机
Loopback Mixing（回环混音）
  一个枚举控制，用于确定是否启用模拟回环路由。启用时，模拟回环被混音到前置通道。同样的路由也用于耳机
  和扬声器输出。作为一个副作用，当设置此模式时，由于只有一DAC 连接到一个混音器部件，耳机和扬声器  独立音量控制将不再可用
Dynamic Power-Control（动态电源控制）
  此控制决定每个插孔检测的电源动态控制是否启用。启用时，部件电源状态（D0/D3）会根据插孔插入状态动  改变，以节省功耗。然而，如果你的系统不能提供适当的插孔检测，这将不起作用；在这种情况下，请关闭此控制
Jack Detect（插孔检测）
  此控制仅提供VT1708 编解码器，它不会为每个插孔插入提供适当的未经请求（unsolicited）事件。开启时  驱动轮询插孔检测，以便耳机自动静音可以工作，而关闭它将降低功耗
