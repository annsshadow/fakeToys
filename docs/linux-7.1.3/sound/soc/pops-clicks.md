## 音频爆音与咔嗒声（Pops and Clicks

爆音（pops）与咔嗒声（clicks）是由音频子系统内部组件的上下电引起的不期望的音频伪像（artifact）。当音频模块被加载或卸载时（模块加载时声卡上电，导致扬声器发出爆裂声），PC 上可以注意到这一点
在使DAPM 的便携系统上，爆音与咔嗒声可能更频繁。这是因为子系统内的组件会根据音频使用情况被动态上电，这随后可能在每次组件电源状态改变时引起轻微的爆音或咔嗒声

## 最小化回放爆音与咔嗒声


目前尚无法完全消除便携音频子系统中的回放爆音，不过未来的音频编解码（codec）硬件将具有更好的爆音与咔嗒声抑制能力。可以通过以特定顺序为音频组件上电来减少回放中的爆音。此顺序在启动与关闭时不同，并遵循一些基本规则：-
```

   Startup Order :- DAC --> Mixers --> Output PGA --> Digital Unmute

   Shutdown Order :- Digital Mute --> Output PGA --> Mixers --> DAC

```
这假设编解码 PCM 输出路径DAC 经过一个混音器（mixer），再经过一PGA（可编程增益放大器）后输出到扬声器

## 拉链噪声（Zipper Noise

当音量控制在其最大增益值附近改变时，音频回放或采集流中会出现不期望的拉链噪声。当增益增加或减少使平均音频信号幅度变化过快时，就会听到拉链噪声。可以通过为每个音量控制启用零交叉（zero cross）设置来将其最小化。ZC 强制增益变化发生在信号穿过零幅度线时
