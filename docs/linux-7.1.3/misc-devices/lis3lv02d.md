## 内核驱动 lis3lv02d


支持的设备：

  - STMicroelectronics LIS3LV02DL、LIS3LV02DQ（12 位精度）
  - STMicroelectronics LIS302DL、LIS3L02DQ、LIS331DL（8 位）以及
    LIS331DLH（16 位）

        - Yan Burman <burman.yan@gmail.com>
 - Eric Piel <eric.piel@tremplin-utc.net>


### 描述

该驱动为多种惠普笔记本中发现的加速度计提供支持，该特性官方称为“HP Mobile Data
Protection System 3D”或“HP 3D DriveGuard”。它会自动检测带有此传感器的笔记本。已知
型号（完整列表见 drivers/platform/x86/hp_accel.c）其坐标轴会自动按标准方式定向
（例如：你可以直接玩 neverball）。加速度计数据可通过 /sys/devices/faux/lis3lv02d
读取。报告的值被缩放为 mg 值（地球重力的 1/1000）。

/sys/devices/faux/lis3lv02d/ 下的 sysfs 属性：

position
      - 加速度计报告的 3D 位置。格式：“(x,y,z)”
rate
      - 读取时报告加速度计设备的采样率（单位 HZ）。
	写入时改变加速度计设备的采样率。
	只接受硬件支持的值。
selftest
      - 按芯片制造商的规范对芯片执行自检。

该驱动还提供一个绝对输入类设备，使笔记本能像弹球机式的摇杆一样工作。摇杆设备可
校准。摇杆设备可以处于两种不同的模式。默认情况下输出值在 -32768 .. 32767 之间缩放。
在摇杆 raw 模式下，摇杆与 sysfs position 条目使用相同的比例尺。由于输入系统的模糊
特性，二者可能存在微小差异。事件也可作为 input 事件设备提供。

自检仅用于硬件诊断目的。它不打算在正常操作期间使用。自检期间位置数据不会被破坏，
但中断行为不能保证可靠工作。在测试模式下，传感元件会在内部轻微移动。自检测量正常
模式与测试模式之间的差异。芯片规范给出了每种芯片的验收限值。限值通过平台数据提供，
以便在不修改实际驱动的情况下调整限值。Selftest 返回“OK x y z”或“FAIL x y z”，其中
x、y、z 是两种模式间测量到的差异。自检模式下坐标轴不会被重映射。测量值被提供给 HW
诊断应用程序，以辅助其做出最终判断。

在惠普笔记本上，如果 led 基础设施被激活，会提供指示磁盘保护的 led 支持，路径为
**/sys/class/leds/hp**：hddprotect。

该驱动的另一个特性是一个名为“freefall”的 misc 设备，它类似于 /dev/rtc，并对来自
设备的自由落体中断做出反应。它支持阻塞操作、poll/select 和 fasync 操作模式。你必须
从该设备读取 1 字节。结果是自上次成功读取以来的自由落体中断次数（如果中断次数过多
放不下则为 255）。使用示例参见 freefall.c 文件。


### 坐标轴朝向

为了在各种笔记本之间获得更好的兼容性，加速度计报告的值被转换为一种“标准”的坐标轴
组织方式（也就是“开箱即可玩 neverball”）：

 - 当笔记本水平放置时，报告的位置约在 X 和 Y 上为 0，Z 上为正值
 - 如果左侧被抬高，X 增大（变为正值）
 - 如果前侧（触摸板所在一侧）被抬高，Y 减小（变为负值）
 - 如果笔记本被倒置，Z 变为负值

如果你的笔记本型号未被识别（参见“dmesg”），可以给维护者发邮件将其加入数据库。报告
新笔记本时，请包含“dmidecode”的输出，以及上述四种情况下
/sys/devices/faux/lis3lv02d/position 的值。

### 问答

Q：我如何安全地模拟自由落体？我有一台惠普“便携工作站”，约 3.5kg，塑料外壳，因此
让它掉到地上根本不可能……

A：该传感器相当灵敏，你的手就能做到。把它举到空中，用手托住跟随意下落约 10 厘米。
这应当足以触发检测。
