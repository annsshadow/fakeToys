## 内核驱动 max6875


支持的芯片：

  - Maxim MAX6874、MAX6875

    Prefix: 'max6875'

    Addresses scanned: None（见下文

    Datasheet: http://pdfserv.maxim-ic.com/en/ds/MAX6874-MAX6875.pdf

作者：Ben Gardner <bgardner@wabtec.com>


### 描述


Maxim MAX6875 是一EEPROM 可编程的电源时序监控器。如果正确接线，它提供的定时输出可用作看门狗。它还提512 字节的用EEPROM

在复位时，MAX6875 将配EEPROM 读入其配置寄存器。然后芯片开始根据寄存器中的值运行

Maxim MAX6874 是一个类似、基本兼容的设备，具有更多的输入与输出：

===========  ===     ===    ====
- vin     gpi    vout
===========  ===     ===    ====
MAX6874        6       4       8
MAX6875        4       3       5
===========  ===     ===    ====

更多信息请参阅数据手册


### Sysfs 条目


eeprom        - 512 字节的用户定EEPROM 空间


### 一般说


MAX6875 的有效地址0x50 0x52

MAX6874 的有效地址0x50x52x54 0x56

该驱动不探测任何地址，因此你需要显式实例化设备

```

  $ modprobe max6875
  $ echo max6875 0x50 > /sys/bus/i2c/devices/i2c-0/new_device

```

MAX6874/MAX6875 忽略地址0，因此该驱动会附加到多个地址。例如，对于地址 0x50，它还会保留 0x51。偶数地址的实例称'max6875'，奇数地址的称'dummy'


### 使用 i2c-dev 编程芯片


使用 i2c-dev 接口访问并编程芯片

读写操作根据地址范围的不同而不同

配置寄存器位于地址 0x00 - 0x45

使用 i2c_smbus_write_byte_data() 写入寄存器，使用 i2c_smbus_read_byte_data() 读取寄存器

命令是寄存器编号

示例

```

  i2c_smbus_write_byte_data(fd, 0x45, 1);

```

```

  value = i2c_smbus_read_byte_data(fd, 0x45);


```

配置 EEPROM 位于地址 0x8000 - 0x8045

用户 EEPROM 位于地址 0x8100 - 0x82ff

使用 i2c_smbus_write_word_data() EEPROM 写入一个字节

命令是地址的高字节x80x81 0x82
```

  cmd = address >> 8;
  val = (address & 0xff) | (data << 8);

```

示例

```

  i2c_smbus_write_word_data(fd, 0x80, 0x5a03);


```

EEPROM 读取数据稍微复杂一些

使用 i2c_smbus_write_byte_data() 设置读取地址，然后使i2c_smbus_read_byte() i2c_smbus_read_i2c_block_data() 读取数据

示例

```

  i2c_smbus_write_byte_data(fd, 0x81, 0x00);

```

```

  value = i2c_smbus_read_byte(fd);

```

```

  count = i2c_smbus_read_i2c_block_data(fd, 0x84, 16, buffer);

```

块读取应读取 16 字节

0x84 是块读取命令

更多细节请参阅数据手册
