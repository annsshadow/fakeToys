## 内核驱动 isl29003


支持的芯片：

- Intersil ISL29003

前缀isl29003'

扫描地址：无

数据手册http://www.intersil.com/data/fn/fn7464.pdf

作者：Daniel Mack <daniel@caiaq.de>


### 描述

ISL29003 是一款集成光传感器，带有 16 位积分型 ADC、可由用户通过 I2C 编程lux 量程
选择（用于优计数/lux），以及 I2C 多功能控制与监控能力。内ADC 提供 16 位分辨率同时可抑制由人造光源引起的 50Hz 60Hz 闪烁
驱动允许设置 lux 量程、位分辨率、工作模式（见下文）以及设备的电源状态，当然也可读取当前lux 值

### 检

ISL29003 没有可用于识别它ID 寄存器，因此检测例程只会尝试从配置好的 I2C 地址
读取，一旦设备对传输返回 ACK，就认为设备存在

### Sysfs 条目


range:
        == ===========================
	0: 0 lux 1000 lux（默认）
	1: 0 lux 鑷?4000 lux
	2: 0 lux 鑷?16,000 lux
	3: 0 lux 鑷?64,000 lux
        == ===========================

resolution:
        == =====================
	0: 2^16 周期（默认）
	1: 2^12 周期
	2: 2^8 周期
	3: 2^4 周期
        == =====================

mode:
        == =================================================
	0: 二极的电流（无符16 位）（默认）
	1: 二极的电流（无符16 位）
	2: 两二极管之差（l1 - l2，有符号 15 位）
        == =================================================

power_state:
        == =================================================
	0: 设备被禁用（默认	1: 设备被启        == =================================================

lux（只读）	返回上一次传感器读取的
