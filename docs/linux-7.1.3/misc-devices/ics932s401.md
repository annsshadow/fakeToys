## 内核驱动 ics932s401


支持的芯片：

  - IDT ICS932S401

    前缀：'ics932s401'

    扫描的地址：I2C 0x69

    数据表：可在 IDT 网站上公开获取

作者：Darrick J. Wong

### 描述


该驱动程序实现对 IDT ICS932S401 芯片系列的支持。

该芯片有 4 个时钟输出——一个用于 CPU 的基准时钟（可能会被倍频以得到
真实的 CPU 时钟）、一个系统时钟、一个 PCI 时钟、一个 USB 时钟和一个
参考时钟。驱动程序报告所选频率和实际频率。如果启用了扩频模式，驱动
程序还会报告时钟信号被扩展的百分比，该值应介于 0 和 -0.5% 之间。所有
频率均以 KHz 报告。

ICS932S401 持续监控所有输入。驱动程序读取寄存器的频率不会高于每隔
一秒一次。
