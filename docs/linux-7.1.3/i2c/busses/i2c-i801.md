### 模块参数


- disable_features（位向量）

禁用该设备通常支持的选定功能。当某项功能由于驱动或硬件缺陷而无法按预期工作时，可用此选项规避问题。位取值如下：

 ====  =========================================
 0x01  禁用 SMBus PEC
 0x02  禁用块缓冲区
 0x08  禁用 I2C 块读取功能
 0x10  不使用中断
 0x20  禁用 SMBus Host Notify
 ====  =========================================


### 描述


ICH（正式名称为 82801AA）、ICH0（82801AB）、ICH2（82801BA）、ICH3（82801CA/CAM）以及后续设备（PCH）是 Intel 的芯片，属于 Intel 面向 Celeron 个人电脑的 '810' 芯片组、面向 Pentium 个人电脑的 '810E' 芯片组、'815E' 芯片组以及其他芯片组的一部分。

ICH 芯片在 TWO 个逻辑 PCI 设备中包含至少 SEVEN 个独立的 PCI 功能。lspci 的输出会显示类似如下的内容：

```
  00:1e.0 PCI bridge: Intel Corporation: Unknown device 2418 (rev 01)
  00:1f.0 ISA bridge: Intel Corporation: Unknown device 2410 (rev 01)
  00:1f.1 IDE interface: Intel Corporation: Unknown device 2411 (rev 01)
  00:1f.2 USB Controller: Intel Corporation: Unknown device 2412 (rev 01)
  00:1f.3 Unknown class [0c05]: Intel Corporation: Unknown device 2413 (rev 01)

```
SMBus 控制器是设备 1f 中的功能 3。类别 0c05 为 SMBus Serial Controller。

ICH 芯片至少在 SMBus 控制器方面与 Intel 的 PIIX4 芯片非常相似。


### 进程调用支持


块进程调用（Block process call）在 82801EB（ICH5）及更新的芯片上受支持。


### I2C 块读取支持


I2C 块读取在 82801EB（ICH5）及更新的芯片上受支持。


### SMBus 2.0 支持


82801DB（ICH4）及更新的芯片支持若干 SMBus 2.0 特性。


### 中断支持


PCI 中断支持在 82801EB（ICH5）及更新的芯片上受支持。


### 隐藏的 ICH SMBus


如果你的系统有一块 Intel ICH 南桥，但你在 lspci 中看不到位于 00:1f.3 的 SMBus 设备，并且在 BIOS 中也找不到任何启用它的方法，这意味着它已被 BIOS 代码隐藏。华硕（Asus）因在其 P4B 主板上率先这样做而闻名，其后许多其他主板也如此。部分厂商机器也受影响。

首先要尝试的是 “i2c-scmi” ACPI 驱动。有可能 SMBus 是有意被隐藏的，因为它将由 ACPI 来驱动。如果 i2c-scmi 驱动对你可用，那就没必要去管 i2c-i801 驱动，也不要尝试取消隐藏 ICH SMBus。即便 i2c-scmi 不可用，你也最好先确认 SMBus 没有被 ACPI 代码使用。尝试加载 “fan” 与 “thermal” 驱动，并查看 /sys/class/thermal。如果你发现了一个类型为 “acpitz” 的 thermal zone，则很可能是 ACPI 正在访问 SMBus，此时不取消隐藏会更安全。只有在你确定 ACPI 没有使用 SMBus 之后，才可以尝试将其取消隐藏。

为了取消隐藏 SMBus，我们需要在内核枚举 PCI 设备之前修改某个 PCI 寄存器的值。这由 drivers/pci/quirks.c 完成，其中必须列出所有受影响的板卡（参见函数 asus_hides_smbus_hostbridge）。如果 SMBus 设备缺失，而你认为 SMBus 上挂载着有趣的东西（例如一个硬件监控芯片），你需要将你的主板加入该列表。

主板通过如下输出的子厂商（subvendor）与子设备（subdevice）ID 来识别：

```
  00:00.0 Class 0600: 8086:2570 (rev 02)
          Subsystem: 1043:80f2
          Flags: bus master, fast devsel, latency 0
          Memory at fc000000 (32-bit, prefetchable) [size=32M]
          Capabilities: [e4] #09 [2106]
          Capabilities: [a0] AGP version 3.0

```
此处主桥 ID 为 2570（82865G/PE/P），子厂商 ID 为 1043（Asus），子设备 ID 为 80f2（P4P800-X）。你可以在 include/linux/pci_ids.h 中找到主桥 ID 与子厂商 ID 的符号名，然后在 drivers/pci/quirks.c 的合适位置为你的子设备 ID 添加一个 case。之后请充分测试，以确保取消隐藏的 SMBus 不会与例如 ACPI 发生冲突。

如果它有效、被证明有用（即 SMBus 上有可用的芯片）且看起来安全，请提交一个补丁以合入内核。

注意：在 lm_sensors 2.10.2 及更高版本中有一个有用的脚本，名为 unhide_ICH_SMBus（位于 prog/hotplug），它使用 fakephp 驱动临时取消隐藏 SMBus，而无需为内核打补丁并重新编译。如果你只是想确认隐藏的 ICH SMBus 上是否有有趣的东西，这会非常方便。
