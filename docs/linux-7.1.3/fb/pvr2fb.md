## pvr2fb - PowerVR 2 图形帧缓冲驱动


这是一个面向基于 PowerVR 2 的图形帧缓冲的驱动，例如 Dreamcast 中所使用的
那一个。

优点：

 - 它提供了一个漂亮的大控制台（1024x768 下 128 列 + 48 行），而无需
   使用又小又难以辨认的字体（在 Dreamcast 上除外）
 - 你可以在 /dev/fb0 之上运行 XF86_FBDev
 - 最重要的是：启动徽标 :-)

缺点：

 - 该驱动在非 Dreamcast 系统上基本未经测试。

## 配置


你可以通过内核命令行向 pvr2fb 传递选项：`video=pvr2fb:option1,option2:value2,option3`
（多个选项用逗号分隔，值与选项之间用 `:` 分隔）。

接受的选项：

==========  ==================================================================
font:X      要使用的默认字体。所有字体都受支持，包括在搞分辨率下非常漂亮的
	    SUN12x22 字体。

mode:X      默认视频模式，格式为 [xres]x[yres]-<bpp>@<刷新率>
	    支持以下视频模式：
	    640x640-16@60、640x480-24@60、640x480-32@60。Dreamcast
	    默认使用 640x480-16@60。在撰写本文时，24bpp 与 32bpp 模式
	    表现不佳。修复工作正在进行中

	   注意：640x240 模式目前是坏的，不应出于任何原因此使用。此处
	   提及仅作为参考。

inverse     反转屏幕上的颜色（用于 LCD 显示屏）

nomtrr      禁用帧缓冲上的写合并（write combining）。这会让驱动变慢，
	    但有报告称在高负载下若启用写合并，（声卡）
	    GUS DMA 与 XFree 之间存在轻微不兼容（声音断断续续）。MTRR 在
	    已配置并支持它的系统上默认启用。

cable:X     线缆类型。可以是以下任意一种：vga、rgb 与
	    composite。如果未指定，我们会猜测。

output:X    输出类型。可以是以下任意一种：pal、ntsc 与
	    vga。如果未指定，我们会猜测。
==========  ==================================================================
