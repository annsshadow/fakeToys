## sa1100fb - SA-1100 LCD 图形帧缓冲驱动


这是面向 SA-1100 LCD 控制器图形帧缓冲的驱动。

## 配置


```

  video=sa1100fb:bpp:<value>,lccr0:<value>,lccr1:<value>,lccr2:<value>,lccr3:<value>

```
在内核命令行上通常足以配置控制器。每像素位数（bpp）值应为 4、8、12 或
16。LCCR 值是显示特定的，应按 SA-1100 开发者手册第 11.7 节文档计算。只要
在 LCCR0 中设置了 SDS 位，就支持双面板显示；GPIO<9:2> 用于下层面板。

对于主动显示或需要额外配置（控制背光、点亮 LCD 等）的显示，命令行选项
可能不足以配置显示。向 sa1100fb_init_fbinfo()、sa1100fb_activate_var()、
sa1100fb_disable_lcd_controller() 与 sa1100fb_enable_lcd_controller() 添加
代码段可能是必要的。
```

	bpp:<value>	配置为 <value> 位每像素
	lccr0:<value>	配置 LCD 控制寄存器 0 (11.7.3)
	lccr1:<value>	配置 LCD 控制寄存器 1 (11.7.4)
	lccr2:<value>	配置 LCD 控制寄存器 2 (11.7.5)
	lccr3:<value>	配置 LCD 控制寄存器 3 (11.7.6)

```
