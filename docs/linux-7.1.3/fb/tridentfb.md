## Tridentfb（帧缓冲驱动

Tridentfb 是一些基Trident 芯片的显卡的帧缓冲驱动
以下芯片列表被认为受支持，但并非全部经过测试
名称中包Cyber TGUI 系列 9440/96XX
名称中包Cyber Image 系列
名称中包Blade 的（Blade3D、CyberBlade……）
较新CyberBladeXP 系列

所有系列都支持加速。仅支持基于 PCI/AGP 的显卡，不包括较旧的 Trident 卡该驱动支持每像素 86 32 位的色深若启用加速，TGUI 系列要求行长度为 2 的幂。这意味着与禁用加速时相比，可能的分辨率与 bpp 范围更受限制（见下面的参数列表）
已知缺陷
1. 在启用加速的情况下，驱动会在 3DImage975 芯片上随机死锁   X11（Xorg）中也会发生同样的情况2. ramdac 速度还需要更精细的调校。对于较旧的芯片，有可能切换到芯片在某些色深下不支持的分辨率
## 如何使用

```

	video=tridentfb

```
```

	video=tridentfb:800x600-16@75,noaccel

```
tridentfb 能理解的二级参数如下
========  =====================================================================
noaccel   关闭加速（当它对你的显卡不工作时）

fp	     使用与平板（flat panel）相关的设置
crt 	 假定存在显示器而非 fp

center 	 对于平板以及小于原生尺寸的分辨率，将图像居中，否则使stretch   拉伸

memsize   KB 为单位的整数值，当你的显卡内存大小被误检时使用	 查看驱动初始化时的输出来了解它报告了什么
memdiff   KB 为单位的整数值，当你的显卡报告的内存多于其实际拥有时应设为非零	 例如我的显卡BIOS 可选的三种情况 2MMM 下都比检测值少 192K	 仅当你的显存取自主内存因而大小可配置时使用。否则使memsize	 如果在某些刚好能放入内存的模式下，你在底部看到垃圾，这可能有帮助	 因为它不再允许切换到该模式
nativex   平板的宽度（像素）。如果你知道它（通常102400 1280）且它与驱动
	  似乎检测到的值不同，则使用它
bpp	     每像素位数（86 32mode     一个模式名称，800x600-8@75，如
	 Documentation/fb/modedb.rst 中所========  =====================================================================

对上述参数使用不合理的值可能会导致驱动行为异常，因此请小心（例memsize=12345678 memdiff=23784 nativex=93
