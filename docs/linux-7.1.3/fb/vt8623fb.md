## vt8623fb —面向 VIA VT8623 芯片组图形核心的 fbdev 驱动



## 支持的硬

VIA VT8623 [CLE266] 芯片组及其图形核（称CastleRock Unichrome
我曾VIA EPIA ML-6000 上测试过 vt8623fb


## 支持的特

 - 4 bpp 伪彩色模式（18bit 调色板，两种变体 - 8 bpp 伪彩色模式（18bit 调色板）
 - 16 bpp 真彩模式（RGB 565 - 32 bpp 真彩模式（RGB 888 - 文本模式（通过 bpp = 0 激活）
 - 双倍扫描模式变体（文本模式下不可用 - 双向平移
 - 挂起/恢复支持
 - DPMS 支持

文本模式即使在更高分辨率下也受支持，但对较低的像素时钟存在限（最大约 100 MHz）。此限制不由驱动强制实施。文本模式仅支持 8bit 宽字（硬件限制）16bit 高字体（驱动限制）
共有两种 4 bpp 模式。第一种模式（nonstd == 0 时选中）为高位字节在前紧凑像素模式。第二种模式（当 nonstd == 1 时选中）为交错平面模式
 字节交错），MSB 在前。两种模式均仅支8bit 宽字体（驱动限制）
挂起/恢复在以下系统上可用：系统在恢复期间初始化显卡，且设备处于活动状（例如被 fbcon 使用）
