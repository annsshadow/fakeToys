## vt8623fb —— 面向 VIA VT8623 芯片组图形核心的 fbdev 驱动



## 支持的硬件


VIA VT8623 [CLE266] 芯片组及其图形核心
（称为 CastleRock 或 Unichrome）

我曾在 VIA EPIA ML-6000 上测试过 vt8623fb


## 支持的特性


 - 4 bpp 伪彩色模式（带 18bit 调色板，两种变体）
 - 8 bpp 伪彩色模式（带 18bit 调色板）
 - 16 bpp 真彩模式（RGB 565）
 - 32 bpp 真彩模式（RGB 888）
 - 文本模式（通过 bpp = 0 激活）
 - 双倍扫描模式变体（文本模式下不可用）
 - 双向平移
 - 挂起/恢复支持
 - DPMS 支持

文本模式即使在更高分辨率下也受支持，但对较低的像素时钟存在限制
（最大约 100 MHz）。此限制不由驱动强制实施。文本模式仅支持 8bit 宽字体
（硬件限制）和 16bit 高字体（驱动限制）。

共有两种 4 bpp 模式。第一种模式（当 nonstd == 0 时选中）为高位字节在前的
紧凑像素模式。第二种模式（当 nonstd == 1 时选中）为交错平面模式
（1 字节交错），MSB 在前。两种模式均仅支持 8bit 宽字体（驱动限制）。

挂起/恢复在以下系统上可用：系统在恢复期间初始化显卡，且设备处于活动状态
（例如被 fbcon 使用）。


## 缺失的特性

（即 TODO 列表）

 - 次级（未被 BIOS 初始化的）设备支持
 - MMIO 支持
 - 隔行扫描模式变体
 - 4 bpp 模式下 fontwidths != 8 的支持
 - 文本模式下 fontheight != 16 的支持
 - 硬件光标
 - 视频叠加支持
 - vsync 同步
 - 加速支持（类似于 8514 的 2D、总线主控传输）


## 已知缺陷


 - 文本模式下禁用光标无效
