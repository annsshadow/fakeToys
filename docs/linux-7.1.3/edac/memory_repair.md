### 简

某些内存设备支持修复操作，以处理其内存介质中的问题。后封装修复（Post Package Repair, PPR）和内存备用（memory sparing）就是此类特性的例子
#### 后封装修复（Post Package Repair, PPR

后封装修复是一种维护操作，它请求内存设备对其介质执行修复操作。它是一种内存自愈特性，通过DRAM 设备中的备用行替换故障内存位置来修复它
例如，带有支PPR 特性的 DRAM 组件CXL 内存设备实现了维护操作。DRAM 组件支持以下类型PPR 功能
 - hard PPR（硬 PPR），用于永久性行修复，以 - soft PPR（软 PPR），用于临时性行修复
PPR 比硬 PPR 快得多，但修复会在断电周期后丢失
在修复操作期间，数据可能无法保留，内存请求也可能无法被正确处理。在这种情况下，不应在运行时执行修复操作
例如，对CXL 内存设备，更多细节请参见 CXL 规范版本 3.1 [^1^]_ 8.2.9.7.1.1 PPR 维护操作.2.9.7.1.2 sPPR 维护操作8.2.9.7.1.3 hPPR 维护操作等章节
#### 内存备用（Memory Sparing

内存备用是一种修复功能，它以特定粒度用一部分功能性内存替换一部分内存。内存备用具cacheline/存储rank 备用等粒度。例如，rank 内存备用模式下，一个内rank 作为同一通道上其rank 的备用，以防它们发生故障
备用 rank 被保留，在指示发生故障之前不作为活动内存使用，保留的容量从系统的总可用内存中扣除
在受内存备用保护的系统中，当错误阈值被超过时，故障 DIMM rank 的内容会被复制到备用 rank。随后故rank 被置为离线，备用 rank 被置为在线，用作活动内存以替代故rank
例如，CXL 内存设备可以支持各种备用的子类，其执行备用的范围各不相同
Cacheline 备用子类指的是可以替换整cacheline 的备用操作。行备用作为 PPR 备用功能的替代方案提供，其范围是一DDR 行。存储体备用允许替换整个存储体。Rank 备用定义为替换整DDR rank 的操作
更多细节请参CXL 规范 3.1 [^1^]_ 8.2.9.7.1.4 内存备用维护操作章节
#### 通用内存修复特性控制的用例


1. soft PPR、hard PPR 和内存备用特性共享相似的控制属性。因此，需要一种标准化的、通用sysfs 修复控制，暴露给用户空间并由管理员、脚本和工具使用
2. CXL 设备检测到内存组件中的错误时，它会通过使用一个设置了“需要维护（maintenance needed）”标志的事件记录，通知主机需要进行修复维护操作。该事件记录指定了需要修复的内存的设备物理地址（DPA）和属性。内核将相应CXL 通用媒体DRAM 跟踪事件报告给用户空间，用户空间工具（例rasdaemon）根据设备请求，使用 sysfs 修复控制发起修复维护操作
3. 用户空间工具（如 rasdaemon）在以下情况下请求对内存区域执行修复操作：设置了维护需要标志、报告了未纠正的内存错误或超过阈值的已纠正内存错误过多，或者为该内存设置了超过已纠正错误阈值的标志
4. 每个内存设备可能存在多个 PPR/备用实例
5. 驱动应强制确保在线修复是安全的。在内存映射功能可能在启动之间发生变化的系统中，一种方法是记录本次启动中看到的内存错误，用以检查在线内存修复请求
