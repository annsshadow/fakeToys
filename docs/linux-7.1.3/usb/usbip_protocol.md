## USB/IP 协议

本文档描述 USB/IP 协议的客户端/服务器架构与报文交互流程，定义了设备列举（OP_REQ_DEVLIST）、导入（OP_REQ_IMPORT）以及 URB 提交与解链（USBIP_CMD_SUBMIT / USBIP_CMD_UNLINK）等报文格式，供实现 USB 设备网络重定向的开发者参考。



## 架构


USB/IP 协议采用服务器/客户端架构。服务器导出 USB 设备，客户端导入它们。被导出 USB 设备的设备驱动运行在客户端机器上。

客户端可以请求已导出 USB 设备的列表。为获取列表，客户端打开到服务器的 TCP/IP 连接，并在该 TCP/IP 连接之上发送 OP_REQ_DEVLIST 报文（因此底层的 OP_REQ_DEVLIST 可能在低层传输层被分片发送）。服务器回复 OP_REP_DEVLIST 报文，其中列出了已导出的 USB 设备。最后 TCP/IP 连接被关闭。

```

 virtual host controller                                 usb host
      "client"                                           "server"
  (imports USB devices)                             (exports USB devices)
          |                                                 |
          |                  OP_REQ_DEVLIST                 |
          | ----------------------------------------------> |
          |                                                 |
          |                  OP_REP_DEVLIST                 |
          | <---------------------------------------------- |
          |                                                 |

```
一旦客户端知晓已导出 USB 设备的列表，它就可以决定使用其中某一个。首先客户端打开到服务器的 TCP/IP 连接并发送 OP_REQ_IMPORT 报文。服务器以 OP_REP_IMPORT 回复。如果导入成功，TCP/IP 连接保持打开，并用于传输客户端与服务器之间的 URB 流量。客户端可以发送两类报文：用于提交 URB 的 USBIP_CMD_SUBMIT，以及用于解除之前所提交 URB 链接的 USBIP_CMD_UNLINK。服务器的应答分别对应为 USBIP_RET_SUBMIT 和 USBIP_RET_UNLINK。

```

 virtual host controller                                 usb host
      "client"                                           "server"
  (imports USB devices)                             (exports USB devices)
          |                                                 |
          |                  OP_REQ_IMPORT                  |
          | ----------------------------------------------> |
          |                                                 |
          |                  OP_REP_IMPORT                  |
          | <---------------------------------------------- |
          |                                                 |
          |                                                 |
          |            USBIP_CMD_SUBMIT(seqnum = n)         |
          | ----------------------------------------------> |
          |                                                 |
          |            USBIP_RET_SUBMIT(seqnum = n)         |
          | <---------------------------------------------- |
          |                        .                        |
          |                        :                        |
          |                                                 |
          |            USBIP_CMD_SUBMIT(seqnum = m)         |
          | ----------------------------------------------> |
          |                                                 |
          |            USBIP_CMD_SUBMIT(seqnum = m+1)       |
          | ----------------------------------------------> |
          |                                                 |
          |            USBIP_CMD_SUBMIT(seqnum = m+2)       |
          | ----------------------------------------------> |
          |                                                 |
          |            USBIP_RET_SUBMIT(seqnum = m)         |
          | <---------------------------------------------- |
          |                                                 |
          |            USBIP_CMD_SUBMIT(seqnum = m+3)       |
          | ----------------------------------------------> |
          |                                                 |
          |            USBIP_RET_SUBMIT(seqnum = m+1)       |
          | <---------------------------------------------- |
          |                                                 |
          |            USBIP_CMD_SUBMIT(seqnum = m+4)       |
          | ----------------------------------------------> |
          |                                                 |
          |            USBIP_RET_SUBMIT(seqnum = m+2)       |
          | <---------------------------------------------- |
          |                        .                        |
          |                        :                        |

```
关于 UNLINK，注意在成功的 USBIP_RET_UNLINK 之后，被解除链接的 URB 提交不会有对应的 USBIP_RET_SUBMIT（这一点在 drivers/usb/usbip/stub_rx.c 的 stub_recv_cmd_unlink 函数中有说明）。

```

 virtual host controller                                 usb host
      "client"                                           "server"
  (imports USB devices)                             (exports USB devices)
          |                                                 |
          |            USBIP_CMD_SUBMIT(seqnum = p)         |
          | ----------------------------------------------> |
          |                                                 |
          |               USBIP_CMD_UNLINK                  |
          |         (seqnum = p+1, unlink_seqnum = p)       |
          | ----------------------------------------------> |
          |                                                 |
          |               USBIP_RET_UNLINK                  |
          |        (seqnum = p+1, status = -ECONNRESET)     |
          | <---------------------------------------------- |
          |                                                 |
          |         Note: No USBIP_RET_SUBMIT(seqnum = p)   |
          | <--X---X---X---X---X---X---X---X---X---X---X--- |
          |                        .                        |
          |                        :                        |
          |                                                 |
          |            USBIP_CMD_SUBMIT(seqnum = q)         |
          | ----------------------------------------------> |
          |                                                 |
          |            USBIP_RET_SUBMIT(seqnum = q)         |
          | <---------------------------------------------- |
          |                                                 |
          |               USBIP_CMD_UNLINK                  |
          |         (seqnum = q+1, unlink_seqnum = q)       |
          | ----------------------------------------------> |
          |                                                 |
          |               USBIP_RET_UNLINK                  |
          |           (seqnum = q+1, status = 0)            |
          | <---------------------------------------------- |
          |                                                 |

```
字段采用网络（大端）字节序，即最高有效字节（MSB）存放在最低地址处。

## 协议版本


本文档描述的 USBIP 版本为 v1.1.1。该版本在消息头中的二进制表示为 0x0111。

该定义位于 tools/usb/usbip/configure.ac。

以下四条命令拥有一个称为 'usbip_header_basic' 的通用基本头，它们的头（称为 'usbip_header'，位于 transfer_buffer 负载之前）长度相同，因此需要填充（padding）。

usbip_header_basic：

+-----------+--------+---------------------------------------------------+
| 偏移      | 长度   | 描述                                              |
+===========+========+===================================================+
| 0         | 4      | command                                           |
+-----------+--------+---------------------------------------------------+
| 4         | 4      | seqnum：标识请求及其对应应答的顺序号；每个连接递增。 |
+-----------+--------+---------------------------------------------------+
| 8         | 4      | devid：唯一指定一个远程 USB 设备，代替 busnum 和  |
|           |        | devnum；对客户端（请求）而言，该值为             |
|           |        | ((busnum << 16) | devnum)；对服务器（应答）而言，应置为 0。 |
+-----------+--------+---------------------------------------------------+
| 0xC       | 4      | direction：                                        |
|           |        |                                                   |
|           |        |    - 0：USBIP_DIR_OUT                             |
|           |        |    - 1：USBIP_DIR_IN                              |
|           |        |                                                   |
|           |        | 仅客户端使用，服务器侧应置为 0。                 |
+-----------+--------+---------------------------------------------------+
| 0x10      | 4      | ep：端点号。仅客户端使用，服务器侧应置为 0；对于  |
|           |        | UNLINK，应置为 0。                                |
+-----------+--------+---------------------------------------------------+

USBIP_CMD_SUBMIT:
	提交一个 URB。

+-----------+--------+---------------------------------------------------+
| 偏移      | 长度   | 描述                                              |
+===========+========+===================================================+
| 0         | 20     | usbip_header_basic，'command' 应为 0x00000001。   |
+-----------+--------+---------------------------------------------------+
| 0x14      | 4      | transfer_flags：可能取值取决于 USBIP_URB 的       |
|           |        | transfer_flags。参见 include/uapi/linux/usbip.h 与 |
|           |        | Documentation/driver-api/usb/URB.rst。参见        |
|           |        | drivers/usb/usbip/usbip_common.c 中的             |
|           |        | usbip_pack_cmd_submit() 与 tweak_transfer_flags()。 |
+-----------+--------+---------------------------------------------------+
| 0x18      | 4      | transfer_buffer_length：使用 URB 的               |
|           |        | transfer_buffer_length。                          |
+-----------+--------+---------------------------------------------------+
| 0x1C      | 4      | start_frame：使用 URB 的 start_frame；ISO 传输的  |
|           |        | 起始帧；若非 ISO 传输应置为 0。                   |
+-----------+--------+---------------------------------------------------+
| 0x20      | 4      | number_of_packets：ISO 包的数量；若非 ISO 传输应  |
|           |        | 置为 0xffffffff。                                 |
+-----------+--------+---------------------------------------------------+
| 0x24      | 4      | interval：服务器端主控制器上该请求的最大时间。    |
+-----------+--------+---------------------------------------------------+
| 0x28      | 8      | setup：USB 设置的数据字节，未使用时填充为零。     |
+-----------+--------+---------------------------------------------------+
| 0x30      | n      | transfer_buffer。若 direction 为 USBIP_DIR_OUT，则 |
|           |        | n 等于 transfer_buffer_length；否则 n 等于 0。对于 |
|           |        | ISO 传输，各 ISO 包之间的填充不传输。             |
+-----------+--------+---------------------------------------------------+
| 0x30+n    | m      | iso_packet_descriptor                             |
+-----------+--------+---------------------------------------------------+

USBIP_RET_SUBMIT:
	提交 URB 的应答。

+-----------+--------+---------------------------------------------------+
| 偏移      | 长度   | 描述                                              |
+===========+========+===================================================+
| 0         | 20     | usbip_header_basic，'command' 应为 0x00000003。   |
+-----------+--------+---------------------------------------------------+
| 0x14      | 4      | status：0 表示 URB 事务成功，否则表示发生了某种   |
|           |        | 错误。                                            |
+-----------+--------+---------------------------------------------------+
| 0x18      | 4      | actual_length：URB 数据字节数；使用 URB 的        |
|           |        | actual_length。                                   |
+-----------+--------+---------------------------------------------------+
| 0x1C      | 4      | start_frame：使用 URB 的 start_frame；ISO 传输的  |
|           |        | 起始帧；若非 ISO 传输应置为 0。                   |
+-----------+--------+---------------------------------------------------+
| 0x20      | 4      | number_of_packets：ISO 包的数量；若非 ISO 传输应  |
|           |        | 置为 0xffffffff。                                 |
+-----------+--------+---------------------------------------------------+
| 0x24      | 4      | error_count                                       |
+-----------+--------+---------------------------------------------------+
| 0x28      | 8      | padding，应置为 0。                               |
+-----------+--------+---------------------------------------------------+
| 0x30      | n      | transfer_buffer。若 direction 为 USBIP_DIR_IN，则  |
|           |        | n 等于 actual_length；否则 n 等于 0。对于 ISO 传输， |
|           |        | 各 ISO 包之间的填充不传输。                       |
+-----------+--------+---------------------------------------------------+
| 0x30+n    | m      | iso_packet_descriptor                             |
+-----------+--------+---------------------------------------------------+

USBIP_CMD_UNLINK:
	解除一个 URB 的链接。

+-----------+--------+---------------------------------------------------+
| 偏移      | 长度   | 描述                                              |
+===========+========+===================================================+
| 0         | 20     | usbip_header_basic，'command' 应为 0x00000002。   |
+-----------+--------+---------------------------------------------------+
| 0x14      | 4      | unlink_seqnum：要解除链接的 SUBMIT 请求的序号。   |
+-----------+--------+---------------------------------------------------+
| 0x18      | 24     | padding，应置为 0。                               |
+-----------+--------+---------------------------------------------------+

USBIP_RET_UNLINK:
	URB 解除链接的应答。

+-----------+--------+---------------------------------------------------+
| 偏移      | 长度   | 描述                                              |
+===========+========+===================================================+
| 0         | 20     | usbip_header_basic，'command' 应为 0x00000004。   |
+-----------+--------+---------------------------------------------------+
| 0x14      | 4      | status：与 USBIP_RET_SUBMIT 的 status 类似（共用  |
|           |        | 相同的内存偏移）。当 UNLINK 成功时，status 为     |
|           |        | -ECONNRESET；当 USBIP_CMD_UNLINK 出现在           |
|           |        | USBIP_RET_SUBMIT 之后时，status 为 0。            |
+-----------+--------+---------------------------------------------------+
| 0x18      | 24     | padding，应置为 0。                               |
+-----------+--------+---------------------------------------------------+
