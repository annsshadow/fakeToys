## 函数描述符


可以写入 FFS 小工具的一些描述符是
如下所述。处理设备和配置描述符
由复合小工具生成，并且不是由用户写入
FFS 小工具。

描述符被写入 FFS 小工具中的“ep0”文件
跟在描述符头后面。

### 接口描述符


可以写入标准USB接口描述符。的类/子类
最近的接口描述符决定了特定于类的类型
描述符被接受。

### 特定于类的描述符


特定于类的描述符仅适用于该类/子类
最近的接口描述符。以下是一些
支持的特定于类的描述符。

#### DFU 功能描述符


当接口类为USB_CLASS_APP_SPEC且接口子类为
是USB_SUBCLASS_DFU，可以提供DFU功能描述符。
DFU 功能描述符在 USB 规范中进行了描述
截至撰写本文时，设备固件升级 (DFU) 版本 1.1。
