
## 内核开发流程指南


本文档旨在帮助开发人员（及其经理）以最小的挫折感与开发社区协作。它试图以这样一种方式记录这个社区的运作方式：即使那些并不十分熟悉 Linux 内核开发（事实上也不熟悉自由软件开发）的人也能看懂。虽然这里包含一些技术内容，但这是一次非常偏重流程的讨论，不需要深入了解内核编程即可理解。
