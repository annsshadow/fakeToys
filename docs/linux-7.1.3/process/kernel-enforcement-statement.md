
### Linux Kernel Enforcement Statement


作为 Linux 内核的开发者，我们深切关注我们的软件如何被使用，以及如何执行我们软件的许可证
遵守 GPL-2.0 的互惠共享义务，对我们软件和社区的长期可持续性至关重要

尽管我们有权就社区内各项贡献所包含的独立版权权益进行维权，但我们共同关注确保个人的维权行动
以有益于社区的方式进行，且不会对我们的软件生态系统健康与发展产生非预期的负面影响
为遏制无益处的维权行为，我们一致认为，代表我们自己及我们任何版权权益的继受人，
做出以下对用户承诺符合我们开发社区的最佳利益：

   尽管 GPL-2.0 有终止条款，我们一致认为，就许可证下任何非防御性权利主张而言
   采用 GPL-3.0 的以下条款作为我们许可证下的附加许可符合我们开发社区的最佳利益

	然而，如果你停止所有违反本许可证的行为，那么来自特定版权持有人的许可将被恢复：
	(a) 临时性地，除非且直到版权持有人明确且最终终止你的许可；
	(b) 永久性地，如果版权持有人在停止违规行为后 60 天内未以合理方式通知你该违规行为

	此外，如果版权持有人以合理方式通知你该违规行为，这是你首次从该版权持有人处收到
	（针对任何作品）违反本许可证的通知，且你在收到通知30 天内纠正了违规行为，
	那么你来自该特定版权持有人的许可将被永久恢复

我们提供这些保证的意图在于鼓励更多地使用该软件。我们希望公司和个人使用、修改并分发该软件
我们希望以开放透明的方式与用户合作，消除任何关于我们在合规或维权方面期望的不确定性，
以免限制对我们软件的采用。我们将法律行动视为最后手段，仅在其他社区努力未能解决问题时才启动

最后，一旦不合规问题得到解决，我们希望用户能愉快地加入我们共同推进本项目
同心协力，我们将变得更强大
