
## Linux 内核项目的连续性


Linux 内核开发项目分布广泛，拥有超过 100 名维护者，各自负责让自己仓库中的修改持续向前流动。不过最后一步是集中式的：修改会被拉入主线仓库。这项工作通常由 Linus Torvalds 完成，但正如 2018 年的 4.19 版本所展示的那样，在需要时也有其他人能够承担这项工作。

如果该仓库的维护者未来变得不愿意或无法继续此项工作（包括协助完成过渡），项目将需要毫不延迟地找到一名或多名接替者。下述流程描述了将如何完成这一工作。$ORGANIZER 为最近一届维护者峰会（Maintainer Summit）的组织者，或由当前的 Linux 基金会（LF）技术顾问委员会（TAB）主席作为后备。

- 在 72 小时内，$ORGANIZER 将与被最近一届维护者峰会邀请的人员展开讨论。将尽快以线上或线下方式召开这些受邀者与 TAB 的会议，以尽可能让更多人能够参与。

- 若过去 15 个月内未举办过维护者峰会，则本次会议的受邀者集合由 TAB 决定。

- 本次会议的受邀者可按需邀请其他维护者加入。

- 本次会议由 $ORGANIZER 主持，将就顶级内核仓库的持续管理考量各种方案，前提是方案应最大化项目及其社区的长期健康。

- 在两周内，该小组的代表将使用 ksummit@lists.linux.dev 邮件列表向更广泛的社区通报后续步骤。

Linux 基金会将在 TAB 的指导下，采取必要步骤以支持并实施该计划。
