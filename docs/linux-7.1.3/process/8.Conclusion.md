
## 更多信息


关于 Linux 内核开发及相关主题的信息来源众多。其中首要的始终是内核源码发行版中的 Documentation 目录。从顶层的 process/howto.rst <process_howto> 开始；同时阅读 process/submitting-patches.rst <submittingpatches>。许多内部内核 API 使用 kerneldoc 机制记录；“make htmldocs” 或 “make pdfdocs” 可用于以 HTML 或 PDF 格式生成这些文档（尽管某些发行版附带的 TeX 版本会遇到内部限制，无法正确处理文档）。

各种网站在不同详细程度上讨论内核开发。本文作者想谦逊地推荐 https://lwn.net/ 作为信息来源；许多特定内核主题的信息可通过 LWN 内核索引找到：

	https://lwn.net/Kernel/Index/

除此之外，对内核开发者来说一个有价值的资源是：

	https://kernelnewbies.org/

当然，也不应忘记 https://kernel.org/，这是内核发布信息的权威位置。

有一些关于内核开发的书籍：

	Linux Device Drivers, 3rd Edition（Jonathan Corbet、Alessandro Rubini 与 Greg Kroah-Hartman）。在线地址：
	https://lwn.net/Kernel/LDD3/。

	Linux Kernel Development（Robert Love）。

	Understanding the Linux Kernel（Daniel Bovet 与 Marco Cesati）。

不过，所有这些书籍都有一个共同的缺点：它们在上架时往往已经有些过时，而且它们已经在书架上待了一段时间了。尽管如此，那里仍有相当多有用的信息。

git 的文档可在以下位置找到：

	https://www.kernel.org/pub/software/scm/git/docs/

	https://www.kernel.org/pub/software/scm/git/docs/user-manual.html


## 结论


向任何读完这篇冗长文档的人表示祝贺。希望它有助于理解 Linux 内核是如何开发的，以及你如何参与这一过程。

最终，重要的是参与。任何开源软件项目都不过是贡献者投入其中的总和。Linux 内核之所以能如此快速而良好地进展，是因为它得到了一群数量惊人的开发者的帮助，他们都在努力让它变得更好。内核是数千人朝着共同目标协作所能成就之事的典范。

不过，内核总能受益于更大的开发者基础。总是有更多的工作要做。但同样重要的是，Linux 生态系统中的大多数其他参与者也可以通过贡献内核而受益。将代码合入主线是提高代码质量、降低维护与分发成本、对内核开发方向拥有更高影响力的关键，诸如此类。这是一种所有相关方都共赢的局面。启动你的编辑器，来加入我们吧；你将受到最热烈的欢迎。
