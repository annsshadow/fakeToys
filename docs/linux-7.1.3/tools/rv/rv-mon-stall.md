## rv-mon-stall
### 停滞任务监视器（Stalled task monitor）


:Manual section: 1

## 概要（SYNOPSIS）


**rv mon stall** [**OPTIONS**]

## 描述（DESCRIPTION）


停滞任务（**stall**）监视器是一个示例性的每任务定时监视器，用于检查任务在就绪后是否在定义的阈值内被调度。

有关此监视器的更多信息，请参见内核文档：
<https://docs.kernel.org/trace/rv/monitor_stall.html>
