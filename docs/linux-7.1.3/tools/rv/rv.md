## 描述


运行时验证（**RV**）是一种轻量级（但严格）的方法
使用复杂系统的实用方法进行形式验证。
而不是依赖于系统的细粒度模型（例如，
重新实现指令级别），RV 通过分析跟踪来工作
系统的实际执行情况，将其与正式系统进行比较
系统行为的规范。

**rv** 工具提供了运行时集合的接口
验证（rv）监视器。

## 命令


**列表**

列出所有可用的监视器。

**周一**

运行监视器。
