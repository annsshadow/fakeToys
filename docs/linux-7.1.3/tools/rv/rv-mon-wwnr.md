## rv-mon-wwnr

## 概要


**rv mon wip** [**OPTIONS**]

## 描述


非运行期间唤醒（**wwnr**）是一个按任务（per-task）采样的监视器。

有关此监视器的更多信息，请参阅内核文档：
<https://docs.kernel.org/trace/rv/monitor_wwnr.html>
