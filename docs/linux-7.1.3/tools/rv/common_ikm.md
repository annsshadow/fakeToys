**-h**, **--help**

        打印监视器的选项及可用的反应器（reactor）列表

**-r**, **--reactor** **reactor**

        启用 **reactor**。可用反应器列表**-h**

**-s**, **--self**

        在使用跟踪（**-t**）时，同时打**rv** 命令自身执行期间发生的事件
        如果 **rv** 命令本身产生了过多事件，工具可能会忙于仅处理自身事件

**-t**, **--trace**

        跟踪监视器的事件与错误

**-v**, **--verbose**

        打印调试信息
