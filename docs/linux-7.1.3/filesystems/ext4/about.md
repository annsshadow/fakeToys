## 关于本书


本文档试图描述 ext4 文件系统的磁盘格式。相同的总体思路也应适用于 ext2/3
文件系统，尽管它们不支持 ext4 支持的所有特性，并且字段会更短。

**注意**：这是一项进行中的工作，基于作者（djwong）在手动拆解文件系统时做的
笔记。数据结构定义应当更新到 Linux 4.18 与 e2fsprogs-1.44。欢迎所有评论与
更正，因为无疑有大量知识可能未反映在新创建的演示文件系统中。

### 许可

本书根据 GNU 通用公共许可证 v2 的条款授权。

### 术语


ext4 将存储设备划分为逻辑块数组，既是为了减少簿记开销，也是为了通过强制
更大的传输大小来提高吞吐量。通常，块大小为 4KiB（与 x86 上的页以及块层默认
块大小相同），尽管实际大小计算为 2 ^ (10 + `sb.s_log_block_size`) 字节。在
本文档中，磁盘位置以这些逻辑块给出，而不是原始 LBA，也不是 1024 字节块。为
方便起见，逻辑块大小在文档其余部分将被称为 `$block_size`。

当在 `preformatted text` 块中引用时，`sb` 指超级块中的字段，`inode` 指
inode 表项中的字段。
