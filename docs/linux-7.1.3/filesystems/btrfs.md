
## BTRFS


Btrfs 是一个写时复制（copy on write）的 Linux 文件系统，旨在实现高级功能，同时关注容错、修复和易管理性。由多家公司联合开发，GPL 许可发布，欢迎任何人贡献

Btrfs 的主要特性包括：

    - 基于范围的文件存储（最大文件大2^64
    - 小文件的空间高效打包
    - 空间高效的索引目
    - 动inode 分配
    - 可写快照
    - 子卷（独立的内部文件系统根）
    - 对象级镜像与条带
    - 数据和元数据上的校验和（支持多种算法
    - 压缩（支持多种算法）
    - Reflink、去
    - Scrub（在线校验和验证
    - 分层配额组（支持子卷和快照）
    - 集成的多设备支持，带有多raid 算法
    - 离线文件系统检
    - 高效的增量备份与文件系统镜像（send/receive
    - Trim/discard
    - 在线文件系统碎片整理
    - 交换文件支持
    - 分区（Zoned）模
    - 写元数据验证
    - 在线调整大小（收缩、扩展）
