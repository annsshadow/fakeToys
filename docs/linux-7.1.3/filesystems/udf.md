
## UDF 文件系统


如果你在使用本驱动读UDF 光盘时遇到问题，请按MAINTAINERS 文件中的说明报告
写入支持需要一个支持写入的块驱动。目dvd+rw 驱动器与介质支持真正的随机扇区写入，因此此类设备上的 udf 文件系统可以直接以读写方式挂载。然CD-RW 介质不支持这一点。取而代之，可以使用 cdrwtool 工具将介质格式化为包（packet）模式，然后pktcdvd 驱动绑定到底cd 设备，以提供所需的缓冲与写（read-modify-write）周期，从而允许文件系统随机扇区写入，同时只向硬件提供完整的包写入。虽dvd+rw 介质并非必须使用，但由于驱动器固件内部提供的写支持非常差，使pktcdvd 驱动通常能提升性能

支持以下挂载选项
	===========	======================================
	gid=		设置默认的组（group）	umask=		设置默认umask	mode=		设置默认的文件权限	dmode=		设置默认的目录权限	uid=		设置默认的用户	bs=		设置块大小	unhide		显示原本被隐藏的文件	undelete	在列表中显示已删除的文件	adinicb		将数据内嵌于 inode 中（默认）	noadinicb	不将数据内嵌inode 中	shortad		使用ad（short ad）	longad		使用ad（long ad，默认）	nostrict	取消严格一致性检查	iocharset=	设置 NLS 字符集	===========	======================================

uid= gid= 选项需要多一点解释。它们接受一个十进制数值，该挂载上的所inode 随后都会显示为属于该 uid gid。挂载选项也接受字符串 "forget"。forget 选项会导致所ID -1 写入磁盘，这UDF 标准用来表示这些文件不支ID 的一种方式
对于可移动介质的典型桌面使用，你应将 ID 设置为交互式登录用户ID，并同时指定 forget 选项。这样，交互式用户将始终把磁盘上的文件视为属于他自己

	=====		================================
	novrs		跳过卷序列识别（volume sequence recognition）	=====		================================

	==========	=================================================
