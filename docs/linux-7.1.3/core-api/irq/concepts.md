## 什么是IRQ？


IRQ 是来自设备的中断请求。目前，他们可以来
通过引脚或数据包。可以连接多个设备
相同的引脚，从而共享一个 IRQ。例如在传统 PCI 总线上：所有设备
通常共享 4 个通道/引脚。请注意，每个设备都可以请求
中断每条车道。

IRQ 号是用于谈论硬件的内核标识符
中断源。通常，这是全局 irq_desc 的索引
数组或稀疏中断树。但除了 linux/interrupt.h
实现，细节是特定于架构的。

IRQ 号是一个可能的中断源的枚举
机器。通常，枚举的是输入引脚的数量
系统中的所有中断控制器。就 ISA 而言，
枚举的是两个 i8259 上每个的 8 个输入引脚
中断控制器。

架构可以为 IRQ 编号分配附加含义，并且
鼓励在有任何手动配置的情况下
所涉及的硬件。 ISA IRQ 是一个典型的例子
赋予这种额外的意义。
