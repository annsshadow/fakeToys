## 启动阶段内存管理


早期系统初始化无法使用“正常”的内存管理，原因很简单——它尚未建立。但仍然需要
为各种数据结构分配内存，例如为物理页分配器分配。

一个称为 `memblock` 的专用分配器执行启动阶段的内存管理。架构特定的初始化必须
在 `setup_arch` 中建立它，并在 `mem_init` 函数中拆除它。

一旦早期内存管理可用，它就提供各种用于内存分配的函数与宏。分配请求可以定向到
第一个（可能也是唯一的）节点，或 NUMA 系统中的特定节点。有些 API 变体在分配
失败时 panic，有些则不会。

Memblock 还提供各种控制自身行为的 API。
