## Linux 高精度事件定时器（HPET）驱动


高精度事件定时器（HPET）硬件遵循 Intel 和 Microsoft 制定的规范，修订版 1。

每个 HPET 有一个固定频率的计数器（10+ MHz，因此称为“高精度”）以及最多 32 个比较器。通常提供三个或更多比较器，每个都可以生成单次中断，并且其中至少一个具有额外的硬件以支持周期性中断。这些比较器也被称为“定时器”，这可能会产生误导，因为通常定时器彼此独立……它们共享一个计数器，使重置变得复杂。

HPET 设备支持两种中断路由模式。在一种模式下，比较器是没有特定系统角色的额外中断源。许多 x86 BIOS 编写者根本不对 HPET 中断进行路由，这就无法使用该模式。它们支持另一种“传统替代”模式，其中前两个比较器会屏蔽来自 8254 定时器和 RTC 的中断。

该驱动支持在驱动 module_init 例程被调用之前检测 HPET 驱动的分配和 HPET 的初始化。这使得使用定时器 0 或 1 作为主定时器的平台代码能够拦截 HPET 初始化。这种初始化的一个示例可以在 arch/x86/kernel/hpet.c 中找到。

该驱动提供的用户空间 API 类似于 RTC 驱动框架中的 API。示例用户空间程序位于 file:samples/timers/hpet_example.c
