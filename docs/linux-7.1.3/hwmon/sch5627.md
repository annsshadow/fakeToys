## 内核驱动 sch5627


支持的芯片：

  - SMSC SCH5627

    前缀: 'sch5627'

    扫描地址: 无，地址从 Super I/O 配置空间读取

    数据手册: 应用笔记可应请求提供

Author: Hans de Goede <hdegoede@redhat.com>


### 描述


SMSC SCH5627 Super I/O 芯片包含完整的硬件监控
能力。它们可监控多达 5 路电压、4 个风扇和 8 路温度。

此外，SCH5627 导出描述哪些温度传感器
影响每个风扇转速的数据。将 pwmX_auto_channels_temp 设为 0 会强制
相应风扇以全速运行，直到写入其他值。

SMSC SCH5627 的硬件监控部分还包含一个集成的
看门狗。为使该看门狗工作，BIOS 必须完成一些主板相关的
初始化；因此如果 BIOS 未启用看门狗，
sch5627 驱动将不会注册看门狗设备。

SMSC SCH5627 的硬件监控部分通过与一个
嵌入式微控制器通信来访问。描述与该微控制器
通信协议的应用笔记可应
请求提供。如需副本请发邮件给我。


### 控制风扇转速


SCH5627 允许部分控制风扇转速。如果某个温度
通道超过 tempX_max，所有风扇会被强制全速运行。tempX_crit
则不适用，此时可能采取其他措施为系统降温。
目前尚不清楚 fanX_min 的值以何种方式影响风扇转速。
