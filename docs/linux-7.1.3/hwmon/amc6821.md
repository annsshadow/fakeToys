## 内核驱动 amc6821


支持的芯片：

	Texas Instruments AMC6821

	前缀：'amc6821'

	扫描地址：0x18, 0x19, 0x1a, 0x2c, 0x2d, 0x2e, 0x4c, 0x4d, 0x4e

	Datasheet: http://focus.ti.com/docs/prod/folders/print/amc6821.html

作者：
	Tomaz Mertelj <tomaz.mertelj@guest.arnes.si>

### 描述


该驱动为 Texas Instruments amc6821 芯片提供支持。该芯片具有一个片内温度传感器、
一个远端温度传感器以及一个 pwm 风扇调节器。
pwm 既可由软件控制，也可自动调节。

该驱动在 sysfs 中提供以下传感器访问接口：

======================= ==      ===============================================
temp1_input		ro	片内温度
temp1_min		rw	"
temp1_max		rw	"
temp1_crit		rw	"
temp1_min_alarm		ro	"
temp1_max_alarm		ro	"
temp1_crit_alarm	ro	"

temp2_input		ro	远端温度
temp2_min		rw	"
temp2_max		rw	"
temp2_crit		rw	"
temp2_min_alarm		ro	"
temp2_max_alarm		ro	"
temp2_crit_alarm	ro	"
temp2_fault		ro	"

fan1_input		ro	转速计速度
fan1_min		rw	"
fan1_max		rw	"
fan1_fault		ro	"
fan1_pulses		rw	每转脉冲数可为 2 或 4。
fan1_target		rw	目标风扇转速，需配合 pwm1_enable
				模式 4 使用。

pwm1			rw	pwm1
pwm1_enable		rw	调节模式，1=开环，2=由远端温度控制风扇，
				3=由片内温度与远端传感器温度的组合
				控制风扇，
				4=由 fan1_target 属性设置的
				目标转速控制风扇。
pwm1_mode		rw	风扇占空比控制模式（0=DC，1=PWM）
pwm1_auto_channels_temp ro	当 pwm_enable==2 时为 1，pwm_enable==3 时为 3
pwm1_auto_point1_pwm	ro	硬连线为 0，两个温度通道共用。
pwm1_auto_point2_pwm	rw	该值两个温度通道共用。
pwm1_auto_point3_pwm	rw	硬连线为 255，两个温度通道共用。

temp1_auto_point1_temp	ro	硬连线为 temp2_auto_point1_temp
				（该值可写）。低于此温度时风扇停止。
temp1_auto_point2_temp	rw	比例区间的下限温度。低于此温度时
				pwm1 = pwm1_auto_point2_pwm。取值范围为
				0 摄氏度到 124 摄氏度，步长 4 摄氏度。
				写入后请读回以获取实际值。
temp1_auto_point3_temp	rw	高于此温度时风扇以最高转速运行。其值可取自
				temp1_auto_point2_temp。它只能取某些离散
				值，取决于 temp1_auto_point2_temp 与
				pwm1_auto_point2_pwm。写入后请读回
				以获取实际值。

temp2_auto_point1_temp	rw	必须介于 0 摄氏度与 63 摄氏度之间，
				用于定义被动散热温度。在闭环模式下，
				低于此温度风扇停止。
temp2_auto_point2_temp	rw	比例区间的下限温度。低于此温度时
				pwm1 = pwm1_auto_point2_pwm。取值范围为
				0 摄氏度到 124 摄氏度，步长 4 摄氏度。

temp2_auto_point3_temp	rw	高于此温度时风扇以最高转速运行。它只能取
				某些离散值，取决于 temp2_auto_point2_temp
				与 pwm1_auto_point2_pwm。写入后请读回
				以获取实际值。
======================= ==      ===============================================

### 模块参数


如果你的主板 BIOS 能正确初始化 amc6821，应当
以 init=0 加载模块。

如果你的主板 BIOS 未初始化该芯片，或你想
使用不同的设置，可以设置以下参数：

- init=1，
- pwminv：默认 0 为正常 pwm 输出，1 为反转 pwm 输出。
