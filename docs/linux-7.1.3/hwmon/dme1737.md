## 内核驱动 dme1737

支持的芯片：

  - SMSC DME1737 及兼容型号（如华硕 A8000）

    前缀：'dme1737'

    扫描地址：I2C 0x2c、0x2d、0x2e

    数据手册：由 SMSC 应要求并在签署 NDA 后提供

  - SMSC SCH3112、SCH3114、SCH3116

    前缀：'sch311x'

    扫描地址：无，地址从 Super-I/O 配置空间读取

    数据手册：可在互联网上获取

  - SMSC SCH5027

    前缀：'sch5027'

    扫描地址：I2C 0x2c、0x2d、0x2e

    数据手册：由 SMSC 应要求并在签署 NDA 后提供

  - SMSC SCH5127

    前缀：'sch5127'

    扫描地址：无，地址从 Super-I/O 配置空间读取

    数据手册：由 SMSC 应要求并在签署 NDA 后提供

### 模块参数

- force_start：bool
			启用对电压、风扇和温度输入以及 PWM 输出控制功能的监控。
			通常不应需要使用此参数，因为 BIOS 一般会自动处理这些。

- probe_all_addr：bool
			在探测 ISA 设备时包含非标准的 LPC 地址 0x162e 和 0x164e。
			以下主板需要此参数：
   - VIA EPIA SN18000

### 描述

本驱动实现了对 SMSC DME1737 和华硕 A8000（二者相同）、SMSC SCH5027、SCH311x
以及 SCH5127 Super-I/O 芯片的硬件监控功能的支持。这些芯片提供对 3 个温度
传感器 temp[1-3]（2 个远端二极管和 1 个内部）的监控、8 路电压 in[0-7]
（7 路外部和 1 路内部）以及最多 6 路风扇转速 fan[1-6] 的监控。此外，这些芯片
还实现了最多 5 路 PWM 输出 pwm[1-3,5-6]，用于手动和自动两种方式控制风扇转速。

对于 DME1737、A8000 和 SCH5027，fan[1-2] 和 pwm[1-2] 始终存在。fan[3-6] 和
pwm[3,5-6] 是可选特性，其可用性取决于芯片的配置。驱动会在初始化期间检测哪些
特性存在，并相应地创建 sysfs 属性。

对于 SCH311x 和 SCH5127，fan[1-3] 和 pwm[1-3] 始终存在，而 fan[4-6] 和
pwm[5-6] 不存在。

DME1737、A8000 和 SCH5027 的硬件监控特性只能通过 SMBus 访问，而 SCH311x 和
SCH5127 只通过 ISA 总线提供访问。因此，如果驱动检测到 DME1737、A8000 或
SCH5027，它会将自己注册为 I2C 客户端驱动；如果检测到 SCH311x 或 SCH5127 芯片，
则注册为平台驱动。

### 电压监控

电压输入以 12 位分辨率采样，并具有内部分压电阻。因此驱动返回的值反映的是真实的
毫伏值，不需要缩放。电压输入映射如下（最后一列表示输入范围）：

```
	in0: +5VTR	(+5V standby)		0V - 6.64V
	in1: Vccp	(processor core)	0V - 3V
	in2: VCC	(internal +3.3V)	0V - 4.38V
	in3: +5V				0V - 6.64V
	in4: +12V				0V - 16V
	in5: VTR	(+3.3V standby)		0V - 4.38V
	in6: Vbat	(+3.0V)			0V - 4.38V

```
```
	in0: +2.5V				0V - 3.32V
	in1: Vccp	(processor core)	0V - 2V
	in2: VCC	(internal +3.3V)	0V - 4.38V
	in3: +5V				0V - 6.64V
	in4: +12V				0V - 16V
	in5: VTR	(+3.3V standby)		0V - 4.38V
	in6: Vbat	(+3.0V)			0V - 4.38V

```
```
	in0: +5VTR	(+5V standby)		0V - 6.64V
	in1: Vccp	(processor core)	0V - 3V
	in2: VCC	(internal +3.3V)	0V - 4.38V
	in3: V2_IN				0V - 1.5V
	in4: V1_IN				0V - 1.5V
	in5: VTR	(+3.3V standby)		0V - 4.38V
	in6: Vbat	(+3.0V)			0V - 4.38V

```
```
	in0: +2.5				0V - 3.32V
	in1: Vccp	(processor core)	0V - 3V
	in2: VCC	(internal +3.3V)	0V - 4.38V
	in3: V2_IN				0V - 1.5V
	in4: V1_IN				0V - 1.5V
	in5: VTR	(+3.3V standby)		0V - 4.38V
	in6: Vbat	(+3.0V)			0V - 4.38V
	in7: Vtrip	(+1.5V)			0V - 1.99V

```
每个电压输入都有相关联的 min 和 max 限值，当越过这些限值时将触发告警。

### 温度监控

温度以 12 位分辨率测量，并以毫摄氏度（millidegree Celsius）报告。该芯片还为全部
3 个温度输入提供偏移量，当被编程后，这些偏移量会被加到输入读数上。芯片会自动完成
所有的缩放，因此驱动报告的是真实温度，不需要任何用户空间调整。温度输入映射如下：
```
	temp1: Remote diode 1 (3904 type) temperature	-127C - +127C
	temp2: DME1737 internal temperature		-127C - +127C
	temp3: Remote diode 2 (3904 type) temperature	-127C - +127C

```
每个温度输入都有相关联的 min 和 max 限值，当越过这些限值时将触发告警。此外，每个
温度输入都有一个 fault 属性，当检测到故障二极管或未连接的输入时返回 1，否则返回 0。

### 风扇监控

风扇转速（RPM）以 16 位分辨率测量。该芯片提供 6 路风扇转速计输入。全部 6 路输入都
有相关联的 min 限值，当越过时触发告警。风扇输入 1-4 提供 type 属性，需要设置为所
连接转速计每转产生的脉冲数。支持的值为 1、2 和 4。风扇输入 5-6 只支持每转产生 2 个
脉冲的风扇。风扇输入 5-6 还提供一个 max 属性，需要设置为该输入在 100% 占空比下可
达到的最大 RPM。芯片会根据该值调整采样率。

### PWM 输出控制

该芯片提供 5 路 PWM 输出。PWM 输出 1-3 与风扇输入 1-3 相关联，PWM 输出 5-6 与风扇
输入 5-6 相关联。PWM 输出 1-3 可以通过相应地设置 enable 属性来配置为手动或自动
模式。PWM 输出 5-6 只能运行在手动模式，因此它们的 enable 属性是只读的。当设置为
手动模式时，通过向相应的 PWM 属性写入占空比值来设定风扇转速。在自动模式下，PWM
属性返回由芯片内风扇控制器设定的当前占空比。所有 PWM 输出都支持通过 freq 属性
设置输出频率。

在自动模式下，芯片支持设置 PWM 斜坡速率（ramp rate），它定义了 PWM 输出对相关联
温度输入变化的调整速度。将 PWM 输出关联到温度输入是通过温度区域（temperature
zones）完成的。该芯片提供 3 个区域，它们到温度输入的分配是静态的，并在初始化期间
确定。这些分配可以通过 zone[1-3]_auto_channels_temp 属性获取。每个 PWM 输出通过
pwm[1-3]_auto_channels_zone 属性被分配到某一个（或多个中最热的一个）温度区域。
每个 PWM 输出有 3 个不同的输出占空比：full、low 和 min。full 在内部硬连线为 255
（100%），而 low 和 min 可以分别通过 pwm[1-3]_auto_point1_pwm 和
pwm[1-3]_auto_pwm_min 编程。区域的温度阈值通过 zone[1-3]_auto_point[1-3]_temp 和
zone[1-3]_auto_point1_temp_hyst 编程：

	=============================== =======================================
	pwm[1-3]_auto_point2_pwm	full-speed duty-cycle (255, i.e., 100%)
	pwm[1-3]_auto_point1_pwm	low-speed duty-cycle
	pwm[1-3]_auto_pwm_min		min-speed duty-cycle

	zone[1-3]_auto_point3_temp	full-speed temp (all outputs)
	zone[1-3]_auto_point2_temp	full-speed temp
	zone[1-3]_auto_point1_temp	low-speed temp
	zone[1-3]_auto_point1_temp_hyst	min-speed temp
	=============================== =======================================

如果相关联区域的温度介于 auto_point1_temp 和 auto_point2_temp 之间，芯片会在
auto_point1_pwm 到 auto_point2_pwm 的范围内线性地调整输出占空比。如果温度下降到
auto_point1_temp_hyst 值以下，输出占空比被设置为 auto_pwm_min 值，该值只支持两个
取值：0 或 auto_point1_pwm。这意味着风扇要么完全停止，要么以低速占空比继续转动。
如果任一温度上升到 auto_point3_temp 值以上，所有 PWM 输出都被设置为 100% 占空比。

以下是芯片如何根据相关联热区的温度设置输出占空比的另一种表示：

	=============== =============== =================
	温度		占空比		占空比
			上升温度	下降温度
	=============== =============== =================
	full-speed	full-speed	full-speed

 - < 线性	-
			调整
			占空比 >

	low-speed	low-speed	low-speed
 - min-speed	low-speed
	min-speed	min-speed	min-speed
 - min-speed	min-speed
	=============== =============== =================

### Sysfs 属性

vrm				RW	电压调节模块（VRM）版本号。

in[0-7]_input			RO	测得的电压，单位毫伏。
in[0-7]_min			RW	电压输入的低限值。
in[0-7]_max			RW	电压输入的高限值。
in[0-7]_alarm			RO	电压输入告警。如果电压输入当前或曾经超出

temp[1-3]_input		RO	测得的温度，单位毫摄氏度。

temp[1-3]_max			RW	温度输入的高限值。
temp[1-3]_offset		RW	温度输入的偏移量。该值会被芯片加到测得的
				温度上。
temp[1-3]_alarm			RO	温度输入的告警。如果温度输入当前或曾经超出
				相关联的 min-max 范围则返回 1，否则返回 0。
temp[1-3]_fault			RO	温度输入故障。如果芯片检测到故障热二极管或未
				连接的温度输入则返回 1，否则返回 0。

zone[1-3]_auto_channels_temp	RO	温度区域到温度输入的映射。该属性是一个位域，
				支持以下值：

      - 1: temp1
      - 2: temp2
      - 4: temp3
zone[1-3]_auto_point1_temp_hyst	RW	自动 PWM 温度点 1 的迟滞。如果温度降到
				auto_point1_temp_hyst 值以下，相应的 PWM
				输出被设置为 pwm_auto_min 值。
zone[1-3]_auto_point[1-3]_temp	RW	自动 PWM 温度点。auto_point1 是低速温度，
				auto_point2 是满速温度，auto_point3 是使所有
				PWM 输出被设置为满速（100% 占空比）的温度。

fan[1-6]_input			RO	测得的风扇转速，单位 RPM。
fan[1-6]_min			RW	风扇输入的低限值。
fan[1-6]_alarm			RO	风扇输入的告警。如果风扇输入当前或曾经低于
				相关联的 min 值则返回 1，否则返回 0。
fan[1-4]_type			RW	所连接风扇的类型。表示为风扇每转产生的脉冲数。
				支持的值为 1、2 和 4。
fan[5-6]_max			RW	100% 占空比下可达到的最大 RPM。芯片据以相应
				调整采样率时需要此值。

pmw[1-3,5-6]			RO/RW	PWM 输出的占空比。支持的值为 0-255
				（0%-100%）。仅当相关联的 PWM 处于手动模式时
				才可写。
pwm[1-3]_enable			RW	PWM 输出 1-3 的使能。支持的值为：

      - 0: 关闭（输出 @ 100%）
      - 1: 手动模式
      - 2: 自动模式
pwm[5-6]_enable			RO	PWM 输出 5-6 的使能。始终返回 1，因为这两路
				输出被硬连线到手动模式。
pmw[1-3,5-6]_freq		RW	PWM 输出的频率。支持的值范围为 11Hz-30000Hz

pmw[1-3]_ramp_rate		RW	PWM 输出的斜坡速率。决定当 PWM 处于自动模式时

				瞬时变化）。
pwm[1-3]_auto_channels_zone	RW	PWM 输出到温度区域的映射。该属性是一个位域，

      - 2: zone2
      - 4: zone3

      - 7: zone[1-3] 中最热的
pwm[1-3]_auto_pwm_min		RW	自动 PWM 最小占空比。支持的值为 0 或
				auto_point1_pwm。
pwm[1-3]_auto_point1_pwm	RW	自动 PWM 占空比点。auto_point1 是低速占空比。
pwm[1-3]_auto_point2_pwm	RO	自动 PWM 占空比点。auto_point2 是满速占空比，
				硬连线为 255（100% 占空比）。
