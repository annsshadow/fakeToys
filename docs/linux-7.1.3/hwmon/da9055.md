## da9055 内核驱动


支持的芯片：
  - Dialog Semiconductors DA9055 PMIC

    Prefix: 'da9055'

    Datasheet: Datasheet is not publicly available.

Authors: David Dajun Chen <dchen@diasemi.com>

### 描述


DA9055 提供一个具10 位分辨率、带跟踪保持电路并组合了模拟输入多路复用器的
模数转换器（ADC）。模拟输入多路复用器允许对最5 个不同输入进行转换。跟保持电路确保在转换期ADC 输入端具有稳定的输入电压
ADC 用于测量以下输入
- Channel 0: VDDOUT —系统电压测量
- Channel 1: ADC_IN1 —高阻抗输入（0 - 2.5V- Channel 2: ADC_IN2 —高阻抗输入（0 - 2.5V- Channel 3: ADC_IN3 —高阻抗输入（0 - 2.5V- Channel 4: Internal Tjunc. —内部结温传感（内部温度传感器
通过使用 sysfs 属性，我们可以测量系统电压 VDDOUT、芯片结温以及辅助通道电压
### 电压监控


电压AUTO 模式采样，也可以手动采样，结果存储在 10 ADC 中
系统电压计算如下
	Milli volt = ((ADC value * 1000) / 85) + 2500

ADC 通道 1 3 上的电压计算如下
	Milli volt = (ADC value * 1000) / 102

### 温度监控


温度10 ADC 采样。结温由 ADC 通道监测
结温计算如下
	Degrees celsius = -0.4084 * (ADC_RES - T_OFFSET) + 307.6332

该驱动支持结温属性
