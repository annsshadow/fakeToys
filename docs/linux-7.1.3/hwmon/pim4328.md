    Prefix: 'pim4328', 'bmr455'

    Addresses scanned: -

    Datasheet:

https://flexpowermodules.com/resources/fpm-techspec-pim4328

  - Flex PIM4820

    Prefixes: 'pim4820'

    Addresses scanned: -

    Datasheet: https://flexpowermodules.com/resources/fpm-techspec-pim4820

  - Flex PIM4006, PIM4106, PIM4206, PIM4306, PIM4406

    Prefixes: 'pim4006', 'pim4106', 'pim4206', 'pim4306', 'pim4406'

Author: Erik Rosen <erik.rosen@metormote.com>


### 描述


该驱动支Flex PIM4328 及兼容的数字电源接口模块的硬件监视
该驱动是核心 PMBus 驱动的一个客户端驱动。有PMBus 客户端驱动的详细信息，请参阅 Documentation/hwmon/pmbus.rst Documentation.hwmon/pmbus-core

### 使用说明


该驱动不会自动检测设备。你必须显式实例化设备。详细信息请参阅 Documentation/i2c/instantiating-devices.rst

### 平台数据支持


该驱动支持标准的 PMBus 驱动平台数据

### Sysfs 接口


支持以下属性。所有属性均为只读
======================= ========================================================
in1_label		"vin"
in1_input		测得的输入电压in1_alarm		输入电压报警
in2_label		"vin.0"
in2_input		输入A 上测得的输入电压
			PIM4328 涓?PIM4X06

in3_label		"vin.1"
in3_input		输入B 上测得的输入电压
			PIM4328 涓?PIM4X06

in4_label		"vcap"
in4_input		保持电容（holdup capacitor）上测得的电压
			PIM4328

curr1_label		"iin.0"
curr1_input		输入A 上测得的输入电流
			PIM4X06

curr2_label		"iin.1"
curr2_input		输入B 上测得的输入电流
			PIM4X06

currX_label		"iout1"
currX_input		测得的输出电流currX_alarm		输出电流报警
			X 对于 PIM4820 1，否则为 3
temp1_input		测得的温度temp1_alarm		高温报警======================= ========================================================
