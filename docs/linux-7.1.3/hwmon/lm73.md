### 描述


LM73 是一款数字温度传感器。所有温度值均以摄氏度给出
### 测量分辨率支

LM73 支持四种分辨率，以每 LSB 多少摄氏度表示：0.25.125.0625 0.3125。更改分辨率模式会影LM73 模数转换器的转换时间。在用户空间，可通过设备'update_interval' sysfs 属性以转换时间为函数指定所需的分辨率。该属性会将输入值的取值范围归一化到数据手册中为分辨率定义的最大时间
    ============= ============= ============
    Resolution    Conv. Time    Input Range
    (C/LSB)       (msec)        (msec)
    ============= ============= ============
    0.25          14             0..14
    0.125         28            15..28
    0.0625        56            29..56
    0.03125       112           57..infinity
    ============= ============= ============

以下示例展示'update_interval' 属性如```

    $ echo 0 > update_interval
    $ cat update_interval
    14
    $ cat temp1_input
    24250

    $ echo 22 > update_interval
    $ cat update_interval
    28
    $ cat temp1_input
    24125

    $ echo 56 > update_interval
    $ cat update_interval
    56
    $ cat temp1_input
    24062

    $ echo 85 > update_interval
    $ cat update_interval
    112
    $ cat temp1_input
    24031

```
如这里所示，lm73 驱动通过阶跃函数自动调整用户'update_interval' 的任何输入。在写操作之后读'update_interval' 的值，可以确认当前实际使用的转换时间
从数学上讲，分辨率可由转换时间通过以下函数推导
   g(x) = 0.250 * [log(x/14) / log(2)]

其中 'x' 'update_interval' 的输出，'g(x)' 是每 LSB 摄氏度为单位的分辨率
### 报警支持


LM73 提供一个简单的过温报警机制。该特性通过 sysfs 属性暴露
属'temp1_max_alarm' 'temp1_min_alarm' LM73 提供的标志，分别指示测得的温度是否超过了 'temp1_max' 'temp1_min' 阈值。这些数值_必须_被读取以清除 LM73 上的寄存器
