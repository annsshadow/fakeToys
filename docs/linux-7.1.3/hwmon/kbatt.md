
## 内核驱动 kbatt


支持的芯片：

  - KEBA 电池监控控制器（FPGA 中的 IP 核）

    Prefix: 'kbatt'

Authors:

	Gerhard Engleder <eg@keba.com>
	Petar Bojanic <boja@keba.com>

### 描述


KEBA 电池监控控制器是一个用于 FPGA 的 IP 核，用于监控纽扣电池的健康状况。纽扣
电池通常用于在断电期间为 RTC 供电以保持当前时间。例如，CP500 FPGA 内置该 IP 核，
用于监控 PLC 的纽扣电池，相应的 cp500 驱动会为 kbatt 驱动创建一个辅助设备。

本驱动向用户空间提供有关纽扣电池健康状况的信息。实际上，应当通知用户空间纽扣
电池即将耗尽并需要更换。

纽扣电池必须进行主动测试，才能知道它是否即将耗尽。为此，会在纽扣电池上加载负载
并评估由此产生的电压。该评估由一些硬连线的模拟逻辑完成，它将电压与一个定义好的
限值进行比较。如果电压高于限值，则认为纽扣电池正常。如果电压低于限值，则纽扣
电池即将耗尽（或者损坏、被移除等），应更换为新电池。KEBA 电池监控控制器允许启动
纽扣电池的测试，并获取电压是高于还是低于限值的结果。无法获取实际电压，只能获得
电压是否低于某个限值的信息。

用于在健康检查时施加到纽扣电池上的测试负载，类似于断电期间的负载。因此，纽扣
电池的寿命会直接随每次测试的持续时间而减少。为了限制对寿命的负面影响，测试被
限制为最多每 10 秒一次。测试负载施加到纽扣电池上的时间为 100ms。因此，在最坏
情况下，纽扣电池的寿命会减少运行时间的 1%，即每年 3.65 天。由于纽扣电池可使用
多年，这种寿命减少可以忽略不计。

本驱动仅提供一个告警属性，当纽扣电池即将耗尽时会被置位。

属性                  R/W  内容
====================== ==== ===================================================
in0_min_alarm          R    带载的纽扣电池电压低于限值
