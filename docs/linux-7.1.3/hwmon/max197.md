## 内核驱动 max197


Author:

  - Vivien Didelot <vivien.didelot@savoirfairelinux.com>

Supported chips:

  - Maxim MAX197

    Prefix: 'max197'

    Datasheet: https://www.analog.com/media/en/technical-documentation/data-sheets/MAX197.pdf

  - Maxim MAX199

    Prefix: 'max199'

    Datasheet: https://www.analog.com/media/en/technical-documentation/data-sheets/MAX199.pdf

### 描述


A/D 转换MAX197 MAX199 都是 8 通道、多量程V2 DAS，带8+4 总线接口与故障保护（Fault Protection）
MAX197 的可用量程为 {0,-5V} 5V，以{0,-10V} 10V，MAX199 上为 {0,-2V} 2V，以{0,-4V} 4V
### 平台数据


MAX197 平台数据（定义于 linux/platform_data/max197.h）应当为
```

    int convert(u8 ctrl);

```
ctrl 是用于启动新转换而要写入的控制字节。成功时，该函数必须返回从芯片读取的 12 位原始值，否则返回负的错误码
控制字节格式
======= ========== ============================================
Bit     Name       Description
7,6     PD1,PD0    时钟与掉电（Power-Down）模5       ACQMOD     内部或外部控制的采集（Acquisition4       RNG        输入端的满量程电压幅3       BIP        单极性或双极性转换模2,1,0   A2,A1,A0   通道
======= ========== ============================================

### Sysfs 接口


  ============== ==============================================================
  in[0-7]_input  对应通道的转换值		 RO

  in[0-7]_min    对应通道的下限（单位 mV）		 对于 MAX197，将被调整为 -100005000 0		 对于 MAX199，将被调整为 -40002000 0		 RW

  in[0-7]_max    对应通道的上限（单位 mV）		 对于 MAX197，将被调整为 0000 10000		 对于 MAX199，将被调整为 0000 4000		 RW
