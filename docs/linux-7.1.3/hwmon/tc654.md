### 描述

本驱动实现对 Microchip TC654 TC655 的支持
TC654 采用兼容 SMBUS 2.0 规范2-wire 接口。TC654 具有两个）路用于测量风扇转速（RPM）的输入，以及一个（1）路可用于风扇控制的 PWM 输出
### 配置说明

通常 pwm1_mode ABI 用于控制 pwm 输出模式。但对于该芯片，输出始终pwm，且 pwm1_mode 决定 pwm 输出是由 pwm1 值控制，还是Vin 模拟输入控制
pwm1_mode 设为 1 时，pwm 输出将依pwm1 值驱动；pwm1_mode 设为 0 时，pwm 输出将依Vin 输入驱动
