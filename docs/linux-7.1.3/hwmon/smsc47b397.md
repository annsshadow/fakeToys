### dc7100 上检HP SIO 并读取温度数据的方法


dc7100 上的温度信息包含SIO 硬件监视器（HWM）中该信息通过一对索数据寄存器访问。索数据对位HWM 基地址 + 0 HWM 基地址 + 1。HWM 基地址可以从逻辑设备 8寄存0x60（MSB）与 0x61（LSB）获得。当前我们使0x480 作为
HWM 基地址，使0x480 0x481 作为索引/数据对
读取温度信息温度信息位于以下寄存器：

=============== ======= =======================================================
Temp1		0x25	（当前这反映所有系统上CPU 温度）Temp2		0x26
Temp3		0x27
Temp4		0x80
=============== ======= =======================================================

编程示例
```

	MOV	DX,480H
	MOV	AX,25H
	OUT	DX,AL
	MOV	DX,481H
	IN	AL,DX

```
AL 中包含十六进制数据，摄氏温度为其十进制等值
例：如果 AL 包含 0x2A，则温度42 摄氏度
读取转速（tach）信息风扇转速信息位于以下寄存器
=============== ======= ======= =================================
		LSB	MSB
Tach1		0x28	0x29	（当前这反映所有系统上CPU
				风扇转速）Tach2		0x2A	0x2B
Tach3		0x2C	0x2D
Tach4		0x2E	0x2F
=============== ======= ======= =================================


	读取 tach LSB 会锁tach MSB	必须先读LSB
### 如何tach 读数转换RPM


tach 读数（TCount）由下式给出Tach MSB * 256) + (Tach LSB)
SIO 统计每转90kHz1.111us）脉冲数RPM = 60/(TCount * 11.111us)

```

	Reg 0x28 = 0x9B
	Reg 0x29 = 0x08

```
TCount = 0x89B = 2203

RPM = 60 / (2203 * 11.11111 E-6) = 2451 RPM

### 配置序列


要编程配置寄存器，必须遵循以下序列：
1. 进入配置模式
2. 配置配置寄存3. 退出配置模
##### 进入配置模式


要将芯片置于配置状态，将配置键x55）写CONFIG PORTx2E）
##### 配置模式


在配置模式下，INDEX PORT 位于 CONFIG PORT 地址，DATA PORT 位于
INDEX PORT 地址 + 1
访问所需的配置寄存器分两步：

a.	将逻辑设备号配置寄存器（即 0x07）的索引写入 INDEX PORT	然后将所需逻辑设备的编号写DATA PORT
b.	将逻辑设备内所需配置寄存器的地址写入 INDEX PORT	然后通过 DATA PORT 写入或读取配置寄存器
注意	如果访问全局配置寄存器，则不需要步(a)
##### 退出配置模

要退出配置状态，0xAA 写入 CONFIG PORTx2E）芯片返回RUN 状态。（这很重要）
##### 编程示例


以下是如何读取位0x20 SIO 设备 ID 的示例：

	; ENTER CONFIGURATION MODE
	MOV	DX,02EH
	MOV	AX,055H
	OUT	DX,AL
	; GLOBAL CONFIGURATION  REGISTER
	MOV	DX,02EH
	MOV	AL,20H
	OUT	DX,AL
	; READ THE DATA
	MOV	DX,02FH
	IN	AL,DX
	; EXIT CONFIGURATION MODE
	MOV	DX,02EH
	MOV	AX,0AAH
	OUT	DX,AL

用于dc7100 上识SIO 的相关寄存器是设IDx20）和设备版本x21）
设备 ID 将读0x6F（SCH5307-NS 0x81，SCH5317 0x85设备版本当前读为 0x01

### 获取 HWM 基地址


以下是如何读取位```

	; ENTER CONFIGURATION MODE
	MOV	DX,02EH
	MOV	AX,055H
	OUT	DX,AL
	; CONFIGURE REGISTER CRE0,
	; LOGICAL DEVICE 8
	MOV	DX,02EH
	MOV	AL,07H
	OUT	DX,AL ;Point to LD# Config Reg
	MOV	DX,02FH
	MOV	AL, 08H
	OUT	DX,AL;Point to Logical Device 8
	;
	MOV	DX,02EH
	MOV	AL,60H
	OUT	DX,AL	; Point to HWM Base Addr MSB
	MOV	DX,02FH
	IN	AL,DX	; Get MSB of HWM Base Addr
	; EXIT CONFIGURATION MODE
	MOV	DX,02EH
	MOV	AX,0AAH
	OUT	DX,AL

```
