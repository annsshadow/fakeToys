## 内核驱动 pwm-fan


该驱动支持使用 PWM 模块驱动风扇。它使用通用 PWM 接口，因此与硬件无关。
只要 SoC 提供暴露通用 PWM API 的 PWM 线路驱动器，即可在许多 SoC 上使用。

作者：Kamil Debski <k.debski@samsung.com>

### 描述


该驱动实现了一个用于驱动连接到 PWM 输出的风扇的简单接口。它使用通用
PWM 接口，因此可与多种 SoC 配合使用。该驱动通过 hwmon 的 sysfs 接口向
用户空间暴露风扇。

通过可选的 'fan1_input' 返回的风扇转速，是从 1 秒内取自测速信号的
中断推演而来。

该驱动在 sysfs 中提供以下传感器访问：

=============== ======= =======================================================
fan1_input	ro	风扇转速计转速（RPM）
pwm1_enable	rw	保持使能模式，定义 pwm1=0 时的行为
			0 -> 禁用 pwm 与稳压器
			1 -> 启用 pwm；若 pwm==0，禁用 pwm，保持稳压器启用
			2 -> 启用 pwm；若 pwm==0，保持 pwm 与稳压器启用
			3 -> 启用 pwm；若 pwm==0，禁用 pwm 与稳压器
pwm1		rw	相对转速（0-255），255=最大转速。
=============== ======= =======================================================
