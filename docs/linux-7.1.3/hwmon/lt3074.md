
## 内核驱动 lt3074


支持的芯片：

  - Analog Devices LT3074

    Prefix: 'lt3074'

    Addresses scanned: -

    Datasheet: https://www.analog.com/en/products/lt3074.html

Authors: Cedric Encarnacion <cedricjustine.encarnacion@analog.com>


### 描述


该驱动支持对带有 PMBus 接口的 Analog Devices LT3074 线性稳压器（Linear Regulator）的硬件监视。

LT3074 是一款低压、超低噪声且超快瞬态响应的线性稳压器，带有 PMBus 串行接口。PMBus 遥测（telemetry）特性提供有关输出电压与电流、输入电压、偏置电压以及芯片温度的信息。

该驱动是核心 PMBus 驱动的一个客户端驱动。有关 PMBus 客户端驱动的详细信息，请参阅 Documentation/hwmon/pmbus.rst。

### 使用说明


该驱动不会自动检测设备。你必须显式实例化设备。详细信息请参阅 Documentation/i2c/instantiating-devices.rst。

### 平台数据支持


该驱动支持标准的 PMBus 驱动平台数据。
