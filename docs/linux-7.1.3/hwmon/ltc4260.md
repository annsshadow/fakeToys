## 内核驱动 ltc4260


支持的芯片：

  - Linear Technology LTC4260

    Prefix: 'ltc4260'

    扫描的地址：-

    Datasheet:

	http://cds.linear.com/docs/en/datasheet/4260fc.pdf

作者：Guenter Roeck <linux@roeck-us.net>


### 描述


LTC4260 热插拔控制器允许将一块板安全地插入活动背板并从中移除。


### 使用说明


该驱动不会探测 LTC4260 设备，因为没有可以安全用于识别该芯片的寄存器。你必须显式地实例化这些设备。

示例：以下命令将为地址 0x10 处的 LTC4260 加载驱动
```

	$ modprobe ltc4260
	$ echo ltc4260 0x10 > /sys/bus/i2c/devices/i2c-1/new_device

```
### Sysfs 条目


电压读数由该驱动提供，按从 ADC 寄存器获取的值报告。如果安装了分压电阻组，请将报告值乘以 (R1+R2)/R2 来计算实际电压，其中 R1 是相对于被测电压的分压电阻值，R2 是相对于地（Ground）的分压电阻值。

电流读数由该驱动提供，按从 ADC 电流检测（Current Sense）寄存器获取的值报告。报告值假设安装了 1 mOhm 的检测电阻。如果安装了不同的检测电阻，请将报告值除以以 mOhm 为单位的检测电阻值来计算实际电流。

======================= =======================
in1_input		SOURCE 电压 (mV)
in1_min_alarm		欠压报警
in1_max_alarm		过压报警

in2_input		ADIN 电压 (mV)
in2_alarm		电源异常报警

curr1_input		SENSE 电流 (mA)
curr1_alarm		SENSE 过流报警
======================= =======================
