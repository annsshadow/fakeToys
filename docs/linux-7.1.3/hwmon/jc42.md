### 描述


该驱动实现对符合 JEDEC JC 42.4 规范的温度传感器的支持，这些传感器被广泛用于
移动设备和服务器上的许多 DDR3 内存模块中。某些系统利用该传感器，通过自动节流
内存控制器来防止内存过热
该驱动会自动检测上述列出的芯片，但也可通过手动实例化来支持其他符合 JC 42.4
规范的芯片
示例：以下命令将为通用JC 42.4 兼容芯片加载驱动
```
	# modprobe jc42
	# echo jc42 0x18 > /sys/bus/i2c/devices/i2c-1/new_device

```
符合 JC 42.4 规范的芯片支持单个温度传感器。可配置最低、最高和临界温度。并针对
高、低和临界阈值提供告警
此外还有用于复位告警阈值控制的迟滞（hysteresis）。按JC 42.4 规范，迟滞阈可配置为 0.5.0 6.0 摄氏度。配置的迟滞值会被舍入到这些限值。芯片仅支持
一个用于配置迟滞的寄存器，该寄存器对所有限值都生效。可通过写入 temp1_crit_hyst
来写入该寄存器。其他迟滞属性为只读
如果 BIOS 已将传感器配置为自动温度管理，则很可能已锁定相关寄存器，即温度限无法被更改
