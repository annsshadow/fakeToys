## 内核驱动 adm1025


支持的设备：

  - Analog Devices ADM1025、ADM1025A

    Prefix: 'adm1025'

    Addresses scanned: I2C 0x2c - 0x2e

    Datasheet: 可在 Analog Devices 网站公开获取

  - Philips NE1619

    Prefix: 'ne1619'

    Addresses scanned: I2C 0x2c - 0x2d

    Datasheet: 可在 Philips 网站公开获取

NE1619 与原ADM1025 存在一些差异：

  - 只有两个可能的地址x2c - 0x2d）  - 没有温度偏移寄存器，但我们反正也没使用它  - 引脚 16 没有 INT 模式。我们反正也不去动它

### 描述


（以下内容来Analog Devices。）ADM1025 是面向基于微处理器的系统的完系统硬件监控器，提供对各种系统参数的测量与限值比较。提供五个电压测输入，用于监+2.5V3.3V5V +12V 电源以及处理器核心电压ADM1025 还可以通过测量自身VCC 来监控第六路电源轨电压。一个输（两个引脚）专用于远端温度感测二极管，片内温度传感器则可用于监控环境
温度
该芯片的一个特性是引脚 11 可以通过两种不同方式硬连线。它可以作为 +12V
电源电压的模拟输入，也可以作VID 读取（位 4）的第五个数字输入。这
有点奇怪，因为两者都有用，而这样设计芯片的原因至少对我而言是模糊的配置寄存器的5 可用于定义芯片的硬连线方式。请注意，作为用户，并不是你需要做出的选择。这个选择已经由你的主板制造商做好了。如果配位设置不当，你会得到错误+12V 读数或错误的 VID 读数。驱动处理此问题
的方式是在初始化过程中保留该位，假定 BIOS 此前已正确设置它。如果某情况下事实并非如此，我们会提供一个模块参数来强制设置模式
本驱动也支持 ADM1025A，它ADM1025 的唯一区别在于“ADM1025A 具有开VID 输入，ADM1025 VID 输入上具有片100k 上拉”。这对我们没有任区别
