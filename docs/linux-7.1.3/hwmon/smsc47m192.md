## 内核驱动 smsc47m192


支持的设备：

  - SMSC LPC47M192、LPC47M15x、LPC47M292 和 LPC47M997

    Prefix: 'smsc47m192'

    Addresses scanned: I2C 0x2c - 0x2d

    Datasheet: LPC47M192 的数据手册可从以下地址公开获取

	       http://www.smsc.com/

	       对于硬件监控而言，LPC47M15x、LPC47M292 和 LPC47M997 是兼容的。

### 描述

该驱动实现对 SMSC LPC47M192 及兼容的 Super-I/O 芯片硬件传感器能力的支持。

这些芯片支持 3 路温度通道和 8 路电压输入，以及 CPU 电压 VID 输入。

它们也具有风扇监控和控制能力，但这些功能通过 ISA 总线访问，不被该驱动支持。请使用
'smsc47m1' 驱动进行风扇监控和控制。

电压和温度由一个 8 位 ADC 测量，温度的分辨率为每摄氏度 1 位。电压被缩放，使得标称
电压对应 192 个计数，即满量程的 3/4。因此每个电压通道的可用范围是 0V ... 255/192*
（标称电压），分辨率为每（标称电压）/192 一位。电压和温度值都按 1000 缩放，sys
文件以 mV 显示电压，以 0.001 摄氏度为单位显示温度。

+12V 模拟电压输入通道（in4_input）与编码后的 CPU 电压的第 4 位复用。这意味着你要么
得到 +12V 电压测量，要么得到 5 位 CPU VID，但不能同时得到两者。默认设置是将该引脚
用作 12V 输入，并只使用 4 位 VID。该驱动假定配置寄存器中的信息是正确的，即如果
主板将此输入接到 VID4，BIOS 已经更新了配置。

温度和电压读数每 1.5 秒更新一次。更频繁地读取只会重复相同的值。


### sysfs 接口

===================== ==========================================================
in0_input	      +2.5V 电压输入
in1_input	      CPU 电压输入（标称 2.25V）
in2_input	      +3.3V 电压输入
in3_input	      +5V 电压输入
in4_input	      +12V 电压输入（若用作 VID4 则可能缺失）
in5_input	      Vcc 电压输入（标称 3.3V）
		      这是传感器芯片自身的供电电压。
in6_input	      +1.5V 电压输入
in7_input	      +1.8V 电压输入

in[0-7]_min,
in[0-7]_max	      对 in[0-7]_input 读数的低/高报警阈值

		      所有电压都以 mV 读写。

in[0-7]_alarm	      电压输入的报警标志
		      这些文件在报警时读为 '1'，否则为 '0'。

temp1_input	      由片上二极管测量的芯片温度
temp[2-3]_input	      由外部二极管测量的温度（其中之一通常接到 CPU 内的二极管）

temp[1-3]_min,
temp[1-3]_max	      温度的低/高报警阈值

temp[1-3]_offset       温度偏移寄存器
		      芯片会把这些寄存器中保存的偏移加到相应的温度读数上。
		      注意 temp1 和 temp2 的偏移共用同一寄存器，它们不能同时为非零。
		      向其中之一写入非零值会将另一个偏移复位为零。

		      所有温度和偏移都以 0.001 摄氏度为单元读写。

temp[1-3]_alarm        温度输入的报警标志，报警时为 '1'，否则为 '0'。
temp[2-3]_input_fault  温度输入 2 和 3 的二极管故障标志。
		      如果相应传感器的两个引脚开路或短路，或二者中任一个与地或 Vcc
		      短路，则检测到故障。'1' 表示二极管故障。

cpu0_vid	      CPU 电压（从 CPU 处收到）

vrm		     用于解码 CPU 电压的 CPU VID 标准
===================== ==========================================================

`**_min`、`**_max`、`*_offset` 和 `vrm` 文件可读可写，其余均为只读。
