### 描述


德州仪器 TMP108 实现一个温度传感器。当温度超过最小或最大值加上或减去一滞回值时，可以设置一个报警引脚。（此驱动不支持报警引脚的中断，
设备运行在比较器模式。）

该传感器-25 +85 C 范围内精度为 0.75C，在 -40 +125 C 范围精度1.0 度。传感器的分辨率0.0625 度。工作温度最小值为 -55 C最大值为 +150 C。滞回值可设置0 4C
TMP108 具有可编程的更新速率，可8 0.5 Hz 之间选择
默认情况TMP108 连续读取温度。为节省功耗，TMP108 具有一次性模式，
此时设备通常处于关闭状态。当请求一次单次测量时，读取温度，结果可被获取随后设备自动关闭。（此驱动仅支持连续模式。）

该驱动为温度提供通用sysfs 接口（参Documentation/hwmon/sysfs-interface.rst 中的“温度”部分）
