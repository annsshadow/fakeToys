## 内核驱动 vt1211


支持的芯片：

  - VIA VT1211

    Prefix: 'vt1211'

    Addresses scanned: 无，地址从 Super-I/O 配置空间读取

    Datasheet: 由 VIA 应要求并在 NDA 下提供

Authors: Juerg Haefliger <juergh@gmail.com>

该驱动基于 Mark D. Studebaker 为内核 2.4 编写的驱动，以及 Lars Ekman 移植到内核 2.6 的版本。

感谢 VIA 的 Joseph Chan 和 Fiona Gatt 提供文档和技术支持。

### 模块参数


- uch_config: int
			覆盖 BIOS 默认的通用通道（UCH）1-5 的配置。
			合法值在 0-31 范围内。位 0 映射到 UCH1，位 1 映射到 UCH2，依此类推。将某位设为 1
			启用该特定 UCH 的热输入，将某位设为 0 启用电压输入。

- int_mode: int
			覆盖 BIOS 默认的温控中断模式。
			唯一可能的值是 0，它强制中断模式 0。在此模式下，任何挂起的中断在读取状态寄存器时被清除，
			但只要温度保持在迟滞上限之上就会重新产生。

请注意，覆盖 BIOS 默认值可能会导致一些不想要的副作用！

### 说明


VIA VT1211 Super-I/O 芯片具备完整的硬件监控能力。它监控 2 个专用温度传感器输入（temp1 和 temp2）、1 个专用电压（in5）和 2 个风扇。此外，该芯片实现了 5 个通用输入通道（UCH1-5），可以各自编程为监控电压或温度。

该芯片还提供风扇转速的手动和自动（根据数据手册）控制。驱动仅支持自动模式，因为手动模式似乎并不像数据手册所描述的那样工作。事实上我根本无法让手动模式工作！请注意，自动模式尚未得到很好的测试（因为我的 EPIA M10000 的风扇并没有连接到 VT1211 的 PWM 输出 :-()。

下表显示了 vt1211 输入与 sysfs 节点之间的关系。

### 电压监控


电压由 8 位 ADC 采样，LSB 约为 10mV。因此支持的输入范围为 0 到 2.60V。超出此范围的电压值需要外部分压电阻。这种外部分压需要通过 sensors.conf 中的 compute 行来补偿，例如：

compute inx @*(1+R1/R2), @/(1+R1/R2)

根据 VIA 的建议，板级分压电阻如下。当然，这完全取决于实际的板卡实现 :-) 你需要为自己的主板找到文档并相应地编辑 sensors.conf。

============= ====== ====== ========= ============
				      期望
电压            R1     R2     分压比     原始值
============= ====== ====== ========= ============
+2.5V         2K     10K    1.2       2083 mV
VccP          ---    ---    1.0       1400 mV [^1^]_
| 5V           14K    10K    2.4       2083 mV |
| --- |
============= ====== ====== ========= ============

       执行缩放并返回正确缩放后的电压值。

每个被测电压都有一个关联的低限和高限，越界时会触发告警。

### 温度监控


温度以毫摄氏度报告。每个被测温度都有一个高限，越界时触发告警。每个温度都有一个关联的迟滞值，温度必须降到该值以下告警才会被清除（这仅对中断模式 0 成立）。如果 BIOS 没有自动将中断模式强制为 0，可以手动强制。详见“模块参数”一节。

除 temp2 外的所有温度通道都是外部的。Temp2 是 VT1211 内部热敏二极管，驱动对 temp2 完成所有缩放并返回毫摄氏度温度。对于外部通道 temp1 和 temp3-temp7，缩放取决于板卡实现，需要在用户空间通过 sensors.conf 完成。

Temp1 是一个 Intel 型热敏二极管，需要以下公式在 sysfs 读数与真实温度之间转换：

compute temp1 (@-Offset)/Gain, (@*Gain)+Offset

根据 VIA VT1211 BIOS 移植指南，应使用以下增益和偏移值：

=============== ======== ===========
二极管类型       偏移     增益
=============== ======== ===========
Intel CPU       88.638   0.9528
		65.000   0.9686 [^3^]_
VIA C3 Ezra     83.869   0.9528
VIA C3 Ezra-T   73.869   0.9528
=============== ======== ===========

       知道它从何而来或如何推导，这里仅出于完整性列出。

Temp3-temp7 支持 NTC 热敏电阻。对于这些通道，驱动返回在 UCH1-UCH5 各引脚处测得的电压。引脚处的电压（Vpin）由热敏电阻（Rth）和

```
  Vpin = 2200 * Rth / (Rs + Rth)   (2200 是 ADC 最大限值 2200 mV)
```

热敏电阻的方程如下（若想知道可谷歌之）

```
  Rth = Ro * exp(B * (1 / T - 1 / To))   (To 为 298.15K（25℃），Ro 为
					  25℃ 时的标称电阻)
```

将上述两个方程混合，并假设 Rs = Ro、B = 3435 可得

```
  compute tempx 1 / (1 / 298.15 - (` (2200 / @ - 1)) / 3435) - 273.15,
		2200 / (1 + (^ (3435 / 298.15 - 3435 / (273.15 + @))))
```

### 风扇转速控制


VT1211 提供 2 个可编程 PWM 输出来控制 2 个风扇的转速。向两个 pwm[1-2]_enable sysfs 节点之一写入 2，会将 PWM 控制器置于自动模式。只有一个控制器控制两个 PWM 输出，但每个 PWM 输出可以单独启用和禁用。

每个 PWM 有 4 个关联的不同输出占空比：全速、高速、低速和关闭。全速和关闭在内部硬连线为 255（100%）和 0（0%）。高速和低速可以通过 pwm[1-2]_auto_point[2-3]_pwm 编程。每个 PWM 输出可以关联一个不同的热输入，但是——奇怪的地方来了——只有一组热阈值存在，它同时控制两个 PWM 的输出占空比。这些热阈值可通过 pwm[1-2]_auto_point[1-4]_temp 访问。注意，尽管有 2 组各 4 个自动点，它们映射到 VT1211 中相同的寄存器，编程一组就足够了（实际上只有第一组 pwm1_auto_point[1-4]_temp 可写，第二组是只读的）。

========================== =========================================
PWM 自动点                 PWM 输出占空比
========================== =========================================
pwm[1-2]_auto_point4_pwm   全速占空比（硬连线为 255）
pwm[1-2]_auto_point3_pwm   高速占空比
pwm[1-2]_auto_point2_pwm   低速占空比
pwm[1-2]_auto_point1_pwm   关闭占空比（硬连线为 0）
========================== =========================================

==========================  =================
温度自动点                  热阈值
==========================  =================
pwm[1-2]_auto_point4_temp   全速温度
pwm[1-2]_auto_point3_temp   高速温度
pwm[1-2]_auto_point2_temp   低速温度
pwm[1-2]_auto_point1_temp   关闭温度
==========================  =================

高速温度
