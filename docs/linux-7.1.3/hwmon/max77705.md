## 内核驱动 max77705


支持的芯片：

  - Maxim Integrated MAX77705

    Prefix: 'max77705'

    Addresses scanned: none

    Datasheet:

	    https://www.analog.com/media/en/technical-documentation/data-sheets/max77505.pdf

作者：
      - Dzmitry Sankouski <dsankouski@gmail.com>

### 描述


除电量计（fuelgauge）外，MAX77705 PMIC 还提供电流与电压测量：
- 芯片输入电流
- 系统总线电流与电压
- VBYP 电压

### Sysfs 属性


================= ========================================
in1_label         "vbyp"
in1_input         测得的芯片 vbyp 电压
in2_label         "vsys"
in2_input         测得的芯片系统总线电压
curr1_label       "iin"
curr1_input       测得的芯片输入电流。
curr2_label       "isys"
curr2_input       测得的芯片系统总线电流。
================= ========================================
