## 内核驱动 ina3221


支持的芯片：

  - Texas Instruments INA3221

    前缀: 'ina3221'

    地址: I2C 0x40 - 0x43

    数据手册: 可在 Texas Instruments 网站公开获取

	       https://www.ti.com/

作者: Andrew F. Davis <afd@ti.com>

### 描述


Texas Instruments INA3221 监视最多三个直流（D.C.）电源高端的电压、电流和功率。INA3221 同时监视分流压降和电源电压，具有可编程序转换时间和均值计算，电流和功率由主机侧根据这些计算得出。

in[^123^]_label           电压通道标签
in[^123^]_enable          电压通道使能控制
in[^123^]_input           总线电压（mV）通道
curr[^123^]_input         电流（mA）测量通道
shunt[^123^]_resistor     分流电阻（uOhm）通道
curr[^123^]_crit          临界告警电流（mA）设置，当相应电流超过此值时触发对应的告警
curr[^123^]_crit_alarm    已超过临界告警电流限制
curr[^123^]_max           警告告警电流（mA）设置，当相应电流平均值超过此值时触发对应的告警
curr[^123^]_max_alarm     已超过警告告警电流限制
in[^456^]_input           分别为通道 1、2、3 的分流电压（uV）
in7_input               分流电压（uV）通道之和
in7_label               分流电压之和的通道标签
curr4_input             电流（mA）测量通道之和，
                        （仅当所有通道对其分流电阻使用相同阻值时可用）
curr4_crit              电流测量之和的临界告警电流（mA）设置，当相应电流超过此值时触发对应的告警
                        （仅当所有通道对其分流电阻使用相同阻值时生效）
curr4_crit_alarm        电流测量之和已超过临界告警电流限制
samples                 均值模式中使用的采样数。

                        支持以下采样数列表：

                          1, 4, 16, 64, 128, 256, 512, 1024

update_interval         数据转换时间（毫秒），遵循：

                          update_interval = C x S x (BC + SC)

                          - C:	已启用通道的数量
                          - S:	采样数
                          - BC:	总线电压转换时间（毫秒）
                          - SC:	分流电压转换时间（毫秒）

                        影响总线电压和分流电压的转换时间。
                        注意，将 update_interval 设为 0ms 会将 BC 和 SC 都设为 140 us（最小转换时间）。
