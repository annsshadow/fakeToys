### 模块参数


- polarity int
  输出的极性：

  - 0 = 高电平有效（active high），
  - 1 = 低电平有效（active low）

### 描述


DS1621 是一个（单实例）数字温度计和恒温器。它同时具有高、低温度限制，可由
用户定义（即编程到片内非易失寄存器中）。温度范围为 -55 摄氏度到 +125 摄氏度，
以 0.5 为步进。您可以将其转换为 -67 到 +257 华氏度的范围，以 0.9 为步进。如果
未提供 polarity 参数，则使用原始值。

至于恒温器，其行为也可以通过 polarity 开关进行编程。一方面（"加热器"），芯片
的恒温器输出 Tout 会在达到或低于低温度限制时触发，并保持高电平直到达到或超过
高温度限制。另一方面（"冷却器"）则相反。因此"加热器"等于"active low"，而
"conditioner"等于"active high"。请注意，DS1621 数据手册在这一点上有些误导，因为
设置 polarity 位并不会简单地反转 Tout。

第二点是，在大量测试中，即使与精确的温度读数相比，Tout 也表现出高达 +/- 0.5 度
的容差。不过，请务必使高、低温度限制之间至少保持 1.0 摄氏度的间隔，以避免 Tout
"抖动"！

当达到或超过高或低限制时，告警位被置位；一旦离开相应的温度范围，模块就会清除
它们。

告警寄存器完全不适合用来确定 Tout 的实际状态。它们只会告诉您其历史——自上电
或复位以来是否有任何限制曾经被达到或超过。请注意：测试表明，即使两个告警都未
置位，Tout 的状态也可能发生变化。

由于不存在版本或厂商识别寄存器，这些设备没有唯一的标识。因此，需要显式实例化
设备以正确识别和发挥其功能（在此地址范围内每个地址对应一个设备：0x48..0x4f）。

DS1625 与 DS1621 引脚兼容且功能等效，但 DS1621 意在取代它。DS1631、DS1721 和
DS1731 也与 DS1621 引脚兼容，并提供多分辨率支持。

此外，DS1721 数据手册称温度标志（THF 和 TLF）在内部使用，然而当实际温度越过
最小或最大设置（默认分别设为 75 和 80 度）时，这些标志确实会被置位和清除。

### 温度转换


- DS1621 - 750ms（较旧的设备可能长达 1000ms）
- DS1625 - 500ms
- DS1631 - 93ms..750ms，分别对应 9..12 位分辨率。
- DS1721 - 93ms..750ms，分别对应 9..12 位分辨率。
- DS1731 - 93ms..750ms，分别对应 9..12 位分辨率。

注意：
在 DS1621 上，对片内非易失寄存器的访问可能持续 10ms 或更短（其他设备未经验证）。

### 温度精度


- DS1621: +/- 0.5 摄氏度（从 0 到 +70 度）
- DS1625: +/- 0.5 摄氏度（从 0 到 +70 度）
- DS1631: +/- 0.5 摄氏度（从 0 到 +70 度）
- DS1721: +/- 1.0 摄氏度（从 -10 到 +85 度）
- DS1731: +/- 1.0 摄氏度（从 -10 到 +85 度）


   有关其他温度下的精度，请参阅器件数据手册。

### 温度分辨率：


如上所述，DS1631、DS1721 和 DS1731 提供多分辨率支持，这是通过 R0 和 R1 配置
寄存器位实现的，其中：

### R0..R1


== ==  ===============================
R0 R1
== ==  ===============================
 0  0  9 bits, 0.5 degrees Celsius
 1  0  10 bits, 0.25 degrees Celsius
 0  1  11 bits, 0.125 degrees Celsius
 1  1  12 bits, 0.0625 degrees Celsius
== ==  ===============================


   在器件初始上电时，默认分辨率设为 12 位。

DS1631、DS1721 或 DS1731 的分辨率模式可以通过设备的 'update_interval' sysfs
属性从用户空间更改。该属性会将输入值范围归一化到数据手册中定义的最大分辨率值，
如下：

============= ================== ===============
Resolution    Conversion Time    Input Range
 (C/LSB)       (msec)             (msec)
============= ================== ===============
0.5             93.75              0....94
0.25            187.5              95...187
0.125           375                188..375
0.0625          750                376..infinity
============= ================== ===============

以下示例展示了 'update_interval' 属性如何

```
  $ cat update_interval
  750
  $ cat temp1_input
  22062
  $
  $ echo 300 > update_interval
  $ cat update_interval
  375
  $ cat temp1_input
  22125
  $
  $ echo 150 > update_interval
  $ cat update_interval
  188
  $ cat temp1_input
  22250
  $
  $ echo 1 > update_interval
  $ cat update_interval
  94
  $ cat temp1_input
  22000
  $
  $ echo 1000 > update_interval
  $ cat update_interval
  750
  $ cat temp1_input
  22062
  $

```
如所示，ds1621 驱动通过阶跃函数自动调整用户传入的 'update_interval'。写入操作
后读回 'update_interval' 值，即可得到设备所使用的转换时间。

从数学上讲，分辨率可以从转换时间通过以下函数推导：

   g(x) = 0.5 * [minimum_conversion_time/x]

其中：

 - 'x' = 'update_interval' 的输出
 - 'g(x)' = 每 LSB 的分辨率（摄氏度）。
 - 93.75ms = 最小转换时间
