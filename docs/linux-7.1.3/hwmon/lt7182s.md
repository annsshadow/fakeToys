
## 内核驱动 lt7182s


支持的芯片：

  - ADI LT7182S

    Prefix: 'lt7182s'

    扫描地址：-

    Datasheet: https://www.analog.com/en/products/lt7182s.html

Author: Guenter Roeck <linux@roeck-us.net>


### 描述


LT7182S 是一款双通道 6A、20V 多相降压（PolyPhase Step-Down）静音交换器，支持数字
电源系统管理。


### 使用注意


本驱动不会探测 PMBus 设备。你需要显式地实例化设备。

示例：以下命令将为 LT7182S 加载驱动

```

    # modprobe lt7182s
    # echo lt7182s 0x4f > /sys/bus/i2c/devices/i2c-4/new_device

```
它也可以通过在设备树中声明一个条目来实例化。
