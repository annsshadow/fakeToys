## 内核驱动 w83793


支持的设备：

  - Winbond W83793G/W83793R

    Prefix: 'w83793'

    Addresses scanned: I2C 0x2c - 0x2f

    Datasheet: 尚未公开

作者：
    - Yuan Mu (Winbond Electronics)
    - Rudolf Marek <r.marek@assembler.cz>


### 模块参数


- reset int
    （默认 0）

    不建议使用该参数，它会丢失主板特定的设置。使用 'reset=1' 可在加载该模块时
    重置芯片。

- force_subclients=bus,caddr,saddr1,saddr2
    用于强制某个芯片的子客户端的 i2c 地址。典型用法是
    `force_subclients=0,0x2f,0x4a,0x4b`，将 bus 0 上芯片 0x2f 的子客户端
    强制为 i2c 地址 0x4a 和 0x4b。


### 描述

该驱动实现对 Winbond W83793G/W83793R 芯片的支持。

- 导出的功能
    该驱动导出 10 个电压传感器、最多 12 路风扇转速计输入、6 路远端温度、最多 8 组
    PWM 风扇控制、在所有温度/PWM 组合上的 SmartFan（自动风扇调速），以及 2 组
    6 引脚 CPU VID 输入。

- 传感器分辨率
    如果你的主板制造商使用了参考设计，voltage0-2 的分辨率为 2mV，voltage3/4/5 为
    16mV，voltage6 为 8mV，voltage7/8 为 24mV。Temp1-4 的分辨率为 0.25 摄氏度，
    temp5-6 的分辨率为 1 摄氏度。

- 温度传感器类型
    Temp1-4 有 2 种可能的类型。可从（也可写入）temp[1-4]_type 读取。

    - 若值为 3，则开始使用远端热敏二极管进行监测（默认）。
    - 若值为 6，则开始使用 Intel CPU 中的温度传感器并通过 PECI 获取结果。

    Temp5-6 可连接到外部热敏电阻（temp[5-6]_type 的值为 4）。

- 报警机制
    对于电压传感器，当测量值低于低电压限值或高于高电压限值时触发报警。
    对于温度传感器，当测量值高于高温限值时触发报警，并且仅在测量值降到滞后值以下
    后才会解除。对于风扇传感器，当测量值低于低速限值时触发报警。

- SmartFan/PWM 控制
    如果你想将某个 pwm 风扇设为手动模式，只需确保它不被任何温度通道控制即可。例如，
    你想将 fan1 设为手动模式，需要检查 temp[1-6]_fan_map 的值，确保这 6 个值中 bit 0
    被清零，然后设置 pwm1 的值来控制风扇。

    每个温度通道可以控制全部 8 路 PWM 输出（通过设置 tempX_fan_map 中的相应位）。
    你可以使用 temp[1-6]_pwm_enable 设置温度通道的模式，2 为 Thermal Cruise 模式，3
    为 SmartFanII 模式。温度通道会尝试加快或减慢所有受控风扇，这意味着一个风扇可能
    从不同温度通道收到不同的 PWM 值请求，但芯片总会为每个风扇选取最安全（最大）的
    PWM 值。

    在 Thermal Cruise 模式下，芯片试图将温度保持在预定值附近，并留有容差范围。因此若
    tempX_input > thermal_cruiseX + toleranceX，芯片会增大 PWM 值；若 tempX_input <
    thermal_cruiseX - toleranceX，芯片会减小 PWM 值。如果温度在容差范围内，PWM 值
    保持不变。

    SmartFanII 的工作方式不同，你必须定义最多 7 个 PWM、温度触发点，定义一个芯片将
    遵循的 PWM/温度曲线。虽然与 Thermal Cruise 模式本质上没有区别，但实现方式迥异，
    能给你更精细的控制。

- 机箱
    如果机箱被打开的报警触发，它会一直保持该状态，直到向 sysfs 文件 "intrusion0_alarm"
    写入 0 来清除。

- VID 和 VRM
    VRM 版本会被自动检测，除非你**确实**知道 cpu 的 VRM 版本且未被正确检测，否则
    不要修改它。


### 注意事项


  只有 Fan1-5 和 PWM1-3 保证始终存在，其它风扇输入和 PWM 输出是否存在取决于芯片的
  引脚配置。
