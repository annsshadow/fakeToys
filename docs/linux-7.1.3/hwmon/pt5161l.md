
## 内核驱动 pt5161l


支持的芯片：

  - Astera Labs PT5161L

    前缀pt5161l'

    扫描的地址：I2C 0x20 - 0x27

    数据表：不公开
作者：Cosmo Chou <cosmo.chou@quantatw.com>

### 描述


该驱动程序实现对 Astera Labs PT5161L 系列 PCIe 重定时器芯片的温度监支持
该驱动程序实现源自以下位置提供的 CSDKhttps://github.com/facebook/openbmc/tree/helium/common/recipes-lib/retimer-v2.14
所使用的通信协议基于 I2C/SMBus 标准
### Sysfs 条目


================ ==============================================
temp1_input      测量的温度（以毫摄氏度为单位================ ==============================================
