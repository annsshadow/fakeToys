## 内核驱动 ltc4245


支持的芯片：

  - Linear Technology LTC4245

    前缀：'ltc4245'

    扫描地址：0x20-0x3f

    Datasheet:

	http://www.linear.com/pc/downloadDocument.do?navId=H0,C1,C1003,C1006,C1140,P19392,D13517

作者：Ira W. Snyder <iws@ovro.caltech.edu>

### 描述


LTC4245 控制器允许电路板在带电背板中安全地插入与移除，适用于如 CompactPCI 与
PCI Express 等多电源系统。

### 使用说明


由于某些可能的地址对探测不友好，本驱动不会主动探测 LTC4245 设备。你必须显式地实例化
这些设备。

示例：以下命令将为地址 0x23 处的 LTC4245 加载驱动
```

	$ modprobe ltc4245
	$ echo ltc4245 0x23 > /sys/bus/i2c/devices/i2c-1/new_device


```

### 注 1


如果你没有将驱动配置为将所有 GPIO 引脚采样为模拟电压，那么 in10_input 与 in11_input
sysfs 属性将不会被创建。驱动将对当前连接到 ADC 的 GPIO 引脚作为模拟电压进行采样，并在
in9_input 中报告该值。

如果你已将驱动配置为将所有 GPIO 引脚采样为模拟电压，那么它们将以轮询方式被采样。如果用户空间
读取过慢，读取包含传感器读数的 sysfs 属性时将返回 -EAGAIN。

LTC4245 芯片可通过两种方法配置为采样所有 GPIO 引脚：

1) 平台数据——参见 include/linux/platform_data/ltc4245.h
2) OF 设备树——为每个芯片添加 "ltc4245,use-extra-gpios" 属性

默认操作模式是采样单个 GPIO 引脚。
