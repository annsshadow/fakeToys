### Description


此 驱动 implements 支持 用于 the National Semiconductor LM85 和
compatible chips including the Analog 设备 ADM1027, ADT7463, ADT7468 和
SMSC EMC6D10x chips family.

The LM85 uses the 2-wire 接口 compatible 与 the SMBUS 2.0
specification. 使用 一个 analog 到 数字 converter 它 measures three (3)
temperatures 和 five (5) voltages. 它 具有 four (4) 16-位 counters 用于
measuring 风扇 speed. Five (5) 数字 inputs 是 provided 用于 sampling the
VID signals 来自 the processor 到 the VRM. Lastly, 存在 three (3) PWM
outputs 该 可 为 使用 到 control 风扇 speed.

The 电压 inputs 具有 内部 scaling resistors 因此 该 the 以下
电压 可 为 measured 无 外部 resistors:

  2.5V, 3.3V, 5V, 12V, 和 CPU 核心 电压 (2.25V)

The temperatures measured 是 one 内部 diode, 和 two remote diodes.
Remote 1 是 generally the CPU 温度. 这些 inputs 是 designed 到
measure 一个 thermal diode 类似 the one 在 一个 Pentium 4 processor 在 一个 套接字
423 或 套接字 478 package. 它们 可 也 measure 温度 使用 一个
transistor 类似 the 2N3904.

一个 sophisticated control 系统 用于 the PWM outputs 是 designed 进入 the
LM85 该 allows 风扇 speed 到 为 adjusted automatically 基于 任何 的 the
three 温度 传感器. 每个 PWM 输出 是 individually adjustable 和
programmable. 一旦 configured, the LM85 将 adjust the PWM outputs 在
响应 到 the measured temperatures 无 further host intervention.
此 特性 可 也 为 已禁用 用于 manual control 的 the PWM's.

每个 的 the measured inputs (电压, 温度, 风扇 speed) 具有
corresponding high/low limit 值. The LM85 将 信号 一个 ALARM 若 任何
measured 值 exceeds 任一个 limit.

The LM85 samples 全部 inputs continuously. The lm85 驱动 将 不 读取
the 寄存器 更多 通常 比 一旦 一个 second. Further, 配置 数据 是
仅 读取 一旦 每个 5 minutes. 存在 twice 作为 much 配置 数据 作为
measurements, 因此 此 将会 seem 到 为 一个 worthwhile optimization.

### 特殊 特性


The LM85 具有 four 风扇 speed monitoring modes. The ADM1027 具有 仅 two.
两者 具有 特殊 circuitry 到 compensate 用于 PWM interactions 与 the
TACH 信号 来自 the fans. The ADM1027 可 为 configured 到 measure the
speed 的 一个 two wire 风扇, 但 the 输入 conditioning circuitry 是 不同
用于 3-wire 和 2-wire 模式. 用于 此 reason, the 2-wire 风扇 modes 是 不
exposed 到 用户 control. The BIOS 应当 initialize them 到 the correct
模式. 若 您've designed 您的 own ADM1027, 您'll 具有 到 modify the
初始化_client 函数 和 add 一个 insmod 参数 到 set 此 up.

到 smooth the 响应 的 fans 到 changes 在 温度, the LM85 具有 一个
可选 filter 用于 smoothing temperatures. The ADM1027 具有 the 相同
配置 选项 但 uses 它 到 rate limit the changes 到 风扇 speed 改为.

The ADM1027, ADT7463 和 ADT7468 具有 一个 10-位 ADC 和 可 因此
measure temperatures 与 0.25 degC resolution. 它们 也 提供 一个 偏移
到 the 温度 readings 即 automatically applied 期间
measurement. 此 偏移 可 为 使用 到 zero out 任何 错误 由于 traces
和 placement. The documentation says 该 the 偏移 是 在 0.25 degC
steps, 但 在 initial testing 的 the ADM1027 它 曾是 1.00 degC steps. Analog
设备 具有 confirmed 此 "bug". The ADT7463 是 reported 到 work 作为
描述 在 the documentation. The 电流 lm85 驱动 执行 不 显示 the
偏移 注册.

The ADT7468 具有 一个 high-frequency PWM 模式, 何处 全部 PWM outputs 是
driven 由 一个 22.5 kHz clock. 这是 一个 全局 模式, 不 per-PWM 输出,
其 means 该 设置 任何 PWM frequency 上文 11.3 kHz 将 switch
全部 3 PWM outputs 到 一个 22.5 kHz frequency. Conversely, 设置 任何 PWM
frequency 下文 11.3 kHz 将 switch 全部 3 PWM outputs 到 一个 frequency
之间 10 和 100 Hz, 其 可 然后 为 tuned separately.

参见 the 厂商 datasheets 用于 更多 information. 存在 应用程序 注意
来自 National (AN-1260) 与 一些 额外 information 关于 the LM85.
The Analog 设备 datasheet 是 very detailed 和 describes 一个 procedure 用于
determining 一个 optimal 配置 用于 the automatic PWM control.

The SMSC EMC6D100 & EMC6D101 监视器 外部 voltages, temperatures, 和
风扇 speeds. 它们 使用 此 monitoring capability 到 alert the 系统 到 out
的 limit conditions 和 可 automatically control the speeds 的 多个
fans 在 一个 PC 或 embedded 系统. The EMC6D101, 可用 在 一个 24-pin SSOP
package, 和 the EMC6D100, 可用 在 一个 28-pin SSOP package, 是 designed
到 为 注册 compatible. The EMC6D100 offers 全部 the 特性 的 the
EMC6D101 增强版 额外 电压 monitoring 和 系统 control 特性.
Unfortunately 它是 不 可能 到 distinguish 之间 the package
versions 在 注册 level 因此 这些 额外 电压 inputs 可 读取
zero. EMC6D102 和 EMC6D103 特性 额外 ADC 位 从而 extending precision
的 电压 和 温度 channels.

SMSC EMC6D103S 是 similar 到 EMC6D103, 但 执行 不 支持 pwm#_auto_pwm_minctl
和 temp#_auto_temp_off.

The LM96000 supports 额外 high frequency PWM modes (22.5 kHz, 24 kHz,
25.7 kHz, 27.7 kHz 和 30 kHz), 其 可 为 configured 在 一个 per-PWM basis.

### 硬件 Configurations


The LM85 可 为 jumpered 用于 3 不同 SMBus 地址. 存在
无 其他 硬件 配置 选项 用于 the LM85.

The lm85 驱动 detects 两者 LM85B 和 LM85C revisions 的 the 芯片. 参见 the
datasheet 用于 一个 complete description 的 the differences. 其他 比
identifying the 芯片, the 驱动 behaves 无 differently 与 regard 到
这些 two chips. The LM85B 是 recommended 用于 新 designs.

The ADM1027, ADT7463 和 ADT7468 chips 具有 一个 可选 SMBALERT 输出
该 可 为 使用 到 信号 the chipset 在 case 一个 limit 是 exceeded 或 the
温度 传感器 fail. 各个 传感器 中断 可 为 masked 因此
它们 won't trigger SMBALERT. The SMBALERT 输出 若 configured replaces one
的 the 其他 函数 (PWM2 或 在0). 此 functionality 是 不 implemented
在 电流 驱动.

The ADT7463 和 ADT7468 也 具有 一个 可选 THERM 输出/输入 其 可
为 connected 到 the processor PROC_HOT 输出. 若 可用, the autofan
control 动态 Tmin 特性 可 为 已启用 到 keep the 系统 温度
之内 spec (just?!) 与 the least 可能 风扇 noise.

### 配置 Notes


Besides 标准 interfaces 驱动 adds 以下:

- Temperatures 和 Zones

每个 温度 传感器 是 associated 与 一个 Zone. 存在 three
传感器 和 因此 three zones (# 1, 2 和 3). 每个 zone 具有 the 以下
温度 配置 points:

- temp#_auto_temp_off
 - 温度 下文 其 fans 应当 为 off 或 spinning very low.
- temp#_auto_temp_min
 - 温度 在…上 其 fans 启动 到 spin.
- temp#_auto_temp_max
 - 温度 当 fans spin 在 full speed.
- temp#_auto_temp_crit
 - 温度 当 全部 fans 将 运行 full speed.

##### PWM Control


存在 three PWM outputs. The LM85 datasheet suggests 该 the
pwm3 输出 control 两者 风扇3 和 风扇4. 每个 PWM 可 为 individually
configured 和 assigned 到 一个 zone 用于 其 control 值. 每个 PWM 可 为
configured individually 根据 the 以下 选项.

- pwm#_auto_pwm_min
 - 此 specifies the PWM 值 用于 temp#_auto_temp_off
	  温度. (PWM 值 来自 0 到 255)

- pwm#_auto_pwm_minctl
 - 此 标志 selects 用于 temp#_auto_temp_off 温度
	  the behaviour 的 fans. 写入 1 到 let fans spinning 在
	  pwm#_auto_pwm_min 或 写入 0 到 let them off.


	它 具有 已经 reported 该 存在 一个 bug 在 the LM85 该 causes
	the 标志 到 为 associated 与 the zones 不 the PWMs. 此
	contradicts 全部 the published documentation. 设置 pwm#_min_ctl
	在 此 case actually affects 全部 PWMs controlled 由 zone '#'.

##### PWM Controlling Zone selection


- pwm#_auto_channels
 - controls zone 即 associated 与 PWM

配置 choices:

========== =============================================
值      Meaning
========== =============================================
      1    Controlled 由 Zone 1
      2    Controlled 由 Zone 2
      3    Controlled 由 Zone 3

The National LM85's 具有 two 厂商 特定 配置
特性. Tach. 模式 和 Spinup Control. 用于 更多 details 在 这些,
参见 the LM85 datasheet 或 应用程序 注意 AN-1260. 这些 特性
是 不 currently 受支持 由 the lm85 驱动.

The Analog 设备 ADM1027 具有 若干 厂商 特定 enhancements.
The 数字 的 pulses-per-rev 的 the fans 可 为 set, Tach monitoring
可 为 optimized 用于 PWM 操作, 和 一个 偏移 可 为 applied 到
the temperatures 到 compensate 用于 systemic 错误 在 the
measurements. 这些 特性 是 不 currently 受支持 由 the lm85
驱动.

此外 到 the ADM1027 特性, the ADT7463 和 ADT7468 也 具有
Tmin control 和 THERM asserted counts. Automatic Tmin control acts 到
adjust the Tmin 值 到 maintain the measured 温度 传感器 在 一个
specified 温度. 那里 isn't much documentation 在 此 特性 在
the ADT7463 数据 sheet. 这是 不 受支持 由 电流 驱动.
