### 模块参数


- update_vbat bool
    0 表示 vbat 应报告加电时的值，1 表示每次读取后应更新 vbat。默认值为 0。在某些主板上，电池电压
    由电池或板载电源提供。只有加电时的首次读取才是实际的电池电压（芯片会自动完成）。在其他主板上，
    电池电压始终馈入芯片，因此随时可读。过度读取可能会缩短电池寿命，但数据手册中未给出相关信息
- fix_pwm_polarity bool
    强制 PWM 极性为高电平有效（危险）。某些芯片被 BIOS 错误配置——PWM 值会被反转。此选项尝试修复
    此问题。请联系你的 BIOS 制造商并要求其修复
- force_id short, short

  强制将多个芯ID 设为指定值，',' 分隔  例如 "force_id=0x8689,0x8633"。该芯片的值为 0 时被忽略  注意：单force_id 值（例如 "force_id=0x8689"）用于所有芯片，要仅设置第一个芯片请使用
  "force_id=0x8689,0"  应仅用于测试
- ignore_resource_conflict bool

  类似acpi_enforce_resources=lax，但只影响此驱动。如果提供此参数并设置为 1，则忽略 ACPI 资源
  冲突  之所以提供此参数，是因为有报告称系统范围acpi_enfore_resources=lax 可能导致某些系统启动失败  注意：这本质上是危险的，因为这意味着 ACPI 和此驱动可能同时访问芯片。这可能导致竞态条件，最坏情  下会导致意外的系统重启

### 硬件接口


此驱动支持的所有芯片都LPC Super-I/O 芯片，通过 LPC 总线（类 ISA I/O 端口）访问。IT8712F
还额外具有一个到硬件监控功能SMBus 接口。不过此驱动不再支持该接口，因为它比 ISA 访问更慢可靠性更差，并且只在少数主板型号上可用

### 风扇速度控制


风扇速度控制功能仅限于手PWM 模式。自动的“Smart Guardian”模式控制仅针对较旧的芯片实现（见下文）但是，如果你想使用“手动模式”，只需pwmN_enable 写入 1
如果你只能使用非常小PWM 值来控制风扇速度，请尝试降低 PWM 基准频率（pwm1_freq）。根据风扇的不同它可能会给你更大的控制范围。相同的频率用于驱动所有风扇输出，这就pwm2_freq pwm3_freq 只读的原因

### 自动风扇速度控制（旧接口

此驱动支持旧版自动风扇速度控制接口，该接口由修订版F IT8705F 芯片以及修订版到 G IT8712F
芯片实现
此接口实4 个温度与 PWM 输出的跳变点（trip point）。跳变点 4 PWM 输出始终为最大值（风扇以全运行），而其3 个跳变点PWM 输出可以自由选择。所4 个跳变点的温度都可以自由选择。此外，跳变1 附加了一个迟滞（hysteresis）温度，以防止风扇开和关之间快速切换
芯片基于输入温度，根据此简单规则自动计PWM 输出值：如果温度值介于跳变点 N 和跳变点 N+1 之间，则
PWM 输出值为跳变N 的值。自动控制模式不如手动控制模式灵活，但它反应更快、更健壮，并且不使用 CPU
周期
在切换到自动风扇速度控制模式之前，必须正确设置跳变点。驱动在实际切换到自动控制模式之前会执行基本完整性检查

此驱动支temp[1-3]_offset sysfs 属性，用于调整热二极管或二极管连接的热晶体管所报告的温度。如温度传感器配置为热敏电阻，则忽略属性值。如果热传感器类型为 Intel PECI，则温度偏移必须编程为关键的
CPU 温度
