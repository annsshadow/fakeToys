## 内核驱动 mc34vr500


支持的芯片：

  - NXP MC34VR500

    Prefix: 'mc34vr500'

    Datasheet: https://www.nxp.com/docs/en/data-sheet/MC34VR500.pdf

Author: Mario Kicherer <dev@kicherer.org>

### 说明


该驱动实现了对 NXP MC34VR500 PMIC 的初步支持。MC34VR500 监控温度、输入电压和输出电流，并提供相应的告警。对于温度，当温度超过以下任一数值时芯片可发送中断：110°、120°、125° 和 130° 摄氏度。对于输入电压，当电压降至 2.8V 以下时发送中断。

目前，该驱动仅实现了输入电压和温度告警。中断映射如下：

<= 2.8V  -> in0_min_alarm
>110°c   -> temp1_max_alarm
>120°c   -> temp1_crit_alarm
>130°c   -> temp1_emergency_alarm
