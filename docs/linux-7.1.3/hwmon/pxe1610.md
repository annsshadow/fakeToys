### 描述


PXE1610/PXE1110 是多轨/多相数字控制器，符合

 - Intel VR13 DC-DC 转换器规范。
 - Intel SVID 协议。

用于基于 Intel VR13 的微处理器的 Vcore 电源调节

 - 服务器、工作站和高端台式机

PXM1310 是多轨控制器，符合

 - Intel VR13 DC-DC 转换器规范。
 - Intel SVID 协议。

用于基于 Intel VR13 和 IMVP8 的系统的 DDR3/DDR4 内存电源调节


### 使用说明


该驱动不会主动探测 PMBus 设备。你需要显式地实例化设备。

示例：以下命令将为 PXE1610 加载驱动
```

    # modprobe pxe1610
    # echo pxe1610 0x70 > /sys/bus/i2c/devices/i2c-4/new_device

```
它也可以通过设备树中声明来实例化
