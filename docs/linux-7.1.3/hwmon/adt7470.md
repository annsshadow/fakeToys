## 内核驱动 adt7470


支持的设备：

  - Analog Devices ADT7470

    Prefix: 'adt7470'

    Addresses scanned: I2C 0x2C, 0x2E, 0x2F

    Datasheet: Publicly available at the Analog Devices website

Author: Darrick J. Wong

### 描述


该驱动实现了Analog Devices ADT7470 芯片的支持。可能还有其他实现此接口的芯片
ADT7470 使用兼容 SMBus 2.0 规范的双线接口。它通过模数转换器（ADC）测量多达十个（10）外部温度。它有四个（4）个 16 位计数器用于测量风扇转速。并有四个（4）个 PWM 输出可用于控制风扇转速
ADT7470 内部设计了一套复杂的 PWM 输出控制系统，可根据十个温度传感器中的任意一个自动调节风扇转速。每PWM 输出都可以单独调整和编程。一旦配置完成，ADT7470 将根据测量到的温度自动调PWM 输出，无需主机的进一步干预。此功能也可以禁用以进行 PWM 的手动控制
每个被测输入（温度、风扇转速）都有对应的高/低限值。如果任一测量值超出任一限值，ADT7470 将发ALARM（告警）信号
ADT7470 持续对所有输入进行采样。会启动一个内核线程，用于周期性地查询温度传感器，从而使自动风扇 PWM 控制能够设置风扇转速。驱动读取寄存器的频率不会超过每 5 秒一次。此外，配置数据每分钟仅读取一次
### 特

ADT7470 具有 8 ADC，能够以 1 摄氏度（degC）的分辨率测量温度
Analog Devices 的数据手册非常详细，并描述了确定自动 PWM 控制最优配置的步骤
### 配置说明


除标准接口外，驱动还增加了以下内容：

- PWM 控制

- pwm#_auto_point1_pwm pwm#_auto_point1_temp 以及
- pwm#_auto_point2_pwm 鍜?pwm#_auto_point2_temp -

  - point1：在较低温度边界设置 PWM 转速  - point2：在较高温度边界设置 PWM 转速
当温度处于两个温度边界之间时，ADT7470 会在较低和较PWM 转速之间进行线性缩放。PWM 取值范围为 0（关闭）255（全速）。当PWM 控制相关的温度传感器超过 pwm#_auto_point2_temp 时，风扇转速将设置为最大值
驱动还允许控PWM 频率
- pwm1_freq

PWM 频率会被舍入到以下频率之一
- 11.0 Hz
- 14.7 Hz
- 22.1 Hz
- 29.4 Hz
- 35.3 Hz
- 44.1 Hz
- 58.8 Hz
- 88.2 Hz
- 1.4 kHz
- 22.5 kHz
