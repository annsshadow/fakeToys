## 内核驱动 lm83


支持的设备：

  - National Semiconductor LM83

    Prefix: 'lm83'

    Addresses scanned: I2C 0x18 - 0x1a, 0x29 - 0x2b, 0x4c - 0x4e

    Datasheet: 可在 National Semiconductor 网站公开获取

	       http://www.national.com/pf/LM/LM83.html

  - National Semiconductor LM82

    Addresses scanned: I2C 0x18 - 0x1a, 0x29 - 0x2b, 0x4c - 0x4e

    Datasheet: 可在 National Semiconductor 网站公开获取

	       http://www.national.com/pf/LM/LM82.html

作者：Jean Delvare <jdelvare@suse.de>

### 描述


LM83 是一款数字温度传感器。它感知自身温度，以及至多三个外部二极管的温度。LM82 是
LM83 的精简版本，只支持一个外部二极管。两者都与 LM84 及所有其他 ADM1021 克隆件兼容。
LM83 与 LM84 的主要区别在于后者只能感知一个外部二极管的温度。

使用 adm1021 驱动来驱动 LM83 应该可以工作，但只会报告两个温度而非四个。

LM83 只出现在少数主板上。下面给出一份已确认列表与一份未确认列表。如果你能确认或
否认这些主板中任何一款确实带有 LM83，请联系我们。注意，LM90 很容易被误检测为 LM83。

已确认的主板：
    ===		=====
    SBS         P014
    SBS         PSL09
    ===		=====

未确认的主板：
    =========== ==========
    Gigabyte    GA-8IK1100
    Iwill       MPX2
    Soltek      SL-75DRV5

已确认 LM82 出现在大多数 AMD Geode 参考设计与测试平台上。

该驱动已由 Magnus Forsström 成功测试，在此向他表示感谢。当然，我们也欢迎更多测试者。

LM83 很少被使用这一事实很容易解释。大多数主板不止带有用于健康监测的温度传感器，
它们还带有电压与风扇转速传感器。这意味着纯温度芯片通常作为辅助芯片，与另一颗提供
更多特性的芯片（如 IT8705F 或类似芯片）配合使用。由于系统通常需要三个温度传感器
（主板、处理器、电源），而主芯片已提供一些温度传感器，因此辅助芯片（如果需要的话）
无需处理超过两个温度。因此，ADM1021 克隆件已足够，不需要像 LM83 这样带四个温度
传感器的芯片。唯一适合使用 LM83 的情况是在 SMP 系统上，例如上面提到的 Iwill MPX2，
因为每多一个 CPU 你都想要一个额外的温度传感器。

在 SBS P014 上则不同，因为 LM83 是唯一的硬件监视芯片组。一个温度传感器用于主板
（实际上测量的是 LM83 自身的温度），一个用于 CPU。另外两个传感器必须用于测量主板
上另外两个点的温度。我们推测这些点是北桥与南桥，但这无法确认。

所有温度值以摄氏度给出。本地温度范围为 0 到 +85 度。远端温度范围为 0 到 +125 度。
分辨率为 1.0 度，精度保证在 3.0 度以内（详见数据手册）。

每个传感器都有自己的高温上限，但临界（critical）上限为所有四个传感器共用。没有像
大多数较新型温度传感器那样的滞后机制。

lm83 驱动更新其数值的频率不会高于每两秒一次；更频繁地读取不会造成危害，但会返回
“旧”值。
