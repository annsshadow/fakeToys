
## 内核驱动 nzxt-kraken3


支持的设备：

- NZXT Kraken X53
- NZXT Kraken X63
- NZXT Kraken X73
- NZXT Kraken Z53
- NZXT Kraken Z63
- NZXT Kraken Z73
- NZXT Kraken 2023
- NZXT Kraken 2023 Elite

作者：Jonas Malaco, Aleksa Savic

### 描述


该驱动为 NZXT Kraken X53/X63/X73、Z53/Z63/Z73 以及 Kraken 2023（标准版Elite 版）一体式 CPU 液冷散热器提供硬件监控支持。所有型号都提供液体温度和泵转速（RPM），以及 PWM 控制（既可以是固定值，也可以通过温度-PWM 曲线）。Z 系列Kraken 2023 型号还额外提供可选连接风扇的转速和占空比，具备相同PWM 控制能力
泵和风扇的占空比控制模式可通过 pwm[1-2]_enable 设置，其1 为手动控制模式，2 为液体温度到 PWM 曲线模式。写0 会在将占空比设为 100% 后禁用驱动对该通道的控制
曲线温度对应固定[20-59] 范围，与检测到的液体温度相关。只能设PWM 值（范围 0-255）。若在曲线模式下，设置点值应适度进行——设备要求每次更改都发送完整曲线；如果一次更改过多，设备可能会锁死或丢弃更改。建议在其他模式下设置好，然后通过切换到曲线模式来应用
设备可以报告自身是否故障。驱动支持这种情况并发出警告。当 USB 线缆已连接但未接 SATA 电源时也会发生
可寻址 RGB LED LCD 屏幕（仅 Z 系列Kraken 2023 型号）不在本驱动支持范围内，但可以通过现有的用户空间工具（`liquidctl`_）进行控制

### 使用说明


由于这些USB HID，驱动可由内核自动加载，并支持热插拔
可能pwm_enable 取值如下：

====== ==========================================================================
0      将风扇设100%
1      直接 PWM 模式（应用对PWM 条目中的值）
2      曲线控制模式（基于冷却液温度应用温度-PWM 占空比曲线）
====== ==========================================================================
