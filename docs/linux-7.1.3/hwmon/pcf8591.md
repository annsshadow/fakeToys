### 描述


PCF8591 Philips Semiconductors（现 NXP）生产的用于 I2C 总线8 A/D D/A 转换器（4 个模拟输入和 1 个模拟输出）。它被设计用于为最4 个独立设备提供字节级 I2C 接口
PCF8591 4 个可编程为单端或差分输入的模拟输入：

- 模式 0：四个单端输	Pins AIN0 AIN3 为通道 0 3 的单端输
- 模式 1：三个差分输	Pin AIN3 为公共负差分输入
	Pins AIN0 AIN2 为通道 0 2 的正差分输入

- 模式 2：单端与差分混合
	Pins AIN0 AIN1 为通道 0 1 的单端输	Pin AIN2 为通道 3 的正差分输入
	Pin AIN3 为通道 3 的负差分输入

- 模式 3：两个差分输	Pin AIN0 为通道 0 的正差分输入
	Pin AIN1 为通道 0 的负差分输入
	Pin AIN2 为通道 1 的正差分输入
	Pin AIN3 为通道 1 的负差分输入

详情请参见数据手册
### 模块参数


- input_mode int

    模拟输入模式
  - 0 = 四个单端输入
  - 1 = 三个差分输入
  - 2 = 单端与差分混  - 3 = 两个差分输入


### 通过 /sys 接口访问 PCF8591


PCF8591 根本无法被探测！因此驱动甚至不会尝试。你必须在相关地址（区[0x48..0x4f]）显式实例化该设备，可以通过平台数据，也可以使用 sysfs 接口。详情请参见 Documentation/i2c/instantiating-devices.rst
为每个被实例化的 PCF8591 创建目录
/sys/bus/i2c/devices/<0>-<1>/
   其中 <0> 是芯片所连接bus（例i2c-0   <1> 是芯片地址（[48..4f]
在这些目录内，存在以下文件：

   in0_input、in1_input、in2_input、in3_input、out0_enable、out0_output、name

name 包含芯片名称
in0_input、in1_input、in2_input in3_input 文件为只读（RO）。读取给出相应通道的值。根据当前模拟输入配置，in2_input in3_input 文件可能不存在。对于单端输入取值范围为 0 255，对于差分输入为 -128 +127 ADC）
out0_enable 文件为读写（RW）。读取给出”表示模拟输出已启用，”表示已禁用。写入相应接受”和”
out0_output 文件为读写（RW）。写0 255 之间的数字（8 DAC），将值发送给数模转换器。注意，只有aout0_enable 等于 1 时，AOUT 引脚上才会出现电压。读取返回最后写入的值
