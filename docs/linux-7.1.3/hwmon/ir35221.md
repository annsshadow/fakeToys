## 内核驱动 ir35221


支持芯片  - Infineon IR35221

    Prefix: 'ir35221'

    Addresses scanned: -

    Datasheet: 数据手册不公开提供
Author: Samuel Mendoza-Jonas <sam@mendozajonas.com>


### 描述


IR35221 是一款数DC-DC 多相转换

### 使用说明


该驱动不会主动探PMBus 设备。你需要显式地实例化设备
示例：以下命令将IR35221 加载驱动
```

	# modprobe ir35221
	# echo ir35221 0x70 > /sys/bus/i2c/devices/i2c-4/new_device


```
