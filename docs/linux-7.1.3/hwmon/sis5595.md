## Kernel driver sis5595


支持的芯片：

  - Silicon Integrated Systems Corp. SiS5595 南桥硬件监控芯片

    前缀：'sis5595'

    扫描的地址：PCI 地址空间中编码的 ISA 地址

    数据手册：可在 Silicon Integrated Systems Corp. 网站公开获取。

   SiS 南桥在同一颗 IC 上集成了类似于 LM78 的芯片。
   本驱动是 lm78.c 的定制副本。

   支持以下版本：

       =============== =============== ==============
       Version         PCI ID          PCI Revision
       =============== =============== ==============
       1               1039/0008       AF or less
       2               1039/0008       B0 or greater
       =============== =============== ==============

   注意：这些芯片包含一个 0008 设备，它与 5595 不兼容。我们通过存在所列的
   “黑名单” PCI ID 来识别它们，并拒绝加载。

### 模块参数


======================= =====================================================
force_addr=0xaddr	设置 I/O 基地址。适用于那些未在 BIOS 中设置地址的主板。
			不会执行 PCI 强制操作；设备仍需出现在 lspci 中。除非驱动
			报错称基地址未设置，否则不要使用此参数。

			示例：'modprobe sis5595 force_addr=0x290'
======================= =====================================================


### 描述


SiS5595 南桥集成了硬件监控功能。它还有一个 I2C 总线，但本驱动仅支持硬件监控。
有关 I2C 总线驱动，请参阅 i2c-sis5595。

SiS5595 实现了零个或一个温度传感器、两个风扇转速传感器、四个或五个电压传感器，以及告警。

在第一版芯片上，有四个电压传感器和一个温度传感器。

在第二版芯片上，温度传感器（temp）和第五个电压传感器（in4）共享一个引脚，该引脚可配置，
但不能通过驱动配置。抱歉。驱动会感知该引脚的配置，这通常由 BIOS 设置。

温度以摄氏度测量。一旦超过最大值即触发告警；当低于最小值时也会触发。
测量范围保证在 -55 到 +125 度之间，分辨率为 1 度。

风扇转速以 RPM（每分钟转数）报告。若转速降到可编程阈值以下则触发告警。
读数可被可编程分频器（1、2、4 或 8）除算，以获得更大的范围或更髙的精度。
并非所有 RPM 值都能精确表示，因此会做一些舍入。分频器为 2 时，可表示的最低值约为 2600 RPM。

电压传感器（又称 IN 传感器）以伏特报告其值。若电压越过可编程的最小或最大阈值则触发告警。
注意此处的“最小”始终指“最接近零”；这对于负电压测量很重要。所有电压输入可测量 0 到 4.08
伏之间的电压，分辨率为 0.016 伏。

除上述告警外，还有一个 BTI 告警，当外部芯片越过其阈值时触发。通常这连接到某个类 LM75 的
芯片；只要至少有一个越过其阈值，该位即被置位。

告警一旦触发，将保持触发状态，直到硬件寄存器至少被读取一次。这意味着告警的原因可能
已经消失了！注意在当前实现中，任何数据被读取时都会读取所有硬件寄存器（除非距上次更新不足 1.5 秒）。
这意味着你可能很容易错过仅触发一次的告警。

SiS5595 每 1.5 秒才更新一次其值；更频繁地读取无害，但会返回“旧”值。

### 问题

某些芯片拒绝被启用。原因不明。驱动会识别这一点并在 dmesg 中打印一条消息。
