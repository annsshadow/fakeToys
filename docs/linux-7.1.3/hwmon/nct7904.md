## nct7904 内核驱动


支持的芯片：

  - Nuvoton NCT7904D

    Prefix: nct7904

    Addresses: I2C 0x2d, 0x2e

    Datasheet: Publicly available at Nuvoton website

	http://www.nuvoton.com/

Author: Vadim V. Vlasov <vvlasov@dev.rtsoft.ru>


### 描述


NCT7904D 是一个硬件监视器，支持最20 个电压传感器、内部温度传感器、Intel PECI
AMD SB-TSI CPU 温度接口、最12 个风扇转速计输入、最4 个带 SmartFan 风扇控制通道

### Sysfs 条目


目前，该驱动仅支持以下功能：

======================= =======================================================
in[1-20]_input		输入电压测量（mV
fan[1-12]_input		风扇转速计测量（rpm
temp1_input		本地温度/1000 度，
			0.125 度分辨率
temp[2-9]_input		CPU 温度/1000 度，
			0.125 度分辨率
pwm[1-4]_enable		写，1/2 对应手动SmartFan 模式			仅当之前已由 BIOS（或配置 EEPROM）配置时			才支持设SmartFan 模式

pwm[1-4]		SmartFan 模式下为只读，在手动控制模式下为======================= =======================================================

该驱动检查传感器控制寄存器，不会导出未启用的传感器。无论如何，已启用的传感实际上可能并未连接，因此提供零读数

### 限制


当前版本不支持以下功能：

 - SmartFan 控制
 - 鐪嬮棬鐙? - GPIO
 - 外部温度传感 - SMI
 - 最最大 - 许多其他…
