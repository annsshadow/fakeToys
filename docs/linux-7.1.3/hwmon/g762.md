## 内核驱动 g762


GMT G762 风扇转速 PWM 控制器直接连接到风扇，并对风扇转速执行闭环或开环控制。该设备支持两种模式——PWM 与 DC。

如需更多信息，可在 http://natisbad.org/NAS/ref/GMT_EDS-762_763-080710-0.2.pdf 获取详细数据手册。sysfs 绑定在 Documentation/hwmon/sysfs-interface.rst 中描述。

在 /sys/bus/i2c/drivers/g762/ 的子目录中，用户可以使用以下条目来控制设备的运行。这可以手动使用以下条目完成，但通常通过像 fancontrol 这样的用户态守护进程完成。

注意，这些条目没有提供设置系统特定硬件特性（参考时钟、每转风扇脉冲数……）的方法；这些可以通过 Documentation/devicetree/bindings/hwmon/gmt,g762.yaml 中文档化的 devicetree 绑定修改，或者在板初始化文件中使用特定的 platform_data 结构体进行修改（见 include/linux/platform_data/g762.h）。

  fan1_target:
	    设置期望的风扇转速。这仅在闭环风扇转速控制（即 `pwm1_enable` 设置为 2）时才有意义。

  fan1_input:
	    提供风扇向设备报告的当前风扇转速值（RPM）。

  fan1_div:
	    风扇时钟分频器。支持的值为 1、2、4 与 8。

  fan1_pulses:
	    每转风扇脉冲数。支持的值为 2 与 4。

  fan1_fault:
	    报告风扇故障，即在约 0.7s 内风扇齿轮引脚无跳变（如果风扇不是被主动关闭）。

  fan1_alarm:
	    在闭环控制模式下，如果风扇 RPM 值偏离编程值 25% 超过 6 秒，则 'fan1_alarm' 被置为 1。

  pwm1_enable:
	    设置当前风扇转速控制模式，即 1 为通过下面描述的 pwm1 进行手动风扇转速控制（开环），2 为通过上面的 fan1_target 进行自动风扇转速控制（闭环）。

  pwm1_mode:
	    设置或获取风扇驱动模式：1 为 PWM 模式，0 为 DC 模式。

  pwm1:
	    在开环模式下获取或设置 PWM 风扇控制值。这是一个介于 0 到 255 之间的整数。0 停止风扇，255 使其全速运转。

无论处于 PWM 模式（'pwm1_mode' 设置为 1）还是 DC 模式（'pwm1_mode' 设置为 0），当当前风扇转速控制模式为开环（'pwm1_enable' 设置为 1）时，风扇转速通过 'pwm1' 条目设置 0 到 255 之间的值来编程（0 停止风扇，255 使其全速运转）。在闭环模式（'pwm1_enable' 设置为 2）下，期望的 RPM 转速可以通过 'fan1_target' 传给芯片。在闭环模式下，目标转速由设备与当前转速（可通过 'fan1_input' 获取）比较，并执行反馈以匹配该目标值。风扇转速值是基于与系统物理特性相关的参数计算的：参考时钟源频率、每转脉冲数等。

注意，驱动最多每秒更新一次其值。
