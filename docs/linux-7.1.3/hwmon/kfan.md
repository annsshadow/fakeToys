
## 内核驱动 kfan


支持的芯片：

  - KEBA 风扇控制器（FPGA 中的 IP 核）

    前缀：'kfan'

作者：

	Gerhard Engleder <eg@keba.com>
	Petar Bojanic <boja@keba.com>

### 描述


KEBA 风扇控制器是面向 FPGA 的 IP 核，用于监控风扇健康状态并控制其转速。
风扇通常用于为 CPU 和整个设备散热。例如 CP500 FPGA 包含此 IP 核，以
监控和控制 PLC 的风扇，相应的 cp500 驱动为 kfan 驱动创建一个辅助设备。

该驱动向用户空间提供风扇健康状态信息。若风扇被移除或阻塞，应通知
用户空间。此外，对于带测速信号的风扇，还会上报以 RPM 为单位的转速。

对于风扇控制，支持 PWM。PWM 255 对应 100%。不可调速的风扇可用 PWM 255
开启、PWM 0 关闭。

====================== ==== ===================================================
属性                  R/W  内容
====================== ==== ===================================================
fan1_fault             R    风扇故障
fan1_input             R    风扇转速计输入（RPM）
pwm1                   RW   风扇目标占空比（0..255）
