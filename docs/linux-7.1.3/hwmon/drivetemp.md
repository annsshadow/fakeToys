
## 内核驱动 drivetemp


### 参考资

ANS T13/1699-D
信息技- AT Attachment 8 - ATA/ATAPI Command Set (ATA8-ACS)

ANS Project T10/BSR INCITS 513
信息技- SCSI Primary Commands - 4 (SPC-4)

ANS Project INCITS 557
信息技- SCSI / ATA Translation - 5 (SAT-5)


### 描述


本驱动支持报告带有温度传感器的磁盘与固态硬盘的温度
如果支持，它使用 ATA SCT Command Transport 特性读取当前驱动器温度，并在可用时读取
温度限制以及历史最低与最高温度。如果不支持 SCT Command Transport，驱动使SMART
属性来读取驱动器温度

### 使用注意


在某些驱动器上，读取驱动器温度可能会重置自旋降速（spin down）定时器。这已经WD120EFAX 驱动器上观察到，但也可能在其它驱动器上出现。如果使'hdtemp' 'smartd' 工具访问驱动器，也会观察到相同的行为。对WD120EFAX 驱动器，在它转换待机模式_之后_，仍然可以使drivetemp 驱动读取驱动器温度，并且在这种模式下读取
驱动器温度不会导致驱动器改变其模式（即驱动器不会自旋启动）。不清楚其它驱动器是有类似行为
对于 WD120EFAX 驱动器，一个已知的变通方法是：以大于自旋降速时间两倍为间隔来读驱动器温度。否则受影响的驱动器将永远不会自旋降速

### Sysfs 条目


只有 temp1_input 属性始终可用。其它属性仅在驱动器报告时才可用。所有温度都以毫摄氏报告
