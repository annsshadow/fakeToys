## 内核驱动 max20751


支持的芯片：

  - maxim MAX20751

    Prefix: 'max20751'

    Addresses scanned: -

    Datasheet: https://datasheets.maximintegrated.com/en/ds/MAX20751.pdf

    Application note: https://pdfserv.maximintegrated.com/en/an/AN5941.pdf

Author: Guenter Roeck <linux@roeck-us.net>


### 描述


该驱动支持带 PMBus 接口与内部降压转换器（Buck Converter）的 MAX20751 多相主控制器（Multiphase Master）。

该驱动是核心 PMBus 驱动的一个客户端驱动。有关 PMBus 客户端驱动的详细信息，请参阅 Documentation/hwmon/pmbus.rst。


### 使用说明


该驱动不会自动检测设备。你必须显式实例化设备。详细信息请参阅 Documentation/i2c/instantiating-devices.rst。


### 平台数据支持


该驱动支持标准的 PMBus 驱动平台数据。


### Sysfs 接口


支持以下属性。

======================= =======================================================
in1_label		"vin1"
in1_input		测得的电压。
in1_min			最小输入电压。
in1_max			最大输入电压。
in1_lcrit		临界最小输入电压。
in1_crit		临界最大输入电压。
in1_min_alarm		输入电压过低报警。
in1_lcrit_alarm		输入电压临界过低报警。
in1_min_alarm		输入电压过低报警。
in1_max_alarm		输入电压过高报警。

in2_label		"vout1"
in2_input		测得的电压。
in2_min			最小输出电压。
in2_max			最大输出电压。
in2_lcrit		临界最小输出电压。
in2_crit		临界最大输出电压。
in2_min_alarm		输出电压过低报警。
in2_lcrit_alarm		输出电压临界过低报警。
in2_min_alarm		输出电压过低报警。
in2_max_alarm		输出电压过高报警。

curr1_input		测得的输出电流。
curr1_label		"iout1"
curr1_max		最大输出电流。
curr1_alarm		电流过高报警。

temp1_input		测得的温度。
temp1_max		最大温度。
temp1_crit		临界高温。
temp1_max_alarm		芯片温度过高报警。
temp1_crit_alarm	芯片温度临界过高报警。

power1_input		输出功率。
power1_label		"pout1"
