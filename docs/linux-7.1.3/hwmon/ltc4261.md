## 内核驱动 ltc4261


支持的芯片：

  - Linear Technology LTC4261

    Prefix: 'ltc4261'

    Addresses scanned: -

    Datasheet:

	http://cds.linear.com/docs/Datasheet/42612fb.pdf

Author: Guenter Roeck <linux@roeck-us.net>


### 描述


LTC4261/LTC4261-2 负电压热插拔（Hot Swap）控制器允许电路板安全地从带电背板中插入和移除

### 使用说明


该驱动不会探LTC4261 设备，因为不存在可用于安全识别该芯片的寄存器。你必须显式实例化设备
示例：以下命令将为地址 0x10 处的 LTC4261 加载驱动
```

	$ modprobe ltc4261
	$ echo ltc4261 0x10 > /sys/bus/i2c/devices/i2c-1/new_device


```
### Sysfs 接口


该驱动提供的电压读数按从 ADC 寄存器获取的原始值上报。如果安装了分压电阻，通过将上报值乘(R1+R2)/R2 计算真实电压，其R1 是相对于被测电压的分压电阻值，R2 是相对于地（Ground）的分压电阻值
该驱动提供的电流读数是按ADC 电流检测（Current Sense）寄存器获取的原始值上报的。上报值假设安装了 1 mOhm 的检测电阻。如果安装了不同的检测电阻，将上报值除以检测电阻值（单位 mOhm）即可得到真实电流
该芯片有两个电压传感器，但只有一组电压报警状态位。在许多设计中，由于 ADIN2 引脚靠近 OV 引脚，这些报警与 ADIN2 传感器相关联。不ADIN2 并非在所有芯片型号上都可用。为确保报警状态上报给用户，使用两个电压传感器同时上报该报警
======================= =============================
in1_input		ADIN2 电压 (mV)
in1_min_alarm		ADIN/ADIN2 欠压报警
in1_max_alarm		ADIN/ADIN2 过压报警

in2_input		ADIN 电压 (mV)
in2_min_alarm		ADIN/ADIN2 欠压报警
in2_max_alarm		ADIN/ADIN2 过压报警

curr1_input		SENSE 电流 (mA)
curr1_alarm		SENSE 过流报警
======================= =============================
