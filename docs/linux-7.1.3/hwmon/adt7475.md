### Description


本驱动实现了Analog Devices ADT7473、ADT7475、ADT7476 ADT7490 芯片系列的支持。ADT7473 ADT7475 仅在细微细节上有所不同。ADT7476 具有额外的特性，包括额外的电压测量输入和 VID 支持。ADT7490 也具有额外的特性，包括额外的电压测量输入和 PECI 支持。在本文档的其余部分，所有受支持的芯片将统一以名"ADT747x" 来指代
ADT747x 使用SMBus 2.0 规范兼容的双线接口。它使用一个模数转换器（ADC）测量三个（3）温度和两个）或更多电压。它有四个（4）个 16 位计数器用于测量风扇转速。有三个）个可用于控制风扇转速的 PWM 输出
ADT747x 内部设计了一个复杂的 PWM 输出控制系统，允许根据三个温度传感器中的任意一个自动调整风扇转速。每PWM 输出都可单独调整和编程。一旦配置完成，ADT747x 会根据测得的温度调整 PWM 输出，无需主机进一步干预。这一特性也可以被禁用，以进PWM 的手动控制
每个被测量的输入（电压、温度、风扇转速）都有相应低限值。如果任何测量值超过任一限值，ADT747x 会发ALARM 信号
ADT747x 持续对所有输入进行采样。驱动读取寄存器的频率不会超过每两秒一次。此外，配置数据每分钟只读取一次

### Special Features


ADT747x 具有一10 ADC，因此可以以 0.25 摄氏度的分辨率测量温度。温度读数可以配置为二进制补码格式或 "Offset 64" 格式，其中从原始值中减去 64 以得到温度值
数据手册非常详细，并描述了确定自PWM 控制最优配置的过程
### Fan Speed Control


驱动为每PWM 通道暴露两个触发点（trip point）
- point1：在较低温度边界处设PWM 转- point2：在较高温度边界处设PWM 转
当温度处于两个温度边界之间时，ADT747x 会在较低和较PWM 转速之间线性缩PWM。温度边界与温度通道相关联，而不是与 PWM 输出相关联，并且给定PWM 输出可以由多个温度通道控制。结果，ADT747x 在某个时刻可能为某个通道计算出多PWM 值，此时将采用最大值（最快的风扇转速）。PWM 值的范围0（关闭）255（全速）
当与 PWM 控制相关联的温度传感器超temp#_max 时，风扇转速可能被设为最大
Tmin - 滞后（hysteresis）处，PWM 输出可以是关闭（0% 占空比）或处于最小值（auto_point1_pwm）。这种行为可以使`pwm[1-*]_stall_disable sysfs attribute` 配置。值为 0 表示风扇将关闭。值为 1 表示风扇将以 auto_point1_pwm 运行
ADT747x 对温度变化的响应灵敏度可以配置。这允许平滑风扇转速的过渡。要设置过渡时间，请`temp[1-*]_smoothing` sysfs 属性中设置以毫秒为单位的值
### Notes


nVidia 二进制驱动通过一个板i2c 总线呈现一ADT7473 芯片。不幸的是，它们未能设置 i2c 适配器类，因此在 nvidia 驱动被打补丁之前，本驱动可能无法找到该芯片
