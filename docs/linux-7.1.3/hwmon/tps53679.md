### 描述


该系列芯片为 multiphase（多相）降压转换器，具有一个或两个输出通道，每个通道最多 8 相。


### 使用说明


该驱动不会自动探测 PMBus 设备。你必须显式地实例化设备。

示例：以下命令将为地址 0x60 处的 TPS53681 加载驱动

```

	# modprobe tps53679
	# echo tps53681 0x60 > /sys/bus/i2c/devices/i2c-1/new_device


```

in1_label		"vin"

in1_input		测得的输入电压。

in1_lcrit		输入电压临界最小值

			TPS53679、TPS53681、TPS53688 专用。

in1_lcrit_alarm		输入电压过低临界告警。

in1_crit		输入电压临界最大值。

in1_crit_alarm		输入电压过高临界告警。

in[N]_label		"vout[1-2]"

   - TPS53647、TPS53667：N=2
   - TPS53679、TPS53588：N=2,3

in[N]_input		测得的输出电压。

in[N]_lcrit		输入电压临界最小值。

			TPS53679、TPS53681、TPS53688 专用。

in[N]_lcrit_alarm	最小电压临界告警。

			TPS53679、TPS53681、TPS53688 专用。

in[N]_alarm		输出电压告警。

			TPS53647、TPS53667 专用。

in[N]_crit		输出电压临界最大值。

			TPS53679、TPS53681、TPS53688 专用。

in[N]_crit_alarm	输出电压过高临界告警。

			TPS53679、TPS53681、TPS53688 专用。

temp[N]_input		测得的温度。

   - TPS53647、TPS53667：N=1
   - TPS53679、TPS53681、TPS53588：N=1,2

temp[N]_max		最高温度。

temp[N]_crit		临界高温。

temp[N]_max_alarm	高温告警。

temp[N]_crit_alarm	临界高温告警。

power1_label		"pin"。

power1_input		测得的输入功率。

power[N]_label		"pout[1-2]"。

   - TPS53647、TPS53667：N=2
   - TPS53676、TPS53679、TPS53681、TPS53588：N=2,3

power[N]_input		测得的输出功率。

curr1_label		"iin"。

curr1_input		测得的输入电流。

curr1_max		最大输入电流。

curr1_max_alarm		输入电流过高告警。

curr1_crit		临界输入电流。

curr1_crit_alarm	输入电流临界告警。

curr[N]_label		"iout[1-2]" 或 "iout1.[0-5]"。

			第一位数字为输出通道，第二位数字为该通道内的相位。按相位遥测仅
			TPS53676 和 TPS53681 支持。

   - TPS53647、TPS53667：N=2
   - TPS53679、TPS53588：N=2,3
   - TPS53676：N=2-8
   - TPS53681：N=2-9

curr[N]_input		测得的输出电流。

curr[N]_max		最大输出电流。

curr[N]_crit		临界高输出电流。

curr[N]_max_alarm	输出电流过高告警。

curr[N]_crit_alarm	输出电流临界过高告警。

			限制与告警属性仅对
			非相位遥测（iout1、iout2）可用。
