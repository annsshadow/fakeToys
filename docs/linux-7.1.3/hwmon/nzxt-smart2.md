
## 内核驱动 nzxt-smart2


支持的设备：

- NZXT RGB 与风扇控制器
- NZXT Smart Device v2

### 描述


本驱动实现对插入设备的风扇的监控与控制。除了典型的速度监控与 PWM 占空比控制外，
还报告每个风扇的电压与电流。

该设备还有两个用于 RGB LED 的连接器；对它们的支持尚未实现（主要是因为没有标准的
sysfs 接口）。

此外，该设备有一个噪声传感器，但该传感器似乎完全没用（而且非常不精确），因此也不
支持它。

### 使用注意


设备应当会被自动检测，驱动应当会自动加载。

如果风扇是在系统通电状态下插拔的，必须重新加载驱动以检测配置变化；否则新风扇无法
被控制（`pwm*` 更改会被忽略）。这是必要的，因为设备有一个专用的“detect fans”命令，
目前它只在初始化期间执行。速度、电压、电流监控即使不重新加载也能工作。作为重新
加载模块的替代方案，可以使用用户空间工具（如 `liquidctl`_) 通过 hidraw 接口运行
“detect fans”命令。

驱动与通过 hidraw 接口访问设备的用户空间工具共存，没有已知问题。


### Sysfs 条目


=======================	========================================================
fan[1-3]_input		风扇速度监控（单位 rpm）。
curr[1-3]_input		供给风扇的电流（单位毫安）。
in[0-2]_input		供给风扇的电压（单位毫伏）。
pwm[1-3]		控制风扇速度：PWM 控制的风扇为 PWM 占空比，其它风扇为
			电压。电压可以在 9-12 V 范围内改变，但 sysfs 属性的值
			始终在 0-255 范围内（1 = 9V，255 = 12V）。将属性设为 0
			会完全关闭风扇。
pwm[1-3]_enable		如果风扇可以通过写入相应的 pwm* 属性来控制则为 1，
			否则为 0。该设备只能控制它自己检测到的风扇，因此该属性
			是只读的。
pwm[1-3]_mode		只读，PWM 控制的风扇为 1，其它风扇（或未连接风扇）为 0。
update_interval		所有输入被更新的间隔（单位毫秒）。默认 1000ms。最小 250ms。
=======================	========================================================
