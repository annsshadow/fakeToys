## 内核驱动 emc2305


支持的芯片：
   Microchip EMC2305、EMC2303、EMC2302、EMC2301

   Prefixes: 'emc2305'

   Datasheet: 可在 Microchip 网站公开获取：
      https://www.microchip.com/en-us/product/EMC2305

### 描述：

该驱动实现对 Microchip EMC2301/2/3/5 基于 RPM 的 PWM 风扇控制器的支持。
EMC2305 风扇控制器最多支持 5 路独立控制的 PWM 风扇驱动。
风扇转速以 RPM 报告。
该驱动支持基于 RPM 的 PWM 控制，以使风扇保持在期望的转速。
该驱动允许为所有风扇提供统一的 PWM 接口，或提供最多可用或已配置的独立 PWM。

该驱动在 hwmon 子系统中提供以下 sysfs 接口：

================= == ===================================================
fan[1-5]_fault    RO TACH1-TACH5 转速计故障指示文件
fan[1-5]_input    RO TACH1-TACH5 转速计输入文件（单位 RPM）
pwm[1-5]          RW fan[1-5] 目标占空比文件（0..255）
================= == ===================================================

thermal 子系统中的 sysfs 接口：

================= == ========================================================================
cur_state         RW 散热设备当前冷却状态文件（0..max_state）
max_state         RO 散热设备最大冷却状态文件
================= == ========================================================================
