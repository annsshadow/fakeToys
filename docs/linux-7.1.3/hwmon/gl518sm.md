## 内核驱动 gl518sm


支持的芯片：

  - Genesys Logic GL518SM 版本 0x00

    Prefix: 'gl518sm'

    扫描地址：I2C 0x2c 与 0x2d

  - Genesys Logic GL518SM 版本 0x80

    Prefix: 'gl518sm'

    扫描地址：I2C 0x2c 与 0x2d

    Datasheet: http://www.genesyslogic.com/

### 描述


   对于版本 0x00 的芯片，`in0`、`in1` 与 `in2` 的值（+5V、+3V 与 +12V）**无法**被读取。这是芯片的限制，而非驱动的限制。

该驱动支持 Genesys Logic GL518SM 芯片。该芯片至少有两版修订，我们称之为版本 0x00 与 0x80。版本 0x80 的芯片支持读取所有电压，而版本 0x00 仅支持 VIN3。

GL518SM 实现一个温度传感器、两个风扇转速传感器和四个电压传感器。它可以通过计算机扬声器报告报警。

温度以摄氏度为单位测量。当温度高于过温上限且尚未降至迟滞下限以下时，报警触发。报警始终反映当前状况。测量保证在 -10 度到 +110 度之间，精度为 +/-3 度。

转速以 RPM（每分钟转数）报告。如果转速降至可编程下限以下，则会触发报警。若你选择关闭 fan1，则不会触发 fan1 报警。

风扇读数可以被一个可编程分频器（1、2、4 或 8）除，以获得更大的范围或更高的精度。并非所有 RPM 值都能被精确表示，因此会进行一些舍入。使用分频器为 2 时，最低可表示的值约为 1900 RPM。

电压传感器（也称为 VIN 传感器）以伏特为单位报告其值。如果电压越过了可编程的最小或最大限制，则会触发报警。注意，此处的“最小”始终表示“最接近零”；这对负电压测量很重要。VDD 输入测量 0.000 到 5.865 伏之间的电压，分辨率为 0.023 伏。其他输入测量 0.000 到 4.845 伏之间的电压，分辨率为 0.019 伏。注意版本 0x00 的芯片不支持读取除 VIN3 外任何输入的当前电压；不过限制设置与报警工作正常。

当报警触发时，你可以通过计算机扬声器的蜂鸣信号得到警示。可以全局启用所有蜂鸣，或仅针对某些报警启用蜂鸣。

如果报警被触发，它将保持触发状态，直到硬件寄存器至少被读取一次（温度报警除外）。这意味着报警的原因可能早已消失！注意在当前的实现中，每当读取任何数据时都会读取所有硬件寄存器（除非距上次更新不足 1.5 秒）。这意味着你很容易错过一次性报警。

GL518SM 仅每 1.5 秒更新一次其值；更频繁地读取不会有害，但会返回“旧”的值。
