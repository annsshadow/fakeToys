
## 内核驱动 sg2042-mcu


支持的芯片：

  - sg2042 板载 MCU

    扫描地址：-

    Prefix: 'sg2042-mcu'

Authors:

  - Inochi Amaoto <inochiama@outlook.com>

### 描述


本驱动支持带 i2c 接口的板载 MCU 的硬件监控。

### 使用注意


本驱动不会自动检测设备。你需要显式地实例化设备。详见
Documentation/i2c/instantiating-devices.rst。

### Sysfs 属性


下表显示了驱动支持的标准条目：

================= =====================================================
名称              描述
================= =====================================================
temp1_input       测得的 SoC 温度
temp1_crit        临界高温
temp1_crit_hyst   从临界温度恢复时的滞回温度
temp2_input       测得的基板温度
================= =====================================================

下表显示了驱动支持的额外条目（MCU 设备位于 i2c 子系统中）：

================= ======= =============================================
名称              Perm    描述
================= ======= =============================================
reset_count       RO      SoC 的重置次数
uptime            RO      MCU 上电后的秒数
reset_reason      RO      上一次重置的原因
repower_policy    RW      触发重新上电时执行的策略
================= ======= =============================================

`repower_policy`
  当 SoC 温度因达到临界温度而触发关机后，降到滞回温度以下时，触发重新上电。
  此条目的有效值为 "repower" 与 "keep"。"keep" 会在触发重新上电时让 SoC 保持
  断电，"repower" 则会启动 SoC。

### Debugfs 接口


如果 debugfs 可用，本驱动会在 `/sys/kernel/debug/sg2042-mcu/*/` 暴露一些硬件相关
的数据。

================= ======= =============================================
名称              Format  描述
================= ======= =============================================
firmware_version  0x%02x  MCU 的固件版本
pcb_version       0x%02x  基板的版本号
board_type        0x%02x  基板的标识符
mcu_type          %d      MCU 的类型：0 为 STM32，1 为 GD32
================= ======= =============================================
