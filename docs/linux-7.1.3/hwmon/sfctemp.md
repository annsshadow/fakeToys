## 内核驱动 sfctemp


支持的芯片：
 - StarFive JH7100
 - StarFive JH7110

作者：
 - Emil Renner Berthing <kernel@esmil.dk>

### 描述


本驱动支持读取 StarFive Technology Co. Ltd. 的 JH7100 与 JH7110 RISC-V SoCs 上的内置温度传感器。

### ``sysfs`` 接口


温度传感器可通过 sysfs 中 `/sys/class/hwmon/hwmonX`（其中 X 为某值）下的标准 hwmon 接口进行使能、禁用与查询：

================ ==== =============================================
名称            权限 描述
================ ==== =============================================
temp1_enable     RW   启用或禁用温度传感器。
                      由驱动自动启用，
                      但可禁用以节省功耗。
temp1_input      RO   以毫摄氏度为单位的温度读数。
================ ==== =============================================
