### 描述


德州仪器 TMP102 实现一个温度传感器。可通过超温关断（Overtemperature Shutdown）寄存器与迟滞（Hysteresis）寄存器设置限值。该传感器在 -25 到 +85 C 范围内精度为 0.5 度，在 -40 到 +125 C 范围内精度为 1.0 度。传感器的分辨率为 0.0625 度。工作温度最低为 -55 C，最高为 +150 C。

TMP102 具有可编程的更新速率，可在 8、4、1 与 0.25 Hz 之间选择。

TMP110 与 TMP113 在软件上与 TMP102 兼容，但具有不同的精度（最大误差）规格。TMP110 的精度（最大误差）为 1.0 度，TMP113 的精度为 0.3 度，而 TMP102 的精度为 2.0 度。
