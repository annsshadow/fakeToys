
## 内核驱动 cros_ec_hwmon


支持的芯片：

  - ChromeOS 嵌入式控制器
    前缀cros_ec'

    扫描的地址

作者：

  - Thomas Wei脽schuh <linux@weissschuh.net>

### 描述


该驱动程序实现对 ChromeOS 嵌入式控制器（用Chromebook 及其他设备）
所暴露的硬件监控命令的支持
通过 hwmon 暴露的通道标签EC 本身获取
### 支持的特

风扇读数
    始终支持
风扇目标转    如果 EC 支持
温度读数
    始终支持
温度阈    如果 EC 支持
PWM 风扇控制
    如果 EC 还支持设置风PWM 值以及风扇模式
    请注意，EC 在挂起时会将风扇控制模式切换回自动。该驱动程序会在
    恢复时将该风扇状态恢复到挂起前的状态
    如果某个风扇可控，该驱动程序也会将其作为冷却设备注册到热管理框架中
