### 模块参数


- init boolean
    (default 0)

    使用 'init=1' 让驱动做额外的软件初始化。默认行为是做尽可能少的初始化，并依    BIOS 来正确设置芯片。如果你知道你有一w83791d 并且遇到了问题，在尝reset=1
    之前先尝init=1
- reset boolean
    (default 0)

    使用 'reset=1' 来复位芯片（通过索引 0x40，位 7）。默认行为是不复位芯片以保留
    BIOS 设置
- force_subclients=bus,caddr,saddr,saddr
    这用于强制某个芯片的子客户端i2c 地址。例如用法是 `force_subclients=0,0x2f,0x4a,0x4b`
    将总线 0 上芯0x2f 的子客户端强制为 i2c 地址 0x4a 0x4b

### 描述


该驱动实现了Winbond W83791D 芯片的支持。W83791G 芯片看起来与 W83791D 相同，只无铅
有时芯片的检测可能会失败，因为它可能处于一种不允许干净访问的内部状态（当前未选择
带有 ID 寄存器的 Bank）。如果你知道芯片的地址，使'force' 参数；这会先将其置于
更易管理的状态
该驱动实现了三个温度传感器、十个电压传感器、五个风扇转速传感器以及每个风扇的手PWM 控制
温度以摄氏度测量，temp1 的测量分辨率1 度，temp2 temp3 0.5 度。当温度高于
过温关闭（Overtemperature Shutdown）值时触发告警；它会一直保持，直到温度降到滞回
（Hysteresis）值以下
电压传感器（也称IN 传感器）以毫伏为单位报告其值。如果电压越过可编程的最小或最限制，则触发告警
风扇转速以 RPM（每分钟转数）报告。如果转速低于可编程限制，则触发告警。风扇读数可除以一个可编程的分频器（所有风扇为 1624 128）以给出更大范围更高精度的读数
每个受控风扇PWM 控制。PWM 占空比可以分别对每个风扇读取和设置。有效值范围从 0
（停止）255（全速）。PWM 1-3 支持热巡航（Thermal Cruise）模式，在该模式PWM
被自动调节以保持 temp 1-3 分别在某个目标温度。有sysfs 接口的描述，请见下文
w83791d 有一个全局位，用于在告警触发时启用扬声器发声，以及一个位掩码用于启用或禁特定告警的蜂鸣。触发的告警要发出蜂鸣声，需要全局蜂鸣使能位和相应的蜂鸣位同时开启
全局使能sysfs 接口通过 sysfs beep_enable 文件。该文件用于旧代码和新代码
蜂鸣位掩码的 sysfs 接口已从原始的单一 sysfs beep_mask 文件的旧方法，迁移到了使多个 `*_beep` 文件的新方法，如 `Documentation/hwmon/sysfs-interface.rst` 中所述
告警对应的位图也发生了类似的变化。原始的旧方法使用包含触发告警位图的单一 sysfs
alarms 文件。新方法使用多个 sysfs `*_alarm` 文件（再次遵sysfs-interface 中描的模式）
由于两种方法都读写底层硬件，它们可以互换使用，并且一处的更改会自动反映在另一处如果你使用旧的位掩码方法，你的用户空间代码负责处理告警和 beep_mask 位图并不相同事实（见下表）
注意：所有新代码都应编写为使用更新的 sysfs-interface 规范，因为它避免了位图问题，
并且是未来的首选接口
该驱动最多每三秒读取一次硬件芯片值。更频繁地请求值的用户模式代码将收到缓存的值
