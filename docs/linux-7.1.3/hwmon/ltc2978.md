### 描述

- LT7170 LT7171 20 A6 V、单路或双相 Silent Switcher 降压稳压器，
  带有数字电源系统管理
- LTC2974 LTC2975 是四通道数字电源管理器
- LTC2978 是八通道电源监视器
- LTC2977 LTC2978 的引脚兼容替代品
- LTC2980 16 通道电源系统管理器，由单个芯片上的两LTC2977 组成。该芯片被实例化
  两个独立的芯片，并报告在两个不同I2C 总线地址上
- LTC3880、LTC3882、LTC3886 LTC3887 是双输出多相降压 DC/DC 控制器
- LTC3883 是单相降DC/DC 控制器
- LTM2987 16 通道电源系统管理器，在单个芯片上包含两个 LTC2977 以及额外的元件。该芯片
  被实例化为两个独立的芯片，并报告在两个不同的 I2C 总线地址上
- LTM4675 是双9A 或单18A μModule 稳压器
- LTM4676 是双13A 或单26A μModule 稳压器
- LTM4686 是双10A 或单20A μModule 稳压器


### 使用说明

该驱动不会探PMBus 设备。你必须显式地实例化设备

示例：以下命令将为地址 0x60 处的 LTC2978 加载驱动

```
	# modprobe ltc2978
	# echo ltc2978 0x60 > /sys/bus/i2c/devices/i2c-1/new_device

```
