### 硬件描述


（摘自数据手册）

LM93 硬件监控器具有一个兼SMBus 2.0 的双线数字接口。LM93 使用 8 ADC 测量两个远程二极管连接晶体管以及其自身裸片和 16 路电源的电压的温度。为了设置风扇转速，LM93 有两PWM 输出，每个由最多四个温度区域控制。风扇控制算法基于查找表。LM93 包含一个数字滤波器，可调用它来平滑温度读数，以更好地控制风扇转速。LM93 有四个转速计输入来测量风扇转速。包含所有测量值的限制和状态寄存器。LM93 建立在以往主板管理 ASIC 的功能之上，并使用了 LM85 的一些特性（即智能转速计模式）。它还增加了对动Vccp 监控PROCHOT 的测量与控制支持。它被设计用来以最少的外部元件监控双处理器 Xeon 级主板
LM94 也以 LM93 兼容模式受到支持。LM94 的额外传感器和特性不受支持

### 用户接口


##### #PROCHOT


LM93 可以监控两个 #PROCHOT 信号。结果位sysfs 文件 prochot1、prochot2、prochot1_avg、prochot2_avg、prochot1_max prochot2_max 中。prochot1_max prochot2_max 分别包含 #PROCHOT1 #PROCHOT2 的用户限制。prochot1 prochot2 包含最近一个完整时间间隔的当前读数。prochot1_avg prochot2_avg 的值类似于一2 周期的指数移动平均（但并不完全——请查阅数据手册）。注意，这第三个值是由芯片本身计算的。所有值的范围0-255，其0 表示没有节流55 表示 > 99.6%
两个 #PROCHOT 信号的监控间隔也是可配置的。这些间隔可sysfs 文件 prochot1_interval prochot2_interval 中找到。这些文件中的值分别指#P1_PROCHOT #P2_PROCHOT 的间隔。选择不在该列表中的值会导致驱动使用下一个最大的间隔。可用间隔为（单位：秒）
#PROCHOT intervals:
	0.73, 1.46, 2.9, 5.8, 11.7, 23.3, 46.6, 93.2, 186, 372

可以LM93 配置为在逻辑上短接两#PROCHOT 信号。即，当 #P1_PROCHOT 被断言时，LM93 会自动断言 #P2_PROCHOT，反之亦然。向 sysfs 文件 prochot_short 写入一个非零整数即可启用此模式
LM93 还可以通过将一PWM 信号驱动到其中一个或两个 #PROCHOT 引脚上来覆盖它们。被覆盖时，该信号周期为 3.56 ms，最小脉冲宽度为 5 个时钟（22.5kHz => 6.25% 占空比），最大脉冲宽度为 80 个时钟（22.5kHz => 99.88% 占空比）
sysfs 文件 prochot1_override prochot2_override 包含布尔整数，分别用于启用或禁用 #P1_PROCHOT #P2_PROCHOT 的覆盖功能。sysfs 文件 prochot_override_duty_cycle 包含一个控制启用覆盖功能时所PWM 信号占空比的值。该值范围为 0 15 表示最小占空比5 表示最大
##### #VRD_HOT


LM93 可以监控两个 #VRD_HOT 信号。结果位sysfs 文件 vrdhot1 vrdhot2 中。每个文件一个值：一个布尔值，1 表示 #VRD_HOT 被断言 表示它被解除断言。这些文件是只读的
```

	If a fan is driven using a low-side drive PWM, the tachometer
	output of the fan is corrupted. The LM93 includes smart tachometer
	circuitry that allows an accurate tachometer reading to be
	achieved despite the signal corruption.  In smart tach mode all
	four signals are measured within 4 seconds.

```
智能转速计模式由驱动通过1 2（将风扇转速计与某pwm 关联）写sysfs 文件 fan<n>_smart_tach 来启用。写0 将禁用该风扇的此功能。注意，如果 PWM 输出频率22500 Hz，则无法启用智能转速计模式（见下文）
##### 手动 PWM


LM93 对两PWM 输出具有固定或覆盖模式（尽管仍有一些条件会覆盖此模式——详见数据手册第 15.10.6 节）。sysfs 文件 pwm1_override pwm2_override 用于启用此模式；每个都是一个布尔整数，其中 0 禁用 启用手动控制模式。sysfs 文件 pwm1 pwm2 用于设置手动占空比；每个是一个整数（0-255），其中 0 0% 占空比，255 100%。注意，占空比值受硬件约束。选择不可用的值会导致驱动使用下一个最大的值。另请注意：当手PWM 模式禁用时，pwm1 pwm2 的值表示硬件所选的当前占空比
##### PWM 输出频率


LM93 支持 PWM 输出通道的多种不同频率。sysfs 文件 pwm1_freq pwm2_freq 用于选择频率。频率值受硬件约束。选择不可用的值会导致驱动使用下一个最大的值。另请注意，此参数对智能转速计模式有影响（见上文）
PWM 输出频率（单Hz）：
	12, 36, 48, 60, 72, 84, 96, 22500 (默认)

##### 自动 PWM


LM93 能够进行复杂的自动风扇控制，有许多不同的配置点。首先，每个 PWM 输出可以绑定到八个控制源的任何组合。最终的 PWM 是所有绑定到PWM 输出的各个控制源中的最大值
八个控制源为：temp1-temp4（数据手册中亦称"zones"）PROCHOT 1 2，以#VRDHOT 1 2。绑定关系在 sysfs 文件 pwm<n>_auto_channels 中表示为一个位掩码，其"1" 启用绑定0" 禁用它。硬件默认为 0x0f（绑定所有温度）
	====== ===========
	0x01   Temp 1
	0x02   Temp 2
	0x04   Temp 3
	0x08   Temp 4
	0x10   #PROCHOT 1
	0x20   #PROCHOT 2
	0x40   #VRDHOT 1
	0x80   #VRDHOT 2
	====== ===========

函数 y = f(x) 将源温度 x 映射PWM 输出 y。LM93 的此函数由一个基准温度和一张包12 个温度偏移的表导出。基准温度在 sysfs 文件 temp<n>_auto_base 中以摄氏度表示。偏移以累积摄氏度表示，温度<n> 的第 <i> 个偏移包含在文件 temp<n>_auto_offset<i> 中。例如，如果基准温度40C
     ========== ======================= =============== =======
     offset #	temp<n>_auto_offset<i>	range		pwm
     ========== ======================= =============== =======
	 1		0		-		 25.00%
	 2		0		-		 28.57%
	 3		1		40C - 41C	 32.14%
	 4		1		41C - 42C	 35.71%
	 5		2		42C - 44C	 39.29%
	 6		2		44C - 46C	 42.86%
	 7		2		48C - 50C	 46.43%
	 8		2		50C - 52C	 50.00%
	 9		2		52C - 54C	 53.57%
	10		2		54C - 56C	 57.14%
	11		2		56C - 58C	 71.43%
	12		2		58C - 60C	 85.71%
 - -		> 60C		100.00%
     ========== ======================= =============== =======

有效的偏移范围为 0C <= x <= 7.5C，以 0.5C 为步长
每个温度通道都有一个独立的基准温度。但请注意，只有两张偏移表：temp[^12^] temp[^34^] 各一张。因此，对例temp1_auto_offset<i> 的任何更改也会影temp2_auto_offset<i>
LM93 还可以对偏移表应用迟滞，以防止在偏移表的两个台阶之间发生不必要的振荡。这些值位sysfs 文件 temp<n>_auto_offset_hyst 中。该文件中的值表示方式与 temp<n>_auto_offset<i> 相同
如果温度读数低于该通道的基准值，LM93 将使用最PWM 值。这些值位sysfs 文件 temp<n>_auto_pwm_min 中。注意，只有两个最小值：temp[^12^] temp[^34^] 各一个。因此，对例temp1_auto_pwm_min 的任何更改也会影temp2_auto_pwm_min
##### PWM 启动周期


PWM 输出0% 占空比被命令到某> 0% 的值时，发生一个启动周期。LM93 在启动期间支持最小占空比。这些值位sysfs 文件 pwm<n>_auto_spinup_min 中。该文件中的值表示方式与其他 PWM 占空比值相同。启动周期的持续时间也是可配置的。这些值位sysfs 文件 pwm<n>_auto_spinup_time 中。该文件中的值是启动时间（单位：秒）。可用的启动时间受硬件约束。选择不可用的值会导致驱动使用下一个最大的值
启动持续时间	0 (禁用，硬件默, 0.1, 0.25, 0.4, 0.7, 1.0, 2.0, 4.0

##### #PROCHOT #VRDHOT PWM 斜坡


如果 #PROCHOT #VRDHOT 信号在与 PWM 输出通道绑定时被断言，LM93 将以离散的步进将 PWM 输出斜坡上升100% 占空比。每个步进的持续时间是可配置的。有两个文件，各包含一个以秒为单位的值：pwm_auto_prochot_ramp pwm_auto_vrdhot_ramp。可用的斜坡时间受硬件约束。选择不可用的值会导致驱动使用下一个最大的值
斜坡时间	0 (禁用，硬件默 0.75，以 0.05 秒为间隔

##### 风扇加

对于每个温度通道，有一个加速温度：如果该通道超过此限制，LM93 会立即将两个 PWM 输出驱动100%。此限制sysfs 文件 temp<n>_auto_boost 中以摄氏度表示。此功能还有一个迟滞温度：在达到加速限制后，温度通道必须降到此值以下，加速功能才会被禁用。该温度同样sysfs 文件 temp<n>_auto_boost_hyst 中以摄氏度表示
##### GPIO 引脚


LM93 可以监控四个专用 GPIO 引脚以及四个转速计输入引脚的逻辑电平。GPIO0-GPIO3 分别对应于（风扇）转速计 1-4。所有八GPIO 都通过读取 sysfs 文件 gpio 中的位掩码来读取。LSB GPIO0，MSB GPIO7
