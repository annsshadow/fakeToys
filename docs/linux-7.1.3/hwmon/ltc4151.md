## 内核驱动 ltc4151


支持的芯片：

  - Linear Technology LTC4151

    前缀ltc4151'

    扫描的地址

    数据手册
	http://www.linear.com/docs/Datasheet/4151fc.pdf

作者：Per Dalen <per.dalen@appeartv.com>


### 描述


LTC4151 是一款高I2C 电流与电压监控器

### 使用说明


该驱动不会探LTC4151 设备，因为没有可安全用于识别该芯片的寄存器你需要显式地实例化设备
示例：以下命令将为地址 0x6f 处的 LTC4151 加载驱动
```

	# modprobe ltc4151
	# echo ltc4151 0x6f > /sys/bus/i2c/devices/i2c-0/new_device


```
### Sysfs 条目


该驱动提供的电压读数按取ADIN VIN 寄存器的方式上报
该驱动提供的电流读数按取Current Sense 寄存器的方式上报。上报的
值假定安装了 1 mOhm 采样电阻
======================= ==================
in1_input		VDIN 电压 (mV)

in2_input		ADIN 电压 (mV)

curr1_input		SENSE 电流 (mA)
======================= ==================
