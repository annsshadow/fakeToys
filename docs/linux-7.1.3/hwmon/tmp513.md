
## 内核驱动 tmp513


支持的芯片：

  - Texas Instruments TMP512

    Prefix: 'tmp512'

    Datasheet: https://www.ti.com/lit/ds/symlink/tmp512.pdf

  - Texas Instruments TMP513

    Prefix: 'tmp513'

    Datasheet: https://www.ti.com/lit/ds/symlink/tmp513.pdf

Authors:

	Eric Tremblay <etremblay@distech-controls.com>

### 描述


本驱动实现对 Texas Instruments TMP512 与 TMP513 的支持。TMP512（双通道）与
TMP513（三通道）是系统监视器，包含远程传感器、一个本地温度传感器，以及高侧电流
分流监视器。这些系统监视器能够测量远程温度、片上温度，以及系统电压/功率/电流
消耗。

温度以摄氏度测量，范围为 -40 到 +125 度，分辨率为 0.0625 摄氏度。

对于滞回（hysteresis）值，只有第一个通道是可写的。写入它会影响到所有其它值，
因为每个通道共享同一个滞回值。滞回以摄氏度表示，范围为 0 到 127.5 度，分辨率为
0.5 度。

本驱动通过以下 sysfs 文件导出温度值：

**temp[1-4]_input**

**temp[1-4]_crit**

**temp[1-4]_crit_alarm**

**temp[1-4]_crit_hyst**

本驱动从芯片读取分流电压并将其转换为电流。可读范围取决于 "ti,pga-gain" 属性
（默认为 8）以及分流电阻值。值的分辨率为 10uV/Rshunt。

本驱动通过以下 sysfs 文件导出分流电流值：

**curr1_input**

**curr1_lcrit**

**curr1_lcrit_alarm**

**curr1_crit**

**curr1_crit_alarm**

总线电压范围以 4mV 的分辨率从芯片读取。芯片可以通过 devicetree 中的
ti,bus-range-microvolt 属性配置为两种不同的范围（32V 或 16V）。

本驱动通过以下 sysfs 文件导出总线电压值：

**in0_input**

**in0_lcrit**

**in0_lcrit_alarm**

**in0_crit**

**in0_crit_alarm**

总线功率与总线电流的范围和分辨率取决于校准寄存器的值。这些值由硬件使用以下
公式计算：

Current = (ShuntVoltage * CalibrationRegister) / 4096
Power   = (Current * BusVoltage) / 5000

本驱动通过以下 sysfs 文件导出总线电流与总线功率值：

**curr2_input**

**power1_input**

**power1_crit**

**power1_crit_alarm**

校准过程遵循数据手册中的流程（无溢出），并取决于分流电阻值与 pga_gain 值。
