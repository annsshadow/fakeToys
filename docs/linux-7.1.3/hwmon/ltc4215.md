## 内核驱动 ltc4215


支持的芯片：

  - Linear Technology LTC4215

    前缀ltc4215'

    扫描的地址x44

    数据手册
	http://www.linear.com/pc/downloadDocument.do?navId=H0,C1,C1003,C1006,C1163,P17572,D12697

作者：Ira W. Snyder <iws@ovro.caltech.edu>


### 描述


LTC4215 控制器允许将电路板安全地插入和移除于带电背板

### 使用说明


该驱动不探测 LTC4215 设备，因为某些可能的地址不便于探测。你必须
显式地实例化设备
示例：以下将为地址 0x44 处的 LTC4215 加载驱动
```

	$ modprobe ltc4215
	$ echo ltc4215 0x44 > /sys/bus/i2c/devices/i2c-0/new_device


```
### Sysfs 条目


LTC4215 对过压、欠压和欠流告警具有内置限值。这使得参考电路很可能被使用
======================= =========================
in1_input		输入电压
in2_input		输出电压

in1_min_alarm		输入欠压告警
in1_max_alarm		输入过压告警

curr1_input		电流
curr1_max_alarm		过流告警

power1_input		功率用量
power1_alarm		电源故障告警
======================= =========================
