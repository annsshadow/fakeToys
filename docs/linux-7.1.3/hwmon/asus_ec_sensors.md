### 描述：

华硕（ASUS）主板通过 Super I/O 芯片以及 ACPI 嵌入式控制器（EC）寄存器发布硬件监控信息。其中部分传感器只能通过 EC 获取。

该驱动能够识别并读取以下传感器：

1. 芯片组（PCH）温度
2. CPU 封装温度
3. 主板温度
4. T_Sensor 接头的读数
5. VRM 温度
6. CPU_Opt 风扇转速（RPM）
7. VRM 散热片风扇转速（RPM）
8. 芯片组风扇转速（RPM）
9. “Water flow meter（水流量计）”接头的读数（RPM）
10. “Water In（进水）”与“Water Out（出水）”温度接头的读数
11. CPU 电流
12. CPU 核心电压

传感器数值从 EC 寄存器读取，为避免与主板固件竞争，驱动会获取 ACPI 互斥体（mutex）——即 WMI 在访问 EC 的方法中所使用的那个互斥体。

### 模块参数

 - mutex_path：字符串
		驱动为每个主板保存了 ACPI 互斥体的路径（实际上，这些路径大体相同）。如果 ASUS 在未来的 BIOS 更新中改变了该路径，在本驱动更新之前，可使用此参数来覆盖所保存的值。
		也可传入特殊字符串 ":GLOBAL_LOCK" 以使用 ACPI 全局锁，而非专用互斥体。
