## 内核驱动 tps40422


支持的芯片：

  - TI TPS40422

    Prefix: 'tps40422'

    Addresses scanned: -

    Datasheet: https://www.ti.com/lit/gpn/tps40422

Author: Zhu Laiwen <richard.zhu@nsn.com>


### 描述


该驱动支持带 PMBus 的 TI TPS40422 双输出或两相同步降压（Buck）控制器。

该驱动是核心 PMBus 驱动的一个客户端驱动。有关 PMBus 客户端驱动的详细信息，请参阅 Documentation/hwmon/pmbus.rst。


### 使用说明


该驱动不会自动检测设备。你必须显式实例化设备。详细信息请参阅 Documentation/i2c/instantiating-devices.rst。


### 平台数据支持


该驱动支持标准的 PMBus 驱动平台数据。


### Sysfs 接口


支持以下属性。

======================= =======================================================
in[1-2]_label		"vout[1-2]"
in[1-2]_input		测得的电压。来自 READ_VOUT 寄存器。
in[1-2]_alarm		电压报警。

curr[1-2]_input		测得的电流。来自 READ_IOUT 寄存器。
curr[1-2]_label		"iout[1-2]"
curr1_max		最大电流。来自 IOUT_OC_WARN_LIMIT 寄存器。
curr1_crit		临界最大电流。来自 IOUT_OC_FAULT_LIMIT 寄存器。
curr1_max_alarm		电流过高报警。来自 IOUT_OC_WARN_LIMIT 状态。
curr1_crit_alarm	电流临界过高报警。来自 IOUT_OC_FAULT 状态。
curr2_alarm		电流过高报警。来自 IOUT_OC_WARNING 状态。

temp1_input		测得的温度。来自 page 0 上的 READ_TEMPERATURE_2 寄存器。
temp1_max		最大温度。来自 OT_WARN_LIMIT 寄存器。
temp1_crit		临界高温。来自 OT_FAULT_LIMIT 寄存器。
temp1_max_alarm		芯片温度过高报警。若 TEMP_OT_WARNING 状态被设置，
			将 page 0 上的 READ_TEMPERATURE_2 与 OT_WARN_LIMIT 比较得出。
temp1_crit_alarm	芯片温度临界过高报警。若 TEMP_OT_FAULT 状态被设置，
			将 page 0 上的 READ_TEMPERATURE_2 与 OT_FAULT_LIMIT 比较得出。
temp2_input		测得的温度。来自 page 1 上的 READ_TEMPERATURE_2 寄存器。
temp2_alarm		page 1 上的芯片温度报警。
======================= =======================================================
