
## 内核驱动 nzxt-kraken2


支持的设备：

- NZXT 海妖 X42
- NZXT 海妖 X52
- NZXT 海妖 X62
- NZXT 海妖 X72

作者：乔纳斯·马拉科

### 描述


该驱动程序启用了对 NZXT Kraken X42/X52/X62/X72 的硬件监控支持
一体化 CPU 液体冷却器。  提供三个传感器：风扇速度、泵
速度和冷却液温度。

风扇和泵控制虽然受固件支持，但目前尚不支持
裸露。  可寻址 RGB LED 位于集成 CPU 水冷头中
和泵头也不支持。  但这两个功能都可以在
现有的用户空间工具（例如`liquidctl`_）。


### 使用说明


由于这些是 USB HID，驱动程序可以由内核自动加载并
支持热插拔。

### 系统文件系统条目


=======================	========================================================
fan1_input 风扇速度（以 rpm 为单位）
fan2_input 泵速（rpm）
temp1_input 冷却剂温度（以摄氏度为单位）
=======================	========================================================
