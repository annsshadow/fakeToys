## 内核驱动 w83792d


支持芯片：

  - Winbond W83792D

    Prefix: 'w83792d'

    Addresses scanned: I2C 0x2c - 0x2f

    Datasheet: http://www.winbond.com.tw

Author: Shane Huang (Winbond)
Updated: Roger Lucas


### 模块参数


- init int
    （默认 1）

    使用 'init=0' 来绕过对芯片的初始化。
    如果你的计算机在加载模块时崩溃，请尝试此参数。

- force_subclients=bus,caddr,saddr,saddr
    用于强制指定某个芯片子客户端的 i2c 地址。示例用法为 `force_subclients=0,0x2f,0x4a,0x4b`，
    将总线 0 上芯片 0x2f 的子客户端强制为 i2c 地址 0x4a 与 0x4b。


### 描述


该驱动实现对 Winbond W83792AD/D 的支持。

有时芯片的检测会失败，因为它可能处于一种不允许干净访问的内部状态（当前未选中带有 ID
寄存器的 Bank）。如果你知道芯片的地址，请使用 'force' 参数；这会先将其置于一个行为更
良好的状态。

该驱动实现了三个温度传感器、七个风扇转速传感器、九个电压传感器，以及两种称为 Smart Fan
I（Thermal Cruise 模式）与 Smart Fan II 的自动风扇调节策略。

该驱动还实现了最多七个风扇控制输出：pwm1-7。pwm1-7 可通过其关联的 pwmX_mode 配置为
PWM 输出或模拟直流（Analogue DC）输出。pwm4 到 pwm7 是否出现取决于 W83792AD/D 被 BIOS
配置的方式。

自动风扇控制模式仅适用于 fan1-fan3。

对于所有 pwmX 输出，值 0 表示最低风扇转速，值 255 表示最高风扇转速。

温度以摄氏度测量，temp1 的测量分辨率为 1°C，temp2 与 temp3 为 0.5°C。当温度高于过温
关断（Overtemperature Shutdown）值时触发报警；它会一直保持，直到温度降到迟滞（Hysteresis）
值以下。

风扇转速以 RPM（每分钟转数）报告。当转速降到可编程下限以下时触发报警。风扇读数可被一个
可编程分频器（1、2、4、8、16、32、64 或 128）除，以提供更宽的测量范围或更高的精度。

电压传感器（也称为 IN 传感器）以毫伏报告其值。当电压越过可编程的最小或最大限制时触发
报警。

报警由“实时状态寄存器”（realtime status register）输出。定义了以下位：

==== ==========
bit   alarm on
==== ==========
0    in0
1    in1
2    temp1
3    temp2
4    temp3
5    fan1
6    fan2
7    fan3
8    in2
9    in3
10   in4
11   in5
12   in6
13   VID change
14   chassis
15   fan7
16   tart1
17   tart2
18   tart3
19   in7
20   in8
21   fan4
22   fan5
23   fan6
==== ==========

当对应风扇在全速旋转 3 分钟后仍无法达到目标温度时，将断言 Tart。

除上述报警外，芯片上还有一个 CHAS 报警，当你的机箱被打开时触发（与实时报警相反，此报警
是锁存的）。

芯片每 3 秒才更新一次数值；更频繁地读取不会造成损害，但会返回“旧”值。


### W83792D 问题


已知问题：
 - 该驱动仅适用于 Winbond W83792D C 版本器件，也有一些主板使用 B 版本的 W83792D 器件。
	in6-in7（测量值、限制）在 C 版本与 B 版本之间的计算方法略有不同。可以通过 CR[0x49h]
	来识别 C 或 B 版本。
 - vid 与 vrm 的功能尚未完成，因为我对它们并不熟悉。欢迎添加支持。
 - 机箱打开检测的功能需要更多测试。
 - 如果你有华硕（ASUS）服务器主板且未找到芯片：那么你需要升级到最新（或测试版）BIOS。
	如果仍无帮助，请联系我们。


### 风扇控制


### 手动模式


按预期工作。你只需要在相应的 pwm# 文件中指定期望的 PWM/DC 值（风扇转速）。

### 热巡航（Thermal cruise）


在此模式下，W83792D 提供 Smart Fan 系统来自动调节风扇转速，使 CPU 与系统的温度保持在
特定范围内。首先必须设置期望的温度与间隔。这通过 thermal_cruise# 文件完成。tolerance#
文件用于创建 T ± tolerance 区间。只要当前温度保持在 thermal_cruise# ± tolerance# 值以下，
风扇转速就会降低。一旦温度超过上限（T+tolerance），风扇将以 pwm# 设定的特定转速开启，
并随温度变化自动控制其 PWM 占空比。可能出现三种情况：

(1) 如果温度仍超过上限，PWM 占空比将缓慢增加。

(2) 如果温度降到上限以下，但仍高于下限（T-tolerance），风扇转速将固定在当前转速，因为
温度处于目标范围内。

(3) 如果温度降到下限以下，PWM 占空比将缓慢降到 0 或一个预设的停止值，直到温度超过下限。
（预设停止值的处理尚未在驱动中实现）

### Smart Fan II


W83792D 还为风扇提供了一种特殊模式。有四个温度点可用。当相关温度传感器检测到温度处于
预设温度区间（sf2_point@_fan# ± tolerance#）内时，将导致风扇以 sf2_level@_fan# 中编程的
值运行。你需要为每个风扇设置四个温度。


### /sys 文件


pwm[1-7]
 - 该文件以范围存储 PWM 占空比或 DC 值（风扇转速）：

	    0（停止）到 255（全速）
pwm[1-3]_enable
 - 该文件控制风扇/温度控制模式：

     - 0 禁用
     - 1 手动模式
     - 2 Smart Fan II
     - 3 热巡航（Thermal Cruise）
pwm[1-7]_mode
 - 选择 PWM 或 DC 模式

     - 0 DC
     - 1 PWM
thermal_cruise[1-3]
 - 选择巡航（degC）的期望温度
tolerance[1-3]
 - 以摄氏度（degC）表示的 ± T 值
sf2_point[1-4]_fan[1-3]
 - 每个风扇用于 Smart Fan II 的四个温度点
sf2_level[1-3]_fan[1-3]
 - 每个风扇用于 Smart Fan II 的三个 PWM/DC 级别
