## 内核驱动 via686a


支持的芯片：

  - Via VT82C686A、VT82C686B  南桥集成硬件监视器

    前缀：'via686a'

    扫描地址：PCI 空间编码地址中的 ISA 地址

    Datasheet：通过 web 表单请求（http://www.via.com.tw/en/resources/download-center/）

### 模块参数


======================= =======================================================
force_addr=0xaddr       设置 I/O 基地址。对于 BIOS 中没有设置地址的主板很有用。
			在求助于此之前，请先查找 BIOS 升级。它不会执行 PCI 强制；
			via686a 仍然必须存在于 lspci 中。除非驱动提示基地址
			未被设置，否则不要使用此参数。
			示例：'modprobe via686a force_addr=0x6000'
======================= =======================================================

### 描述


驱动不区分这些芯片，统一按 686A 报告。

Via 686a 南桥集成了硬件监视功能。它还有一个 I2C 总线，但本驱动仅支持硬件监视。
有关 I2C 总线驱动，请参见 <file:Documentation/i2c/busses/i2c-viapro.rst>

Via 686a 实现了三个温度传感器、两个风扇转速传感器、五个电压传感器与报警。

温度以摄氏度测量。一旦越过过温关断（Overtemperature Shutdown）限制，就会触发一次报警；
一旦温度降回到迟滞值以下，报警会再次触发。

风扇转速以 RPM（每分钟转数）报告。如果转速下降到可编程限制以下，会触发报警。风扇读数可以
除以一个可编程分频器（1、2、4 或 8）以获得更大的量程或更高的精度。并非所有 RPM 值都能被精确
表示，因此会进行一定的取整。当分频器为 2 时，可表示的最低值约为 2600 RPM。

电压传感器（也称为 IN 传感器）以伏特报告其值。如果电压越过了可编程的最小或最大限制，会触发
报警。电压在内部经过缩放，因此每个电压通道具有不同的分辨率与量程。

如果触发了报警，它会一直保持触发，直到硬件寄存器至少被读取一次。这意味着报警的原因可能
已经消失了！请注意，在当前的实现中，只要读取了任何数据，就会读取所有硬件寄存器（除非距上次
更新不足 1.5 秒）。这意味着你很容易错过只触发一次的报警。

驱动每 1.5 秒才更新一次其值；更频繁地读取不会有坏处，但会返回“旧”值。

### 已知问题


本驱动处理集成在某些 VIA 南桥中的传感器。有可能某个主板制造商在产品设计中使用了 VT82C686A/B
芯片，但对其硬件监视特性不感兴趣，在这种情况下传感器输入不会被接线。Asus K7V、A7V 与 A7V133
主板就是这种情况，仅举几例。因此，如果你需要使用 force_addr 参数，并且得到的值看起来毫无意义，
不必再查找了：你的芯片根本就没有接上硬件监视。
