
## 内核驱动 mp2975


支持的芯片：

  - MPS MP12254

    Prefix: 'mp2975'

作者：

	Vadim Pasternak <vadimp@nvidia.com>

### 描述


该驱动实现了对 Monolithic Power Systems, Inc.（MPS）厂商的双环路数字多相控制器 MP2975 的支持。

该设备：

- 支持多达两条电源轨。
- 提供 8 个脉宽调制（PWM），可配置为轨 1 最多 8 相、轨 2 最多 4 相操作。
- 支持用于遥测的页 0 与页 1，以及用于配置的页 2 与页 3。
- 可将 VOUT 读数配置为 direct 或 VID 格式，并允许在轨 1 与轨 2 上设置不同格式。对于 VID，提供以下协议：带 5-mV DAC 的 VR13 模式；带 10-mV DAC 的 VR13 模式；带 5-mV DAC 的 IMVP9 模式。

设备支持：

- SVID 接口。
- AVSBus 接口。

设备符合：

- PMBus rev 1.3 接口。

设备以 direct 格式支持读取输出电流、输出电压、输入与输出功率以及温度。
设备以 linear 格式支持读取输入电压与输入功率。
设备以 VID 与 direct 格式支持读取输出电压。
支持以下 VID 模式：VR12、VR13、IMVP9。

驱动为电流提供以下属性：

- 对于电流输入：输入、最大报警；
- 对于电流输出：输入、最大报警与最高值；
- 对于相电流：输入与标签。
  属性。

驱动通过 'sysfs' 文件导出以下属性，其中

- 'n' 是遥测页数（从 1 到 2）；
- 'k' 是配置的相数（从 1 到 8）；
- 索引 1、1*n 对应 "iin"；
- 索引 n+1、n+2 对应 "iout"；
- 索引 2**n+1 ... 2**n + k 对应相位。

**curr[1-{2n}]_alarm**

**curr[{n+1}-{n+2}]_highest**

**curr[1-{2n+k}]_input**

**curr[1-{2n+k}]_label**

驱动为电压提供以下属性：

- 对于电压输入：输入、高临界阈值、高临界报警，均仅来自页 0；
- 对于电压输出：输入、低与高临界阈值、低与高临界报警，来自页 0 与页 1；

驱动通过 'sysfs' 文件导出以下属性，其中

- 'n' 是遥测页数（从 1 到 2）；
- 索引 1 对应 "iin"；
- 索引 n+1、n+2 对应 "vout"；

**in[1-{2n+1}]_crit**

**in[1-{2n+1}]_crit_alarm**

**in[1-{2n+1}]_input**

**in[1-{2n+1}]_label**

**in[2-{n+1}]_lcrit**

**in[2-{n+1}1_lcrit_alarm**

驱动为功率提供以下属性：

- 对于功率输入：报警与输入。
- 对于功率输出：最高值与输入。

驱动通过 'sysfs' 文件导出以下属性，其中

- 'n' 是遥测页数（从 1 到 2）；
- 索引 1 对应 "pin"；
- 索引 n+1、n+2 对应 "pout"；

**power1_alarm**

**power[2-{n+1}]_highest**

**power[1-{2n+1}]_input**

**power[1-{2n+1}]_label**

驱动为温度提供以下属性（仅来自页 0）：


**temp1_crit**

**temp1_crit_alarm**

**temp1_input**

**temp1_max**

**temp1_max_alarm**
