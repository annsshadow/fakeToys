### 描述


ADT7310/ADT7410 是一款温度传感器，额定温度范围为 -55°C 到 +150°C。它具有 +/-0.5°C 的高精度，
并可以 13 位（0.0625°C）或 16 位（0.0078°C）的分辨率运行。该传感器提供一个 INT 引脚用于指示
已超过最小或最大温度设定点，以及一个临界温度（CT）引脚用于指示已超过临界温度设定点。两个引脚都可以
配置为 0°C - 15°C 的通用迟滞，以及一个从 1 到 4 个事件的故障队列。两个引脚都可以单独设为低有效或
高有效，而整个设备可以运行在比较器模式或中断模式。ADT7410 支持连续温度采样，以及每秒采样一个温度值，
甚至仅在需要时获取一个样本以节省功耗。此外，如果需要电源管理，它可以完全关闭其 ADC。

ADT7320/ADT7420 是寄存器兼容的，唯一的区别是封装、稍窄的工作温度范围（-40°C 到 +150°C），以及
更好的精度（0.25°C 而非 0.50°C）。

ADT7310/ADT7320 与 ADT7410/ADT7420 之间的区别在于控制接口，ADT7310 与 ADT7320 使用 SPI，而
ADT7410 与 ADT7420 使用 I2C。

### 配置说明


由于设备使用一个迟滞值，它是最小、最大与临界温度的偏移量，因此只能为 temp#_max_hyst 设置。然而，
temp#_min_hyst 与 temp#_crit_hyst 会显示它们相应的迟滞。
设备被设置为 16 位分辨率与比较器模式。

temp#_min_hyst		 温度最小迟滞（只读）

temp#_crit_hyst		 临界温度迟滞（只读）
temp#_min_alarm		 温度最小报警标志

temp#_crit_alarm	 临界温度报警标志
