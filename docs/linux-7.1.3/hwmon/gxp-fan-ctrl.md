## 内核驱动 gxp-fan-ctrl


支持芯片：

  - HPE GXP SOC

Author: Nick Hawkins <nick.hawkins@hpe.com>


### 说明


gxp-fan-ctrl 是一个为 HPE GXP SoC 提供风扇控制的驱动。该驱动允许收集风扇状态并使用风扇 PWM 控制。


### Sysfs 属性


======================= ===========================================================
pwm[0-7]		Fan 0 到 7 各自的 PWM 值（0-255）
fan[0-7]_fault		Fan 0 到 7 各自的故障状态：1 故障，0 正常
fan[0-7]_enable         Fan 0 到 7 各自的使能状态：1 启用，0 禁用
======================= ===========================================================
