## ltc3815 内核驱动


支持的芯片：

  - Linear Technology LTC3815

    Prefix: 'ltc3815'

    Addresses scanned: -

    Datasheet: http://www.linear.com/product/ltc3815

Author: Guenter Roeck <linux@roeck-us.net>


### 描述


LTC3815 是一个单片同步 DC/DC 降压转换器。


### 使用说明


该驱动不会探测 PMBus 设备。你需要显式实例化设备。

示例：以下命令将加载 LTC3815 的驱动

```
	# modprobe ltc3815
	# echo ltc3815 0x20 > /sys/bus/i2c/devices/i2c-1/new_device

```
### Sysfs 属性


======================= =======================================================
in1_label		"vin"
in1_input		测量的输入电压。
in1_alarm		输入电压告警。
in1_highest		最高输入电压。
in1_reset_history	重置输入电压历史。

in2_label		"vout1"。
in2_input		测量的输出电压。
in2_alarm		输出电压告警。
in2_highest		最高输出电压。
in2_reset_history	重置输出电压历史。

temp1_input		测量的芯片温度。
temp1_alarm		温度告警。
temp1_highest		测量到的最高温度。
temp1_reset_history	重置温度历史。

curr1_label		"iin"。
curr1_input		测量的输入电流。
curr1_highest		最高输入电流。
curr1_reset_history	重置输入电流历史。

curr2_label		"iout1"。
curr2_input		测量的输出电流。
curr2_alarm		输出电流告警。
curr2_highest		最高输出电流。
curr2_reset_history	重置输出电流历史。
