## 内核驱动 hih6130


支持的芯片：

  - Honeywell HIH-6130 / HIH-6131

    Prefix: 'hih6130'

    Addresses scanned: none

    Datasheet: Publicly available at the Honeywell website

	http://sensing.honeywell.com/index.php?ci_id=3106&la_id=1&defId=44872

作者：
  Iain Paton <ipaton0@gmail.com>

### 描述


HIH-6130 与 HIH-6131 是 SO8 封装的湿度与温度传感器。两者的区别在于 HIH-6131 带有防凝露过滤器。

这些器件使用 I2C 协议通信。默认情况下所有传感器都设置为相同的 I2C 地址 0x27，因此可在板级设置代码中使用 I2C_BOARD_INFO("hih6130", 0x27)。

有关如何实例化 I2C 器件的详情，请参阅 Documentation/i2c/instantiating-devices.rst。

### sysfs 接口


temp1_input
	温度输入

humidity1_input
	湿度输入
