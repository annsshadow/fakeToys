## 内核驱动 g760a


支持的芯片：

  - Global Mixed-mode Technology Inc. G760A

    前缀g760a'

    数据手册：可GMT 网站公开获取

      http://www.gmt.com.tw/product/datasheet/EDS-760A.pdf

作者：Herbert Valerio Riedel <hvr@gnu.org>

### 描述


GMT G760A 风扇转PWM 控制器直接连接到风扇，并对风扇转速执行闭环控制
风扇转速通过设定两个连续速度脉冲的周期（经由 'pwm1'）来编程。该周期假定32kHz 时钟源的时钟周期数定义
将周期设0 停止风扇；将周期设为 255 将风扇设为最大转速
通过 'fan1_input' 返回的测得风扇转速，由测得的速度脉冲周期推得，同样假32kHz 时钟源和每转 2 个脉冲的风扇
'alarms' 文件提供G760A 芯片状态寄存器中两个告警位的访问：当实际风转速与编程设定的风扇转速相差超20% 时，0 置位；当风扇转速低1920
RPM 时，1 置位
g760a 驱动不会以快于每两秒一次的频率更新其数值；更频繁地读取不会造成损害但会返回“旧”值
