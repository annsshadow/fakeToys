## 内核驱动 ltc2945


支持的设备：

  - Linear Technology LTC2945

    Prefix: 'ltc2945'

    Addresses scanned: -

    Datasheet:

	https://www.analog.com/media/en/technical-documentation/data-sheets/2945fb.pdf

Author: Guenter Roeck <linux@roeck-us.net>


### 描述


LTC2945 是一款轨到轨（rail-to-rail）系统监控器，用于测量电流、电压和功耗

### 使用说明


该驱动不会对 LTC2945 设备进行探测，因为没有可安全用于识别该芯片的寄存器。你必须显式地实例化这些设备
示例：以下命令将为地址 0x10 处的 LTC2945 加载驱动

```

	$ modprobe ltc2945
	$ echo ltc2945 0x10 > /sys/bus/i2c/devices/i2c-1/new_device


```

### Sysfs 属

该驱动提供的电压读数是直接取ADC 寄存器报告的值。如果安装了分压电阻，请将报告值乘(R1+R2)/R2 来计算真实电压，其中 R1 是接在被测电压一侧的分压电阻，R2 是接在接地（Ground）一侧的分压电阻
该驱动提供的电流读数是取ADC 电流检测（Current Sense）寄存器报告的值。该报告值假设安装的1 mOhm 的检测电阻。如果安装了不同的检测电阻，请将报告值除以以 mOhm 为单位的检测电阻值，以计算真实电流
