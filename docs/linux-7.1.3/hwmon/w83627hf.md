## 内核驱动 w83627hf

支持的设备：
  - Winbond W83627HF（仅 ISA 访问    Prefix: 'w83627hf'
    Addresses scanned: ISA address retrieved from Super I/O registers
  - Winbond W83627THF
    Prefix: 'w83627thf'
    Addresses scanned: ISA address retrieved from Super I/O registers
  - Winbond W83697HF
    Prefix: 'w83697hf'
    Addresses scanned: ISA address retrieved from Super I/O registers
  - Winbond W83637HF
    Prefix: 'w83637hf'
    Addresses scanned: ISA address retrieved from Super I/O registers
  - Winbond W83687THF
    Prefix: 'w83687thf'
    Addresses scanned: ISA address retrieved from Super I/O registers
    Datasheet: Provided by Winbond on request(http://www.winbond.com/hq/enu)

### 模块参数

- force_i2c: int
  初始化传感器I2C 地址
- init: int
  （默认为 1  使用 'init=0' 来绕过芯片的初始化  如果你的计算机在加载模块时崩溃，可以尝试此选项
### 描述

该驱**实现Winbond W83627HF、W83627THF、W83697HF W83637HF Super I/O
芯片ISA 访问。我们将它们统称Winbond 芯片
该驱动支ISA 访问，这应当i2c 访问更可靠。此外，对于同时包含 Super I/O 芯片
和第二个i2c Winbond 芯片（通常W83782D）的 Tyan 主板，使用此驱动可以避免
i2c 地址冲突以及 w83781d 驱动中所需的复杂初始化
如果你确实想要对这些 Super I/O 芯片进行 i2c 访问，请使用 w83781d 驱动。不过，既然
已经开发了这个 ISA 驱动，现在这不再是推荐的方法
`w83627_HF_` 使用引脚 110-106 作为 VID0-VID4。`w83627_THF_` 使用相同的引脚作GPIO[0:4]。从技术上讲，`w83627_THF_` 不支VID 读取。然而这两颗芯片具有完全相同128 引脚封装。因此，尽管这些引脚没有标注用于该用途，w83627thf 仍有可能VID 信号
路由到了这些引脚。因此，w83627thf 驱动将这些解释为 VID。如果你板卡上的 VID 不工作，
首先参见 lm_sensors 包中doc/vid[^1^]。如果那仍然没有帮助，你可以直接忽略这个
虚假VID 读数，不会造成任何危害
关于该驱动的更多信息，请参阅 w83781d 驱动文档
[^1^] http://www.lm-sensors.org/browser/lm-sensors/trunk/doc/vid

### 强制地址

该驱动曾经有一个名force_addr 的模块参数，可用于强制硬件监控块的基 I/O 地址这是针对 BIOS 损坏的主板的一种变通方法。由于技术原因，该模块参数已被移除。如果你
需要此功能，可以在加载驱动之前使用 isaset 工具（lm-sensors 的一部分）来获得相同结果
```

	isaset -y -f 0x2e 0x87
	isaset -y -f 0x2e 0x87

```
```

	isaset -y 0x2e 0x2f 0x07 0x0b

```
```

	isaset -y 0x2e 0x2f 0x60 0x02
	isaset -y 0x2e 0x2f 0x61 0x90

```
```

	isaset -y -f 0x2e 0xaa

```
上述序列假设 Super-I/O 配置空间位于 0x2e/0x2f，但 0x4e/0x4f 也是可能的
