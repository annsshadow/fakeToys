描述
___________

LTC2947 是一款高精度功率与能量监视器，可测量电流、电压、功率、温度、电荷与能量。该设备
根据芯片配置支持 SPI I2C。该设备还可测量作为能量的累积量。它有两组寄存器用于
写与能量相关的值。这两组寄存器可独立配置，例如：energy1 始终累积，energy2 在当前为正时累积（例如用于检查电池充电效率）。该设备还支持一GPIO 引脚，可配置为输出，
以根据测量到的温度控制风扇。随后，一旦温度读数高于定义的阈值，GPIO 即被激活。temp2
通道用于控制该阈值并读取相应的报警
