### 描述


INA238 是一款带有 I2C 接口的电流分流、功率与温度监测器件。它包含多项可编程
功能，包括报警、转换速率、采样平均以及可选的分流电压精度。

分流电阻值（以微欧为单位）可通过设备属性设置，既可由 platform 代码设置，
也可由 device tree 数据设置。若使用 device tree，请参阅
Documentation/devicetree/bindings/hwmon/ti,ina2xx.yaml 了解绑定信息。

INA237 是 INA238 的功能等效变体，精度略有不同。INA228 是 INA238 的另一变体，
具有更高的 ADC 分辨率，同时还报告能量值。

INA700 与 INA780 是该芯片系列中内置分流电阻的变体，它们同样会报告能量值。

SQ52206 是来自 Silergy 的基本兼容芯片，它会报告能量值以及峰值功耗。

curr1_max_alarm		最大电流报警

energy1_input		能量测量值 (uJ)
				（仅 SQ52206、INA237 与 INA780）
				(SQ52206, INA237, and INA780 only)

temp1_input		芯片温度测量值 (mC)
