支持的设备：

### 描述


本驱动实现了对 Maxim MAX6650 与 MAX6651 的支持。

这两款器件非常相似，但 MAX6550（应为 MAX6650）功能集有所精简，例如
只有一路风扇输入，而非 MAX6651 的四路。

该驱动无法区分这两款器件。

驱动通过 sysfs 提供以下传感器访问：

=============== ======= =======================================================
fan1_input	ro	风扇转速计速度（单位 RPM）
fan2_input	ro	同上
fan3_input	ro	同上
fan4_input	ro	同上
fan1_target	rw	期望的风扇速度（单位 RPM，仅闭环模式）
pwm1_enable	rw	调节器模式，0=全开，1=开环，2=闭环
			3=关闭
pwm1		rw	相对速度（0-255），255=最大速度。
			仅用于开环模式。
fan1_div	rw	设置输入可处理的速度范围。合法
			值为 1、2、4、8。对更快的风扇使用更小的值。
=============== ======= =======================================================

### 使用注意


本驱动不会自动检测设备。你必须显式实例化设备。详情请参阅
Documentation/i2c/instantiating-devices.rst。

### 模块参数


如果你的主板 BIOS 已正确初始化 MAX6650/6651，你可以不带参数直接加载
模块。那样它不会触碰配置寄存器。如果你的主板 BIOS 没有初始化该芯片，
或者你想要不同的设置，可以设置以下参数：

voltage_12V: 5=5V 风扇，12=12V 风扇，0=不改变
prescaler: 可能的值为 1、2、4、8、16，或 0 表示不改变
clock: 驱动应假定的芯片时钟频率（单位 Hz）[^254000^]

在尝试更改这些参数之前，请阅读 MAX6650/6651 数据手册，并确保你充分
理解这些参数的含义。
