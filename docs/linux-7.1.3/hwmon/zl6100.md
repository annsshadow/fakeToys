### 描述


本驱动支持 Renesas / Intersil / Zilker Labs ZL6100 及兼容的数字 DC-DC 控制器的硬件监控。该驱动是核心 PMBus 驱动的一个客户端驱动。有关 PMBus 客户端驱动的详细信息，请参阅 Documentation/hwmon/pmbus.rst 与 Documentation.hwmon/pmbus-core。


### 使用注意事项


本驱动不会自动检测设备。你需要显式地实例化这些设备。详见 Documentation/i2c/instantiating-devices.rst。


  不要使用 i2cdump 命令访问芯片寄存器，也不要在用于保存和恢复配置数据的命令寄存器（0x11、0x12、0x15、0x16 和 0xf4）上使用任何 i2ctools 命令。本驱动所支持的芯片会将对这些命令寄存器的任何访问（包括读命令）都解释为执行该命令的请求。除非对这些寄存器的写访问受到保护，否则可能导致掉电、板卡复位和/或 Flash 损坏。最坏情况下，你的板卡可能会变成砖。


### 平台数据支持


该驱动支持标准的 PMBus 驱动平台数据。


### 模块参数


### delay


Renesas/Intersil/Zilker Labs 的 DC-DC 控制器在 I2C 总线访问之间需要最小的时间间隔。根据 Intersil 的说法，最小间隔为 2 ms，不过 1 ms 似乎也足够，且在测试中未引起任何问题。已知该问题会影响目前所有受支持的芯片。为了手动覆盖，驱动提供了一个可写的模块参数 'delay'，可用于将间隔设置为 0 到 65,535 微秒之间的值。


### Sysfs 属性


支持以下属性。限制值（Limits）为可读写；所有其他属性均为只读。

======================= ========================================================
in1_label		"vin"
in1_input		测得的输入电压。
in1_min			最小输入电压。
in1_max			最大输入电压。
in1_lcrit		临界最小输入电压。
in1_crit		临界最大输入电压。
in1_min_alarm		输入电压过低告警。
in1_max_alarm		输入电压过高告警。
in1_lcrit_alarm		输入电压临界过低告警。
in1_crit_alarm		输入电压临界过高告警。

in2_label		"vmon"
in2_input		在 VMON（ZL2004）或 VDRV（ZL9101M, ZL9117M）引脚上测得的电压。上报电压为引脚电压的 16 倍（由芯片内部调整）。
in2_lcrit		VMON/VDRV 临界最小电压。
in2_crit		VMON/VDRV 临界最大电压。
in2_lcrit_alarm		VMON/VDRV 电压临界过低告警。
in2_crit_alarm		VMON/VDRV 电压临界过高告警。

			vmon 属性仅在 ZL2004、ZL8802、ZL9101M、ZL9117M 与 ZLS4009 上支持。

inX_label		"vout[^12^]"
inX_input		测得的输出电压。
inX_lcrit		临界最小输出电压。
inX_crit		临界最大输出电压。
inX_lcrit_alarm		输出电压临界过低告警。
inX_crit_alarm		输出电压临界过高告警。

			X 对于 ZL2004、ZL9101M 与 ZL9117M 为 3；对于 ZL8802 为 3、4；其他情况下为 2。

curr1_label		"iin"
curr1_input		测得的输入电流。

			iin 属性仅在 ZL8802 上支持。

currY_label		"iout[^12^]"
currY_input		测得的输出电流。
currY_lcrit		临界最小输出电流。
currY_crit		临界最大输出电流。
currY_lcrit_alarm	输出电流临界过低告警。
currY_crit_alarm	输出电流临界过高告警。

			Y 对于 ZL8802 为 2、3；其他情况下为 1。

temp[^12^]_input		测得的温度。
temp[^12^]_min		最小温度。
temp[^12^]_max		最大温度。
temp[^12^]_lcrit		临界低温。
temp[^12^]_crit		临界高温。
temp[^12^]_min_alarm	芯片温度过低告警。
temp[^12^]_max_alarm	芯片温度过高告警。
temp[^12^]_lcrit_alarm	芯片温度临界过低告警。
temp[^12^]_crit_alarm	芯片温度临界过高告警。
