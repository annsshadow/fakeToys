## 内核驱动 max31730


支持的芯片：

  - Maxim MAX31730

    Prefix: 'max31730'

    Addresses scanned: 0x1c, 0x1d, 0x1e, 0x1f, 0x4c, 0x4d, 0x4e, 0x4f

    Datasheet: https://www.analog.com/media/en/technical-documentation/data-sheets/max31730.pdf

Author: Guenter Roeck <linux@roeck-us.net>


### 描述


该驱动实现对 Maxim MAX31730 的支持。

MAX31730 温度传感器监测其自身温度以及三个外部二极管连接晶体管的温度。工作电源电压范围为 3.0V 至 3.6V。电阻抵消（resistance cancellation）可补偿电路板走线和外部热二极管中的高串联电阻，而 beta 补偿可纠正因低 beta 感测晶体管导致的温度测量误差。


### Sysfs 条目


=================== == =======================================================
temp[1-4]_enable    RW 温度启用/禁用
                      设为 0 启用通道，0 禁用
temp[1-4]_input     RO 温度输入
temp[2-4]_fault     RO 远端通道的故障指示器
temp[1-4]_max       RW 最高温度
temp[1-4]_max_alarm RW 最高温度报警
temp[1-4]_min       RW 最低温度。所有通道共用。
                       仅 temp1_min 可写。
temp[1-4]_min_alarm RO 最低温度报警
temp[2-4]_offset    RW 远端通道的温度偏移
=================== == =======================================================
