
## 内核驱动 max127


作者：

  - Tao Ren <rentao.bupt@gmail.com>

支持的芯片：

  - Maxim MAX127

    前缀：'max127'

    数据手册：https://www.analog.com/media/en/technical-documentation/data-sheets/max127-max128.pdf

### 描述


MAX127 是一款多量程、12 位数据采集系统（DAS），提供 8 路模拟输入通道，
各通道可独立通过软件编程设置多种量程。可用量程为 {0,5V}、{0,10V}、
{-5,5V} 和 {-10,10V}。

MAX127 具有 2 线、兼容 I2C 的串行接口，可使用 SDA 和 SCL 线路在多个
设备间通信。

### Sysfs 接口


  ============== ==============================================================
  in[0-7]_input  对应通道的输入电压（单位 mV）。
		 RO

  in[0-7]_min    对应通道的较低输入限值（单位 mV）。
		 ADC 量程与 LSB 会在限值改变时更新。
		 对于 MAX127，会被调整为 -10000、-5000 或 0。
		 RW

  in[0-7]_max    对应通道的较高输入限值（单位 mV）。
		 ADC 量程与 LSB 会在限值改变时更新。
		 对于 MAX127，会被调整为 0、5000 或 10000。
		 RW
  ============== ==============================================================
