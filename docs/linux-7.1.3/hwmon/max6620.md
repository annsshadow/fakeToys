
## 内核驱动 max6620


支持的芯片：

    Maxim MAX6620

    Prefix: 'max6620'

    Addresses scanned: none

    Datasheet: https://www.analog.com/media/en/technical-documentation/data-sheets/max6620.pdf

### 描述


该驱动实现对 Maxim MAX6620 风扇控制器的支持。

该驱动将风扇控制器配置为 RPM 模式。为了让读数具有更大的范围或精度，可以通过可编程寄存器（1、2、4、8、16 或 32）设置期望值。为更大的转速设置更高的值。

该驱动在 sysfs 中提供以下传感器访问：

================ ======= =====================================================
fan[1-4]_alarm   ro      风扇报警。
fan[1-4]_div     rw      设置风扇的标称 RPM 范围。有效值为
                         1、2、4、8、16 和 32。
fan[1-4]_input   ro      风扇转速（单位 RPM）。
fan[1-4]_target  rw      期望的风扇转速（单位 RPM）。
================ ======= =====================================================

### 使用说明


该驱动不会自动探测设备。你需要显式地实例化设备。有关详细信息，请参阅 Documentation/i2c/instantiating-devices.rst。
