## Kernel driver adm1026


支持的芯片：
  - Analog Devices ADM1026

    Prefix: 'adm1026'

    Addresses scanned: I2C 0x2c, 0x2d, 0x2e

    Datasheet: 可在 Analog Devices 网站公开获取

	       https://www.onsemi.com/PowerSolutions/product.do?id=ADM1026

Authors:
 - Philip Pokorny <ppokorny@penguincomputing.com> for Penguin Computing
 - Justin Thiessen <jthiessen@penguincomputing.com>

### 模块参数


- gpio_input: int 数组（最小值 = 1，最大值 = 17）
    要编程为输入的 GPIO 引脚列表（0-16）

- gpio_output: int 数组（最小值 = 1，最大值 = 17）
    要编程为输出的 GPIO 引脚列表（0-16）

- gpio_inverted: int 数组（最小值 = 1，最大值 = 17）
    要编程为反相的 GPIO 引脚列表（0-16）

- gpio_normal: int 数组（最小值 = 1，最大值 = 17）
    要编程为正常/非反相的 GPIO 引脚列表（0-16）

- gpio_fan: int 数组（最小值 = 1，最大值 = 8）
    要编程为风扇转速（tach）的 GPIO 引脚列表（0-7）


### 说明


本驱动实现对 Analog Devices ADM1026 的支持。Analog Devices 称之为“完整的
热系统管理控制器”。

ADM1026 实现了三个（3）温度传感器、17 个电压传感器、16 条通用数字 I/O 线、
八个（8）风扇转速传感器（8 位）、一个模拟输出和一个 PWM 输出，以及上述各项的
限制、告警和屏蔽位。片上甚至有 8k 字节的 EEPROM 存储器。

温度以摄氏度测量。有两个外部传感器输入和一个内部传感器。每个传感器都有一个
高限和低限。如果超出限制，可以产生一个中断（#SMBALERT）。中断可以被屏蔽。此外，
每个传感器都有过温限制。如果超出此限制，将置位 #THERM 输出。当前温度和限制的分辨率为 1 度。

风扇转速以 RPM（每分钟转数）报告，但通过对一个 22.5kHz 内部时钟计数来测量。每个风扇都有一个
对应于最小风扇转速的高限。如果超出限制，可以产生一个中断。每个风扇可以被编程为将参考时钟
分频 1、2、4 或 8。并非所有 RPM 值都能精确表示，因此会做一些舍入。在分频为 8 时，每转两脉冲风扇
可测量的最低速度为 661 RPM。

共有 17 个电压传感器。如果电压越过了可编程的最小或最大限制，就会触发告警。注意，此处的“最小”
始终指“最接近零”；这对于负电压测量很重要。几个输入带有集成衰减器，因此可以直接测量更高的电压。
3.3V、5V、12V、-12V 和电池电压都有专用输入。有几个输入被缩放为 0-3V 满量程范围，用于 SCSI 终结器电源。
其余输入未缩放，满量程范围为 0-2.5V。提供了一个 2.5V 或 1.82V 参考电压用于负电压测量。

如果告警被触发，它将一直保持触发状态，直到硬件寄存器至少被读取一次。这意味着告警的原因可能已经
消失！注意，在当前实现中，只要读取任何数据，就会读取所有硬件寄存器（除非距上次更新不足 2.0 秒）。
这意味着你很容易错过只触发一次的告警。

ADM1026 持续测量。模拟输入大约每秒测量 4 次。风扇转速测量时间取决于风扇速度和分频系数。测量所有
风扇转速可能耗时长达 1.5 秒。

ADM1026 能够根据温度传感器输入自动控风扇速度。PWM 输出和 DAC 输出都可用于控制风扇速度。通常只会
使用这两个输出之一。将最小 PWM 或 DAC 值写入相应的控制寄存器。然后为每个温度传感器在 tmin 值中
设置低温限制。控制范围固定为 20 °C，并且温度传感器当前值与 tmin 之间的最大差值设定控制输出。关于使用
PWM 和 DAC 输出控制风扇速度的若干示例电路，请参见数据手册。风扇转速传感器没有 PWM 补偿，因此最好从
电源引线而非地引线控制风扇电压。

数据手册展示了一个将 VID 信号连接到 GPIO 线的示例应用。遗憾的是，芯片可能并未以这种方式连接到 VID 线。
驱动假定芯片**确实**以这种方式连接，以获取 VID 电压。
