## 调节API 设计笔记


本文档简要且部分结构化地概述了影响调节器 API 设计的一些设计考量
### 瀹夊叏鎬。

 - 调节器配置中的错误可能对系统产生非常严重的后果，可能包括持久的硬件损坏 - 不可能自动确定系统的电源配置——同一芯片的软件等价变体可能具有不同的
   电源需求，且并非所有具有电源需求的组件对软件都是可见的

     API 不应更改硬件状态，除非它明确知道这些更改在此特定系统上执行是安全的
### 娑堣垂鑰呯敤渚。

 - 系统中绝大多数设备除了能够打开或关闭电源外，没有任何运行时配置其电源的需求
 - 系统中的许多电源由许多不同的消费者共享

     消费API 的结构应使这些用例非常容易处理，并使消费者无需任何额外工作
     即可与共享的电源配合使用
