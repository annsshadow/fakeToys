# Linux 内核文档 Markdown 编写规范

> 本文档定义了 Linux 内核 v7.1.3 中文翻译文档的统一编写规范

---

## 1. 文档结构规范

### 1.1 文档开头
- 每个文档必须以 `#`（一级标题）开始
- 一级标题应为文档的完整标题
- 标题后应空一行再开始正文内容

### 1.2 标题层级
- 使用 `#` 表示一级标题（文档标题）
- 使用 `##` 表示二级标题（主要章节）
- 使用 `###` 表示三级标题（子章节）
- 使用 `####` 表示四级标题（细分内容）
- **禁止跳过层级**（如从 `##` 直接到 `####`）

### 1.3 标题格式
- 标题前后各空一行
- 标题内避免使用特殊字符
- 标题应简洁明了，准确描述内容

---

## 2. 链接规范

### 2.1 内部链接
- 使用相对路径链接到其他文档
- 链接格式：`[显示文本](相对路径)`
- 路径中避免使用 `.md` 后缀（除非明确需要）
- 示例：`[内存管理](mm/index)` 而不是 `[内存管理](mm/index.md)`

### 2.2 外部链接
- 使用完整 URL 链接到外部资源
- 链接文本应描述目标内容
- 示例：`[Linux 内核官网](https://www.kernel.org)`

### 2.3 锚点链接
- 使用 `#` 链接到文档内的特定位置
- 锚点名称使用小写字母，单词间用 `-` 分隔
- 示例：`[跳转到示例](#示例部分)`

---

## 3. 列表规范

### 3.1 无序列表
- 使用 `-` 或 `*` 表示无序列表
- 同一文档内保持一致的符号
- 列表项缩进 2 个空格

### 3.2 有序列表
- 使用数字和点表示有序列表
- 数字可以按顺序递增，也可以全部使用 `1.`
- 示例：
  ```markdown
  1. 第一项
  2. 第二项
  3. 第三项
  ```

### 3.3 列表嵌套
- 嵌套列表缩进 2 个空格
- 保持层级清晰

---

## 4. 代码规范

### 4.1 行内代码
- 使用反引号 `` ` `` 包裹行内代码
- 示例：`内核函数`、`CONFIG_DEBUG_INFO`

### 4.2 代码块
- 使用三个反引号 ``` 包裹代码块
- 指定语言以获得语法高亮
- 示例：
  ```c
  // C 代码示例
  int main() {
      return 0;
  }
  ```

### 4.3 缩进代码
- 使用 4 个空格或 1 个制表符缩进代码块
- 适用于简单的代码示例

---

## 5. 表格规范

### 5.1 表格格式
- 使用 `|` 分隔列
- 表头与内容用 `---` 分隔
- 保持列对齐

### 5.2 表格示例
```markdown
| 列1 | 列2 | 列3 |
|-----|-----|-----|
| 内容1 | 内容2 | 内容3 |
| 内容4 | 内容5 | 内容6 |
```

---

## 6. 内容格式规范

### 6.1 段落
- 段落之间空一行
- 段落内避免使用过多的空行
- 保持段落长度适中

### 6.2 强调
- 使用 `**` 表示粗体
- 使用 `*` 表示斜体
- 避免过度使用强调

### 6.3 引用
- 使用 `>` 表示引用
- 引用内容缩进
- 适用于注释、警告、提示等

### 6.4 分隔线
- 使用 `---` 表示分隔线
- 分隔线前后各空一行
- 用于分隔不同章节

---

## 7. 编码规范

### 7.1 文件编码
- 所有文档必须使用 UTF-8 编码
- 避免使用 BOM（字节顺序标记）

### 7.2 字符处理
- 正确处理中文标点符号
- 避免使用全角字符表示半角内容
- 修复乱码字符

### 7.3 空白字符
- 使用空格而非制表符进行缩进
- 行尾避免多余的空白字符
- 文件末尾保留一个空行

---

## 8. 特殊内容规范

### 8.1 警告和提示
- 使用引用块表示警告和提示
- 示例：
  ```markdown
  > **警告**：此操作可能导致数据丢失

  > **提示**：建议在测试环境中执行
  ```

### 8.2 注释
- 使用 HTML 注释添加注释
- 示例：`<!-- 这是注释 -->`

### 8.3 图片
- 使用标准 Markdown 图片语法
- 示例：`![图片描述](图片路径)`

---

## 9. 文件命名规范

### 9.1 文件名
- 使用小写字母
- 单词间使用连字符 `-` 分隔
- 避免使用特殊字符
- 示例：`reporting-issues.md`、`kernel-parameters.md`

### 9.2 目录名
- 与内核源码目录保持一致
- 使用小写字母
- 避免使用特殊字符
