## 解码 IOCTL 幻数（Magic Number）


要解码一个十六进制 IOCTL 码：

大多数架构使用这种通用格式，但请查看 include/ARCH/ioctl.h 了解具体细节，例如 powerpc 使用 3 位来编码读/写，用 13 位编码大小。

 ====== ==================================
 位      含义
 ====== ==================================
 31-30	00 - 无参数：使用 _IO 宏
	10 - 读：_IOR
	01 - 写：_IOW
	11 - 读/写：_IOWR

 29-16	参数大小

 15-8	每个驱动理论上唯一的 ascii 字符

 7-0	函数编号
 ====== ==================================

例如 0x82187201 是一个读操作，参数长度为 0x218，
```

	#define VFAT_IOCTL_READDIR_BOTH         _IOR('r', 1, struct dirent [2])

```
