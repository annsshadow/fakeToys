## 媒体设备模型


发现设备内部拓扑并在运行时对其进行配置，是媒体控制器 API 的目标之一为实现这一点，硬件设备Linux 内核接口被建模为有向图上的图对象。构该图的对象类型有
- **entity（实体）** 是基本的媒体硬件或软件构建块。它可以对应于种   繁多的逻辑块，例如物理硬件设备（如 CMOS 传感器）、逻辑硬件设备
   （SoC 图像处理流水线中的一个构建块）、DMA 通道或物理连接器
- **interface（接口）** Linux 内核用户空间 API 接口的图表示，例   控制图中一个或多个实体的设备节点或 sysfs 文件
- **pad（衬垫）** 是实体可借此与其他实体交互的数据连接端点。实体产生的
   数据（不限于视频）从实体的输出流向一个或多个实体的输入。pad 不应
   与芯片边界处的物理引脚混淆
- **data link（数据链路）** 是两pad 之间的点对点有向连接，可以位   同一实体上或不同实体上。数据从pad 流向pad
- **interface link（接口链路）** Linux 内核接口与实体之间的点对   双向控制连接
- **ancillary link（辅助链路）** 是表示两个实体构成一个单一逻辑单元   点对点连接。例如，它可以表示特定相机传感器与镜头控制器构成一个单一
   物理模块，即该镜头控制器驱动该相机传感器的镜头
