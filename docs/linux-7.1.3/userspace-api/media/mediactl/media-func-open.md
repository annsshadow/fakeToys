

######## 媒体打开()


## 姓名


media-open - 打开媒体设备

## 概要



#include <fcntl.h>


## 论点


`device_name`
待打开的设备

`flags`
打开旗帜。访问模式必须是0002”或0003”
其他标志没有任何作用

## 描述


要打开媒体设备应用程序，请使用以下命令调用`open()`
所需的设备名称。该功能无副作用；该设备
配置保持不变

当设备以只读模式打开时，尝试修改
配置将导致错误，并且`errno`将被设置
EBADF銆。

## 杩斿洖鍊。


`open()`成功时返回新的文件描述符。出错时
返回-1，并适当设置`errno`。可能的错误代码
是：

欧洲航空航天中心
不允许请求的文件访问权限

电子文件
该进程已打开最大文件数

绌。
已达到打开文件总数的系统限制

伊诺
可用内核内存不足

恩熙
不存在与该设备特殊文件对应的设备
