


######## 在有线传输系统中使用的属性


## DVB-C 传输系统


DVB-C Annex-A 是广泛使用的有线标准。传输使用 QAM 调制。

DVB-C Annex-C 针对 6MHz 优化，用于日本。它支持 Annex A 调制类型的子集，
以及 0.13 而非 0.15 的滚降系数。

以下参数对 DVB-C Annex A/C 有效：

- DTV_API_VERSION <DTV-API-VERSION>

- DTV_DELIVERY_SYSTEM <DTV-DELIVERY-SYSTEM>

- DTV_TUNE <DTV-TUNE>

- DTV_CLEAR <DTV-CLEAR>

- DTV_FREQUENCY <DTV-FREQUENCY>

- DTV_MODULATION <DTV-MODULATION>

- DTV_INVERSION <DTV-INVERSION>

- DTV_SYMBOL_RATE <DTV-SYMBOL-RATE>

- DTV_INNER_FEC <DTV-INNER-FEC>

- DTV_LNA <DTV-LNA>

此外，DTV QoS 统计 <frontend-stat-properties> 也有效。



## DVB-C Annex B 传输系统


DVB-C Annex-B 仅用于少数国家，如美国。

以下参数对 DVB-C Annex B 有效：

- DTV_API_VERSION <DTV-API-VERSION>

- DTV_DELIVERY_SYSTEM <DTV-DELIVERY-SYSTEM>

- DTV_TUNE <DTV-TUNE>

- DTV_CLEAR <DTV-CLEAR>

- DTV_FREQUENCY <DTV-FREQUENCY>

- DTV_MODULATION <DTV-MODULATION>

- DTV_INVERSION <DTV-INVERSION>

- DTV_LNA <DTV-LNA>

此外，DTV QoS 统计 <frontend-stat-properties> 也有效。
