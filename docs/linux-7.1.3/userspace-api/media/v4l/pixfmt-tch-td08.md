######## V4L2_TCH_FMT_DELTA_TD08 ('TD08')


**man V4L2_TCH_FMT_DELTA_TD08(2)**

8 位有符号触摸增量

## 描述


此格式表示来自触摸控制器的增量数据
增量值的范围可以-128 127。通常这些值会在一个小范围内变化，取决于传感器是否被触摸。若某个触摸屏节点存在故障或线路未连接，则可能会出现完整值域
**字节序*
每个单元为一个字节
