######## V4L2_PIX_FMT_CNF4 ('CNF4')


深度传感器置信度信息，以每像4 位打包数组形式存

## 说明


Intel RealSense 深度相机使用的专有格式，包含深度置信度信息，范围0-15，其0 表示该传感器无法解析任何信号5 表示特定传感器的最大置信度（实际误差范围可能因传感器而异）

每两个相邻像素被打包进一个字节
字节 n 的位 0-3 对应深度像素 2*n 的置信度值，4-7 对应深度像素 2*n+1 的置信度值

**位打包表示*

    :header-rows:  0
    :stub-columns: 0
    :widths: 64 64

    - - Y'\ `01[3:0]`\ (bits 7--4) Y'\ `00[3:0]`\ (bits 3--0)
      - Y'\ `03[3:0]`\ (bits 7--4) Y'\ `02[3:0]`\ (bits 3--0)
