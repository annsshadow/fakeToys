


######## 打包HSV 格式

本文档定V4L2 中打包的 HSV（色饱和明度）像素格式，说明 24 位与 32 位布局下各通道的位域排列，供摄像头与图像采集应用在内核空间协商与配置颜色格式时参考



## 描述


**色调**（h）以度为单位测量，度LSB 之间的对应关系取决于所使用hsv 编码，参colorspaces
**饱和*（s）和**明度**（v）以圆柱体（cylinder）的百分比来测量 为最小值，255 为最大值


这些值以 24 位或 32 位格式打包
