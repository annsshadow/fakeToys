

######## V4L2 open()

## 名称

v4l2-open - 打开一V4L2 设备

## 概要



    #include <fcntl.h>

## 参数

`device_name`
    要打开的设备
`flags`
    打开标志。访问模式必须为 `O_RDWR`。这只是一个技术细节，输入设备仍然只支持读取，输出设备只支持写入
    当给`O_NONBLOCK` 标志时，`read()` 函数VIDIOC_DQBUF <VIDIOC_QBUF> ioctl 在没有数据可用或驱动传出队列中没有缓冲区时将返回 `EAGAIN` 错误码，否则这些函数会阻塞直到数据可用。所有与应用程序交换数据V4L2 驱动都必须支`O_NONBLOCK` 标志
    其他标志无效
## 描述

要打开一V4L2 设备，应用程序使用期望的设备名调`open()`。此函数没有副作用；所有数据格式参数、当前输入或输出、控制值或其他属性都保持不变。在加载驱动后的第一`open()` 调用时它们会被重置为默认值，驱动永远不会处于未定义状态
## 杩斿洖鍊。
成功`open()` 返回新的文件描述符。出错时返回 -1，并适当设置 `errno` 变量。可能的错误码有
EACCES
    调用者无权访问该设备
EBUSY
    驱动不支持多次打开，且设备已在使用中
ENODEV
    未找到设备或已被移除
ENOMEM
    没有足够的可用内核内存来完成请求
EMFILE
    该进程已经打开了最大数量的文件
ENFILE
    系统上打开文件总数已达上限
