

######## 事件接口


V4L2 事件接口为用户提供了一种手段，以便在设备上发生某些特定条件时立即得到通知。例如，这可能包括帧开始或信号丢失事件。V4L2 控制的值或状态变化也可以通过事件上报。

要接收事件，用户首先必须使用 VIDIOC_SUBSCRIBE_EVENT ioctl 订阅其感兴趣的事件。一旦某个事件被订阅，已订阅类型的事件便可使用 VIDIOC_DQEVENT ioctl 出队。事件可以使用 VIDIOC_UNSUBSCRIBE_EVENT ioctl 取消订阅。特殊事件类型 V4L2_EVENT_ALL 可用于取消订阅驱动支持的所有事件。

事件订阅与事件队列是针对文件句柄特定的。在一个文件句柄上订阅某个事件不会影响其他文件句柄。

有关可出队事件的信息可通过在视频设备上使用 select 或 poll 系统调用获取。V4L2 事件在 poll 系统调用上使用 POLLPRI 事件，在 select 系统调用上使用异常事件。

从内核 3.1 开始，可以对事件给出某些保证：

1. 每个已订阅事件都有自己专用的内部事件队列。这意味着某一事件类型的洪泛不会干扰其他事件类型。

2. 如果某个特定已订阅事件的内部事件队列变满，那么该队列中最旧的事件将被丢弃。

3. 在适用的情况下，某些事件类型可以确保即将被丢弃的最旧事件的负载将与次旧事件的负载合并。从而确保信息不会丢失，而只会丢失通向该信息的中间步骤。请查阅你想要订阅的事件的文档，了解这对该事件是否适用。
