

######## 视频内存到内存接

V4L2 内存到内存设备可以在内存中将视频数据从一种格式压缩、解压缩、转换或以其他方式转换为另一种格式。此类内存到内存设备设置 `V4L2_CAP_VIDEO_M2M` `V4L2_CAP_VIDEO_M2M_MPLANE` 能力。内存到内存设备的例子有编解码器、缩放器、去隔行器或格式转换器（例如YUV 转换RGB）
内存到内存视频节点的行为如同普通视频节点，但它同时支持输出（将帧从内存发送到硬件）和捕获（从硬件接收处理后的帧到内存）流 I/O。应用程序必须为两侧都设置流 I/O，最后为捕获和输出都调用 VIDIOC_STREAMON <VIDIOC_STREAMON> 以启动硬件
内存到内存设备作为共享资源运作：你可以多次打开视频节点，每个应用程序设置其自身对文件句柄是本地的属性，并且每个应用程序都可以独立于其他应用程序使用它。驱动将仲裁对硬件的访问，并在另一个文件处理程序获得访问权时重新编程硬件。这与通常的视频节点行为不同，在通常行为中视频属性对设备是全局的（即通过一个文件句柄所做的更改在另一个文件句柄中可见）
最常见的内存到内存设备之一是编解码器。编解码器比大多数设备更复杂，需要为其编解码器参数进行额外设置。这是通过编解码器控件完成的。参codec-controls。关于如何使用编解码器内存到内存设备的更多细节在以下章节中给出
