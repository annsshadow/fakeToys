本参考文献集覆盖视频处理与显示技术的多个核心领域，是理解 V4L2 子系统及其相关接口的重要背景资料。为便于中文读者快速把握标准版图，下面按用途对条目做分类概述；具体到每一标准，其原始编号、正式标题与发布方链接均在正文中保留英文，以便核对与溯源。

视频编码与压缩标准：包括 ITU-T H.264/HEVC、VP8/VP9/AV1，以及 ISO/IEC 13818 系列（即 MPEG-2 的系统与视频部分），用于规定音视频数据的压缩算法、码流结构与封装格式。

色彩空间与色彩管理规范：包括 ITU-R BT.601/BT.709/BT.2020 与 IEC 61966 系列（sRGB、xvYCC、opRGB 等），定义不同显示制式下的色域范围，以及色值到电信号的映射关系。

显示接口与传输协议：包括 VESA DisplayPort、HDMI、DVI 相关规范，以及 EDID、E-DDC 等显示器识别与配置通道标准，描述主机与显示器之间的物理连接与能力协商。

广播与电视系统标准：包括 CEA、SMPTE、ETSI 等组织发布的一系列规范，涵盖模拟与数字电视、图文电视、宽屏信令（WSS）等内容。

无线电数据与其他专项规范：包括 RDS（IEC 62106）、RBDS（NRSC-4-B）等，用于在广播信道中承载辅助数据。
