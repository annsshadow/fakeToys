


######## 仅亮度（Luma）格式

本页列出 V4L2 中仅包含亮度（luma/Y）分量的灰度像素格式及其逐字节内存布局，供应用开发者在采集或处理单通道亮度图像时正确选择像素格式。


这一系列格式只存储 Y'CbCr 图像的亮度（luma）分量。它们通常被称为灰度（greyscale）
格式。

   - 在以下所有表格中，位 7 是一个字节中最显著的位。
   - 格式以创建字节对齐的重复模式所需的最少像素数来描述。`...` 表示模式的重复。
   - Y'\ `x`\ [9:2] 表示第 `x` 列像素的 Y' 值的第 9 到 2 位。
   - `0` 表示被设为 0 的填充位。

    \normalsize


    对于 Y16 和 Y16_BE 格式，实际采样精度可能低于 16 位。例如，每像素 10 位使用的
    值范围是 0 到 1023。对于 IPU3_Y10 格式，25 个像素被打包进 32 字节，最后一个字节
    的最高 6 位用 0 填充。

    对于 Y012 和 Y12 格式，Y012 将其数据放在 12 个高位中，低 4 位为填充零，而 Y12 格式
    的填充位于 16 位字的最高有效位中。

    Y10、Y12 和 Y14 格式的 'P' 变体根据 MIPI CSI-2 规范定义的 RAW10、RAW12 和 RAW14
    打包方案进行打包。
