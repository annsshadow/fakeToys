
######## 简

某些视频捕获设备可以对画面的一小部分进行采样，并将其缩小或放大任意大小的图像。接着，设备可将图像插入到更大的图像中。某些视频输出设可以裁剪输入图像的一部分，将其放大或缩小，并以任意扫描行与水平偏移插到视频信号中。我们称这些能力为裁剪、缩放与合成
在视**捕获** 设备上，源是视频信号，裁剪目标决定实际被采样的区域目标是存储在内存缓冲区中的图像。合成区域指定硬件实际写入缓冲区的哪一部分
在视**输出** 设备上，源是内存缓冲区中的图像，裁剪目标是要在显示器显示的图像的一部分。目标是显示器或图形屏幕。应用程序可以选择图像应显示在
显示的哪一部分。此类窗口的大小与位置由合成目标控制
即使设备既不支持裁剪也不支持合成，所有裁剪与合成目标的矩形也都有定义在这种情况下其大小与位置是固定的。如果设备不支持缩放，则裁剪与合成矩具有相同大小
