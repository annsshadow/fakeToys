######## V4L2_PIX_FMT_Y12I ('Y12I')

## 说明


这是一幅每像素深度12 位的灰度图像，但来自 2 个源的像素被交织并按位打包。每个像素以小端（little-endian）顺序存储在一24 位字中。在小端机器上，可以使用以下方式对这些像素进行去交织


    __u8 *buf;
    left0 = 0xfff & **(__u16 **)buf;
    right0 = **(__u16 **)(buf + 1) >> 4;

**位打包表示*
像素跨越字节边界，每个交织像素的比率3 字节
