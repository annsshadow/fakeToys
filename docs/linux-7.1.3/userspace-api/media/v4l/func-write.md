

######## V4L2 write()

## 名称

v4l2-write - 写入 V4L2 设备

## 概要



    #include <unistd.h>

## 参数

`fd`
    `open()` 返回的文件描述符
`buf`
    待写入数据的缓冲
`count`
    缓冲区中的字节数

## 描述

`write()` 将最`count` 个字节从`buf` 起始的缓冲区写入由文件描述符 `fd` 引用的设备。当硬件输出尚未激活时，该函数会启用它们。当 `count` 为零时，`write()` 返回 0 而不会产生其他影响
当应用程序未能及时提供更多数据时，之前的视频帧、原VBI 图像、切片的 VPS WSS 数据会被再次显示。切片的图文电视（Teletext）或隐藏字幕（Closed Caption）数据不会被重复，驱动会插入一条空行代替
## 杩斿洖鍊。
成功时，返回写入的字节数。零表示没有写入任何内容。出错时返回 -1，并适当设置 `errno` 变量。在这种情况下，下一次写入将从新帧的开始处进行。可能的错误码有
EAGAIN
    已使O_NONBLOCK <func-open> 标志选择了非阻塞 I/O，且当时没有可用的缓冲区空间来立即写入数据
EBADF
    `fd` 不是有效的文件描述符，或者未以写入方式打开
EBUSY
    驱动不支持多个写入流，且设备已在使用中
EFAULT
    `buf` 引用了一个不可访问的内存区域
EINTR
    在任何数据写入之前，调用被信号中断
EIO
    I/O 错误。这表示某些硬件问题
EINVAL
    此驱动不支持 `write()` 函数，或者不适用于此设备，或者一般不适用于此类设备
