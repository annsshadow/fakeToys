
######## V4L2_PIX_FMT_M420 ('M420')


具有 ½ 水平和垂直色度分辨率的格式，也称为 YUV 4:2:0。混合平面行交错布局。


## 描述


M420 是一种具有 ½ 水平和垂直色度子采样（YUV 4:2:0）的 YUV 格式。像素被组织为交错排列的亮度和色度平面。两行亮度数据之后跟随一行色度数据。

亮度平面每个像素一个字节。色度平面包含交错的 CbCr 像素，在水平和垂直方向均被 ½ 子采样。每对 CbCr 属于四个像素。例如，Cb\ `0`/Cr\ `0` 属于 Y'\ `00`、Y'\ `01`、Y'\ `10`、Y'\ `11`。

所有行长度相同：如果 Y 行包含填充字节，CbCr 行也同样包含。

**字节序。**
每个单元为一个字节。


    :header-rows:  0
    :stub-columns: 0

    - - start + 0:
      - Y'\ `00`
      - Y'\ `01`
      - Y'\ `02`
      - Y'\ `03`
    - - start + 4:
      - Y'\ `10`
      - Y'\ `11`
      - Y'\ `12`
      - Y'\ `13`
    - - start + 8:
      - Cb\ `00`
      - Cr\ `00`
      - Cb\ `01`
      - Cr\ `01`
    - - start + 16:
      - Y'\ `20`
      - Y'\ `21`
      - Y'\ `22`
      - Y'\ `23`
    - - start + 20:
      - Y'\ `30`
      - Y'\ `31`
      - Y'\ `32`
      - Y'\ `33`
    - - start + 24:
      - Cb\ `10`
      - Cr\ `10`
      - Cb\ `11`
      - Cr\ `11`


**色度采样位置：**
色度采样点在水平和垂直方向上处于交错位置<yuv-chroma-centered>。
