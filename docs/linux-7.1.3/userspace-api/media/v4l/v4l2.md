######## 修订历史


:revision: 4.10 / 2016-07-15 (**rr**)

引入 HSV 格式。


:revision: 4.5 / 2015-10-29 (**rr**)

扩展 VIDIOC_G_EXT_CTRLS；将 ctrl_class 替换为一个包含 ctrl_class 与 which 的新联合体。which 用于选择控件的当前值或默认值。


:revision: 4.4 / 2015-05-26 (**ap**)

将 V4L2_TUNER_ADC 重命名为 V4L2_TUNER_SDR。新增 V4L2_CID_RF_TUNER_RF_GAIN 控件。为软件定义无线电（Software Defined Radio，SDR）接口新增发射端支持。


:revision: 4.1 / 2015-02-13 (**mcc**)

修正媒体控制器（media controller）设备节点的文档，并新增对 DVB 设备节点的支持。新增对调谐器（Tuner）子设备的支持。


:revision: 3.19 / 2014-12-05 (**hv**)

重写色彩空间（Colorspace）章节，向 struct `v4l2_pix_format`、struct `v4l2_pix_format_mplane` 与 struct `v4l2_mbus_framefmt` 中新增枚举 `v4l2_ycbcr_encoding` 与枚举 `v4l2_quantization` 字段。


:revision: 3.17 / 2014-08-04 (**lp, hv**)

扩展 struct `v4l2_pix_format`。新增格式标志。新增复合控件类型与 VIDIOC_QUERY_EXT_CTRL。


:revision: 3.15 / 2014-02-03 (**hv, ap**)

更新“通用 API 元素（Common API Elements）”的若干章节：“打开与关闭设备（Opening and Closing Devices）”“查询能力（Querying Capabilities）”“应用程序优先级（Application Priority）”“视频输入与输出（Video Inputs and Outputs）”“音频输入与输出（Audio Inputs and Outputs）”“调谐器与调制器（Tuners and Modulators）”“视频标准（Video Standards）”以及“数字视频（DV）时序（Digital Video (DV) Timings）”。新增 SDR API。


:revision: 3.14 / 2013-11-25 (**rr**)

将 v4l2_rect 上的宽度与高度设为无符号类型。


:revision: 3.11 / 2013-05-26 (**hv**)

移除已过时的 VIDIOC_DBG_G_CHIP_IDENT ioctl。


:revision: 3.10 / 2013-03-25 (**hv**)

移除已过时的、未使用的 DV_PRESET ioctl：VIDIOC_G_DV_PRESET、VIDIOC_S_DV_PRESET、VIDIOC_QUERY_DV_PRESET 与 VIDIOC_ENUM_DV_PRESET。移除相关的 v4l2_input/output 能力标志 V4L2_IN_CAP_PRESETS 与 V4L2_OUT_CAP_PRESETS。新增 VIDIOC_DBG_G_CHIP_INFO。


:revision: 3.9 / 2012-12-03 (**sa, sn**)

向 v4l2_buffer 新增时间戳类型。新增 V4L2_EVENT_CTRL_CH_RANGE 控件事件变化标志。


:revision: 3.6 / 2012-07-02 (**hv**)

新增 VIDIOC_ENUM_FREQ_BANDS。


:revision: 3.5 / 2012-05-07 (**sa, sn, hv**)

新增 V4L2_CTRL_TYPE_INTEGER_MENU 与 V4L2 子设备选择 API。改进了 V4L2_CID_COLORFX 控件的描述，新增 V4L2_CID_COLORFX_CBCR 控件。新增相机控件 V4L2_CID_AUTO_EXPOSURE_BIAS、V4L2_CID_AUTO_N_PRESET_WHITE_BALANCE、V4L2_CID_IMAGE_STABILIZATION、V4L2_CID_ISO_SENSITIVITY、V4L2_CID_ISO_SENSITIVITY_AUTO、V4L2_CID_EXPOSURE_METERING、V4L2_CID_SCENE_MODE、V4L2_CID_3A_LOCK、V4L2_CID_AUTO_FOCUS_START、V4L2_CID_AUTO_FOCUS_STOP、V4L2_CID_AUTO_FOCUS_STATUS 与 V4L2_CID_AUTO_FOCUS_RANGE。新增 VIDIOC_ENUM_DV_TIMINGS、VIDIOC_QUERY_DV_TIMINGS 与 VIDIOC_DV_TIMINGS_CAP。
