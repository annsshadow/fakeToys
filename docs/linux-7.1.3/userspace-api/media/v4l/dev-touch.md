

######## 触摸设备


触摸设备通过名为 `/dev/v4l-touch0` `/dev/v4l-touch255` 的字符设备特殊文件访问，主设备号81，次设备号动态分配为 0 255
## 概述


传感器可以是光学的，或投射电容式触摸（PCT）
需要进行处理以分析原始数据并生成输入事件。在某些系统中，这可能由 ASIC 完成，原始数据纯粹作为诊断或调优的旁路通道。在其他系统中，ASIC 是一个简单的模拟前端设备，以高速率传送触摸数据，任何触摸处理都必须在主机上完成
对于电容式触摸感应，触摸屏由一组水平和垂直的导体（也称为行/列、X/Y 线或 tx/rx）组成。互电容在导体交叉的节点处测量。相反，自电容独立地测量来自每列和每行的信号
触摸输入可以通过将原始电容测量值与无触摸参考（或“基线”）测量值进行比较来确定
Delta = Raw - Reference

参考测量值考虑了触摸传感器矩阵中电容的变化，例如制造不规则、环境或边缘效应
## 查询能力


支持触摸接口的设备会设置 `v4l2_capability` `capabilities` 字段（由 VIDIOC_QUERYCAP ioctl 返回）中`V4L2_CAP_VIDEO_CAPTURE` 标志`V4L2_CAP_TOUCH` 标志
必须至少支持一种读/写或I/O 方法
触摸设备支持的格式记录在 Touch Formats <tch-formats> 中
## 数据格式协商


触摸设备可以支持任何 I/O 方法
