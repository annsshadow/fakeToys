######## 原始 Bayer 格式


## 描述


原始 Bayer 格式用于图像传感器在图像经过任何（或大量）处理之前。
这些格式包含绿色、红色和蓝色分量，红绿交替的行以及
蓝绿像素以不同的顺序排列。另请参阅 `Bayer 滤镜的维基百科词条
<https://en.wikipedia.org/wiki/Bayer_filter>`__。
