
######## 配置


应用程序可以使用选择 API <VIDIOC_G_SELECTION> 在视频信号或缓冲区中选择
一个区域，并查询默认设置与硬件限制
视频硬件可能存在各种裁剪（cropping）、合成（composing）和缩放（scaling限制。它可能只能放大或缩小、只支持离散的缩放系数，或者在水平和垂直方上具有不同的缩放能力。同样，它也可能根本不支持缩放。与此同时，裁剪/合成
矩形可能需要对齐，并且源端和宿端都可能存在任意的上下限尺寸约束。因此，
与通常情况一样，驱动程序应当调整所请求的参数并返回实际选定的值。应程序可以使用约束标志 <v4l2-selection-flags> 来控制舍入行为

## 视频采集的配

请参sel-targets-capture 图以了解视频采集设备可用的选择目标示例。建在配置合成目标之前先配置裁剪目标
可被采样的区域的左上角坐标、宽度和高度的取值范围由 `V4L2_SEL_TGT_CROP_BOUNDS`
目标给出。建议驱动开发者将左上角置`(0,0)` 位置。矩形坐标以像素为单位表示
源矩形（即实际被采样的区域）的左上角、宽度和高度`V4L2_SEL_TGT_CROP`
目标给出。它使用`V4L2_SEL_TGT_CROP_BOUNDS` 相同的坐标系。有效的裁剪区域
必须完全落在采集边界之内。驱动程序可能会根据硬件限制进一步调整所请求大小或位置
每个采集设备都有一个默认源矩形，由 `V4L2_SEL_TGT_CROP_DEFAULT` 目标给出该矩形应当覆盖驱动编写者认为的完整画面。驱动程序应在驱动首次加载时活动裁剪矩形设为默认值，但此后不应再改动
合成目标指向一个内存缓冲区。合成坐标的限制通过 `V4L2_SEL_TGT_COMPOSE_BOUNDS`
获取。所有坐标均以像素表示。矩形的左上角必须位`(0,0)` 位置。宽度和高度
等于VIDIOC_S_FMT <VIDIOC_G_FMT> 设定的图像尺寸
硬件将图像插入其中的缓冲区部分由 `V4L2_SEL_TGT_COMPOSE` 目标控制。矩形的
坐标也使用与边界矩形相同的坐标系表示。合成矩形必须完全落在边界矩形之内驱动程序必须将合成矩形调整至符合边界限制。此外，驱动程序还可以根据硬限制进行其他调整。应用程序可以使用约束标<v4l2-selection-flags> 控制
舍入行为
对于采集设备，默认合成矩形通过 `V4L2_SEL_TGT_COMPOSE_DEFAULT` 查询。它通常
等于边界矩形
硬件修改的缓冲区部分`V4L2_SEL_TGT_COMPOSE_PADDED` 给出。它包含使用
`V4L2_SEL_TGT_COMPOSE` 定义的所有像素，加上硬件在插入过程中修改的所有填数据。此矩形之外的所有像*不得**被硬件更改。位于填充区域内但位于活区域之外的像素内容未定义。应用程序可以使用填充矩形和活动矩形来检测无像素的位置，并在必要时将其去除

## 视频输出的配

对于输出设备，目标与 ioctl 的使用方式与视频采集的情形类似*合成**矩形
指向将图像插入到视频信号中。裁剪矩形则指向一个内存缓冲区。建议先配置合成
目标，再配置裁剪目标
裁剪目标指向包含要插入视频信号或图形屏幕的图像的内存缓冲区。裁剪坐标的
限制通过 `V4L2_SEL_TGT_CROP_BOUNDS` 获取。所有坐标均以像素表示。左上角始终
位于 `(0,0)` 点。宽度和高度等于使用 VIDIOC_S_FMT <VIDIOC_G_FMT> ioctl 指定图像尺寸
源矩形（即硬件从中处理图像数据的区域）的左上角、宽度和高度`V4L2_SEL_TGT_CROP` 给出。其坐标使用与边界矩形相同的坐标系表示。活动裁剪区必须完全落在裁剪边界之内，驱动程序可能会根据硬件限制进一步调整所请求大小或位置
对于输出设备，默认裁剪矩形通过 `V4L2_SEL_TGT_CROP_DEFAULT` 查询。它通常
等于边界矩形
硬件将图像插入其中的视频信号或图形显示部分由 `V4L2_SEL_TGT_COMPOSE` 目标
控制。矩形坐标以像素表示。合成矩形必须完全落在边界矩形之内。驱动程序必须将
该区域调整至符合边界限制。此外，驱动程序还可以根据硬件限制进行其他调整
设备具有一个默认合成矩形，`V4L2_SEL_TGT_COMPOSE_DEFAULT` 目标给出。该
矩形应当覆盖驱动编写者认为的完整画面。建议驱动开发者将左上角置`(0,0)`
位置。驱动程序应在驱动首次加载时将活动合成矩形设为默认矩形
设备可能会向视频信号中引入除内存缓冲区图像之外的额外内容，例如图像周围的
边框。然而，此类填充区域属于驱动相关的特性，不在本文档覆盖范围之内。鼓驱动开发者保持填充矩形与活动矩形一致。填充目标通过 `V4L2_SEL_TGT_COMPOSE_PADDED`
标识符访问。它必须包含 `V4L2_SEL_TGT_COMPOSE` 目标的所有像素

## 缩放控制


应用程序可以通过比较使用 `V4L2_SEL_TGT_CROP` `V4L2_SEL_TGT_COMPOSE` 目标
获取的矩形宽度和高度，来检测是否执行了缩放。如果两者不相等，则应用了缩放应用程序可以使用这些值计算缩放比例
