    - - 旗帜名称
      - ID
      - 定义
      - 适用于 V4L2
      - 对 V4L2 子开发有效
    - - `V4L2_SEL_FLAG_GE`
      - (1 << 0)
      - 建议驱动程序应选择大于或等于的矩形（在
尺寸）比要求的要大。尽管驾驶员可能会选择较小的
大小，它只会由于硬件限制而这样做。没有这个
标志（和`V4L2_SEL_FLAG_LE`）的行为是选择
最接近的可能的矩形。
      - 是的
      - 是的
    - - `V4L2_SEL_FLAG_LE`
      - (1 << 1)
      - 建议驱动程序应该选择小于或等于的矩形（在
尺寸）比要求的要大。尽管驾驶员可能会选择更大的
大小，它只会由于硬件限制而这样做。
      - 是的
      - 是的
    - - `V4L2_SEL_FLAG_KEEP_CONFIG`
      - (1 << 2)
      - 配置不得传播到任何进一步的处理
步骤。如果未给出此标志，则传播配置
在子设备内部进行所有进一步的处理步骤。
      - 不
      - 是的
