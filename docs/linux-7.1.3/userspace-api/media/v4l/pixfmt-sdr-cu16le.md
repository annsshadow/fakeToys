
######## V4L2_SDR_FMT_CU16LE ('CU16')


复数无符16 位小IQ 采样


## 描述


该格式包含复数采样序列。每个复数由两部分组成，称为同相（In-phase）和正交
（Quadrature，IQ）。I Q 均表示为 16 位无符号小端数值。I 值在前，Q 值在后

**字节序*
每个单元为一个字节


    :header-rows:  0
    :stub-columns: 0

    - - start + 0:
      - I'\ `0[7:0]`
      - I'\ `0[15:8]`
    - - start + 2:
      - Q'\ `0[7:0]`
      - Q'\ `0[15:8]`
