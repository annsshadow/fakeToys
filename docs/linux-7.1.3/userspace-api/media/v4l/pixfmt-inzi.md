
######## V4L2_PIX_FMT_INZI ('INZI')


红外 10 位与深度 16 位图像联合格式


## 描述


Intel SR300 深度相机使用的专有多平面格式，由红外图像后接深度数据组成。像素定义为 32-bpp，深度与红外数据被拆分为尺寸相同的独立连续平面。


第一个平面——红外数据——按照 V4L2_PIX_FMT_Y10 <V4L2-PIX-FMT-Y10> 灰度格式存储。每个像素是一个 16 位单元，实际数据存放在低 10 位（LSB）中，取值范围为 0 到 1023。其余 6 个高位（MSB）以零填充。


第二个平面提供每像素 16 位的深度数据，按 V4L2-PIX-FMT-Z16 <V4L2-PIX-FMT-Z16> 格式排列。


**帧结构。**
每个单元是一个 16 位字，高位数据存放在更高的内存地址处（字节序为小端）。
