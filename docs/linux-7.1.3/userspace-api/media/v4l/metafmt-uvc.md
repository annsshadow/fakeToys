


######## V4L2_META_FMT_UVC ('UVCH')


UVC 有效载荷头（Payload Header）数据


## 描述


该格式描述标准的 UVC 元数据，这些元数据从 UVC 包头部提取，并由 UVC 驱动通过元数据视频节点提供。这些数据包含 UVC 有效载荷头内容标准部分的精确副本，以及精确解释时间戳所需的辅助定时信息，这些信息包含在那些头中。详见"UVC 1.5 Class specification"的"2.4.3.3 Video and Still Image Payload Headers"一节。

每个 UVC 有效载荷头的大小在 2 到 12 字节之间。缓冲区可以包含多个头，如果相机为相应帧传输了多个这样的头。然而，当缓冲区已满、当它们不包含有用信息（例如那些没有 SCR 字段或该字段与前一个头相同）时，或者一般在设备发送大量头时为了进行速率限制，驱动可能会丢弃头。

每个单独的块包含以下字段：

    :widths: 1 4
    :header-rows:  1
    :stub-columns: 0

    - - Field
      - Description
    - - __u64 ts;
      - 以主机字节序表示的系统时间戳，由驱动在接收到有效载荷时测量
    - - __u16 sof;
      - 以主机字节序表示的 USB 帧号（Frame Number），同样由驱动在尽可能接近上述时间戳时获取，以便它们之间能够相互关联
    - - `1` **其余部分是 UVC 有效载荷头的精确副本：**
    - - __u8 length;
      - 块其余部分的长度，包括此字段。请注意，无论此值为多少，对于 V4L2_META_FMT_UVC，内核都不会复制超过 2-12 字节。
    - - __u8 flags;
      - 标志，指示其他标准 UVC 字段是否存在
    - - __u8 buf[];
      - 头的其余部分，可能包含 UVC PTS 和 SCR 字段
