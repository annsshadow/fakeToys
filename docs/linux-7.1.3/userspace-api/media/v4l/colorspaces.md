

######## 色彩空间（Colorspaces）


“颜色”是一个非常复杂的概念，依赖于物理、化学和生物学。仅仅因为你有三个数值描述了某个像素颜色的“红”、“绿”、“蓝”分量，并不意味着你就能准确地显示那个颜色。色彩空间（colorspace）定义了拥有一个例如 (255, 0, 0) 这样的 RGB 值究竟**意味着**什么。即在完美校准的环境中，屏幕上应当重现哪种颜色。

为了做到这一点，我们首先需要对颜色有一个好的定义，即某种能够唯一、明确地定义一种颜色的方法，以便他人能够重现它。人类视觉是三色的，因为人眼具有对三种不同光波长敏感的色彩感受器。因此需要用三个数值来描述颜色。庆幸你不是一只皮皮虾，因为它们对 12 种不同波长敏感，那样的话我们就不会用 RGB，而是要用 ABCDEFGHIJKL 色彩空间了……

颜色只存在于眼睛和大脑中，是色彩感受器受刺激强度的结果。这基于光谱功率分布（SPD），即一张图，显示进入眼睛时覆盖可见光谱各波长的光强（辐射功率）。色度学（colorimetry）研究的是 SPD 与人脑感知到的颜色之间的关系。

由于人眼只有三种色彩感受器，完全可能出现不同的 SPD 导致这些感受器受到相同刺激、并被感知为相同颜色的情况，即便光的 SPD 不同。

在 1920 年代，人们设计了实验来确定 SPD 与感知颜色之间的关系，由此产生了 CIE 1931 标准，该标准定义了建模颜色感知的光谱加权函数。具体而言，该标准定义了可以接受 SPD 并计算每种色彩感受器所受刺激的函数。经过进一步的数学变换后，这些刺激被称为 **CIE XYZ 三刺激值**，而 X、Y、Z 这三个值明确地描述了一个人类感知到的颜色。这些 X、Y、Z 值都在 [0…1] 范围内。

CIE XYZ 色彩空间中的 Y 值对应于亮度（luminance）。通常 CIE XYZ 色彩空间会变换到归一化的 CIE xyY 色彩空间：

	x = X / (X + Y + Z)

	y = Y / (X + Y + Z)

x 和 y 值是色度坐标，可用于在不需要亮度分量 Y 的情况下定义一个颜色。这些色彩空间名称如此相似非常令人困惑。只要注意：如果颜色是用小写 ‘x’ 和 ‘y’ 指定的，那么使用的是 CIE xyY 色彩空间；大写 ‘X’ 和 ‘Y’ 指的是 CIE XYZ 色彩空间。此外，y 与亮度毫无关系。x 和 y 一起指定一个颜色，而 Y 是亮度。从实用角度看，这确实是你唯一需要记住的。在本节末尾你会找到更深入的阅读资源，如果你感兴趣的话。

显示器或电视机会通过发射三种不同波长的光来重现颜色，这些光的组合会刺激眼睛中的色彩感受器，从而产生颜色感知。历史上，这些波长由显示器中使用的红、绿、蓝荧光粉定义。这些**原色（color primaries）**是定义一个色彩空间的一部分。

不同的显示设备会有不同的原色，而某些原色比其他的更适合某些显示技术。这导致了用于不同显示技术或用途的各种色彩空间。要定义一个色彩空间，你需要定义三种原色（通常定义为来自 CIE xyY 色彩空间的 x、y 色度坐标），还需要定义白色参考：即三种原色都达到最大功率时获得的颜色。这决定了原色的相对功率或能量。通常选择接近日光，即被定义为 CIE D65 照明体（Illuminant）的值。

总结一下：CIE XYZ 色彩空间唯一地标识颜色。其他色彩空间由在 CIE xyY 色彩空间中定义的三个色度坐标来定义。基于这些坐标可以构造一个 3x3 矩阵，把 CIE XYZ 颜色变换到新色彩空间中的颜色。

由特定色度原色导出的 CIE XYZ 和 RGB 色彩空间都是线性色彩空间。但无论是眼睛还是显示技术都不是线性的。在线性色彩空间中把所有分量的值加倍，并不会被感知为颜色强度加倍。因此每个色彩空间还定义了一个传递函数，它接受一个线性颜色分量值并将其变换为非线性的分量值，这更接近眼睛和显示器的非线性表现。线性分量值记为 RGB，非线性记为 R'G'B'。一般来说，图形中使用的颜色都是 R'G'B'，openGL 除外，它使用线性 RGB。在处理 openGL 时需要特别小心，要提供线性 RGB 颜色，或者使用 openGL 内置支持来应用逆向传递函数。

定义一个色彩空间的最后一部分是一个把非线性 R'G'B' 变换到非线性 Y'CbCr 的函数。这个函数由所谓的亮度系数（luma coefficients）决定。同一个色彩空间可能允许多种 Y'CbCr 编码。许多颜色编码倾向于使用亮度（Y'）和色度（CbCr），而不是 R'G'B'。由于人眼对亮度差异比对颜色差异更敏感，这种编码允许相比亮度数据减少颜色信息量。注意亮度（Y'）与 CIE XYZ 色彩空间中的 Y 无关。还要注意，Y'CbCr 常被称为 YCbCr 或 YUV，尽管严格来说这是错误的。

有时人们会把 Y'CbCr 误认为是一个色彩空间。这是不对的，它只是把 R'G'B' 颜色编码为亮度和色度值。与 R'G'B' 颜色相关联的底层色彩空间，也与 Y'CbCr 颜色相关联。

最后一步是 RGB、R'G'B' 或 Y'CbCr 值如何被量化。X、Y、Z 都在 [0…1] 范围内的 CIE XYZ 色彩空间描述了人类能感知的所有颜色，但变换到另一个色彩空间会产生 [0…1] 范围之外的颜色。一旦被钳制（clamp）到 [0…1] 范围，这些颜色就无法在该色彩空间中重现了。这种钳制缩小了色彩空间的范围或色域（gamut）。[0…1] 范围如何被转换为 [0…255] 范围内的整数值（或更高，取决于色深）称为量化（quantization）。这**不是**色彩空间定义的一部分。在实践中，RGB 或 R'G'B' 值是全范围（full range）的，即它们使用完整的 [0…255] 范围。另一方面，Y'CbCr 值是limited range，Y' 使用 [16…235]，Cb 和 Cr 使用 [16…240]。

遗憾的是，在某些情况下也会使用 limited range RGB，其分量使用 [16…235] 范围。全范围 Y'CbCr 也存在，使用 [0…255] 范围。

为了正确解释一个颜色，你需要知道量化范围、它是 R'G'B' 还是 Y'CbCr、所使用的 Y'CbCr 编码以及色彩空间。从这些信息你可以计算出对应的 CIE XYZ 颜色，并再次将其映射到你的显示设备所使用的任意色彩空间。

色彩空间定义本身由三个色度原色、白色参考色度、一个传递函数以及把 R'G'B' 变换为 Y'CbCr 所需的亮度系数组成。虽然有些色彩空间标准正确地定义了全部四项，但色彩空间标准往往只定义其中一些，缺失的部分你需要依赖其他标准。色彩空间常常混合不同标准这一事实，也导致了非常混乱的命名约定——一个标准的名字被用来命名一个色彩空间，而实际上该标准也是许多其他色彩空间的一部分。
