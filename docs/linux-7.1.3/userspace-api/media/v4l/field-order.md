
######## 场序（Field Order）


我们必须区分逐行（progressive）和隔行（interlaced）视频。逐行视频按顺序传输视频图像的所有扫描行。隔行视频将一幅图像分为两个场（field），分别只包含图像的奇数行和偶数行。所谓奇数场和偶数场交替传输，由于场之间存在微小延迟，阴极射线电视机将扫描行交织显示，从而得到原始帧。发明这种奇特技术的原因是，在类似电影的刷新率下，图像会过快淡出。传输场可以在不将帧率加倍（以及随之而来的每个频道所需带宽加倍）的情况下减少闪烁。

理解一台摄像机并非一次暴露一帧很重要，而只是将帧分解为场来传输。实际上，这两个场是在两个不同的时刻捕获的。屏幕上的物体完全可能在一个场到下一个场之间移动。对于分析运动的应用程序来说，识别一帧中哪个场更旧，即**时间顺序（temporal order）**，至关重要。

当驱动以场为单位而非交织方式提供或接收图像时，应用程序理解这些场如何组合成帧也很重要。我们区分顶场（top，又称奇数场）和底场（bottom，又称偶数场），即**空间顺序（spatial order）**：顶场的第一行是隔行帧的第一行，底场的第一行是该帧的第二行。

然而，由于场是一个接一个捕获的，争论一帧是从顶场还是底场开始并无意义。任意两个连续的顶场和底场，或底场和顶场，都能构成一个有效的帧。只有当源本来就是逐行的，例如将电影转制为视频时，两个场才可能来自同一帧，从而产生自然的顺序。

与直觉相反，顶场不一定是较旧的场。较旧的场包含顶行还是底行，是由视频标准决定的约定。因此才有了场的时间顺序与空间顺序的区分。下面的图示应当能让这一点更清晰。

在 V4L 中，假设所有摄像机在媒体总线上以它们被捕获的相同顺序传输场，因此如果顶场先被捕获（是较旧的场），顶场也会先在总线上传输。

所有视频采集和输出设备都必须报告当前的场序。某些驱动可能允许选择不同的顺序，为此应用程序在调用 VIDIOC_S_FMT <VIDIOC_G_FMT> ioctl 之前初始化 struct `v4l2_pix_format` 的 `field` 字段。如果不希望这样，它应具有值 `V4L2_FIELD_ANY` (0)。


## enum v4l2_field



    :header-rows:  0
    :stub-columns: 0
    :widths:       3 1 4

    - - `V4L2_FIELD_ANY`
      - 0
      - 当任何场格式都可接受时，应用程序请求该场序。驱动根据硬件能力或例如所请求的图像大小来选择，并返回实际的场序。驱动绝不能返回 `V4L2_FIELD_ANY`。如果可能存在多种场序，驱动必须在 VIDIOC_S_FMT <VIDIOC_G_FMT> 或 VIDIOC_TRY_FMT <VIDIOC_G_FMT> 期间选择其中一种可能的场序。struct `v4l2_buffer` 的 `field` 永远不能是 `V4L2_FIELD_ANY`。
    - - `V4L2_FIELD_NONE`
      - 1
      - 图像为逐行（基于帧）格式，而非隔行（基于场）。
    - - `V4L2_FIELD_TOP`
      - 2
      - 图像仅由顶场（又称奇数场）组成。
    - - `V4L2_FIELD_BOTTOM`
      - 3
      - 图像仅由底场（又称偶数场）组成。应用程序可能希望阻止设备捕获隔行图像，因为它们在运动物体周围会出现“梳状（comb）”或“羽化（feathering）”伪影。
    - - `V4L2_FIELD_INTERLACED`
      - 4
      - 图像包含两个场，逐行交织。场的时间顺序（顶场还是底场更旧）取决于当前视频标准。在 M/NTSC 中，底场是较旧的场。在所有其它标准中，顶场是较旧的场。
    - - `V4L2_FIELD_SEQ_TB`
      - 5
      - 图像包含两个场，顶场的行先存储在内存中，紧接着是底场的行。场始终按时间顺序存储，较旧的场先存入内存。图像大小指的是帧，而非场。
    - - `V4L2_FIELD_SEQ_BT`
      - 6
      - 图像包含两个场，底场的行先存储在内存中，紧接着是顶场的行。场始终按时间顺序存储，较旧的场先存入内存。图像大小指的是帧，而非场。
    - - `V4L2_FIELD_ALTERNATE`
      - 7
      - 一帧的两个场在单独的缓冲区中按时间顺序传递，即较旧的场先传。为了指示场的奇偶（当前场是顶场还是底场），驱动或应用程序（取决于数据方向）必须将 struct `v4l2_buffer` 的 `field` 设为 `V4L2_FIELD_TOP` 或 `V4L2_FIELD_BOTTOM`。任意两个连续的场配对构成一个帧。如果场是连续的、且它们之间没有任何丢弃的场（场可以单独丢弃），则可以通过 struct `v4l2_buffer` 的 `sequence` 字段判断。使用 read/write I/O 方法时不能选择这种格式，因为无法传达一个场是顶场还是底场。
    - - `V4L2_FIELD_INTERLACED_TB`
      - 8
      - 图像包含两个场，逐行交织，顶场在前。顶场是较旧的场。
    - - `V4L2_FIELD_INTERLACED_BT`
      - 9
      - 图像包含两个场，逐行交织，顶场在前。底场是较旧的场。
