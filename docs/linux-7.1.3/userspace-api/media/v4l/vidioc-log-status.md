######## ioctl VIDIOC_LOG_STATUS


## 名称


VIDIOC_LOG_STATUS - 记录驱动状态信息

## 概要


`int ioctl(int fd, VIDIOC_LOG_STATUS)`

## 参数


`fd`
    由 `open()` 返回的文件描述符。

## 描述


随着视频/音频设备日益复杂，问题的调试也变得愈发困难。调用此 ioctl 时，驱动会将当前设备状态输出到内核日志。这在处理无声、无图像以及频道调谐错误等问题时尤为有用。此外，许多现代设备会自动检测视频与音频标准，此 ioctl 将报告设备所认为的标准。不匹配情况可为定位问题提供线索。

此 ioctl 是可选的，并非所有驱动都支持。它于 Linux 2.6.15 中引入。

## 返回值


成功时返回 0，出错时返回 -1 并相应设置 `errno` 变量。通用错误码在“通用错误码 <gen-errors>”章节中描述。
