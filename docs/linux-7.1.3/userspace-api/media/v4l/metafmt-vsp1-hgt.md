
######## V4L2_META_FMT_VSP1_HGT ('VSPT')


Renesas R-Car VSP1 二维直方图数据


## 描述


该格式描述由 Renesas R-Car VSP1 二维直方图（HGT）引擎生成的直方图数据。

VSP1 HGT 是一个在 HSV 数据上运行的直方图计算引擎。它作用于可能经过裁剪与子采样（subsampled）
的输入图像，计算 S 分量的总和、最大值与最小值，以及基于 H 与 S 分量的加权频率直方图。

直方图是一个由 6 个色相（Hue）与 32 个饱和度（Saturation）桶组成的矩阵，总共 192 个。每个
HSV 值根据其色相区域（Hue area）配置，被加入一个或多个权重介于 1 到 16 之间的桶中。找到
对应的桶是通过独立检查 H 与 S 值来完成的。

矩阵中桶的饱和度位置 **n**（0 - 31）由以下表达式求得：

    n = S / 8

矩阵中桶的色相位置 **m**（0 - 5）取决于 HGT 色相区域如何配置。有 6 个用户可配置的色相区域，
可配置为覆盖重叠的色相值：


    \small

```

         Area 0       Area 1       Area 2       Area 3       Area 4       Area 5
        ________     ________     ________     ________     ________     ________
   \   /|      |\   /|      |\   /|      |\   /|      |\   /|      |\   /|      |\   /
    \ / |      | \ / |      | \ / |      | \ / |      | \ / |      | \ / |      | \ /
     X  |      |  X  |      |  X  |      |  X  |      |  X  |      |  X  |      |  X
    / \ |      | / \ |      | / \ |      | / \ |      | / \ |      | / \ |      | / \
   /   \|      |/   \|      |/   \|      |/   \|      |/   \|      |/   \|      |/   \
  5U   0L      0U   1L      1U   2L      2U   3L      3U   4L      4U   5L      5U   0L
        <0..............................Hue Value............................255>


```

    \normalsize

当两个连续区域不重叠时（n+1L 等于 nU），边界值被视为较低区域的一部分。

色相值包含在某个区域中心（包含 nL 与 nU 之间）的像素归属于该单一区域，并赋以权重 16。色相值
包含在两个区域之间的重叠区域（排除 n+1L 与 nU 之间）的像素归属于两个区域，并根据其沿对角线的
位置（向下取整）为这些区域各赋一个权重。

色相区域的设置必须匹配以下约束之一：

```

    0L <= 0U <= 1L <= 1U <= 2L <= 2U <= 3L <= 3U <= 4L <= 4U <= 5L <= 5U

```
```

    0U <= 1L <= 1U <= 2L <= 2U <= 3L <= 3U <= 4L <= 4U <= 5L <= 5U <= 0L

```
