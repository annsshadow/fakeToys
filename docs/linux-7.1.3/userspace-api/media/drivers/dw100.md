
## DW100 鍘荤暩鍙橀┍鍔。

i.MX8MP SoC 上的 Vivante DW100 Dewarp 处理IP 核对输入图像施加一可编程的几何变换，以校正镜头引入的畸变
该变换函数在硬件上表现为一个网格映射，由使X、Y 顶点坐标索引16x16
像素宏块组成```

每个 x、y 坐标寄存器使16 位以无符12.4 定点格式（UQ12.4）记录坐标地址```

    .----------------------.--------..----------------------.--------.
    |         31~20        | 19~16  ||         15~4         |  3~0   |
    |       (integer)      | (frac) ||       (integer)      | (frac) |

    <-------------------------------><------------------------------->
                Y coordinate                     X coordinate

                           Remap Register Layout

```
去畸变映射由应用程序通过 V4L2_CID_DW100_DEWARPING_16x16_VERTEX_MAP 控件设置。该控件
包含一u32 值数组，存储网格每个顶点的（x, y）目标坐标。x 坐标存放在低 16 位，
y 坐标存放在高 16 位
数组的元素个数必须与图像尺寸匹配

    elems = (DIV_ROUND_UP(width, 16) + 1) * (DIV_ROUND_UP(height, 16) + 1);

如果应用程序未设置该控件，驱动将使用单位映射（identity map）
有关 DW100 硬件操作的更多细节可IMX8MP_ 参考手册的 **13.15 DeWarp** 中找到
Vivante DW100 m2m 驱动实现了以下驱动专有控件：

`V4L2_CID_DW100_DEWARPING_16x16_VERTEX_MAP (__u32 array)`
    DW100 驱动指定其去畸变映射（即 LUT）数据块，如 IMX8MP_ 参考手册的
    **13.15.2.3 Dewarping Remap** 所述，是一U32 动态数组。图像被划分为许    16x16 的小块。如果图像的高不能被 16 整除，则最右侧/最底侧块的大小为其余数    去畸变映射仅保存块的顶点坐标。去畸变网格映射x y 的顶点坐标组成。每x、y
    坐标寄存器使16 位（UQ12.4）记录坐标地址，Y 坐标位于高位，X 坐标位于低位    sink 格式发生改变时，驱动会修改此控件的尺寸，以反映新的输入分辨率
