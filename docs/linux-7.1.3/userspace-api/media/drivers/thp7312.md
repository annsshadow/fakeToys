
## THine THP7312 ISP 驱动


THP7312 驱动实现以下驱动特定的控制：

`V4L2_CID_THP7312_LOW_LIGHT_COMPENSATION`
    启用/禁用在自动曝光启用时，基于光照条件对帧率进行自动调整。

`V4L2_CID_THP7312_AUTO_FOCUS_METHOD`
    设置自动对焦的方法。仅在自动对焦启用时生效。

```

        :header-rows:  0
        :stub-columns: 0
        :widths:       1 4

        * - ``0``
          - 基于对比度的自动对焦
        * - ``1``
          - PDAF
        * - ``2``
          - 基于对比度与 PDAF 的混合

    该控制支持的值取决于连接到 THP7312 的相机传感器模块。如果模块没有对焦镜头
    致动器，THP7312 驱动将不会暴露此控制。如果模块具有可控对焦镜头但传感器不
    支持 PDAF，则仅基于对比度的自动对焦值有效。否则该控制的所有值都受支持。

```
`V4L2_CID_THP7312_NOISE_REDUCTION_AUTO`
    启用/禁用自动降噪。

`V4L2_CID_THP7312_NOISE_REDUCTION_ABSOLUTE`
    设置降噪强度，其中 0 最弱、10 最强。
