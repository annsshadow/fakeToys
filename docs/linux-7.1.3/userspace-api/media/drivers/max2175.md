
## Maxim Integrated MAX2175 RF 到比特调谐器驱动


MAX2175 驱动实现了以下驱动特定的控制：

### ``V4L2_CID_MAX2175_I2S_ENABLE``


    启用/禁用调谐器的 I2S 输出。这是一个私有控制，只能使用子设备（subdev）接口访问。
    更多细节请参阅 Documentation/driver-api/media/v4l2-controls.rst。

    :header-rows:  0
    :stub-columns: 0
    :widths:       1 4

    - - `(0)`
      - I2S 输出被禁用。
    - - `(1)`
      - I2S 输出被启用。

### ``V4L2_CID_MAX2175_HSLS``


    调谐器针对给定频带的高端/低端（HSLS）控制。

    :header-rows:  0
    :stub-columns: 0
    :widths:       1 4

    - - `(0)`
      - 本振（LO）频率位置在期望频率之下。
    - - `(1)`
      - 本振（LO）频率位置在期望频率之上。

### ``V4L2_CID_MAX2175_RX_MODE (menu)``


    Rx 模式控制调谐器的多个预设参数，例如采样时钟（sck）、采样率等。数据手册中将这些多个设置统一放在一个名为 Rx 模式的标签下。下面的列表展示了受支持的模式及其简要说明。

    :header-rows:  0
    :stub-columns: 0
    :widths:       1 4

    - - `"Europe modes"`
    - - `"FM 1.2" (0)`
      - 配置 FM 频带，采样率为 0.512 百万样本/秒，sck 为 10.24 MHz。
    - - `"DAB 1.2" (1)`
      - 配置 VHF 频带，采样率为 2.048 百万样本/秒，sck 为 32.768 MHz。

    - - `"North America modes"`
    - - `"FM 1.0" (0)`
      - 配置 FM 频带，采样率为 0.7441875 百万样本/秒，sck 为 14.88375 MHz。
    - - `"DAB 1.2" (1)`
      - 配置 FM 频带，采样率为 0.372 百万样本/秒，sck 为 7.441875 MHz。
