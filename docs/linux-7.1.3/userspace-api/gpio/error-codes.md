


######## GPIO 错误码（Error Codes）



    :header-rows:  0
    :stub-columns: 0
    :widths: 1 16

    - -  `EAGAIN`（又名 `EWOULDBLOCK`）

       - 设备以非阻塞模式打开，且由于无可用数据，无法执行读取。

    - -  `EBADF`

       - 文件描述符无效。

    - -  `EBUSY`

       - ioctl 无法处理，因为设备正忙。通常在 ioctl 尝试使用已被分配的资源时返回。在首先执行其他操作修复问题之前，不得重试该 ioctl。

    - -  `EFAULT`

       - 在从/向用户空间拷贝数据时发生失败，可能由无效指针引用引起。

    - -  `EINVAL`

       - 一个或多个 ioctl 参数无效或超出允许范围。这是一个被广泛使用的错误码。

    - -  `ENODEV`

       - 设备未找到或已被移除。

    - -  `ENOMEM`

       - 没有足够的内存来处理期望的操作。

    - -  `EPERM`

       - 权限被拒绝。通常在尝试执行与当前线路配置不兼容的操作时返回。

    - -  `EIO`

       - I/O 错误。通常在与硬件设备通信或请求硬件不支持的特性出现问题时返回。这可能表明硬件损坏或不稳定。这是一种“出问题了，我放弃！”类型的错误。

    - - `ENXIO`

       - 通常在请求需要中断支持的特性时返回，但该线路不支持中断。


  #. 此列表并非详尽无遗；ioctl 可能返回其他错误码。
     由于错误可能产生副作用（如驱动重置），应用程序应在遇到
     意外错误时中止，否则应假定设备处于不良状态。

  #. 特定于请求的错误码在各请求的描述中列出。
