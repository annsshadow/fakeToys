
## fwctl pds 驱动


:作者: Shannon Nelson

## 概述


PDS Core 设备通过一个名为 pds_core.fwctl.N 的 auxiliary_device 提供 fwctl 服务。
pds_fwctl 驱动绑定到该设备，并向 fwctl 子系统注册自身。由此产生的用户空间接口
由 AMD Pensando 软件包中用于分布式服务卡（DSC，Distributed Service Card）的应用程序使用。

pds_fwctl 驱动对固件内部细节知之甚少。它只知道如何通过 pds_core 的消息队列向固件
发送用于 fwctl 请求的命令。可用的 fwctl 操作集合取决于 DSC 中的固件，并且用户空间
应用程序的版本必须与固件匹配，以便二者能够相互通信。

当建立连接时，pds_fwctl 驱动会向固件请求一份固件对象端点列表，并针对每个端点请求
该端点对应的操作列表。

每个操作描述都包含一个由固件定义的命令属性，该属性映射到 FWCTL 的作用域级别。
驱动将这些固件值转换为 FWCTL 作用域值，之后可用于过滤作用域化的用户请求。

## pds_fwctl 用户 API


每个 RPC 请求都包含目标端点和操作 id，以及输入和输出缓冲区的长度与指针。驱动会
校验所请求的端点与操作是否存在，然后将请求的作用域与该操作所需的作用域进行比对。
随后请求与请求数据被组合在一起，经由 pds_core 的消息队列发送到固件，结果返回给调用者。

RPC 端点、操作以及缓冲区内容由设备中特定的固件包定义，在不同的产品配置之间有所差异。
具体细节可在相应产品的 SDK 文档中找到。
