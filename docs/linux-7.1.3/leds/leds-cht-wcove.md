## Intel Cherry Trail Whiskey Cove PMIC LED 内核驱动


### /sys/class/leds/<led>/hw_pattern


为 Whiskey Cove PMIC LED 指定一个硬件模式。

```

    "0 2000 1 2000"

	^
	|
    Max-|     ---
	|    /   \
	|   /     \
	|  /       \     /
	| /         \   /
    Min-|-           ---
	|
	0------2------4--> time (sec)

```
上升和下降时间必须为相同的值。
支持的呼吸频率为 1/4、1/2、1 和 2 Hz，对应取值为 2000、1000、500 和 250。

所设置的模式仅控制时序。最大亮度使用上一次设置的亮度值，并且可以通过写入 brightness 属性在呼吸过程中改变最大亮度。

这与 LED 子系统（LED subsystem）中的闪烁工作方式类似：无论是软件还是硬件闪烁，亮度都可以在闪烁过程中改变。该硬件上的呼吸模式实际上只是闪烁的一种变体模式。
