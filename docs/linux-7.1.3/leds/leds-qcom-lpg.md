
## Qualcomm LPG 内核驱动


### 描述


Qualcomm LPG 可见于多Qualcomm PMIC 中，由若PWM 通道、一个可编程模式查找表和一RGB LED 电流阱（current sink）组成
为了适应各种使用场景，LPG 通道可以作为独立LED 暴露，也可以组合RGB LED，或者以 PWM 通道的方式被访问。每PWM 通道的输出被路由到其他硬件模块，例如 RGB 电流阱、GPIO 引脚等
每个 PWM 通道可以工作27 微秒384 秒之间的周期，占空比分辨率为 9 位
为了CPU 子系统处于更深空闲状态时仍能支持状态通知，LPG 提供了模式（pattern）支持。它由一个共享的亮度值查找表，以及每个通道用于选择表中使用范围、速率以及模式是否应重复的属性组成
一个通道的模式可以使"pattern" 触发器、通过 hw_pattern 属性进行编程
### /sys/class/leds/<led>/hw_pattern


Qualcomm LPG LED 指定一个硬件模式
该模式由一系列亮度和保持时间（hold-time）对组成，保持时间以毫秒表示。保持时间是模式的一个属性，因此模式中每个元素必须相同（下文描述的暂停除外）。由LPG 硬件无法执行 leds-trigger-pattern 格式所期望的线性过渡，模式中的每个条目之后必须跟一个相同亮度的零长度条目
```

    "255 500 255 0 0 500 0 0"

        ^
        |
    255 +----+    +----+
        |    |    |    |      ...
      0 |    +----+    +----
        +---------------------->
        0    5   10   15     time (100ms)

```

LPG 支持为模式中的第一个和最后一个元素指定更长的保持时间，即所谓的 "low pause"（低暂停）和 "high pause"（高暂停）
```

    "255 1000 255 0 0 500 0 0 255 500 255 0 0 500 0 0"

        ^
        |
    255 +--------+    +----+    +----+    +--------+
        |        |    |    |    |    |    |        |      ...
      0 |        +----+    +----+    +----+        +----
        +----------------------------->
        0    5   10   15  20   25   time (100ms)

```

类似地，最后一个条目可以通过使用更高的保持时间来拉长
为了节省共享查找表的空间，LPG 支持 "ping-pong"（乒乓）模式，在这种情况下，每次运行模式时先正序运行，再逆序运行。当给定模式是回文（palindrome）时，驱动会自动使用此模式。在这种情况下，"high pause" 表示模式反向运行前的等待时间，因此模式中中间条目的指定保持时间可以有不同的保持时间
