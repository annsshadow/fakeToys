
## 联发科 MT6370 RGB LED 设备


### 描述


MT6370 集成了一个四通道 RGB LED 驱动，旨在为移动设备应用提供各种照明效果。该 RGB
LED 设备包含一个智能 LED 串控制器，可以驱动 3 路 LED，灌电流（sink current）最高
达 24mA，以及一个 CHG_VIN 电源良好指示 LED，灌电流最高达 6mA。它为 RGB LED 提供三种
操作模式：PWM 调光模式、呼吸（breath）模式，以及恒流模式。该设备可以通过 I2C 接口
增加或降低 RGB LED 的亮度。

一个通道的呼吸模式可以使用 "pattern" 触发器、通过 hw_pattern 属性来编程。

### /sys/class/leds/<led>/hw_pattern


为 MT6370 RGB LED 指定一个硬件呼吸模式。

呼吸模式是一系列时序对，保持时间以毫秒表示。亮度由 '/sys/class/leds/<led>/brightness'
控制。模式不包含亮度设置。硬件模式仅根据当前亮度设置来控制每个模式阶段的时序。

```

         "0 Tr1 0 Tr2 0 Tf1 0 Tf2 0 Ton 0 Toff" --> '0' 为虚拟亮度代码

          ^
          |           ============
          |          /            \                                /
    Icurr |         /              \                              /
          |        /                \                            /
          |       /                  \                          /   .....重复
          |      /                    \                        /
          |   ---                      ---                  ---
          |---                            ---            ---
          +----------------------------------============------------> 时间
          < Tr1><Tr2><   Ton    ><Tf1><Tf2 ><  Toff    >< Tr1><Tr2>

```
时序描述：

  - Tr1:    0% - 30% 负载的第一次上升时间。
  - Tr2:    31% - 100% 负载的第二次上升时间。
  - Ton:    100% 负载的导通时间。
  - Tf1:    100% - 31% 负载的第一次下降时间。
  - Tf2:    30% 到 0% 负载的第二次下降时间。
  - Toff:   0% 负载的关断时间。

  - Tr1/Tr2/Tf1/Tf2/Ton: 125ms 到 3125ms，每步 200ms。
  - Toff: 250ms 到 6250ms，每步 400ms。

```

       "0 125 0 125 0 125 0 125 0 625 0 1050"

```
这将配置 Tr1/Tr2/Tf1/Tf2 为 125ms，Ton 为 625ms，Toff 为 1050ms。
