
## 看门狗（Watchdog）模块参数


本文件提供许多 Linux 看门狗驱动模块参数的信息。看门狗驱动的参数规格应列在此处，除非该驱动拥有自己的驱动专用信息文件。

关于为内建驱动与可加载模块提供内核参数的信息，请参见 Documentation/admin-guide/kernel-parameters.rst。

-------------------------------------------------

watchdog core：
    open_timeout：
	看门狗框架负责 ping 一个正在运行的硬件看门狗的最长时间（以秒为单位），
	直到用户空间打开对应的 /dev/watchdogN 设备。值为 0 表示超时时间为无限。
	将其设置为非零值有助于确保：要么用户空间正常启动，要么主板被复位并允许
	引导加载程序中的回退逻辑尝试其它操作。
