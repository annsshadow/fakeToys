## 程序类型与 ELF 段


下表列出了 libbpf 所支持的程序类型、相关的附加（attach）类型以及对应的 ELF 段名。ELF 段名遵循以下规则：

- `type` 为精确匹配，例如 `SEC("socket")`
- `type+` 表示既可以是精确的 `SEC("type")`，也可以是格式良好的 `SEC("type/extras")`，其中 `type` 与 `extras` 之间用分隔符 '`/`' 隔开。

当指定了 `extras` 时，它们提供了如何自动附加（auto-attach）BPF 程序的细节。`extras` 的格式取决于程序类型，例如 tracepoint 使用 `SEC("tracepoint/<category>/<name>")`，USDT 探针使用 `SEC("usdt/<path>:<provider>:<name>")`。有关 extras 的更详细说明见脚注。
