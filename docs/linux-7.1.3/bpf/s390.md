## 在 s390 上测试 BPF


######## 1. 简介


IBM Z 是大型机，其源自 1964 年的 IBM System/360。它们由 Linux 内核以 "s390" 之名提供
支持。本文档描述如何在 s390 的 QEMU 客户机中测试 BPF。

######## 2. 一次性设置


构建并运行测试套件需要以下内容：

  - s390 GCC
  - s390 开发头文件与库
  - 支持 BPF 的 Clang
  - 支持 s390 的 QEMU
  - 带有 s390 rootfs 的磁盘镜像

Debian 原生支持开箱即用地安装 s390 的编译器与库。
```

  sudo debootstrap \
    --variant=minbase \
    --include=sudo \
    testing \
    ./s390-toolchain
  sudo mount --rbind /dev ./s390-toolchain/dev
  sudo mount --rbind /proc ./s390-toolchain/proc
  sudo mount --rbind /sys ./s390-toolchain/sys
  sudo chroot ./s390-toolchain

```
```

  sudo dpkg --add-architecture s390x
  sudo apt-get update
  sudo apt-get install \
    bc \
    bison \
    cmake \
    debootstrap \
    dwarves \
    flex \
    g++ \
    gcc \
    g++-s390x-linux-gnu \
    gcc-s390x-linux-gnu \
    gdb-multiarch \
    git \
    make \
    python3 \
    qemu-system-misc \
    qemu-utils \
    rsync \
    libcap-dev:s390x \
    libelf-dev:s390x \
    libncurses-dev

```
```

  git clone https://github.com/llvm/llvm-project.git
  ln -s ../../clang llvm-project/llvm/tools/
  mkdir llvm-project-build
  cd llvm-project-build
  cmake \
    -DLLVM_TARGETS_TO_BUILD=BPF \
    -DCMAKE_BUILD_TYPE=Release \
    -DCMAKE_INSTALL_PREFIX=/opt/clang-bpf \
    ../llvm-project/llvm
  make
  sudo make install
  export PATH=/opt/clang-bpf/bin:$PATH

```
```

  qemu-img create -f raw ./s390.img 1G
  sudo losetup -f ./s390.img
  sudo mkfs.ext4 /dev/loopX
  mkdir ./s390.rootfs
  sudo mount /dev/loopX ./s390.rootfs
  sudo debootstrap \
    --foreign \
    --arch=s390x \
    --variant=minbase \
    --include=" \
      iproute2, \
      iputils-ping, \
      isc-dhcp-client, \
      kmod, \
      libcap2, \
      libelf1, \
      netcat, \
      procps" \
    testing \
    ./s390.rootfs
  sudo umount ./s390.rootfs
  sudo losetup -d /dev/loopX

```
######## 3. 编译


除了运行 BPF 测试套件所需的常规 Kconfig 选项之外，还
```

  CONFIG_NET_9P=y
  CONFIG_9P_FS=y
  CONFIG_NET_9P_VIRTIO=y
  CONFIG_VIRTIO_PCI=y

```
因为这样可以提供一种非常简便的方式与 s390 虚拟机共享文件。

编译内核、模块和测试套件，以及准备 gdb 脚本以
```

  make ARCH=s390 CROSS_COMPILE=s390x-linux-gnu- menuconfig
  make ARCH=s390 CROSS_COMPILE=s390x-linux-gnu- bzImage modules scripts_gdb
  make ARCH=s390 CROSS_COMPILE=s390x-linux-gnu- \
    -C tools/testing/selftests \
    TARGETS=bpf \
    INSTALL_PATH=$PWD/tools/testing/selftests/kselftest_install \
    install

```
######## 4. 运行测试套件


```

  qemu-system-s390x \
    -cpu max,zpci=on \
    -smp 2 \
    -m 4G \
    -kernel linux/arch/s390/boot/compressed/vmlinux \
    -drive file=./s390.img,if=virtio,format=raw \
    -nographic \
    -append 'root=/dev/vda rw console=ttyS1' \
    -virtfs local,path=./linux,security_model=none,mount_tag=linux \
    -object rng-random,filename=/dev/urandom,id=rng0 \
    -device virtio-rng-ccw,rng=rng0 \
    -netdev user,id=net0 \
    -device virtio-net-ccw,netdev=net0

```
在真实的 IBM Z 上使用它时，可以添加 `-enable-kvm` 以获得更好的性能。首次启动虚拟机时，磁盘镜像
```

  /debootstrap/debootstrap --second-stage

```
包含宿主机上构建的代码，以及 `/proc` 和 `/sys`
```

  mkdir -p /linux
  mount -t 9p linux /linux
  mount -t proc proc /proc
  mount -t sysfs sys /sys

```
```

  cd /linux/tools/testing/selftests/kselftest_install
  ./run_kselftest.sh

```
```

  cd /linux/tools/testing/selftests/bpf
  ./test_verifier

```
######## 5. 调试


可以使用 QEMU 的 GDB stub 调试 s390 内核，它通过向 QEMU 传入 `-s` 来启用。

最好关闭 KASLR，这样 gdb 才能知道去哪里找到
```

  RANDOMIZE_BASE=n

```
```

  gdb-multiarch -ex 'target remote localhost:1234' ./vmlinux

```
######## 6. 网络


如果需要在虚拟机中使用网络，例如为了
```

  dhclient eth0

```
