## 旧版 BPF 数据包访问指


`ISA 标准文档 <instruction-set.html#legacy-bpf-packet-access-instructions>`_ 所述，Linux 有特殊的 eBPF 指令用于访问数据包数据，这些指令从经BPF 沿用而来，以保留运行eBPF 解释器中的旧版套接字过滤器的性能

这些指令有两种形式：`BPF_ABS | <size> | BPF_LD` `BPF_IND | <size> | BPF_LD`

这些指令用于访问数据包数据，且只能在程序上下文是指向网络数据包的指针时使用。`BPF_ABS` 访问由立即数数据指定的绝对偏移处的数据包数据，`BPF_IND` 访问的偏移是在立即数数据之外还包括一个寄存器值的偏移处的数据包数据

这些指令有七个隐式操作数

- 寄存R6 是一个隐式输入，必须包含一个指struct sk_buff 的指针
- 寄存R0 是一个隐式输出，包含从数据包获取的数据
- 寄存R1-R5 是被该指令破坏的临时寄存器

这些指令也有一个隐式的程序退出条件。如eBPF 程序尝试访问数据包边界之外的数据，程序执行将被中止

```

  R0 = ntohl(*(u32 *) ((struct sk_buff *) R6->data + imm))

```

其中 `ntohl()` 将一32 位值从网络字节序转换为主机字节序

```

  R0 = ntohl(*(u32 *) ((struct sk_buff *) R6->data + src + imm))

```
