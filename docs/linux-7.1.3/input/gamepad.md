### Linux 游戏手柄规范


:Author: 2013 by David Herrmann <dh.herrmann@gmail.com>


#### 简介


Linux 为游戏手柄硬件提供了许多不同的输入驱动。为了避免用户空间为每个游戏手柄
处理不同的按键映射，本文档定义了游戏手柄应当如何上报其数据。

#### 几何布局


```

            ____________________________              __
           / [__ZL__]          [__ZR__] \               |
          / [__ TL __]        [__ TR __] \              | Front Triggers
       __/________________________________\__         __|
      /                                  _   \          |
     /      /\           __             (N)   \         |
    /       ||      __  |MO|  __     _       _ \        | Main Pad
   |    <===DP===> |SE|      |ST|   (W) -|- (E) |       |
    \       ||    ___          ___       _     /        |
    /\      \/   /   \        /   \     (S)   /\      __|
   /  \________ | LS  | ____ |  RS | ________/  \       |
  |         /  \ \___/ /    \ \___/ /  \         |      | Control Sticks
  |        /    \_____/      \_____/    \        |    __|
  |       /                              \       |
   \_____/                                \_____/

       |________|______|    |______|___________|
         D-Pad    Left       Right   Action Pad
                 Stick       Stick

                   |_____________|
                      Menu Pad

```
大多数游戏手柄具有以下特性：

  - 动作键区（Action-Pad）
    右侧菱形排列的 4 个按键。这些按键在大多数设备上标签不同，因此我们将其定义为
    NORTH、SOUTH、WEST 和 EAST。
  - 方向键（D-Pad）
    左侧的 4 个分别指向上、下、左、右的按键。
  - 菜单键区（Menu-Pad）
    布局各异，但通常是 2 个按键：SELECT - START。此外，许多游戏手柄还有一个带
    特殊品牌的按键，用作特殊的系统按键。它通常与其他按键外观不同，用于弹出系统
    菜单或系统设置。
  - 模拟摇杆（Analog-Sticks）
    模拟摇杆提供可自由移动的摇杆来控制方向。并非所有设备都有两个或任意一个，但
    大多数情况下都存在。按下模拟摇杆时也可能提供一个数字按键。
  - 扳机键（Triggers）
    扳机键位于手柄上侧、呈竖直方向。并非所有设备都提供，但上侧按键通常称为左/右
    扳机，下侧按键称为 Z-Left 和 Z-Right。
  - 震动（Rumble）
    许多设备提供力反馈特性，但大多只是简单的震动马达。

#### 检测


所有遵循本文所述协议的手柄都映射 BTN_GAMEPAD。它是 BTN_SOUTH/BTN_A 的别名。
可据此将某个设备识别为游戏手柄。然而，并非所有手柄都提供全部特性，因此你需要先
测试你所需的所有特性。各项特性如何映射见下文。

旧版驱动常常不遵守这些规则。由于向后兼容的原因我们无法更改它们，因此你需要自己
在用户空间提供修正映射。其中一些可能也提供可改变映射的模块选项，你可以建议用户
进行设置。

所有新款游戏手柄都应遵循此映射。若发现不遵循的情况，请报告缺陷。

市面上有许多功能较少/性能较弱的设备，它们复用了本协议的按键。但它们尽量以兼容的
方式这样做。例如，“Nintendo Wii Nunchuk” 提供两个扳机键和一个模拟摇杆。它上报时
就像是一个只有一个模拟摇杆、右侧有两个扳机键的游戏手柄。但这意味着，如果你只支持
“真正的”游戏手柄，就必须对设备所上报的 _所有_ 你需要的事件都进行测试。否则，你
也会收到只上报一小部分事件的设备。

任何其他看起来/用起来不像游戏手柄的设备，都不应上报这些事件。

#### 事件


游戏手柄上报以下事件：

- 动作键区（Action-Pad）：

  每个游戏手柄设备至少有两个动作按键。这意味着，每个设备都会上报 BTN_SOUTH（即
  BTN_GAMEPAD 的别名）。无论按键上的标签是什么，按键码都按照按键的物理位置发送。

  请注意，2 键和 3 键手柄相当罕见且古老。你可能需要过滤掉那些没有上报全部四个
  按键的游戏手柄。

    - 2 键手柄：

      若只有 2 个动作按键，它们上报为 BTN_SOUTH 和 BTN_EAST。对于竖直布局，上方
      按键为 BTN_EAST。对于水平布局，更靠右的按键为 BTN_EAST。

    - 3 键手柄：

      若只有 3 个动作按键，它们（从左到右）上报为 BTN_WEST、BTN_SOUTH、BTN_EAST。
      若按键完美竖直排列，则（从上到下）上报为 BTN_WEST、BTN_SOUTH、BTN_EAST。

    - 4 键手柄：

      若四个动作按键都存在，它们可以有两种不同排列。若为菱形，则按物理位置上报为
      BTN_NORTH、BTN_WEST、BTN_SOUTH、BTN_EAST。若为矩形，则左上按键为 BTN_NORTH，
      左下为 BTN_WEST，右下为 BTN_SOUTH，右上为 BTN_EAST。

- 方向键（D-Pad）：

  每个游戏手柄都提供一个具有四个方向（上、下、左、右）的 D-Pad。其中一些作为数字
  按键提供，一些作为模拟按键提供，有些甚至可能同时上报两者。内核不会在两者之间进行
  转换，因此应用程序应同时支持两者，并在两者都上报时选择更合适的。

    - 数字按键上报为：

      BTN_DPAD_*

    - 模拟按键上报为：

      ABS_HAT0X 和 ABS_HAT0Y

  （对于 ABS 值，负为左/上，正为右/下）

- 模拟摇杆（Analog-Sticks）：

  左侧模拟摇杆上报为 ABS_X、ABS_Y。右侧模拟摇杆上报为 ABS_RX、ABS_RY。可能有零个、
  一个或两个摇杆。若模拟摇杆提供数字按键，则相应映射为 BTN_THUMBL（第一/左）和
  BTN_THUMBR（第二/右）。

  （对于 ABS 值，负为左/上，正为右/下）

- 扳机键（Triggers）：

  扳机键可以作为数字或模拟按键，或两者皆有。用户空间必须正确处理任何情况，并选择
  最合适的模式。

  上方扳机键上报为 BTN_TR 或 ABS_HAT1X（右）以及 BTN_TL 或 ABS_HAT1Y（左）。下方
  扳机键上报为 BTN_TR2 或 ABS_HAT2X（右/ZR）以及 BTN_TL2 或 ABS_HAT2Y（左/ZL）。

  若只存在一组扳机键组合（上+下），则上报为 “右” 扳机（BTN_TR/ABS_HAT1X）。

  （ABS 扳机值从 0 开始，压力以正值上报）

- 菜单键区（Menu-Pad）：

  菜单按键始终为数字按键，并依据其位置而非标签进行映射。即：

    - 1 键手柄：

      映射为 BTN_START

    - 2 键手柄：

      左键映射为 BTN_SELECT，右键映射为 BTN_START

  许多手柄还有第三个带品牌或特殊符号及含义的按键。此类按键映射为 BTN_MODE。例如
  Nintendo 的 “HOME” 键、Xbox 的 “X” 键或 Sony PlayStation 的 “PS” 键。

- 震动（Rumble）：

  震动以 FF_RUMBLE 标识。

- 握把按键（Grip buttons）：

  许多手柄在背面包含按键，通常称为握把键（grip）或后置按键（rear buttons），或称
  拨片（paddles）。这些按键通常可由固件重新编程为 “普通” 按键，但有时也会暴露给
  软件。一些典型例子包括：Steam Deck 背面有 R4、R5、L4 和 L5；Xbox Elite 手柄有
  P1-P4；Switch 2 Pro 手柄有 GL 和 GR。

  对于这些控制器，BTN_GRIPR 和 BTN_GRIPR2 应用于上方和下方（若存在）的右握把按键，
  BTN_GRIPL 和 BTN_GRIPL2 应用于上方和下方（若存在）的左握把按键。

- 配置档（Profile）：

  一些手柄提供多值配置档选择开关。例如 Xbox Adaptive 和 Xbox Elite 2 控制器。当
  活动配置档被切换时，其新选中的值会作为 ABS_PROFILE 事件发出。
