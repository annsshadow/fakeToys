## 手指感应板 Intellimouse 模式（滚轮、第 4 和第 5 个按钮）

A) MSID 4：滚轮模式加上前进页（第 4 个按钮）和后退页（第 5 个按钮）

1. 将采样率设为 200；
2. 将采样率设为 200；
3. 将采样率设为 80；
4. 发出 "Get device ID" 命令（0xF2）并等待响应；
5. FSP 会响应 0x04。

```

    Packet 1
    Bit 7 6 5 4 3 2 1 0       7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0
    BYTE  |---------------|BYTE |---------------|BYTE|---------------|BYTE|---------------|
      1   |Y|X|y|x|1|M|R|L|  2  |X|X|X|X|X|X|X|X|  3 |Y|Y|Y|Y|Y|Y|Y|Y|  4 | | |B|F|W|W|W|W|
	  |---------------|     |---------------|    |---------------|    |---------------|

    Byte 1: Bit7 => Y 溢出
	    Bit6 => X 溢出
	    Bit5 => Y 符号位
	    Bit4 => X 符号位
	    Bit3 => 1
	    Bit2 => 中键，1 表示按下，0 表示未按下。
	    Bit1 => 右键，1 表示按下，0 表示未按下。
	    Bit0 => 左键，1 表示按下，0 表示未按下。
    Byte 2: X 移动量（9 位 2 的补码整数）
    Byte 3: Y 移动量（9 位 2 的补码整数）
    Byte 4: Bit3~Bit0 => 自上次数据报告以来的滚轮移动量。
			有效值：-8 ~ +7
	    Bit4 => 1 = 第 4 个鼠标按钮按下，前进一页。
		    0 = 第 4 个鼠标按钮未按下。
	    Bit5 => 1 = 第 5 个鼠标按钮按下，后退一页。
		    0 = 第 5 个鼠标按钮未按下。

```
B) MSID 6：水平和垂直滚动

- 将寄存器 0x40 的 bit 1 设为 1

FSP 用 4 位替换滚轮的移动量，以表示水平和垂直滚动。

```

    Packet 1
    Bit 7 6 5 4 3 2 1 0       7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0
    BYTE  |---------------|BYTE |---------------|BYTE|---------------|BYTE|---------------|
      1   |Y|X|y|x|1|M|R|L|  2  |X|X|X|X|X|X|X|X|  3 |Y|Y|Y|Y|Y|Y|Y|Y|  4 | | |B|F|r|l|u|d|
	  |---------------|     |---------------|    |---------------|    |---------------|

    Byte 1: Bit7 => Y 溢出
	    Bit6 => X 溢出
	    Bit5 => Y 符号位
	    Bit4 => X 符号位
	    Bit3 => 1
	    Bit2 => 中键，1 表示按下，0 表示未按下。
	    Bit1 => 右键，1 表示按下，0 表示未按下。
	    Bit0 => 左键，1 表示按下，0 表示未按下。
    Byte 2: X 移动量（9 位 2 的补码整数）
    Byte 3: Y 移动量（9 位 2 的补码整数）
    Byte 4: Bit0 => 垂直向下滚动移动量。
	    Bit1 => 垂直向上滚动移动量。
	    Bit2 => 水平向左滚动移动量。
	    Bit3 => 水平向右滚动移动量。
	    Bit4 => 1 = 第 4 个鼠标按钮按下，前进一页。
		    0 = 第 4 个鼠标按钮未按下。
	    Bit5 => 1 = 第 5 个鼠标按钮按下，后退一页。
		    0 = 第 5 个鼠标按钮未按下。

```
C) MSID 7

FSP 使用 2 个数据包（8 字节）来表示绝对位置。
因此我们有 PACKET NUMBER 来标识数据包。

  如果 PACKET NUMBER 为 0，该数据包是 Packet 1。
  如果 PACKET NUMBER 为 1，该数据包是 Packet 2。
  请在程序中计数这个数字。

启用 MSID 7 的同时会启用 MSID6 特殊数据包。

## STL3888-Cx 与 STL3888-Dx 的绝对位置

```

当两根手指中有一根抬起时，设备会输出四个连续的 MFMC#0 报告数据包，其
X 和 Y 为零，表示第 1 根手指抬起；或者输出四个连续的 MFMC#1 报告数据包，
其 X 和 Y 为零，表示第 2 根手指抬起。另一方面，如果两根手指都抬起，设备
会输出四个连续的单指绝对坐标（SFAC）数据包，其 X 和 Y 为零。

		    => 10，通知数据包
	    Bit5 => 恒为 0
	    Bit4 => 0：左键由触控板命令（OPC）生成
		    1：左键由外部按钮生成
		    即使左键未被按下，默认值也为 1。
	    Bit3 => 1
	    Bit2 => 中键，1 表示按下，0 表示未按下。
	    Bit1 => 右键，1 表示按下，0 表示未按下。
	    Bit0 => 左键，1 表示按下，0 表示未按下。
    Byte 2: 消息类型：
	    0xba => 手势信息
	    0xc0 => 单指保持旋转手势
    Byte 3: 收到的消息的第一个参数：
	    0xba => 手势 ID（参见 "Gesture ID" 小节）
	    0xc0 => 区域 ID
    Byte 4: 收到的消息的第二个参数：
	    0xba => 无（N/A）
	    0xc0 => 手指抬起/按下信息

```
多手指、多坐标模式的示例序列：

	通知数据包（有效位 == 1）、MFMC packet 1（byte 1, bit 2 == 0）、
	MFMC packet 2（byte 1, bit 2 == 1）、MFMC packet 1、MFMC packet 2、
	……、通知数据包（有效位 == 0）

	也就是说，当设备处于 MFMC 模式时，主机会收到每根手指交错排列的
	绝对坐标数据包。

## FSP 启用/禁用数据包

```

    Bit 7 6 5 4 3 2 1 0       7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0
    BYTE  |---------------|BYTE |---------------|BYTE|---------------|BYTE|---------------|
      1   |Y|X|0|0|1|M|R|L|  2  |0|1|0|1|1|0|1|E|  3 | | | | | | | | |  4 | | | | | | | | |
	  |---------------|     |---------------|    |---------------|    |---------------|

    当 FSP 收到 PS/2 启用/禁用命令时，FSP 会发出启用/禁用数据包。主机会
    收到中键、右键、左键被设置的数据包。该数据包仅使用 byte 0 和 byte 1
    作为原始数据包的模式。忽略数据包的其他字节。

    Byte 1: Bit7 => 0，Y 溢出
	    Bit6 => 0，X 溢出
	    Bit5 => 0，Y 符号位
	    Bit4 => 0，X 符号位
	    Bit3 => 1
	    Bit2 => 1，中键
	    Bit1 => 1，右键
	    Bit0 => 1，左键
    Byte 2: Bit7~1 => (0101101b)
	    Bit0 => 1 = 启用
		    0 = 禁用
    Byte 3: 不关心
    Byte 4: 不关心（MOUSE ID 3, 4）
    Byte 5~8: 不关心（绝对数据包）

```

	buttons = reg[0x20] & 0x30

		A 小节了解数据包解析详情

```

## 寄存器读写的编程序列

寄存器反转要求：

以下值在发送给 FSP 之前需要被反转（C 语言中的 '~' 运算符）
```

	0xe8, 0xe9, 0xee, 0xf2, 0xf3 和 0xff。

```
寄存器交换要求：

以下值需要将其高 4 位与低 4 位进行交换
```

	10, 20, 40, 60, 80, 100 和 200。

寄存器读取序列：

 1. 向 FSP 发送 0xf3 PS/2 命令；

 2. 向 FSP 发送 0x66 PS/2 命令；

 3. 向 FSP 发送 0x88 PS/2 命令；

 4. 向 FSP 发送 0xf3 PS/2 命令；

 5. 如果要读取的寄存器地址不要求被反转（参见 "Register inversion
	requirement" 小节），跳到步骤 6

	  a. 向 FSP 发送 0x68 PS/2 命令；

	  b. 向 FSP 发送反转后的寄存器地址，并跳到步骤 8；

 6. 如果要读取的寄存器地址不要求被交换（参见 "Register swapping
	requirement" 小节），跳到步骤 7

	  a. 向 FSP 发送 0xcc PS/2 命令；

	  b. 向 FSP 发送交换后的寄存器地址，并跳到步骤 8；

 7. 向 FSP 发送 0x66 PS/2 命令；

	  a. 向 FSP 发送原始寄存器地址，并跳到步骤 8；

 8. 向 FSP 发送 0xe9（状态请求）PS/2 命令；

 9. 从 FSP 读取的响应的第 4 个字节应当是

```
		host: 0xe9
		3888: 0xfa (??) (??) (val)

	* 注意，自 Cx 版本起，硬件会在状态请求结果的第 3 个字节返回寄存器值的
	  反码（1's complement）：

		host: 0xe9
		3888: 0xfa (??) (~val) (val)

```
寄存器写入序列：

 1. 向 FSP 发送 0xf3 PS/2 命令；

 2. 如果要写入的寄存器地址不要求被反转（参见 "Register inversion
	requirement" 小节），跳到步骤 3

	  a. 向 FSP 发送 0x74 PS/2 命令；

	  b. 向 FSP 发送反转后的寄存器地址，并跳到步骤 5；

 3. 如果要写入的寄存器地址不要求被交换（参见 "Register swapping
	requirement" 小节），跳到步骤 4

	  a. 向 FSP 发送 0x77 PS/2 命令；

	  b. 向 FSP 发送交换后的寄存器地址，并跳到步骤 5；

 4. 向 FSP 发送 0x55 PS/2 命令；

	  a. 向 FSP 发送寄存器地址，并跳到步骤 5；

 5. 向 FSP 发送 0xf3 PS/2 命令；

 6. 如果要写入的寄存器值不要求被反转（参见 "Register inversion
	requirement" 小节），跳到步骤 7

	  a. 向 FSP 发送 0x47 PS/2 命令；

	  b. 向 FSP 发送反转后的寄存器值，并跳到步骤 9；

 7. 如果要写入的寄存器值不要求被交换（参见 "Register swapping
	requirement" 小节），跳到步骤 8

	  a. 向 FSP 发送 0x44 PS/2 命令；

	  b. 向 FSP 发送交换后的寄存器值，并跳到步骤 9；

 8. 向 FSP 发送 0x33 PS/2 命令；

	  a. 向 FSP 发送寄存器值；

 9. 寄存器写入序列完成。

 - 自 Cx 版本起，硬件会在状态请求结果的第 3 个字节返回寄存器值的反码。
	主机可以选择在寄存器写入结束时再向 FSP 发送一个 0xe9（状态请求）
	PS/2 命令，以验证寄存器写入操作是否成功（?? 表示不关心）
```

		host: 0xe9
		3888: 0xfa (??) (~val) (val)

```
## 页寄存器读写的编程序列

为了克服所支持寄存器数量上限的限制，硬件将寄存器分成称为 "页" 的不同组。
每一页最多可包含 255 个寄存器。

上电后的默认页是 0x82；因此，如果要访问寄存器 0x8301，必须先使用以下序列
切换到页 0x83，然后再使用上一节描述的寄存器读/写序列，从偏移 0x01 开始
读/写。

页寄存器读取序列：

 1. 向 FSP 发送 0xf3 PS/2 命令；

 2. 向 FSP 发送 0x66 PS/2 命令；

 3. 向 FSP 发送 0x88 PS/2 命令；

 4. 向 FSP 发送 0xf3 PS/2 命令；

 5. 向 FSP 发送 0x83 PS/2 命令；

 6. 向 FSP 发送 0x88 PS/2 命令；

 7. 向 FSP 发送 0xe9（状态请求）PS/2 命令；

 8. 从 FSP 读取的响应应当是所请求的页值。


页寄存器写入序列：

 1. 向 FSP 发送 0xf3 PS/2 命令；

 2. 向 FSP 发送 0x38 PS/2 命令；

 3. 向 FSP 发送 0x88 PS/2 命令；

 4. 向 FSP 发送 0xf3 PS/2 命令；

 5. 如果要写入的页地址不要求被反转（参见 "Register inversion
	requirement" 小节），跳到步骤 6

	  a. 向 FSP 发送 0x47 PS/2 命令；

	  b. 向 FSP 发送反转后的页地址，并跳到步骤 9；

 6. 如果要写入的页地址不要求被交换（参见 "Register swapping
	requirement" 小节），跳到步骤 7

	  a. 向 FSP 发送 0x44 PS/2 命令；

	  b. 向 FSP 发送交换后的页地址，并跳到步骤 9；

 7. 向 FSP 发送 0x33 PS/2 命令；

 8. 向 FSP 发送页地址；

 9. 页寄存器写入序列完成。
