## 手指感应Intellimouse 模式（滚轮、第 4 和第 5 个按钮）

A) MSID 4：滚轮模式加上前进页（第 4 个按钮）和后退页（5 个按钮）

1. 将采样率设为 200
2. 将采样率设为 200
3. 将采样率设为 80
4. 发出 "Get device ID" 命令xF2）并等待响应
5. FSP 会响0x04

```

    Packet 1
    Bit 7 6 5 4 3 2 1 0       7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0      7 6 5 4 3 2 1 0
    BYTE  |---------------|BYTE |---------------|BYTE|---------------|BYTE|---------------|
      1   |Y|X|y|x|1|M|R|L|  2  |X|X|X|X|X|X|X|X|  3 |Y|Y|Y|Y|Y|Y|Y|Y|  4 | | |B|F|W|W|W|W|
	  |---------------|     |---------------|    |---------------|    |---------------|

    Byte 1: Bit7 => Y 溢出
	    Bit6 => X 溢出
	    Bit5 => Y 符号
	    Bit4 => X 符号
	    Bit3 => 1
	    Bit2 => 中键 表示按下 表示未按下
	    Bit1 => 右键 表示按下 表示未按下
	    Bit0 => 左键 表示按下 表示未按下
    Byte 2: X 移动量（9 2 的补码整数）
    Byte 3: Y 移动量（9 2 的补码整数）

			有效值：-8 ~ +7

		    0 = 4 个鼠标按钮未按下
	    Bit5 => 1 = 5 个鼠标按钮按下，后退一页
		    0 = 5 个鼠标按钮未按下

```

C) MSID 7

FSP 使用 2 个数据包 字节）来表示绝对位置

	……、通知数据包（有效== 0

	也就是说，当设备处于 MFMC 模式时，主机会收到每根手指交错排列的
	绝对坐标数据包

```

寄存器读取序列：

 1. FSP 发0xf3 PS/2 命令

 2. FSP 发0x66 PS/2 命令

 3. FSP 发0x88 PS/2 命令

 4. FSP 发0xf3 PS/2 命令

 5. 如果要读取的寄存器地址不要求被反转（参"Register inversion
	requirement" 小节），跳到步骤 6

 6. 如果要读取的寄存器地址不要求被交换（参"Register swapping
	requirement" 小节），跳到步骤 7

	  a. FSP 发0xcc PS/2 命令

	  b. FSP 发送交换后的寄存器地址，并跳到步骤 8

 7. FSP 发0x66 PS/2 命令

	  a. FSP 发送原始寄存器地址，并跳到步骤 8

 8. FSP 发0xe9（状态请求）PS/2 命令

```
