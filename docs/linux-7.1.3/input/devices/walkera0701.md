## Walkera WK-0701 发射

Walkera WK-0701 发射器随附于出厂即飞Walkera 直升机（HM36、HM37、HM60）。walkera0701 模块可将此发射器用作游戏杆（joystick）

## 杩炴帴鑷?PC


在发射器背面可以找到 S-video 接口。处理器到高频（HF）部分的调制脉冲可在该接口的2 脚找到，3 脚为 GND。第 3 脚与 CPU 之间有一5k6 电阻。要将调制脉冲送入 PC，信号脉冲必须被放大

## 软件


编译带有 walkera0701 模块的内核。walkera0701 模块需要独占访问并口，在加walkera0701 模块之前必须卸载 lp 之类的模块，并检dmesg 中的错误信息。用线缆将发射器连接PC，并运行 jstest /dev/input/js0 查看来自发射器的值。如果发射器的“游戏杆”无法改变任何值，请检/proc/interrupts 的输出。当发射器开启时，并口（通常irq7）对应的值必须递增

### 信号脉冲


```

                     (模拟 ANALOG)
      SYNC      BIN   OCT
    +---------+      +------+
    |         |      |      |
  --+         +------+      +---

```

 SYNC , BIN1, OCT1, BIN2, OCT2 ... BIN24, OCT24, BIN25, 下一SYNC ..

### 二进制数据表

一个二进制值和一个八进制值可组合为一个半字节（nibble）。在两个同步脉冲之间可采样到 24 个半字节 + 一个二进制值
前四个通道（模拟游戏杆值）的值位于前 10 个半字节中。模拟值由一个符号位9 位绝对值二进制值表示（每通道 10 位）。下一个半字节是前十个半字节的校验和
接下来的半字12..21 表示四个通道（并非所有通道都能由发射器直接控制）。二进制表示与前四个通道相同。半字节 22 23 中是一个特殊的魔数（magic number）。半字节 24 是半字节 12..23 的校验和
在半字节 24 的最后一个八进制值之后和下一个同步脉冲之前，可多采样一个二进制值。该位和魔数在软件驱动中未使用。关于该魔数的部分细节可Walkera_Wk-0701_PCM.pdf 中找到
