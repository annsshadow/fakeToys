该驱动为新的 Apple Macbook Air Macbook Pro 笔记本上的多点触控（multi-touch）触控板添加支持。它在这些计算机上取appletouch 驱动，并Xorg 系统synaptics 驱动良好集成
已知可在 Macbook Air、Macbook Pro Penryn 以及新的 unibody Macbook 5 Macbook Pro 5 上工作
### 用法


该驱动会在支持的 usb 设备 id 上自动加载，并同时作为事件设备（/dev/input/event*）与通过 mousedev 驱动的鼠标（/dev/input/mice）可用
### USB 竞争


Apple 多点触控触控板通过同一 usb 设备的不同接口报告鼠标与键盘事件。这会与 HID 驱动产生竞争条件（race condition），如果不另行告知，HID 驱动会找到标准的 HID 鼠标与键盘，并占用整个设备。为补救此问题，usb 产品 id 必须列在 hid 驱动mouse_ignore 列表中
### 调试输出


为方便新硬件版本的开发，可以通过 debug 内核模块参数打开详细的包输出。范[1-9]
```

    echo -n 9 > /sys/module/bcm5974/parameters/debug

    tail -f /var/log/debug

    echo -n 0 > /sys/module/bcm5974/parameters/debug

```
