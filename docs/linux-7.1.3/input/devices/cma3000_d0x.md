## CMA3000-D0x 加速度

支持的设备：
- VTI CMA3000-D0x

Datasheet:
  CMA3000-D0X Product Family Specification 8281000A.02.pdf
  <http://www.vti.fi/en/>

:Author: Hemanth V <hemanthv@ti.com>


### 描述


CMA3000 三轴加速度计支持运动检测（Motion detect）、测量（Measurement）和自由落体（Free fall）模式
运动检测模式（Motion Detect Mode）：
    这是一种低功耗模式，仅当运动量超过所定义阈值时才产生中断
测量模式（Measurement Mode）：
    该模式用于读X、Y、Z 轴上的加速度数据，支400000 Hz 采样频率
自由落体模式（Free fall Mode）：
    该模式旨在节省系统资源
阈值：
    芯片支持为上述模式定义阈值，包括时间g 值。更多细节请参阅产品规范
CMA3000 芯片支持互斥I2C SPI 接口进行通信，目前驱动仅支持基于 I2C 的通信。总线模式的初始配置设置在非易失性存储器中，之后可通过总线接口命令修改
驱动通过输入（input）子系统报告加速度数据。当检测到自由落体时，它会生成值为 1 ABS_MISC 事件
需要配置平台数据（Platform data）以设置初始默认值
### 平台数据（Platform Data

fuzz_x:
    X 轴上的噪
fuzz_y:
    Y 轴上的噪
fuzz_z:
    Z 轴上的噪
g_range:
    G 范围，单位毫 g，即 2000 8000

mode:
    默认工作模式

mdthr:
    运动检g 范围阈
mdfftmr:
    运动检测和自由落体时间阈
ffthr:
    自由落体 g 范围阈
### 输入接口（Input Interface

Input driver version is 1.0.0
Input device ID: bus 0x18 vendor 0x0 product 0x0 version 0x0
Input device name: "cma3000-accelerometer"
