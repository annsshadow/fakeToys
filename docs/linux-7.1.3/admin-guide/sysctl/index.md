## 简介


sysctl 是一种在运行时配置内核某些方面的方法，而 /proc/sys/ 目录的存在让你甚至不需要特殊工具就能做到！
事实上，使用这些配置设施只需要四样东西：

- 一个正在运行的 Linux 系统
- root 访问权限
- 常识（如今这点尤其难得）
- 了解所有这些值的含义

快速执行 'ls /proc/sys' 即可看到，该目录由若干（架构相关？）子目录组成。每个子目录主要关于内核的一个部分，因此你可以逐块地进行配置，或者只是做一些“主题式调整”。

本文档涉及：

=============== ===============================================================
abi/		执行域与人格（personalities）
<$ARCH>		各种 CPU 架构的调优控制（如 csky、s390）
crypto/		加密子系统
debug/		调试特性
dev/		设备特定信息（如 dev/cdrom/info）
fs/		特定文件系统
		文件句柄、inode、目录项（dentry）和配额调优
		binfmt_misc <Documentation/admin-guide/binfmt-misc.rst>
kernel/		全局内核信息/调优
		杂项
		一些架构相关的控制
		安全（LSM）相关
net/		网络相关，文档参见：<Documentation/networking/>
proc/		<空>
sunrpc/		SUN 远程过程调用（NFS）
user/		每个用户命名空间的限制
vm/		内存管理调优
		缓冲区和缓存管理
xen/		Xen 虚拟机监控器控制
=============== ===============================================================
