## DRBD-9 的内核数据结

本文档描DRBD-9 的内核数据结构。从 Linux v3.14 开始，我们正在重组 DRBD 以使用此数据结构
## 基本数据结构


一个节点拥有若DRBD 资源。每个这样的资源拥有若干设备（又称卷，volumes）以及到其他节点对等节点"，peer nodes）的连接。每DRBD 设备在本地由一个块设备表示
DRBD 对象相互连接形成一个如下所示的矩阵；在 drbd_device ```

  /--------------+---------------+.....+---------------\
  |   resource   |    device     |     |    device     |
  +--------------+---------------+.....+---------------+
  |  connection  |  peer_device  |     |  peer_device  |
  +--------------+---------------+.....+---------------+
  :              :               :     :               :
  :              :               :     :               :
  +--------------+---------------+.....+---------------+
  |  connection  |  peer_device  |     |  peer_device  |
  \--------------+---------------+.....+---------------/

```
在此表中，水平方向上，设备可以通过其卷号（volume number）从资源访问。同样，peer_device 可以通过其卷号从连接访问。垂直方向的对象通过双链表连接。存在从 peer_device 到其连接和设备的反向指针，以及从连接和设备到其资源的反向指针
所有资源都drbd_resources 双链表中。此外，所有设备都可以通过其次设备号（minor device number）经drbd_devices idr 访问
drbd_resource、drbd_connection drbd_device 对象都是引用计数的。peer_device 对象仅用于建立设备与连接之间的链接；其生命周期由其所引用的设备和连接的生命周期决定
