## Renesas R-Car 精细显示处理器（FDP1）驱动


R-Car FDP1 驱动实现以下驱动专用控制。

`V4L2_CID_DEINTERLACING_MODE (menu)`
    视频去隔行模式（如 Bob、Weave 等）。R-Car FDP1 驱动实现以下模式。

    :header-rows:  0
    :stub-columns: 0
    :widths:       1 4

    - - `"Progressive" (0)`
      - 输入图像视频流是逐行的（非隔行）。不执行去隔行。除（可选的）格式与
        编码转换外，输出帧与输入帧相同。
    - - `"Adaptive 2D/3D" (1)`
      - 2D 与 3D 去隔行的运动自适应版本。在快速运动时使用 3D 去隔行，否则使用
        带对角插值的 2D 去隔行。
    - - `"Fixed 2D" (2)`
      - 当前场通过对相邻行求平均在垂直方向缩放，以恢复缺失的行。此方法也称为
        混合或行平均（LAV）。
    - - `"Fixed 3D" (3)`
      - 前一个和后一个场求平均，以恢复当前场缺失的行。此方法也称为场平均（FAV）。
    - - `"Previous field" (4)`
      - 当前场与前一个场交织，即使用前一个场来填充当前场缺失的行。此方法也称为
        交织去隔行。
    - - `"Next field" (5)`
      - 当前场与后一个场交织，即使用后一个场来填充当前场缺失的行。此方法也称为
        交织去隔行。
