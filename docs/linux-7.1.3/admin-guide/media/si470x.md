


## Silicon Labs Si470x FM 收音机接收器驱动


版权所|copy| 2009 Tobias Lorenz <tobias.lorenz@gmx.net>


### 来自 Silicon Labs 的信

Silicon Laboratories 是无线电 IC 的制造商，这IC 如今是手机中
最常用的无线电接收器。通常它们通过 I2C 连接。但 SiLabs 也提供了一参考设计，将这IC 与一个小微控制器 C8051F321 集成在一起，构成一USB 收音机。该参考设计的一部分还包括以二进制和源代码形式提供的
收音机应用程序。该软件还包含自动固件升级到最新版本的功能。有关这些的
信息可以在此下载http://www.silabs.com/usbradio


### 支持IC


以下 IC 具有非常相似的寄存器集，因此已经被或将要被该驱动支持
- Si4700：FM 收音机接收器
- Si4701：FM 收音机接收器，支RDS
- Si4702：FM 收音机接收器
- Si4703：FM 收音机接收器，支RDS
- Si4704：FM 收音机接收器，无需外部天线
- Si4705：FM 收音机接收器，无需外部天线，支RDS，Dig I/O
- Si4706：增强型 FM RDS/TMC 收音机接收器，无需外部天线，支RDS
- Si4707：带 SAME 解码器的专用气象波段收音机接收器，支RDS
- Si4708：最小的 FM 接收- Si4709：最小的 FM 接收器，支持 RDS

有关这些的更多信息可以在此下载：
http://www.silabs.com/products/mcu/Pages/USBFMRadioRD.aspx

### 软件


测试通常Debian/testing 下使用大多数应用程序进行
- fmtools - 管理 FM 调谐器卡的实用工- gnomeradio - 用于 GNOME 桌面FM 收音机调谐器
- gradio - GTK FM 收音机调谐器
- kradio - KDE 下舒适的收音机应用程- radio - 基于 ncurses 的收音机应用程序
- mplayer - Linux 终极电影播放- v4l2-ctl - 命令video4linux 实用工具
例如，你可以使用

	v4l2-ctl -d /dev/radio0 --set-ctrl=volume=10,mute=0 --set-freq=95.21 --all

还有一个库 libv4l 可以使用。它将具有一个频率搜索函数，要么利用radio-si470x 中的硬件功能，要么实现我们在上述每个程序中当前都有的
函数。将来收音机程序应该利用 libv4l
有关处理 RDS 信息的项目正在此处进行：
http://rdsd.berlios.de/

目前还没有将 TMC 语句变得人类可读的项目

### 音频列出（Audio Listing

USB 音频ALSA snd_usb_audio 模块提供。建议同时选择 SND_USB_AUDIO因为要从收音机获得声音需要它。为了列出（listening）你必须重定向声音，
例如使用以下命令之一。请根据你的需要调整音频设备（/dev/dsp* hw:x,x）
如果你只是想测试音频（质量很差）

	cat /dev/dsp1 > /dev/dsp

如果你使sox + OSS 试试

	sox -2 --endian little -r 96000 -t oss /dev/dsp1 -t oss /dev/dsp

或使sox + alsa

	sox --endian little -c 2 -S -r 96000 -t alsa hw:1 -t alsa -r 96000 hw:0

如果你使arts 试试

	arecord -D hw:1,0 -r96000 -c2 -f S16_LE | artsdsp aplay -B -

如果你使mplayer 试试

	mplayer -radio adevice=hw=1.0:arate=96000 \
		-rawaudio rate=96000 \
		radio://<frequency>/capture

### 模块参数


加载模块后，你仍然可以在 /sys/module/radio_si470x/parameters 下的
sysfs 挂载点中访问其中一些参数。只读文件（0444）的内容不会更新即使使用私有视频控制改变space、band de。其他参数可在运行时更改

### 错误


如果你经常得-EIO 错误，请增大 tune_timeout
当超时或达到频段限制时，hw_freq_seek 返回 -EAGAIN
如果你从 snd_usb_audio 得到任何错误，请ALSA 相关人员报告

### 未决问题（Open Issues

V4L 次设备（minor device）分配与参数设置并不完美。目前一个解决方正在讨论中
有一个用于下上传新固件镜像的 USB 接口。可以通过 request_firmware
接口实现对其的支持
有一RDS 中断模式。驱动已经在使用相同的接口来轮询 RDS 信息，但
当前未使用中断模式
有一LED 接口，可用于覆盖在固件中编程LED 控制。这可以使用
内核中的 LED 支持函数提供
