### 通过 debugfs 暴露的参
SI476x 允许用户获取多个特征，这些特征对EoL 测试 / RF 性能评估非常有用，而这些参数与 V4L2 子系统关系甚微。此类参数通过 debugfs 暴露，并可通过常规的文I/O 操作访问
该驱动暴露以下文件：

- /sys/kernel/debug/<device-name>/acf
  该文件包ACF（自动受控特性，Automatically Controlled Features）状态信息。文件内容为具有以下布局的二进制数据
  .. tabularcolumns:: |p{7ex}|p{12ex}|L|

  =============  ==============   ====================================
  Offset	 Name		  Description
  =============  ==============   ====================================
  0x00		 blend_int	  标志，当立体声分离度低于混合阈值时置位
  0x01		 hblend_int	  标志，当 HiBlend 截止频率低于阈值时置位
  0x02		 hicut_int	  标志，当 HiCut 截止频率低于阈值时置位
  0x03		 chbw_int	  标志，当通道滤波器带宽小于阈值时置位
  0x04		 softmute_int	  指示 softmute 衰减已升高超softmute 阈值的标志
  0x05		 smute		  0 - 音频未软静音 / 1 - 音频已软静音
  0x06		 smattn		  软静音衰减电平（dB  0x07		 chbw		  通道滤波器带宽（kHz  0x08		 hicut		  HiCut 截止频率，单100Hz
  0x09		 hiblend	  HiBlend 截止频率，单100 Hz
  0x10		 pilot		  0 - 立体声导频不存在 / 1 - 立体声导频存  0x11		 stblend	  立体声混合比例（%  =============  ==============   ====================================


- /sys/kernel/debug/<device-name>/rds_blckcnt
  该文件包含关RDS 接收的统计信息。其二进制数据具有以下布局
  .. tabularcolumns:: |p{7ex}|p{12ex}|L|

  =============  ==============   ====================================
  Offset	 Name		  Description
  =============  ==============   ====================================
  0x00		 expected	  期望RDS 块数
  0x02		 received	  接收到的 RDS 块数
  0x04		 uncorrectable	  不可纠正RDS 块数
  =============  ==============   ====================================

- /sys/kernel/debug/<device-name>/agc
  该文件包含与 AGC（自动增益控制，Automatic Gain Control）相关的参数信息

  布局为：

  .. tabularcolumns:: |p{7ex}|p{12ex}|L|

  =============  ==============   ====================================
  Offset	 Name		  Description
  =============  ==============   ====================================
  0x00		 mxhi		  0 - FM 混频PD 高阈值未触发
				  1 - FM 混频PD 高阈值已触发
  0x01		 mxlo		  同上（针FM 混频PD 低阈值）
  0x02		 lnahi		  同上（针FM LNA PD 高阈值）
  0x03		 lnalo		  同上（针FM LNA PD 低阈值）
  0x04		 fmagc1		  FMAGC1 衰减器电阻（详见数据手册  0x05		 fmagc2		  FMAGC2 同上
  0x06		 pgagain	  PGA 增益（dB  0x07		 fmwblang	  FM/WB LNA 增益（dB  =============  ==============   ====================================

- /sys/kernel/debug/<device-name>/rsq
  该文件包含与 RSQ（接收信号质量，Received Signal Quality）相关的参数信息

  布局为：

  .. tabularcolumns:: |p{7ex}|p{12ex}|p{60ex}|

  =============  ==============   ====================================
  Offset	 Name		  Description
  =============  ==============   ====================================
  0x00		 multhint	  0 - 多径值未越过多径高阈				  1 - 多径值已越过多径高阈  0x01		 multlint	  多径低阈值的同上
  0x02		 snrhint	  0 - 接收信号SNR 未越过高阈				  1 - 接收信号SNR 已越过高阈  0x03		 snrlint	  低阈值的同上
  0x04		 rssihint	  RSSI 高阈值的同上
  0x05		 rssilint	  RSSI 低阈值的同上
  0x06		 bltf		  指示 seek 命令是否到达 / 环绕seek 频段限制的标  0x07		 snr_ready	  指示 SNR 度量已就  0x08		 rssiready	  RSSI 度量的同  0x09		 injside	  0 - 正在使用低边注入 / 1 - 使用高边注入
  0x10		 afcrl		  指示 AFC 是否达到轨限的标  0x11		 valid		  指示通道是否有效的标  0x12		 readfreq	  当前调谐频率
  0x14		 freqoff	  有符号频率偏移，单位 2ppm
  0x15		 rssi		  RSSI 的有符号值（dBuV  0x16		 snr		  有符RF SNR（dB  0x17		 issi		  有符号镜像强度信号指  0x18		 lassi		  有符号低边相邻通道强度指示
  0x19		 hassi		  高边的同  0x20		 mult		  多径指示
  0x21		 dev		  频率偏移
  0x24		 assi		  相邻通道 SSI
  0x25		 usn		  超声波噪声指  0x26		 pilotdev	  导频偏移，单100 Hz
  0x27		 rdsdev		  RDS 的同  0x28		 assidev	  ASSI 的同  0x29		 strongdev	  频率偏移
  0x30		 rdspi		  RDS PI 鐮?  =============  ==============   ====================================
