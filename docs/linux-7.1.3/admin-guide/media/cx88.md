## cx88 驱动


Author:  Gerd Hoffmann

这是 cx2388x 芯片的 v4l2 设备驱动。


### 当前状态


视频
 - 可用。
 - 不支持叠加。

音频
 - 可用。TV 标准检测由驱动完成，因为硬件在自动检测方面有缺陷。
 - 音频数据 dma（即无需到声卡的回环线缆即可录音）通过 cx88-alsa 支持。

vbi
 - 可用。


### 如何添加对新卡的支持


驱动需要一些关于 TV 卡的配置信息。这些内容在 cx88-cards.c 中。如果驱动工作
不佳，你可能需要在该文件中为你的卡添加新条目。检查内核日志（使用 dmesg）以
查看驱动是否认识你的卡。会有一行类似如下：

	cx8800[^0^]: subsystem: 0070:3400, board: Hauppauge WinTV \
		34xxx models [card=1,autodetected]

如果你的卡被列为 “board: UNKNOWN/GENERIC”，则驱动不认识它。那么该怎么做？

1) 尝试升级到最新的快照，也许它已经被添加了。
2) 你可以尝试自己创建新条目，查看 cx88-cards.c。如果成功了，将你的更改作为
   统一 diff（“diff -u”）发邮件给我。
3) 或者你可以将配置信息发邮件给我。要添加该卡，我们至少需要以下信息：

     - PCI 子系统 ID（上一行中的“0070:3400”，“lspci -v”输出也可以）。
     - 卡使用的调谐器类型。你可以使用 tuner=<n> insmod 选项通过试错来寻找一个。
       如果你知道卡使用哪一个，也可以查看 CARDLIST.tuner 中的列表。
