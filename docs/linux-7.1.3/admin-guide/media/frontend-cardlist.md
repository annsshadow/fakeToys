## 前端驱动

本页汇Linux 媒体子系统中各类前端（frontend）解调器与调谐器驱动所支持的芯片型号清单，ATSC、DVB-C、DVB-S 等制式分类，并涵盖通用接口（EN50221）控制器驱动，便于按硬件选型查找对应驱动


  #) 由于布线不同，不能保证每个前端驱动都能开箱即用地与每张卡配合工作

  #) 解调器芯片可以与各种调谐PLL 芯片配合使用，但并非所有组合都受支持。通常
     解调器和调谐PLL 芯片位于一个金属盒内以进行屏蔽，整个金属盒有它自己的部件号
