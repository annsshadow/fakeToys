

## Silicon Labs Si4713 FM 无线电发射器驱动

Contact: Eduardo Valentin <eduardo.valentin@nokia.com>


### 关于设备的信息


该芯片是 Silicon Labs 的产品。它是一个 I2C 设备，当前地址为 0x63。
基本上，它具有发射与信号噪声电平测量功能。

Si4713 集成了用于 FM 广播立体声发射的发射功能。
该芯片还允许进行集成的接收功率扫描，以识别低信号功率的 FM 频道。

该芯片通过命令与响应进行编程。同时还有若干属性可以改变该芯片的行为。

用户必须遵守当地关于射频（RF）发射的法规。

### 设备驱动描述


有两个模块用于处理该设备。一个是 I2C 设备驱动，另一个是平台驱动。

I2C 设备驱动向内核导出一个 v4l2-subdev 接口。
所有属性也可以通过 v4l2 扩展控制接口，使用 v4l2-subdev 调用
（g_ext_ctrls、s_ext_ctrls）来访问。

平台设备驱动向用户空间导出一个 v4l2 无线电设备接口。
因此，它使用 I2C 设备驱动作为子设备，以便将用户命令发送到实际设备。
基本上它是对 I2C 设备驱动的一个封装。

应用程序可以使用 v4l2 无线电 API 来指定工作频率、静音状态等。
但其大部分属性将出现在扩展控制中。

当 v4l2 静音属性被设为 1（真）时，驱动将关闭该芯片。

下面是它们的简要说明：

- Pilot 是设备发出的一个可听音调。

- pilot_frequency - 配置立体声导频音的频率。
- pilot_deviation - 配置导频音的频偏电平。
- pilot_enabled - 启用或禁用导频音功能。

- si4713 设备能够对发射的信号施加音频压缩。

- acomp_enabled - 启用或禁用音频动态范围控制功能。
- acomp_gain - 设置音频动态范围控制的增益。
- acomp_threshold - 设置音频动态范围控制的阈值电平。
- acomp_attack_time - 设置音频动态范围控制的启动时间。
- acomp_release_time - 设置音频动态范围控制的释放时间。

- 限幅器（Limiter）设置音频频偏限制功能。一旦发生过调，就可以调整音频输入的前端增益，从而始终防止过调。

- limiter_enabled - 启用或禁用限幅器功能。
- limiter_deviation - 配置音频频率频偏电平。
- limiter_release_time - 设置限幅器的释放时间。

- 调谐功率

- power_level - 设置信号发射的输出功率电平。
  antenna_capacitor - 选择天线调谐电容的值，若设为 0 则手动或自动选择。

- RDS 相关

- rds_ps_name - 设置用于发射的 RDS ps 名称字段。
- rds_radio_text - 设置用于发射的 RDS 电台文本。
- rds_pi - 设置用于发射的 RDS PI 字段。
- rds_pty - 设置用于发射的 RDS PTY 字段。

- 区域相关

- preemphasis - 设置用于发射的预加重。

### RNL


该设备还有一个用于测量接收噪声电平的接口。为此，你应当对设备节点执行 ioctl。下面是一个代码示例：


	int main (int argc, char *argv[])
	{
		struct si4713_rnl rnl;
		int fd = open("/dev/radio0", O_RDWR);
		int rval;

		if (argc < 2)
			return -EINVAL;

		if (fd < 0)
			return fd;

		sscanf(argv[^1^], "%d", &rnl.frequency);

		rval = ioctl(fd, SI4713_IOC_MEASURE_RNL, &rnl);
		if (rval < 0)
			return rval;

		printf("received noise level: %d
", rnl.rnl);

		close(fd);
	}

struct si4713_rnl 与 SI4713_IOC_MEASURE_RNL 定义在
include/linux/platform_data/media/si4713.h 中。

### 立体声/单声道与 RDS 子信道


该设备也可以使用可用的子信道进行配置以进行发射。为此，请使用
S/G_MODULATOR ioctl 并正确配置 txsubchans。有关该 ioctl 的正确用法，请参考
V4L2 API 规范。

### 测试


测试通常使用 v4l2-ctl 工具来管理 FM 调谐器卡。该工具可在 v4l-dvb 仓库的
v4l2-apps/util 目录下找到。

设置 rds ps 名称的示例：


	# v4l2-ctl -d /dev/radio0 --set-ctrl=rds_ps_name="Dummy"
