
## 参考


数字电视的主要开发站点和 GIT 存储库
司机是https://linuxtv.org.

DVB 邮件列表 linux-dvb 托管在 vger 上。请参阅
http://vger.kernel.org/vger-lists.html#linux-media了解详情。

还有一些其他旧列表托管在：
https://linuxtv.org/lists.php. 如果您对历史感兴趣
原因请查看https://linuxtv.org/pipermail/linux-dvb/.存档

媒体子系统 Wiki 托管于https://linuxtv.org/wiki/.
在那里，您会找到大量来自开发和使用的信息
媒体板。请在向新手提问之前先检查一下
邮件列表或 IRC 频道。

API 文档记录在内核树中。你可以找到它
html 和 pdf 格式，以及其他有用的文档，位于：

  - https://linuxtv.org/docs.php.

您还可以在https://linuxtv.org/downloads/.找到有用的材料

为了获得某些驱动程序工作所需的固件，有
内核树中的脚本，位于scripts/get_dvb_firmware。
