## LDM - 逻辑磁盘管理器（动态磁盘）


:Author: 最初由 FlatCap - Richard Russon <ldm@flatcap.org> 撰写。
:Last Updated: Anton Altaparmakov 于 2007 年 3 月 30 日为 Windows Vista 更新。

### 概述


Windows 2000、XP 和 Vista 使用了一种新的分区方案。它完全取代了 MSDOS 风格的分区。它将自己的信息存储
在物理磁盘末尾的一个 1MiB 日志式数据库中。分区的大小仅受磁盘空间限制。分区的最大数量接近 2000。

在 LDM 下创建的任何分区都称为“动态磁盘”。不再有主分区或扩展分区。普通的 MSDOS 风格分区现在称为基本磁盘。

如果你希望使用跨区卷、条带卷、镜像卷或 RAID 5 卷，必须使用动态磁盘。日志功能使 Windows 能够在不需要
重启的情况下对这些分区和文件系统进行更改。

一旦 LDM 驱动划分了磁盘，你就可以使用 MD 驱动来组装任何多分区卷，例如条带、RAID5。

为了防止遗留应用程序重新分区磁盘，LDM 创建一个包含占据整个磁盘的单一分区的虚拟 MSDOS 分区。这正是
Linux LDM 驱动所支持的内容。

Vista 中实现的一种较新方法是把 LDM 放在 GPT 标签磁盘之上。Linux LDM 驱动尚不支持这一点。

LDM 数据库可能不会按照分区在磁盘上出现的顺序存储它们，但驱动会对它们排序。

```

  hda: 102400 sectors w/32KiB Cache, CHS=50/64/32
  hda: [LDM] hda1 hda2 hda3 hda4 hda5 hda6 hda7


```
### 编译 LDM 支持


要启用 LDM，请选择以下两个选项：

  - "Advanced partition selection"（高级分区选择）CONFIG_PARTITION_ADVANCED
  - "Windows Logical Disk Manager (Dynamic Disk) support"（Windows 逻辑磁盘管理器（动态磁盘）支持）CONFIG_LDM_PARTITION

如果你认为驱动没有按预期工作，可以启用额外的调试代码。这会产生大量输出。该选项为：

  - "Windows LDM extra logging"（Windows LDM 额外日志）CONFIG_LDM_DEBUG

注意：分区代码不能被编译为模块。

与所有分区代码一样，如果驱动没有看到其类型分区的迹象，它会将控制权传递给另一个驱动，因此启用它无害。

如果你有动态磁盘但没有启用该驱动，那么你将只会看到一个占据整个磁盘的虚拟 MSDOS 分区。你将无法挂载
磁盘上的任何卷。


### 引导


如果启用了 LDM 支持，那么 lilo 能够从任何被发现的分区引导。然而，grub 不理解 LDM 分区，无法从动态磁盘引导。
