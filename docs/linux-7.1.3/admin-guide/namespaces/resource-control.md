## 用户命名空间与资源控制


内核包含许多种类的对象，这些对象要么没有单独的限制，要么在允许一组进程切换其 UID 时限制无效。在管理员不信任其用户或用户程序（users' programs）的系统上，用户命名空间会将系统暴露给潜在的资源滥用。

为了缓解这一问题，我们建议管理员在任何启用了用户命名空间的系统上启用内存控制组（memory control groups）。此外，我们建议管理员配置内存控制组，以限制任何不受信任用户可使用的最大内存。

内存控制组可通过安装大多数发行版都提供的 libcgroup 包，并编辑 /etc/cgrules.conf、/etc/cgconfig.conf 以及配置 libpam-cgroup 来进行配置。
