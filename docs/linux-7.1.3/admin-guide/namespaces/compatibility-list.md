## 命名空间兼容性列


本文档包含有关用户在创建位于不同命名空间中的任务时可能遇到的问题的信息

以下是摘要。该矩阵显示了当任务共享某些命名空间（列）而位于不同其它命名空间（行）时出现的已知问题

====	===	===	===	===	====	===
- UTS	IPC	VFS	PID	User	Net
====	===	===	===	===	====	===
UTS	 X
IPC		 X	 1
VFS			 X
PID		 1	 1	 X
User		 2	 2		 X
Net						 X
====	===	===	===	===	====	===

1. IPC PID 命名空间都提ID 用于在内核中寻址对象。例如，带有 IPCID 的信号量或带pid 的进程组

   在这两种情况下，任务都不应尝试通过共享文件系统IPC shmem/message 将此 ID 暴露给位于不同命名空间中的其它任务。事实是，该 ID 仅在其被获取的命名空间内有效，并可能引用另一个命名空间中的其它对象

2. 按设计，不同用户命名空间中的两个相等的用ID VFS 的角度来看不应相等。换句话说，一个用户命名空间中的用10 不应拥有对属于另一个命名空间中用户 10 的文件的相同访问权限

   IPC 命名空间被共享时也是如此——来自不同用户命名空间的两个用户即使具有相等UID 也不应访问相同的 IPC 对象

   但目前并非如此
