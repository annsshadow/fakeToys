
## GPIO 测试驱动


   本模块已被更灵活gpio-sim.rst 取代   新的开发应使用那个 API，已有开发也建议尽快迁移   本模块将继续得到维护，但不再添加新特性
GPIO 测试驱动（gpio-mockup）提供了一种创建模GPIO 芯片用于测试的方法这些芯片暴露的线路既可以使用标准 GPIO 字符设备接口访问，也可以使用专用debugfs 目录结构进行操作
### 使用模块参数创建模拟芯片


加载 gpio-mockup 驱动时可以传递若干参数给模块
    gpio_mockup_ranges

        该参数接受一个整数对的数组形式的参数。每一对定义基础 GPIO 编号
        （非负整数）以及该芯片最后一个之后的第一个编号。如果基础 GPIO         -1，gpiolib 会自动分配它；而随后的参数是该芯片暴露的线路数
        示例：gpio_mockup_ranges=-1,8,-1,16,405,409

        上面这一行创建了三个芯片。第一个暴8 条线路，第二16 条，
        第三4 条。第三个芯片的基础 GPIO 设为 405，而前两个芯片的基础
        GPIO 会自动分配
    gpio_mockup_named_lines

        该参数不接受任何参数。它让驱动知道它暴露GPIO 线路应当被命名
        名称格式为：gpio-mockup-X-Y，其X mockup 芯片ID，Y         线路偏移
### 操作模拟线路


每个 mockup 芯片/sys/kernel/debug/gpio-mockup/ 下创建自己的子目录该目录以芯片label 命名。还会创建一个以芯片名称命名的符号链接，指向label 目录
在每个子目录内，每条 GPIO 线路都有一个单独的属性。属性的名称代表该线路在
芯片中的偏移
从线路属性读取会返回当前值。向其写入（0 1）会改变模拟上拉/下拉电阻配置 - 上拉 - 下拉）
