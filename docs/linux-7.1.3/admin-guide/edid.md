
## EDID


在过去显式配置图形参数的美好时光
在名为 xorg.conf 的文件中，甚至可以管理损坏的硬件。

如今，随着内核模式设置的出现，显卡已
要么正常工作，因为所有组件都遵循标准 -
或者电脑无法使用，因为之后屏幕仍然黑屏
启动或显示错误区域。发生这种情况的情况有：

- 显卡无法识别显示器。
- 显卡无法检测到任何 EDID 数据。
- 图形板错误地将 EDID 数据转发到驱动程序。
- 显示器不发送或发送虚假 EDID 数据。
- KVM 发送自己的 EDID 数据，而不是查询连接的显示器。

添加内核参数“nomodeset”在大多数情况下会有所帮助，但会导致
以后有限制。

作为这种情况的补救措施，内核配置项
引入了 CONFIG_DRM_LOAD_EDID_FIRMWARE。它允许提供一个
/lib/firmware 中单独准备或更正的 EDID 数据集
通过固件接口加载的目录。
