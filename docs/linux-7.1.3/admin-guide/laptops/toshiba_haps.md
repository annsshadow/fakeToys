### 1. 描述


该驱动为各种 Toshiba 笔记本电脑中配备的加速度计提供支持，官方称之为 "Toshiba HDD Protection - Shock Sensor"（东芝硬盘保护——冲击传感器），并能自动检测带有该设备的笔记本电脑。
在 Windows 上，Toshiba 提供的软件会监控该设备，并在突然移动或剧烈震动时提供自动的硬盘保护（磁头卸载）。然而，该驱动仅通过一个 sysfs 文件提供通知，以便用户空间工具或守护进程做出相应动作，同时还提供一个 sysfs 文件来设置期望的保护级别或传感器灵敏度。


### 2. 接口


该设备带有 3 个方法：

====	=====================================================================
_STA    检查设备是否存在，若设备不存在或不受支持则返回零。
PTLV    设置期望的保护级别。
RSSS    关闭 HDD 保护接口几秒钟，然后恢复正常操作。
====	=====================================================================

注意：
  固态硬盘（SSD）的存在可能导致该驱动加载失败，因为这类驱动器没有可移动部件，因此既不需要任何"保护"，也会在评估该设备下的 _STA 方法时失败。


### 3. 加速度计轴


该设备不报告任何轴，但为查询传感器位置提供了一对 HCI（Hardware Configuration Interface，硬件配置接口）调用（0x6D 和 0xA6），这些调用自内核 3.15 版本起由内核模块 toshiba_acpi 处理。


### 4. 支持的设备


该驱动将自己绑定到 ACPI 设备 TOS620A，任何带有该设备的 Toshiba 笔记本电脑都受支持，前提是它们配备了传统的 HDD 而不仅仅是 SSD，或者是 HDD 与 SSD 的组合。


### 5. 用法


位于 /sys/devices/LNXSYSTM:00/LNXSYBUS:00/TOS620A:00/ 下的 sysfs 文件为：

================   ============================================================
protection_level   protection_level 可读也可写，提供了一种让用户空间查询当前
		   保护级别以及设置期望保护级别的方式，其取值为
```

		     ============   =======   ==========   ========
		     0 - 禁用   1 - 低   2 - 中   3 - 高
		     ============   =======   ==========   ========

```
reset_protection   reset_protection 条目仅可写，只接受 "1" 这一个参数，用于触发
		   保护接口的复位。
================   ============================================================
