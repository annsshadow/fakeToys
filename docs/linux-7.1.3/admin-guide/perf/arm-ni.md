## Arm 片上网络互连 PMU


NI-700 及其同类为每个互连内的时钟域实现了一个独立的 PMU。相应地，驱动会暴露多个名为 arm_ni_<x>_cd_<y> PMU 设备，其<x> 为（任意的）实例标识符，<y> 为该特定实例内的时钟ID。若系统中存在多NI 实例，可通过 sysfs 父子关系将这PMU 设备与底层硬件实例相关联
每个 PMU 为其时钟域内存在的接口类型暴露基础事件别名。这些别名需要用 "eventid" "nodeid" 参数进行限定，以指定要计数的事件码以及在其上进行计数的接口（依据 xxNI_NODE_INFO 寄存器中反映的已配置硬件 ID）。例外是 PMU 周期计数器的 "cycles" 别名，它已用 PMU 节点类型编码，无需进一步限定
