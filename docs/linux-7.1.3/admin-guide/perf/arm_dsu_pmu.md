## ARM DynamIQ 共享单元 (DSU) PMU


ARM DynamIQ 共享单元将一个或多个内核L3 内存系统集成
控制逻辑和外部接口形成多核集群。项目管理单
允许对与 L3 缓存、Snoop 控制单元相关的各种事件进行计
等，使用32位独立计数器。它还提供了一64 位周期计数器

PMU 只能通过 CPU 系统寄存器访问，并且
连接到同一 DSU 的核心。与大多数其他非核心 PMU 一样，DSU
PMU 不支持进程特定事件，并且不能在采样模式下使用

DSU 为通过硬件实现的事件子集提供位
寄存器。驱动程序无法确定其他事件是
是否可用。因此，驱动程序仅公开那些公布的事
```

  /sys/bus/event_sources/devices/arm_dsu_<N>/

```
用户应参考产品的TRM来了解支持的事件
并对未列出的事件使用原始事件代码

该驱动程序还在“关联的_cpus”中公开连接DSU 实例CPU


```

	perf stat -a -e arm_dsu_0/cycles/

```
