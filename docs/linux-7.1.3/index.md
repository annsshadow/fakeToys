

## Linux 内核文档


这是内核文档树的顶层。内核文档与内核本身一样，在很大程度上仍是一项
进行中的工作；尤其是当我们努力将许多分散的文档整合成一个连贯的整体时，
情况更是如此。我们随时欢迎对文档的改进；如果您想提供帮助，请加入
vger.kernel.org 上的 linux-doc 邮件列表。
