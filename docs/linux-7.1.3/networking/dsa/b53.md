
## Broadcom RoboSwitch 以太网交换机驱动


Broadcom RoboSwitch 以太网交换机系列被广泛应用于各类
xDSL 路由器、电缆调制解调器以及其他多媒体设备中。

当前实现支持 BCM5325E、BCM5365、BCM539x、
BCM53115 以及 BCM53125，同时也支持 BCM63XX。

## 实现细节


该驱动位于 `drivers/net/dsa/b53/`，并作为一个
DSA 驱动实现；有关该子系统及其提供的功能详情，请参见
`Documentation/networking/dsa/dsa.rst`。

如果可能，交换机会被配置为启用 Broadcom 特有的 4 字节
交换标签（switch tag），该标签由交换机为每一个转发到
CPU 接口的数据包插入；相应地，CPU 网络接口也应为进入
CPU 端口的数据包插入类似的标签。标签格式在
`net/dsa/tag_brcm.c` 中有说明。

设备的配置取决于是否支持标签（tagging）。

接口名称与示例网络配置依据
dsa-config-showcases 中描述的配置使用。

### 支持标签（tagging）的配置


基于标签的配置是推荐的方式。它并非 b53
DSA 驱动所特有，而是适用于所有支持标签的 DSA 驱动。

参见 dsa-tagged-configuration。

### 不支持标签（tagging）的配置


较旧的型号（5325、5365）支持一种尚不支持的不同标签格式。
539x 与 531x5 需要托管模式（managed mode）以及一些特殊处理，
这些目前也尚未支持。在这些情况下标签支持被禁用，交换机
需要不同的配置。

该配置与 dsa-vlan-configuration 略有不同。

b53 会在所有 VLAN 中标记 CPU 端口，因为否则任何 PVID
无标签的 VLAN 编程都会基本改变 CPU 端口的默认 PVID 并将其
变为无标签，这是不可取的。

与 dsa-vlan-configuration 中描述的配置不同，
在单端口（single port）与网关（gateway）配置中，必须从用户接口配置中
移除默认 VLAN 1，而在网桥（bridge）示例中无需额外添加
VLAN 配置。

#### 单端口


该配置只能通过 VLAN 标签与网桥设置来建立。
默认情况下数据包以 vid 1 打标签：


  # tag traffic on CPU port
  ip link add link eth0 name eth0.1 type vlan id 1
  ip link add link eth0 name eth0.2 type vlan id 2
  ip link add link eth0 name eth0.3 type vlan id 3

  # The conduit interface needs to be brought up before the user ports.
  ip link set eth0 up
  ip link set eth0.1 up
  ip link set eth0.2 up
  ip link set eth0.3 up

  # bring up the user interfaces
  ip link set wan up
  ip link set lan1 up
  ip link set lan2 up

  # create bridge
  ip link add name br0 type bridge

  # activate VLAN filtering
  ip link set dev br0 type bridge vlan_filtering 1

  # add ports to bridges
  ip link set dev wan master br0
  ip link set dev lan1 master br0
  ip link set dev lan2 master br0

  # tag traffic on ports
  bridge vlan add dev lan1 vid 2 pvid untagged
  bridge vlan del dev lan1 vid 1
  bridge vlan add dev lan2 vid 3 pvid untagged
  bridge vlan del dev lan2 vid 1

  # configure the VLANs
  ip addr add 192.0.2.1/30 dev eth0.1
  ip addr add 192.0.2.5/30 dev eth0.2
  ip addr add 192.0.2.9/30 dev eth0.3

  # bring up the bridge devices
  ip link set br0 up


#### 网桥（bridge）



  # tag traffic on CPU port
  ip link add link eth0 name eth0.1 type vlan id 1

  # The conduit interface needs to be brought up before the user ports.
  ip link set eth0 up
  ip link set eth0.1 up

  # bring up the user interfaces
  ip link set wan up
  ip link set lan1 up
  ip link set lan2 up

  # create bridge
  ip link add name br0 type bridge

  # activate VLAN filtering
  ip link set dev br0 type bridge vlan_filtering 1

  # add ports to bridge
  ip link set dev wan master br0
  ip link set dev lan1 master br0
  ip link set dev lan2 master br0
  ip link set eth0.1 master br0

  # configure the bridge
  ip addr add 192.0.2.129/25 dev br0

  # bring up the bridge
  ip link set dev br0 up

#### 网关（gateway）



  # tag traffic on CPU port
  ip link add link eth0 name eth0.1 type vlan id 1
  ip link add link eth0 name eth0.2 type vlan id 2

  # The conduit interface needs to be brought up before the user ports.
  ip link set eth0 up
  ip link set eth0.1 up
  ip link set eth0.2 up

  # bring up the user interfaces
  ip link set wan up
  ip link set lan1 up
  ip link set lan2 up

  # create bridge
  ip link add name br0 type bridge

  # activate VLAN filtering
  ip link set dev br0 type bridge vlan_filtering 1

  # add ports to bridges
  ip link set dev wan master br0
  ip link set eth0.1 master br0
  ip link set dev lan1 master br0
  ip link set dev lan2 master br0

  # tag traffic on ports
  bridge vlan add dev wan vid 2 pvid untagged
  bridge vlan del dev wan vid 1

  # configure the VLANs
  ip addr add 192.0.2.1/30 dev eth0.2
  ip addr add 192.0.2.129/25 dev br0

  # bring up the bridge devices
  ip link set br0 up
