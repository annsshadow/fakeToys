
## IPv6


ipv6 模块的选项在加载时作为参数提供。

模块选项可以作为命令行参数传递给 insmod 或 modprobe 命令，但通常指定在
`/etc/modules.d/*.conf` 配置文件中，或指定在某个发行版特定的配置文件中。

可用的 ipv6 模块参数如下所列。如果未指定某个参数，则使用其默认值。

参数如下：

disable

	指定是否加载 IPv6 模块，但禁用其全部功能。当另一个模块依赖于
	已加载的 IPv6 模块，但又不需要任何 IPv6 地址或操作时，可以使用此项。

	可能的值及其效果为：

	0
		IPv6 已启用。

		这是默认值。

	1
		IPv6 已禁用。

		不会向接口添加任何 IPv6 地址，并且将无法打开 IPv6 套接字。

		需要重新启动才能启用 IPv6。

autoconf

	指定是否在全部接口上启用 IPv6 地址自动配置。当不希望地址根据
	路由器通告中收到的前缀自动生成时，可以使用此项。

	可能的值及其效果为：

	0
		在所有接口上禁用 IPv6 地址自动配置。

		只会向接口添加 IPv6 环回地址（::1）和链路本地地址。

	1
		在所有接口上启用 IPv6 地址自动配置。

		这是默认值。

disable_ipv6

	指定是否在全部接口上禁用 IPv6。当不需要任何 IPv6 地址时，可以使用此项。

	可能的值及其效果为：

	0
		在所有接口上启用 IPv6。

		这是默认值。

	1
		在所有接口上禁用 IPv6。

		不会向接口添加任何 IPv6 地址。
