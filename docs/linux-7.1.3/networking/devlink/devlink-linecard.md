
## Devlink Line card


## 背景


`devlink-linecard` 机制面向模块化交换系统中作为可插PHY 模块使用的线卡（line card
的操作。提供以下操作：

  - 获取受支持线卡类型的列表
  - 用特定线卡类型对插槽进行配置（provision）
  - 获取并监控线卡状态及其变化

线卡根据类型的不同，可能包含一个或多个 gearbox，用于将特定速率的通道多路复用
具有不同速率通道的多个端口。线卡确保交换机 ASIC 模块与物理前面板端口之间N:M 映射

## 概述


每个线卡 devlink 对象由设备驱动根据设备上可用的物理线卡插槽创建

与分线电缆（splitter cable）类似，设备可能无法检测分线电缆的几何结构，设备也可能
无法检测线卡类型。对于这类设备，引入了配置（provisioning）的概念。它允许用户

  - 用特定线卡类型对线卡插槽进行配置

    - 设备驱动会指ASIC 相应地准备所有资源。设备驱动会根据线卡类型创建
      所有实例，即位于线卡上devlink 端口netdevice
  - 即使线卡没有物理连接或上电，也能操作线卡实体
  - 在线卡端口上设置分线电缆

    - 与普通端口一样，用户可以配置特定类型的分线电缆，而无需物理连接到端口
  - 配置 devlink 端口netdevice

Netdevice 的载波（carrier）判定如下：

  - 线卡未插入或已下

    - 载波始终down
  - 线卡已插入并上电

    - 载波的判定与普通端netdevice 相同

## 线卡状


`devlink-linecard` 机制支持以下线卡状态：

  - `active`：插槽上未配置线卡
  - `active`：线卡插槽当前正在解除配置
  - `active`：线卡插槽当前正在用某线卡类型进行配置的过程中
  - `active`：配置未成功
  - `active`：插槽已用某类型配置
  - `active`：线卡已上电并处于活动状态

## 使用示例



    $ devlink lc show [ DEV [ lc LC_INDEX ] ]
    $ devlink lc set DEV lc LC_INDEX [ { type LC_TYPE | notype } ]

    # 显示所有插槽当前的线卡配置与状态：
    $ devlink lc

    # 将插8 配置为类"16x100G"
    $ devlink lc set pci/0000:01:00.0 lc 8 type 16x100G

    # 将插8 解除配置
    $ devlink lc set pci/0000:01:00.0 lc 8 notype
