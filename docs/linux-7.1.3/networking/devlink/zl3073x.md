
## zl3073x devlink 支持


本文档描述 `zl3073x` 设备驱动实现的 devlink 特性。

## 参数


   :widths: 5 5 90

   - - 名称
     - 模式
     - 说明
   - - `clock_id`
     - driverinit
     - 设置驱动用于注册 DPLL 设备与引脚的时钟 ID。

## Info versions


`zl3073x` 驱动上报以下版本

    :widths: 5 5 5 90

    - - 名称
      - 类型
      - 示例
      - 描述
    - - `asic.id`
      - fixed
      - 1E94
      - 芯片标识号
    - - `asic.rev`
      - fixed
      - 300
      - 芯片修订号
    - - `fw`
      - running
      - 7006
      - 固件版本号
    - - `custom_cfg`
      - running
      - 1.3.0.1
      - OEM 定制的设备配置版本

## Flash Update


`zl3073x` 驱动实现了使用 `devlink-flash` 接口进行闪存更新的支持。它
支持使用包含多个组件（固件部件与配置）的组合闪存映像（"bundle"）更新
设备闪存。

在闪存操作期间，标准固件接口不可用，因此驱动注销所有 DPLL 及其
关联引脚，并在闪存操作完成后重新注册它们。

该驱动不支持任何覆盖掩码标志。
