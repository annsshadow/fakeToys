
## i40e devlink 支持


本文档描述了 `i40e` 设备驱动实现的 devlink 特性。

## 参数


    :widths: 5 5 90

    - - 名称
      - 模式
      - 说明
    - - `max_mac_per_vf`
      - runtime
      - 控制一个 VF 在 i40e 设备上可使用的 MAC 地址的最大数量。

        默认情况下（`0`），驱动强制执行其内部根据已分配 VF 数量计算出的每-VF
        MAC 过滤限制。

        如果设置为非零值，该参数将充当严格上限：
        驱动将使用用户提供的数值，而不是其内部计算结果。

        **重要说明：**

        - 该值**必须在启用 SR-IOV 之前设置**。
          在 SR-IOV 已启用时尝试更改它将返回错误。
        - MAC 过滤器是所有 VF 共享的**硬件资源**。
          设置较高的值可能导致其他 VF 的过滤器被饿死。
        - 该值是一种**管理策略**。无论此处设置何值，当达到硬件的绝对
          上限时，硬件都可能返回错误。

        默认值为 `0`（使用内部计算）。


## 版本信息（Info versions）


`i40e` 驱动报告以下版本

    :widths: 5 5 5 90

    - - 名称
      - 类型
      - 示例
      - 描述
    - - `board.id`
      - fixed
      - K15190-000
      - 板卡的产品板组装（PBA）标识符。
    - - `fw.mgmt`
      - running
      - 9.130
      - 控制 PHY、链路等的管理固件的 2 位版本号。
    - - `fw.mgmt.api`
      - running
      - 1.15
      - 管理固件通过 AdminQ 导出的 API 的 2 位版本号。驱动用它来识别支持哪些命令。
    - - `fw.mgmt.build`
      - running
      - 73618
      - 管理固件源代码的构建号。
    - - `fw.undi`
      - running
      - 1.3429.0
      - 包含 UEFI 驱动的 Option ROM 版本。版本以 `major.minor.patch` 格式报告。每当发生重大的不兼容变更，或次版本号将要溢出时，主版本号会递增。次版本号针对非不兼容变更递增，并在主版本号递增时重置为 1。补丁版本通常为 0，但当以针对较旧基础 Option ROM 的补丁形式提供修复时会递增。
    - - `fw.psid.api`
      - running
      - 9.30
      - 定义闪存内容格式的版本。
    - - `fw.bundle_id`
      - running
      - 0x8000e5f3
      - 加载到设备上的固件镜像文件的唯一标识符。也称为 NVM 的 EETRACK 标识符。
