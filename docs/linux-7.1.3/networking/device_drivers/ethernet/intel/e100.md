本次发布内容


本文件描述了适用Intel(R) PRO/100 系列适配器的 Linux 基础驱动。该驱动包含对基Itanium(R)2 的系统的支持

有关硬件要求的问题，请参阅随 Intel PRO/100 适配器提供的文档

以下特性现已在受支持的内核中提供：
 - 原生 VLAN
 - 通道绑定（teaming
 - SNMP

通道绑定文档可在 Linux 内核源码中找到：
/Documentation/networking/bonding.rst

驱动配置参数


除非另有说明，每个参数的默认值通常为推荐设置

Rx Descriptors锛。
   接收描述符的数量。接收描述符是一种数据结构，用于向网络控制器描述接收缓冲区及其属性。描述符中的数据由控制器使用，将来自控制器的数据写入主机内存。在 3.x.x 驱动中，该参数的有效范围64-256。默认值为 256。该参数可以
```

     ethtool -G eth? rx n

   Where n is the number of desired Rx descriptors.

```
Tx Descriptors锛。
   发送描述符的数量。发送描述符是一种数据结构，用于向网络控制器描述发送缓冲区及其属性。描述符中的数据由控制器使用，从主机内存读取数据到控制器。在 3.x.x 驱动中，该参数的有效范围64-256。默认值为 128。该参数
```

     ethtool -G eth? tx n

   Where n is the number of desired Tx descriptors.

```
Speed/Duplex锛。
   驱动通过自动协商确定链路速率和双工设
```

     ethtool -s eth?  autoneg off speed {10|100} duplex {full|half}

   NOTE: setting the speed/duplex to incorrect values will cause the link to
   fail.

```
Event Log Message Level锛。
   驱动使用消息级别标志将事件记录到 syslog。消息级别可在驱动加载时设置。也可以
```

     ethtool -s eth? msglvl n


```
其他配置


在不同发行版上配置驱


配置网络驱动在系统启动时正确加载是依赖于发行版的操作。通常，配置过程包括向 `/etc/modprobe.d/*.conf` 添加别名行，以及编辑其他系统启动脚本或配置文件。许多流行的 Linux 发行版附带了可为您进行这些更改的工具。要了解为您的系统配置网络设备的正确方法，请参阅您的发行版文档。如果在此过程中系统要求您提供驱动或模块名称，则适用Intel PRO/100 系列适配器的 Linux 基础驱动名称e100

例如，如果您为两PRO/100 适配器（eth0 eth1）安e100 驱动，请将以下内容添加到配置文件中的
```

       alias eth0 e100
       alias eth1 e100

```
查看链路消息


要在控制台上看到链路消息和其Intel 驱动信息，必须将 dmesg 级别提高到六。这可以在加e100 之前在命令行中输入以下内容来完成
```

       dmesg -n 6

```
如果您希望看到驱动发出的所有消息（包括调试消息），请将 dmesg 级别设置为八

注意：此设置不会在重启后保留

ethtool


驱动利用 ethtool 接口进行驱动配置和诊断，以及显示统计信息。此功能需ethtool 1.6 或更高版本

最新版本的 ethtool 可从以下地址获取
https://www.kernel.org/pub/software/network/ethtool/

启用局域网唤醒（WoL

WoL 通过 ethtool 实用程序提供。有关使ethtool 启用 WoL 的说明，请参ethtool 手册页。WoL 将在系统下次关机或重启期间启用。对于此驱动版本，要启用 WoL，必须在关机或重启系统时加载 e100 驱动

NAPI


e100 驱动支持 NAPI（接收轮询模式）

有关详细信息，请参阅 Documentation/networking/napi.rst <napi>

同一以太网广播网络上的多个接


由于 Linux 上默认的 ARP 行为，不可能让同一以太网广播域（未分区的交换机）中两个 IP 网络上的系统按预期运行。所有以太网接口都会响应分配给该系统的任IP 地址IP 流量。这会导致接收流量不均衡

如果服务器上有多个接口，请通过以下方式开ARP 过滤

```

	echo 1 > /proc/sys/net/ipv4/conf/all/arp_filter

    (this only works if your kernel's version is higher than 2.4.5), or

```
(2) 将接口安装到独立的广播域中（在不同的交换机中，或在划分为 VLAN 的交换机中）
