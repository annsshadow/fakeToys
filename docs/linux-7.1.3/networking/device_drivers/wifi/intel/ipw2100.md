## 3. 命令行参


如果驱动被构建为模块，可以使modprobe 命令在命令行输入以下可选参数来使用它们
```

	modprobe ipw2100 [<option>=<VAL1><,VAL2>...]

```
例如，要在加载驱动时禁用无线电，输入

	modprobe ipw2100 disable=1

ipw2100 驱动支持以下模块参数

==========	===============	===========  =================================
Name		Value			Example     Meaning
==========	===============	===========  =================================
debug		0x0-0xffffffff	debug=1024  调试级别设为 1024
mode		0,1,2		mode=1      AdHoc
channel		int		channel=3   仅在 AdHoc Monitor 模式下有
associate	boolean		associate=0 不要自动关联
disable		boolean		disable=1   不给硬件上电
==========	===============	===========  =================================


```
对于设备级别的文件，参见 /sys/bus/pci/drivers/ipw2100

  rf_kill
	读取

	==  =========================================
	0   RF kill 未启用（无线电开启）
	1   基于软件RF kill 已激活（无线电关闭）
	2   基于硬件RF kill 已激活（无线电关闭）

	0   如果基于软件RF kill 处于激活状态，则重新打开无线

	==  ==================================================
```

```
## 5. 无线电关闭开关（Radio Kill Switch


大多数笔记本电脑提供让用户物理禁用无线电的能力。一些厂商将其实现为一个不需要软件即可开关无线电的物理开关。然而，在其他笔记本上，该开关通过按下按钮控制，然后由软件驱动调用以开关无线电。这被称为“基于软件的 RF 关闭开关（software based RF kill switch）

参见 Sysfs 辅助文件 'rf_kill' 以确定你的系统上 RF 开关的状态

## 7. 电源管理


IPW2100 支持通过一个私有的 wireless extension 接口配置节能协议（Power Save Protocol）。IPW2100 支持以下不同模式

	===	===========================================================
	off	无电源管理。无线电始终开启
	on	自动电源管理
	1-5	不同级别的电源管理。数字越大节电越多，但会影响
		数据包延迟
	===	===========================================================

电源管理的工作原理是：在一段时间没有数据包通过无线电后，关闭无线电的电源。一旦断电，无线电在该状态下保持一段给定的时间。为了获得更高的节电效果，从处理最后一个数据包到睡眠的间隔更短，而睡眠周期更长

当无线电处于睡眠状态时，向站点发送数据的接入点必须将数据包缓存在 AP 中，直到站点唤醒并请求任何被缓存的数据包。如果你AP 不能正确支持 PSP 协议，在启用电源管理时你可能会遇到数据包丢失或非常差的性能。如果是这种情况，你将需要尝试为你的 AP 寻找固件更新，或禁用电源管理（通过 `iwconfig eth1 power off`

要配IPW2100 上的电源级别，你需要组合使iwconfig iwpriv。iwconfig 用于打开、关闭电源管理，并将其设为自动

	=========================  ====================================
	iwconfig eth1 power off    禁用无线电断
	iwconfig eth1 power on     启用无线电电源管理到上次设置的级别（默认AUTO
	iwpriv eth1 set_power 0    将电源级别设AUTO，并在先前未启用的情况下启用电源管理
	iwpriv eth1 set_power 1-5  按指定设置电源级别，并在先前未启用的情况下启用电源管
	=========================  ====================================

```

	iwpriv eth1 get_power

它将返回当前配置的周期或超时，形式为 xxxx/yyyy (z) 的字符串，其xxxx 是超时间隔（处理完数据包后的时间量），yyyy 是睡眠周期（在为无线电上电并查询接入点以获取缓存数据包之前等待的时间量），z 是“电源级别”。如果电源管理被关闭，xxxx/yyyy 将被替换为“off”——如果调`iwconfig eth1 power on`，报告的级别将是活动级别
