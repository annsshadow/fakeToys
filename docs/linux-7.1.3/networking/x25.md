
## Linux X.25 项目


作为我在大学的第三年毕业论文，我承担起为 Linux 编写一X.25 实现的工作。我的目标是提供一个完整的 X.25 分组层（Packet Layer）和一LAPB 模块，以便能够使Linux 运行"正常"X.25。市面上有两X.25 卡：一类是智能卡，在卡上自身就实现LAPB；另一类是非智能卡，只进行成帧、位填充和校验和计算。这两类都需要由系统来处理
因此，我决定编写这个实现，使得就分组层而言，链路层是由 Linux 内核的某一低层执行的，因此它不关心 LAPB 的实现。因LAPB 模块将由非智能的 X.25 卡驱动调用，而不是由智能卡驱动调用，这将提供一个统一的设备驱动接口，并简化配置
稍微增加一点复杂性，也可以实802.2 LLC，它可以X.25 运行在以太网（或令牌环，Token Ring）上，并符合 JNT Pink Book"，这将对分组层有不同的接口，但不会有混淆，因LLC 所服务的设备类别与 LAPB 完全分离
就在你认为它不会再更混乱的时候，又出现了另一个选项，XOT。它允许 X.25 分组层帧通过 Internet 使用 TCP/IP 作为可靠的链路层来运行。RFC1613 规定了该协议的格式和行为。如果时间允许，也会积极考虑这个选项
