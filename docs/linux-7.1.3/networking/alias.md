
## IP别名


IP 别名是管理多IP 地址/掩码的过时方
每个接口iproute2 等较新的工具支持多个
每个接口的地址/前缀，但仍然支持别名
为了向后兼容

别名是通过在运ifconfig 时添加冒号和字符串形成的
该字符串通常是数字，但这不是必须的


## 别名创建


别名创建是通过“神奇”接口命名完成的：例如。创建一
200.1.1.1 eth0 的别...
```

  # ifconfig eth0:0 200.1.1.1  etc,etc....
	~~ -> request alias #0 creation (if not yet exists) for eth0

```
相应的路由也是通过该命令设置的 请注意：
该路由始终指向基本接口


## 别名删除


```

  # ifconfig eth0:0 down
	~~~~~~~~~~ -> will delete alias


```
## 别名（重新）配置


别名不是真正的设备，但程序应该能够配
并照常引用它们（ifconfig、route 等）


## 与主设备的关


如果基本设备关闭，添加的别名也将被删除
