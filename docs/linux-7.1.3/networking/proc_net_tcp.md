
## /proc/net/tcp /proc/net/tcp6 变量


本文档描述了接口 /proc/net/tcp /proc/net/tcp6请注意，这些接口已被弃用，推荐使tcp_diag
这些 /proc 接口提供有关当前活动 TCP 连接的信息，分别net/ipv4/tcp_ipv4.c 中的 tcp4_seq_show() net/ipv6/tcp_ipv6.c 中的 tcp6_seq_show() 实现
它会首先列出所有处于监听状态的 TCP 套接字，接着列出所有已建立TCP 连接proc/net/tcp 的一个典型表项如下所示（已拆
