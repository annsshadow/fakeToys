
## /proc/net/tcp 与 /proc/net/tcp6 变量


本文档描述了接口 /proc/net/tcp 与 /proc/net/tcp6。
请注意，这些接口已被弃用，推荐使用 tcp_diag。

这些 /proc 接口提供有关当前活动 TCP 连接的信息，分别由 net/ipv4/tcp_ipv4.c 中的 tcp4_seq_show() 与 net/ipv6/tcp_ipv6.c 中的 tcp6_seq_show() 实现。

它会首先列出所有处于监听状态的 TCP 套接字，接着列出所有已建立的 TCP 连接。/proc/net/tcp 的一个典型表项如下所示（已拆
```

   46: 010310AC:9C4C 030310AC:1770 01
   |      |      |      |      |   |--> 连接状态
   |      |      |      |      |------> 远端 TCP 端口号
   |      |      |      |-------------> 远端 IPv4 地址
   |      |      |--------------------> 本地 TCP 端口号
   |      |---------------------------> 本地 IPv4 地址
   |----------------------------------> 表项编号

   00000150:00000000 01:00000019 00000000
      |        |     |     |       |--> 未恢复的 RTO 超时次数
      |        |     |     |----------> 定时器到期前的 jiffies 数
      |        |     |----------------> timer_active（见下）
      |        |----------------------> 接收队列
      |-------------------------------> 发送队列

   1000        0 54165785 4 cd1e6040 25 4 27 3 -1
    |          |    |     |    |     |  | |  | |--> 慢启动大小阈值，
    |          |    |     |    |     |  | |  |      若阈值 >= 0xFFFF 则为 -1
    |          |    |     |    |     |  | |  |----> 发送拥塞窗口
    |          |    |     |    |     |  | |-------> (ack.quick<<1)|ack.pingpong
    |          |    |     |    |     |  |---------> 软时钟的预测滴答
    |          |    |     |    |     |              （延迟 ACK 控制数据）
    |          |    |     |    |     |------------> 重传超时
    |          |    |     |    |------------------> 套接字在内存中的位置
    |          |    |     |-----------------------> 套接字引用计数
    |          |    |-----------------------------> inode
    |          |----------------------------------> 未应答的 0 窗口探测
    |---------------------------------------------> uid

```
timer_active：

 ==  ================================================================
  0  无待处理定时器
  1  重传定时器待处理
  2  另一个定时器（如延迟 ack 或保活）待处理
  3  这是一个处于 TIME_WAIT 状态的套接字。并非所有字段都会包含
     数据（甚至可能不存在）
  4  零窗口探测定时器待处理
 ==  ================================================================
