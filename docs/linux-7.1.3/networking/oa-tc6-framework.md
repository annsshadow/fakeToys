
## OPEN Alliance 10BASE-T1x MAC-PHY 串行接口（TC6）框架支

### 简

IEEE 802.3cg 项目定义了两种运行在单对导线上的 10 Mbit/s PHY0BASE-T1L（条146）是一种长距离 PHY，支持在 1 km 单对平衡导线上进行全双工点对点通信0BASE-T1S（条147）是一种短距离 PHY，支持在 15 m 单对平衡导线上进行全/半双工点对点通信，或25 m 单对平衡导线上进行半双工多点总线通信
此外，IEEE 802.3cg 项目定义了新的物理层冲突避免（PLCA）协调子层（条款 148），旨在CSMA/CD 介质访问方法提供更高的确定性。PLCA 与运行在多点模式10BASE-T1S PHY 协同工作
上述 PHY 旨在覆盖工业和汽车环境中的低低成本应用。IEEE 802.3 在条22 中规定的 MII 接口需要大量引脚（16 个），这是实现该目标需要解决的主要成本因素之一
MAC-PHY 方案集成IEEE 条款 4 MAC 10BASE-T1x PHY，向主机微控制器暴露一个低引脚数的串行外设接口（SPI）。这也使得能够为未集MAC 控制器的现有低端微控制器添加以太网功能
### 概述


MAC-PHY 被规定为通过单个全双工串行外设接口承载数据（以太网帧）和控制（寄存器访问）事务
### 协议概述


协议定义了两类事务：用于以太网帧传输的数据事务，以及用于寄存器读/写传输的控制事务。数据块（chunk）是数据事务的基本元素，每个数据块由 4 字节开销加上 64 字节有效载荷组成。以太网帧通过一个或多个数据块传输。控制事务由一个或多个寄存器读/写控制命令组成
SPI 事务SPI 主机通过CSn 拉低来发起，并通过CSn 拉高来结束。在每个 SPI 事务之间，SPI 主机可能需要时间进行额外处理并设置下一SPI 数据或控制事务
SPI 数据事务由数量相等的发送（TX）和接收（RX）数据块组成。发送和接收方向的数据块彼此独立地可能包含或不包含有效帧数据，从而允许同时发送和接收不同长度的帧
每个发送数据块32 位数据头开始，其后MOSI 上的数据块有效载荷。数据头指示是否存在发送帧数据，并提供信息以确定有效载荷中的哪些字节包含有效帧数据
与此同时，接收数据块MISO 上被接收。每个接收数据块由一个数据块有效载荷组成，并32 位数据尾结束。数据尾指示有效载荷中是否存在接收帧数据，并提供信息以确定有效载荷中的哪些字节包含有效帧数据

- 初始PHYLIB 接口
- 注册 mac-phy 中断

- 将来10Base-T1x MAC-PHY 的接收以太网帧转发到 n/w 子系统
#### 数据事务


通常SPI 主机传输MAC-PHY 的以太网帧将被转换为多个发送数据块。每个发送数据块都带有一4 字节头，其中包含确定 64 字节数据块有效载荷内发送帧数据的有效性和位置所需的信息

  +---------------------------------------------------+
  |                     Tx Chunk                      |
  | +---------------------------+  +----------------+ |   MOSI
  | | 64 bytes chunk payload    |  | 4 bytes header | |------------>
  | +---------------------------+  +----------------+ |
  +---------------------------------------------------+

4 字节头包含以下字段，

DNC（位 31 数据-非控制标志。该标志指定 SPI 事务的类型。对TX 数据块，该位应置'1'              0 - 控制命令
              1 - 鏁版嵁鍧。
SEQ（位 30 数据块序列。该位用于向 MAC-PHY 指示偶数/奇数发送数据块序列
NORX（位 29 无接收标志。SPI 主机可设置该位以防止 MAC-PHY 在当前数据块上通过 MISO 传RX 数据（尾中的 DV = 0），表示主机不会处理它。通常，SPI 主机应将 NORX = 0，表示其将接受并处理当前数据块内的任何接收帧数据
RSVD（位 28..24 保留：所有保留位应置'0'
VS（位 23..22 厂商特定。这些位由实现定义。如MAC-PHY 未实现这些位，主机应将其置为 '0'
DV（位 21 数据有效标志。SPI 主机使用该位来指示当前数据块是否包含有效的发送帧数据（DV = 1 DV = 0）。当'0' 时，MAC-PHY 忽略该数据块有效载荷。注意接收路径不受数据头DV 位设置的影响
SV（位 20 起始有效标志。当当前发送数据块有效载荷中存在以太网帧的起始时，SPI 主机应设置该位。否则该位应为零。该位不应与 IEEE 802.3 [^2^] 中描述的帧起始定界符（SFD）字节混淆
SWO（位 19..16 起始字偏移。当 SV = 1 时，该字段应包含指向待发送的新以太网帧起始的发送数据块有效载荷中的 32 位字偏移。当 SV = 0 时，主机应将该字段写为零
RSVD（位 15 保留：所有保留位应置'0'
EV（位 14 结束有效标志。当当前发送数据块有效载荷中存在以太网帧的结尾时，SPI 主机应设置该位。否则该位应为零
EBO（位 13..8 结束字节偏移。当 EV = 1 时，该字段应包含指向待发送以太网帧最后一个字节的发送数据块有效载荷中的字节偏移。当 EV = 0 时该字段应为零
TSC（位 7..6 时间戳捕获。当帧被发送到网络上时请求捕获时间戳                 00 - 不捕获时间戳
                 01 - 将时间戳捕获到时间戳捕获寄存A
                 10 - 将时间戳捕获到时间戳捕获寄存B
                 11 - 将时间戳捕获到时间戳捕获寄存C

RSVD（位 5..1 保留：所有保留位应置'0'
P（位 0 奇偶校验。对发送数据头计算的奇偶校验位。使用奇校验
MAC-PHY 中用于存储传入发送数据块有效载荷的可用缓冲区数量表示为发送信用（transmit credits）。MAC-PHY 中可用的发送信用可以从缓冲区状态寄存器或来MAC-PHY 的尾（尾信息见下文）读取。SPI 主机写入的数据块数量不应超过可用的发送信用，否则将导致发送缓冲区溢出错误
如果前一个数据尾没有可用发送信用，一旦发送信用可用于发送发送数据块，MAC-PHY 会向 SPI 主机发起中断。在接收到第一个数据头时，该中断将被撤销，并且第一个数据块的接收尾中将包含发送信用可用信息
通常MAC-PHY 传输SPI 主机的以太网帧将作为多个接收数据块发送。每个接收数据块将具64 字节的数据块有效载荷，其后跟4 字节尾，其中包含确定 64 字节数据块有效载荷内接收帧数据的有效性和位置所需的信息

  +---------------------------------------------------+
  |                     Rx Chunk                      |
  | +----------------+  +---------------------------+ |   MISO
  | | 4 bytes footer |  | 64 bytes chunk payload    | |------------>
  | +----------------+  +---------------------------+ |
  +---------------------------------------------------+

4 字节尾包含以下字段，

EXST（位 31 扩展状态。当 STATUS0 STATUS1 寄存器中的任何位被置位且未被屏蔽时，该位被置位
HDRB（位 30 接收头错误。置位时，表MAC-PHY 接收到带有奇偶校验错误的控制或数据头
SYNC（位 29 配置同步标志。该位反CONFIG0 配置寄存器（见表 12）中 SYNC 位的状态。为零表MAC-PHY 配置可能SPI 主机的预期不一致。配置完成后，SPI 主机设置配置寄存器中的相应位，该位会反映在此字段中
RCA（位 28..24 可用接收数据块。RCA 字段SPI 主机指示在当前接收数据块之外还可读取的帧数据接收数据块的最小数量。当 MAC-PHY 缓冲区中没有待读取的接收帧数据时，该字段为零
VS（位 23..22 厂商特定。这些位由实现定义。如果未实现，MAC-PHY 应将这些位置'0'
DV（位 21 数据有效标志。MAC-PHY 使用该位来指示当前接收数据块是否包含有效的接收帧数据（DV = 1 DV = 0）。当'0' 时，SPI 主机应忽略该数据块有效载荷
SV（位 20 起始有效标志。当当前数据块有效载荷包含以太网帧的起始时，MAC-PHY 设置该位。否则该位为零。SV 位不应与 IEEE 802.3 [^2^] 中描述的帧起始定界符（SFD）字节混淆
SWO（位 19..16 起始字偏移。当 SV = 1 时，该字段包含指向接收的新以太网帧第一个字节的接收数据块有效载荷中32 位字偏移。当接收时间戳已添加到接收的以太网帧开头（RTSA = 1）时，SWO 指向时间戳的最高有效字节。当 SV = 0 时该字段为零
FD（位 15 帧丢弃。置位时，该位表MAC 检测到 SPI 主机应丢弃所接收以太网帧的状况。该位仅在接收以太网帧结尾（EV = 1）时有效，其他所有时刻应为零
EV（位 14 结束有效标志。当接收以太网帧的结尾出现在该接收数据块有效载荷中时，MAC-PHY 设置该位
EBO（位 13..8 结束字节偏移：当 EV = 1 时，该字段包含指向接收以太网帧最后一个字节的接收数据块有效载荷中的字节偏移。当 EV = 0 时该字段为零
RTSA（位 7 已添加接收时间戳。当 32 位或 64 位时间戳已添加到接收以太网帧开头时，该位被置位。当 SV = 0 时，MAC-PHY 应将该位置为零
RTSP（位 6 接收时间戳奇偶校验。对添加到接收以太网帧开头的 32 64 位时间戳计算的奇偶校验位。使用奇校验。当 RTSA = 0 时，MAC-PHY 应将该位置为零
TXC（位 5..1 发送信用。该字段包含 SPI 主机在单次事务中可以写入而不导致发送缓冲区溢出错误的帧数据发送数据块的最小数量
P（位 0 奇偶校验。对接收数据尾计算的奇偶校验位。使用奇校验
SPI 主机将根MAC-PHY 中可用的接收数据块发起数据接收事务，该信息由接收数据块尾（RCA - 可用接收数据块）提供。SPI 主机将创建数据无效的发送数据块（空数据块）或数据有效的发送数据块（在有有效以太网帧要发送给 MAC-PHY 的情况下）。MAC-PHY 中可用的接收数据块可以从缓冲区状态寄存器或尾中读取
如果前一个数据尾没有可用接收数据块，一旦接收数据块再次可用于读取，MAC-PHY 会向 SPI 主机发起中断。在接收到第一个数据头时，该中断将被撤销，并且第一个数据块的接收尾中将包含可用接收数据块信息
#### MAC-PHY 中断


当满足以下条件时，MAC-PHY 中断被发起
可用接收数据- 当上一个数据尾没有可用接收数据块且接收数据块可用于读取时，该中断被发起。在接收到第一个数据头时，该中断将被撤销
可用发送数据块信用 - 当上一个数据尾指示无可用发送信用且发送信用可用于发送发送数据块时，该中断被发起。在接收到第一个数据头时，该中断将被撤销
扩展状态事- 当上一个数据尾指示无扩展状态且扩展事件变为可用时，该中断被发起。在这种情况下，主机应读取状#0 寄存器以了解相应的错事件。在接收到第一个数据头时，该中断将被撤销
#### 控制事务


4 字节控制头包含以下字段，

DNC（位 31 数据-非控制标志。该标志指定 SPI 事务的类型。对于控制命令，该位应为 '0'              0 - 控制命令
              1 - 鏁版嵁鍧。
HDRB（位 30 接收头错误。由 MAC-PHY 置位时，表示接收到的头带有奇偶校验错误。SPI 主机应始终清除该位。MAC-PHY 会忽SPI 主机MOSI 上发送的 HDRB 值
WNR（位 29 非读。该位指示数据是写入寄存器（置位时）还是从寄存器读取（清除时）
AID（位 28 地址自增禁用。清除时，地址将在每次寄存器读或写之后自动加一。置位时，禁用地址自动递增，允许在同一寄存器地址上进行连续的读和写
MMS（位 27..24 内存映射选择器。该字段选择要访问的特定寄存器内存映射
ADDR（位 23..8 地址。所选内存映射中要访问的第一个寄存器的地址
LEN（位 7..1 长度。指定要写的寄存器数量。该字段被解释为寄存器数量减 1，从而允许从 ADDR 指定的地址开始最多连续读/128 个寄存器。长度为 0 时应读或写一个寄存器
P（位 0 奇偶校验。对控制命令头计算的奇偶校验位。使用奇校验
控制事务由一个或多个控制命令组成。SPI 主机使用控制命令来读和写 MAC-PHY 内的寄存器。每个控制命令由一4 字节控制命令头组成，如果是控制写命令，则后跟寄存器写数据
MAC-PHY 会忽略控制写命令结束时来SPI 主机的最4 字节数据。控制写命令也会MAC-PHY 回显SPI 主机，以在发生任何总线错误时识别哪个寄存器写失败。回显的控制写命令前 4 字节SPI 主机应忽略的未使用值，后跟 4 字节回显控制头和回显寄存器写数据。控制写命令可以写入单个寄存器或多个连续寄存器。写入多个连续寄存器时，地址MAC-PHY 自动递增。写入任何未实现或未定义的寄存器都将被忽略且不产生任何效果
对于控制读命令的剩余部分，MAC-PHY 会忽略来SPI 主机的控制头之后的所有数据。控制读命令也会MAC-PHY 回显SPI 主机，以在发生任何总线错误时识别哪个寄存器读失败。回显的控制读命令前 4 字节SPI 主机应忽略的未使用值，后跟 4 字节回显控制头和寄存器读数据。控制读命令可以读取单个寄存器或多个连续寄存器。读取多个连续寄存器时，地址MAC-PHY 自动递增。读取任何未实现或未定义的寄存器都应返回零
