
## PSE 电源接口（PSE PI）文

供电设备电源接口（Power Sourcing Equipment Power Interface，PSE PI）在
以太网供电（Power over Ethernet，PoE）系统的架构中扮演着关键角色。它
本质上是一份蓝本，描述了如何将一个或多个电源连接到俗称以太网 RJ45 端口八针模块化插孔。该连接方案对于实现通过以太网线缆同时传输电力与数据至关
重要
### 文档与标

IEEE 802.3 标准PSE PI 提供了详尽的文档。具体而言
- 3.2.3 PI 引脚分配”一节涵盖了采用两对线供电的 PoE 系统的引脚分配- 45.2.4 PSE PI”一节阐述了通过以太网线缆全部四对线供电PoE 系统
  配置
### PSE PI 与单对以太网

单对以太网（Single Pair Ethernet，SPE）代表了另一种以太网连接方式仅使用一对导体同时传输数据和电力。与 PSE PI 中为标准以太网所详述配置（可能涉及跨四对或两对线的多种供电安排）不同，SPE 由于其单对线设计
而采用更简单的模型。因此，PSE PI 中为多对以太网描述的、在供电引脚分配之间
做选择的复杂性，并不适用SPE
### 理解 PSE PI

供电设备电源接口（PSE PI）是一个定义供电设备（PSE）如何通过以太网线向受电设备（PD）供电的框架。它详述了两种主要的供电配置，称Alternative A
Alternative B，二者不仅通过供电方式区分，还涉及极性与数据传输方向差异
### Alternative A B 概述


- **Alternative A* 使用 RJ45 的导1 6。无论对10/100BaseT
  还是 1G/2G/5G/10GBaseT 网络，所用线对均承载数据。此备选方案的供电极  会随 MDI（Medium Dependent Interface）或 MDI-X（Medium Dependent Interface
  Crossover）配置而变化
- **Alternative B* 使用 RJ45 的导4 8。在 10/100BaseT 网络中，
  所用线对为不承载数据的备用线对，受数据传输方向影响较小。对1G/2G/5G/
  10GBaseT 网络则不然。Alternative B 包含两个极性不同的配置，称variant X
  variant S，以适应不同的网络需求与设备规格

### 设备树配置：描述 PSE PI 配置


设备树中是否需要一个独立的 PSE PI 节点，受以太网供电（PoE）系统搭复杂程度的影响。下面是对简单与复杂 PSE PI 配置的描述，用以说明这一决策
过程
**简PSE PI 配置*
在直接的场景中，PSE PI 搭建涉及单个 PSE 控制器与以太网端口之间直接的
一对一连接。此搭建通常支持基本PoE 功能，无需动态配置或管理多种供电
模式。对于此类简单配置，在现有的 PSE 控制器节点内详细说明 PSE PI 可能
已足够，因为系统不包含需要独立节点的额外复杂性。这里的重点是清晰、直接地
将供电与特定以太网端口关联起来
**复杂 PSE PI 配置*
相反，复杂的 PSE PI 搭建可能包含多个 PSE 控制器或辅助电路，共同管理对
一个以太网端口的供电。此类配置可能支持一系列 PoE 标准，并需要能够根运行模式（例PoE2 PoE4）或所连接设备的具体要求动态配置供电。在这些
情况下，一个专用的 PSE PI 节点对于准确记录系统架构变得必不可少。该节点
将详细说明不PSE 控制器之间的交互、对各种 PoE 模式的支持，以及协调网络
基础设施中供电所需的任何额外逻辑
**指导*

对于简单的 PSE 搭建，由于系统性质直接，在 PSE 控制器节点中包含 PSE PI
信息可能已足够。然而，涉及多个组件或高PoE 特性的复杂配置，则受益于一专用PSE PI 节点。此方法遵循 IEEE 802.3 规范，提升了文档清晰度，并确准确体现 PoE 系统的复杂性
### PSE PI 节点：关键信

设备树中PSE PI（供电设备电源接口）节点可以包含若干关键信息，这信息对于定义 PoE（以太网供电）系统的供电能力与配置至关重要。以下是此类
信息的列表，并附带了它们为何必要、以及为何在 PSE 控制器节点中可能找不到的
解释
1. **受电线对配置**

   - **描述* 标识以太网线缆中用于供电的线对   - **必要性：** 对于确保按照板卡设计正确为相应线对供电至关重要   - **PSE 控制器节点：** 通常缺乏关于物理线对使用方式的细节，侧重     电源调节
2. **受电线对极*

   - **描述* 指定每个受电线对的极性（正或负）   - **必要性：** 对于PD 安全、有效地传输电力至关重要   - **PSE 控制器节点：** 极性管理可能超PSE 控制器的标准功能
3. **PSE 单元关联**

   - **描述* 详述在多单元配置中，PSE 单元与以太网端口或线对的关联   - **必要性：** 允许在复杂系统中优化电源资源分配   - **PSE 控制器节点：** 控制器可能不直接管理单元关联，而是侧重     电源流动调节
4. **PoE 标准的支*

   - **描述* 列出系统所支持PoE 标准与配置   - **必要性：** 确保系统与各PD 的兼容性，并遵循行业标准   - **PSE 控制器节点：** 具体能力可能取决于整PSE PI 设计，而非     控制器本身。每PI 有多PSE 单元并不一定意味着支持多种 PoE 标准
5. **保护机制**

   - **描述* 概述额外的保护机制，例如过流保护与热管理   - **必要性：** 提供额外的安全性与稳定性，补充 PSE 控制器的保护   - **PSE 控制器节点：** 某些保护可能通过控制器之外的、特定于板卡     硬件或算法实现
