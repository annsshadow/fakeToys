> `origin/main` 干净树同样失败、CI 不受影响 ⇒ 别把它当代码回归。
> ③ **远端 443 间歇断网** —— git 的 HTTPS 出口偶发中断，而 API 通道正常；
> 文档给的处置是 fetch/push 重试 2–3 次，且**断网期间不要判定「分支没推上去」**。
> **本轮现量复现**：11-14 推送时连续遇到代理隧道 502 与直连超时，SSH 通道探测成功、
> HTTPS 恢复后重试即成功，与文档描述完全一致。
> **处置**：纯环境债，观察即可，不写产品码、不改门禁。解除条件是构建期缓存预置
> （离线镜像 / 把 zip 纳入构建缓存）与出口稳定；在此之前它只是「复跑时要认得的噪声」。
