# OA4Rust 完成计划 — 本轮进展与门禁命令（2026-08-17）

## 已落地改动（工作树，持久）
1. **BPMN `task_return`（退回）handler 真实化**
   - `crates/processplatform_service_processing/src/lib.rs`：新增 `pub async fn task_return`（约 2361 行）。
     语义：当前 task 置 `returned` → 写 `x_record(type='return')` → 回查同 work 最近 `completed`/`returned` task 并将其 `task_status` 重置为 `pending`（若无前驱则重置自身）→ 将 `x_work.work_status` 置 `processing`（**非终态**，区别于 `disagree` 的 `rejected`）。
   - `crates/processplatform_service_processing/src/routes.rs`：新增路由 `POST /jaxrs/processplatform/service/processing/task/{id}/return`。
2. **集成测试扩充** `tests/integration_tests/scenarios/bpmn_process.rs`
   - 新增 `bpmn_task_actions_flow`：
     - Part A（transfer + return 非终态）：起 work+task → `POST .../task/{id}/transfer` 断言 `person=="bob"` → `POST .../task/{id}/return` 断言 `returned==true` / `workStatus=="processing"` / `taskStatus=="pending"`，并查库确认 `x_record(record_type='return')` 存在、`x_task.task_status=='pending'`。
     - Part B（disagree 终态）：起第二个 work+task → `POST .../task/{id}/disagree` 断言 `disagreed==true` / `taskStatus=="rejected"` / `workStatus=="rejected"`，查库确认 `x_record(record_type='disagree')` 存在。
   - `tests/integration_runner.rs`：注册 `run_scenario("bpmn_task_actions", ...)`。
3. **度量脚本三重修复** `scripts/measure_routed_db_touch.py`
   - 模块感知解析（按 `(文件stem, ident)` 双重索引，修复跨子模块 handler 误查）。
   - 花括号匹配修复（新增 `find_matching_brace` 替代 `find_matching_paren`，修复函数体被提前截断导致的 shell 误判）。
   - SeaORM 模式补齐（`.insert()` / `.update()` / `delete_by_id` / `.save()` / `.all()` / `.one()` / `.exec()` / `ActiveModel`）。
