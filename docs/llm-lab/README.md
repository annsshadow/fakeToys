# LLM 实验 · llm-lab

从零开始、动手搞懂大模型训练。不堆术语，而是**亲手把一个 GPT 从零造出来、训练起来、再优化**，全程配可运行代码。

## 两条代码轨

| 轨道 | 目录 | 依赖 | 定位 |
| --- | --- | --- | --- |
| **原理轨** | `llm-lab/minigrad` | 只需 `numpy` | 纯手写自动微分 + GPT，任何环境都能跑。看懂每一行就看懂了反向传播、注意力与训练循环。 |
| **实战轨** | `llm-lab/torchgpt` | 需要 `torch` | 用 PyTorch 复刻 nanoGPT，覆盖 AMP、梯度累积、LoRA、DPO、困惑度评估等工程手段。 |

两轨结构刻意对齐（同样的 Pre-LN、因果注意力、4x MLP）：先在原理轨搞懂"为什么"，再去实战轨看"工程上怎么做"。
