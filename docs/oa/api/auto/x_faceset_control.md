# x_faceset_control

## Endpoints

- `POST /face/detect/{name}/{id}` — detect
- `POST /faceset/addface/{faceset}` — addface
- `POST /faceset/removeface/{faceset}` — removeface
- `POST /search/{faceset}` — search
- `POST /compare` — compare
- `POST /face/analyze` — analyze
- `POST /face/detectattr/{attr}` — detectattr
- `POST /faceset/getFaceSet/{faceset}` — getFaceSet
- `POST /faceset/createfaceset/{faceset}` — createFaceSet
- `UNKNOWN x_faceset_control` — clazz
