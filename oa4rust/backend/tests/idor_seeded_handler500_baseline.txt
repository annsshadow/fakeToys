# 格式（TAB 分隔 5 字段）：
#   <METHOD> <route>\t<category:... | column:...>\towner:<责任人>\tdue:YYYY-MM-DD\tcond:<转绿条件>
#
# 规则：
#   - 修复一族后删对应行并下调 idor_matrix.rs 的 BASELINE_COUNT；
#   - 复现不出来的行必须立刻删；基线外的新 500 一律红；
#   - 每行必须填齐 owner / due / cond；缺项或 due 非法 → 门禁 FAIL；
#   - 当天日期（UTC+8）超过 due 而该行仍在基线 → 门禁 FAIL，
#     报出超期行、超期天数、原定转绿条件（机器执行，不靠人记）。
