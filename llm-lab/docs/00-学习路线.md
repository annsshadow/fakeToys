# 00 · 学习路线图

这是一份"从零开始、动手搞懂大模型训练"的课程。它不堆术语，而是让你**亲手把一个 GPT 从零造出来、训练起来、再优化**。全程配可运行的代码。

## 两条代码轨，互相印证

| 轨道 | 目录 | 依赖 | 定位 |
| --- | --- | --- | --- |
| **原理轨** | [`minigrad/`](../minigrad) | 只需 `numpy` | 纯手写自动微分 + GPT。**本仓库任何环境都能跑**。看懂每一行，就看懂了反向传播、注意力、训练循环的全部机制。 |
| **实战轨** | [`torchgpt/`](../torchgpt) | 需要 `torch` | 用 PyTorch 复刻 nanoGPT，演示工业界真正会用的东西：AMP 混合精度、梯度累积/裁剪、LoRA、DPO、困惑度评估。 |

两轨结构刻意保持一致（同样的 Pre-LN、因果注意力、4x MLP）。先在原理轨把"为什么"搞懂，再去实战轨看"工程上怎么做"。

## 建议学习顺序

1. **先跑起来**（5 分钟）
   ```bash
   cd llm-lab
   pip install -r requirements.txt
   python -m minigrad.train          # 训练一个字符级 GPT，看 loss 从 ~4.1 降到 ~0.3 并生成文本
   pytest tests/ -q                   # 32 项测试全绿（含逐算子数值梯度校验、KV cache 等价性）
   ```
2. **逐篇读讲义 + 读对应代码 + 做练习**（下表）
3. **想上 GPU 实战**：装 `torch`（`pip install -r requirements-torch.txt`），跑 `torchgpt`，`pytest` 里原本跳过的 7 个用例会自动激活。

## 学完你会掌握

- 反向传播到底在算什么（能手写一个 autograd 引擎并用数值梯度验证它）；
- 一个 GPT 的每个组件（嵌入、注意力、LayerNorm、残差、输出头）为何这样设计；
- 一个真实训练循环的全部环节（切批、求损失、优化器、学习率、验证、checkpoint）；
- 从单卡到多卡的规模化手段，以及微调、对齐、评估、推理加速的主流方法。

> 这是一个**学习项目**：模型只有几万到几十万参数，为的是"看得见、跑得动、改得起"。但它的每个机制，和真正的大模型是同构的。
