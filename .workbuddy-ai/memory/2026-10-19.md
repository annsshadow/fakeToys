## main 分支 pull 被"假脏"文件阻断（已解决）

- 现象：`git pull` 报 "local changes would be overwritten by merge"，涉及 `docs/audits/o2server-endpoint-inventory.json` 与 `o2server-parity-report.json`。
- 根因 1：本仓库 `core.autocrlf=true` 与用户全局 `false` 冲突 → 已将本地改为 `false` 对齐全局。
- 根因 2：HEAD blob 本身含 CRLF，而 `.gitattributes` 强制 `*.json text eol=lf` → 这类文件在 status 中**永久假脏**，stash/restore/skip-worktree 均无法清除（skip-worktree 还会阻断 merge 更新该路径）。
- 关键发现：这 2 个文件在 origin/main 的 461 个新提交中**已被删除**，本地残留的是旧审计产物。
- 解法：`git update-index --no-skip-worktree` 清标志 → `git rm -f` 删除残留文件 → `git merge --ff-only origin/main` 成功（454c9a2aa → 73009afaa）。噪音 stash 已验证零内容差异后 drop。
- 经验：遇 merge 阻断先跑 `git diff --stat --ignore-cr-at-eol` 判断是否纯换行符噪音；再确认目标路径在远端是否已被删除；结构性假脏的根治是 renormalize（`git add --renormalize`）提交一次。
